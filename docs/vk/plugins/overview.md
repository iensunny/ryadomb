# Плагины для сообществ

Плагины — это тип встраиваемых приложений на платформе VK Mini Apps, которые работают в контексте сообщества и расширяют его возможности. Они помогают автоматизировать работу администраторов сообщества, добавлять сценарии для подписчиков и подключать внешние сервисы.

Плагин настраивается под конкретное сообщество. Например, в плагине доставки отображается меню только того ресторана, для которого создано сообщество. При этом интерфейс плагина зависит от роли пользователя: администратор управляет меню и настройками доставки, подписчик выбирает позиции и оформляет заказ.

Плагины можно [монетизировать](#Монетизация), продвигать с помощью рекламы и размещать в специальном [каталоге](https://vk.ru/community_apps).

:::note
**Важно!** Размещение плагинов для сообществ в Одноклассниках через платформу VK Mini Apps недоступно. Приложения для групп в Одноклассниках создаются непосредственно на сайте ok.ru. Подробнее — в документации [API Одноклассники](https://apiok.ru/apps/groups).
:::

## Как работают плагины

У плагина два основных сценария использования:

* Администратор сообщества устанавливает плагин и настраивает его.
* Пользователь (подписчик сообщества) использует плагин в настроенной конфигурации.

При установке в сообщество и запуске пользователями плагин получает [параметры запуска](mini-apps/development/launch-params). По ним он определяет сообщество и роль текущего пользователя и показывает соответствующий интерфейс.

### Ограничения 

* Плагин работает корректно только в [контексте сообщества](#Контекст%20сообщества).
* Плагин можно разместить только в специальном [каталоге плагинов](#Каталог%20плагинов).
* В сообщество можно добавить не более 5 плагинов.

### Контекст сообщества

Плагин может открываться в двух режимах:

* В контексте сообщества — когда плагин запущен внутри сообщества и получает его идентификатор. Пользователь видит только те функции, которые доступны его роли в этом сообществе.
    
    > Если у пользователя нет доступа к закрытому сообществу, плагин по прямой ссылке откроется без контекста.

* Без контекста — при запуске из источников, которые не передают идентификатор сообщества. Пользователь увидит только экран с предложением установить плагин в сообщество.

Контекст нужен, чтобы плагин понимал, для какого сообщества он запущен, и показывал нужный интерфейс: настройки и инструменты для администраторов, пользовательский режим для подписчиков.

### Ролевая модель

Используйте роль пользователя в сообществе, чтобы управлять доступом к функциям. Например:

* Показывать настройки и расширенные функции только администраторам сообщества.
* Отображать разные сценарии в зависимости от роли пользователя.
* Показывать определённый контент только для подписчиков сообщества.

Подробнее о параметрах запуска и работе с VK Bridge — в разделе [Добавление в сообщество](plugins/how-to-add).

> Нельзя ограничивать доступ к функциям требованием подписаться на сообщество.

## Возможности платформы

### Виджеты

Плагин может отображаться на странице сообщества в виде виджета. Виджет подходит для сценариев, где важно отобразить часть данных из плагина прямо на странице сообщества: расписание, статусы, подборки, счётчики, карточки товаров и услуг.

Виджет обычно дополняет плагин: пользователь видит краткую информацию в сообществе и переходит в плагин за подробностями и действиями.

Примеры плагинов с виджетами:

* [Виджет в сообществе](https://vk.ru/app6244292)
* [Spycat — виджеты для продаж](https://vk.ru/app5686299)
* [Конструктор виджетов](https://vk.ru/widgets_constructor)
* [LiveWidget](https://vk.ru/app6232540)

Подробнее о настройке виджетов — в разделе [Виджеты сообществ](api/community-apps-widgets/getting-started).

### Сообщения сообщества

Сообщения сообщества помогают связаться с пользователем после того, как он закрыл плагин.

Отправлять сообщения можно как пользователям, так и администраторам сообществ. Например, плагин может отправлять сообщение каждому, кто заполнил форму, и уведомлять администратора сообщества о новой заявке.

К сообщению можно прикреплять изображения, документы, видео, аудио и точку на карте.

Подробнее — в разделе [Сообщения сообществ](api/community-messages/getting-started).

## Монетизация

Монетизируйте плагин так, чтобы условия были понятны администратору сообщества и соответствовали правилам платформы. Например, подписка на расширенные функции или тарифы для сообществ по количеству пользователей.

Рекомендации:

* Описывайте, что входит в бесплатный режим и что оплачивается.
* Оставляйте возможность установить плагин и ознакомиться с ним без оплаты.
* Продумайте поведение при окончании подписки.

Подробнее — в разделе [Монетизация мини-приложений на платформе VK Mini Apps](mini-apps/monetization/overview).

## Каталог плагинов

Каталог — это витрина плагинов для сообществ. Администратор может попасть в каталог плагинов из настроек сообщества или по прямой ссылке: [vk.ru/community_apps](https://vk.ru/community_apps). 

В каталог попадают только те плагины, которые прошли модерацию. При этом одобрение модераторами не гарантирует публикацию: часть проверенных плагинов в каталоге не отображается. 

* [Модерация плагинов](plugins/creating-and-settings#Модерация)
* [Каталог плагинов](plugins/catalog)

> Если плагин не прошёл модерацию, установить его можно только по прямой ссылке. Такой плагин будет отмечен как непроверенный.
