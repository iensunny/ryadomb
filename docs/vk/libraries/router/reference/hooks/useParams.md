# useParams

Используйте эту функцию, чтобы извлечь из URL значения [path-параметров](libraries/router/parameters#Path-параметры), которые были указаны в маршруте через двоеточие, например `/persik/:emotion` или `/user/:id/contacts/:rec2`.

## Пример

```TypeScript
import { useParams } from '@vkontake/vk-mini-apps-router';

// В маршруте путь задан как /user/:id/contacts/:rec2.
// Приложению передан путь /user/123/contacts/45.

// Получить значения параметров
const params = useParams<'id' | 'rec2'>(); // Вернёт { id: '123', rec2: '45' }

// Далее в коде к параметрам можно обращаться 
// как params.id и params.rec2
```

## Объявление

```TypeScript
export function useParams<T extends string = string>(id?: NavId): Params<T> | undefined
```

## Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `T`&#x0d;&#x0a;*необязательный* | `string` | Имя URL-параметра или параметров, если их несколько. В качестве разделителя используйте вертикальную черту ("\|"). Подробнее об указании имён параметров — [ниже](#Указание%20имён%20параметров). |
| `id`&#x0d;&#x0a;*необязательный* | `NavId` | Идентификатор маршрута, который дополнительно используется для правильной работы анимации переходов. Подробности — [ниже](#Использование%20параметра%20id). |

## Результат

Функция возвращает объект, содержащий свойство, совпадающее по имени с запрашиваемым параметром, и значение параметра. Например:

```TypeScript
// В маршруте путь задан как /user/:id.
// Приложению передан путь /user/123.
const params = useParams<'id'>(); // Вернёт { id: '123' }
```

Если параметр отсутствует или маршрут не был найден в списке маршрутов, [заданных при создании роутера](libraries/router/setting-routes), функция вернёт пустой массив (`[]`). Например:

```TypeScript
// В маршруте путь задан как /user/:id.
// Приложению передан путь /user/.
const params = useParams<'id'>(); // Вернёт []
```

## Особенности использования

### Указание имён параметров

Указывать имена URL-параметров в угловых скобках необязательно. Однако такое указание даёт среде разработки и компилятору информацию о параметрах. После указания параметров при дальнейшей работе среда будет показывать подсказки при вводе, а TypeScript-компилятор — выполнять необходимые проверки при анализе и сборке кода.

:::note
**Важно!** Указывайте либо все имена параметров, либо ни одно из них. Среда и компилятор будут работать только с теми параметрами, имена которых переданы в угловых скобках. Если вы пропустите имя параметра, но сошлётесь на него в коде, компилятор сообщит об ошибке.
:::

```TypeScript
// В маршруте путь задан как /user/:id/contacts/:rec2.
// Приложению передан путь /user/123/contacts/45.

// Если получить значение параметров так, то...
const params = useParams<'id' | 'rec2'>(); // Вернёт { id: '123', rec2: '45' }
params.id = ...   // OK
params.rec2 = ... // OK

// Если получить значение параметров так, то...
const params = useParams<'id'>(); // Вернёт { id: '123' }
params.id = ...   // OK
params.rec2 = ... // Ошибка!
```

### Использование параметра id

Укажите параметр `id`, чтобы обеспечить правильную работу анимации перехода между панелями или при закрытии модальных окон. Библиотека извлечёт значения параметров, которые соответствовали предыдущему экрану и будет использовать этот экран для отрисовки анимации.

Параметр указывается как объект с одним из следующих свойств: `panel`, `modal` или `tab`. Например:

```TypeScript
// Путь /persik/:emotion.
// Указываем, что нам нужны параметры для панели 'persik'
const params = useParams<'emotion'>({ panel: 'persik' }); // params = { emotion: 'fish' }
```

Предположим, что выполняется переход с `/persik/fish` на `/`. Роутер будет отображать анимацию при переходе. Новый маршрут не использует параметры, а старый использует параметр `{ emotion: 'fish' }`. Так как мы указали `id` при вызове `useParams()`, роутер выберет параметры из предыдущего маршрута и сохранит вид панели при анимации.

:::note
**Важно!** Передавайте в параметр `id` объект только с одним свойством: `panel`, `modal` или `tab`. Использование нескольких свойств приведёт к ошибке.
:::

```TypeScript
const params = useParams<'emotion'>({ panel: 'persik' }); // OK
const params = useParams<'emotion'>({ panel: 'persik', tab: `tab1` }); // Ошибка!
```

### Область действия

Вызовы функции `useParams()` должны проходить в рамках компонента [`RouterProvider`](libraries/router/reference/components/RouterProvider).
