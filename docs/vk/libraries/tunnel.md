# VK Tunnel

> Источник: [https://dev.vk.ru/ru/libraries/tunnel](https://dev.vk.ru/ru/libraries/tunnel)
:::note
**Из-за технических работ с 2 октября 2025 года VK Tunnel недоступен**

При подключении сервис вернёт ошибку. Для отладки и демонстрации ваших веб-приложений рекомендуем временно использовать сторонние решения.
:::

**VK Tunnel** — npm-пакет, с помощью которого вы можете сделать локальный веб-сервер доступным в интернете. Это нужно при отладке и демонстрации веб-приложений.

Файлы создаваемого веб-приложения находятся на компьютере разработчика. Чтобы проверить взаимодействие приложения с внешними сервисами, например с платформой ВКонтакте, или продемонстрировать работу приложения, необходимо сделать локальный веб-сервер доступным в интернете. VK Tunnel помогает выполнить эту задачу.

VK Tunnel запускается на компьютере разработчика и создаёт специальное соединение (туннель), с помощью которого локальный веб-сервер становится доступным в интернете. Во время работы туннеля все внешние запросы к серверу и ответы на них проходят через туннель.  

![alt=Работа VK Tunnel;title=Работа VK Tunnel](81f54f45195f36d5d51ef758285665fb48b9f653d3ab90abb6c26266 "6405880795206800711")

Альтернативой использованию VK Tunnel является загрузка файлов веб-приложения на какой-нибудь публично доступный сервер или предоставление доступа к локальному серверу другим способом.

VK Tunnel предоставляет доступ к локальному серверу по протоколам HTTP, HTTPS, WebSocket и WebSocket Secure.

## Исходный код

GitHub: https://github.com/vkcom/vk-tunnel-client

## Установка

```yarn
yarn global add @vkontakte/vk-tunnel
```

```npm
npm install @vkontakte/vk-tunnel -g
```

Мы рекомендуем указать `global` для yarn или `-g` для npm, чтобы устанавливаемый пакет был доступен всем проектам на вашем компьютере.

## Запуск и использование

### 1. Укажите настройки

Перед запуском VK Tunnel вам может потребоваться создать переменные окружения или конфигурационный файл с настройками утилиты. Настройки можно указать и при запуске VK Tunnel из командной строки. Подробнее о настройках — [ниже](#Настройки).

### 2. Запустите локальный веб-сервер

Для старта VK Tunnel необходимо, чтобы ваш веб-сервер был запущен. Если он ещё не работает, запустите его.  

### 3. Запустите VK Tunnel

#### В приложениях, созданных из шаблона

В мини-приложениях, созданных с помощью [пакета `create-vk-mini-app`](mini-apps/getting-started/create-vk-mini-app), VK Tunnel подключён и сконфигурирован, а в файл `package.json` добавлен скрипт для его запуска.

Чтобы запустить VK Tunnel в таких приложениях, выполните следующую команду:

```Командная&nbsp;строка
npm run tunnel
```

#### В произвольном приложении

Чтобы запустить VK Tunnel для любого серверного приложения, в командной строке укажите `vk-tunnel` и параметры запуска, например так:

```Командная&nbsp;строка
vk-tunnel --insecure=1 --http-protocol=http --ws-protocol=ws --host=localhost --port=5173 --timeout=5000
```

### 4. Получите адрес для локального сервера

1. После запуска VK Tunnel покажет URL вида `https://oauth.vk.ru/code_auth?stage=check&code=2f...cba`. Откройте этот URL в браузере, чтобы пройти авторизацию.

1. Вернитесь в окно командной строки и подтвердите действие: введите **Y/y** или нажмите **Enter**.

    VK Tunnel создаст специальное соединение и отобразит HTTP- и WebSocket-адреса, которые вы можете использовать для доступа к локальному серверу из интернета.

    ![alt=Сгенерированные адреса;title=Сгенерированные адреса](331b58e0a55d10041719c949e2b86692ae04b41f15ec64304bec479b "1770715061676415273")

    Скопируйте HTTP-адрес и укажите его в настройках вашего мини-приложения или игры.

## Настройки

Указать настройки утилиты VK Tunnel вы можете с помощью:

* Переменных окружения («env» в таблице ниже).

* Параметров командной строки («>…» в таблице ниже).

* Значений в конфигурационном файле `vk-tunnel-config.json` («json» в таблице ниже).

### Список настроек

### Дополнительные настройки в `vk-tunnel-config.json`

При отладке мини-приложения или игры было бы удобно, чтобы сгенерированный адрес автоматически подставлялся в настройки мини-приложения или игры. VK Tunnel предоставляет такую возможность. Для этого укажите следующие настройки в файле `vk-tunnel-config.json`:

| Настройка | Описание |
| --- |  --- |
| `app_id` | Идентификатор разрабатываемого мини-приложения или игры ВКонтакте. Вы можете найти его в настройках мини-приложения или игры. |
| `endpoints` | Массив, в котором вы указываете список платформ, а также [группы тестировщиков](mini-apps/settings/test-groups), для которых будет использоваться сгенерированный адрес. ВКонтакте автоматически установит этот адрес в [настройках приложения](mini-apps/settings/general/placement) и [тестовых групп](mini-apps/settings/test-groups).&#x0d;&#x0a;&#x0d;&#x0a;Первые элементы массива — одна или несколько строк, которые указывают платформы:&#x0d;&#x0a; &nbsp;&nbsp; &bull; `mobile` — мобильное приложение ВКонтакте.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `mvk` — мобильная версия сайта.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `web` — десктопная версия сайта.&#x0d;&#x0a;&#x0d;&#x0a;Далее вы можете указать группы тестировщиков в формате `testing_group:название-группы`. Пример использования в JSON-файле — [ниже](#Пример%20JSON-файла).&#x0d;&#x0a;&#x0d;&#x0a;Тестовые группы используются только для мини-приложений. Игры их не поддерживают.&#x0d;&#x0a;&#x0d;&#x0a;Указать можно не более трёх групп. Если указать больше, адрес не будет заменён ни для одной из групп. |

### Пример JSON-файла

```JSON
{
    "app_id": "123456",
    "endpoints": [
        "mobile",
        "mvk",
        "web",
        "testing_group:Тестовая группа 1",
        "testing_group:Тестовая группа 2"
    ],
    "port": "3000",
    "http-protocol": "https",
    "insecure": "0"
}
```

### Приоритет настроек

Параметры командной строки имеют наивысший приоритет. Если они не указаны, VK Tunnel использует значения из конфигурационного файла `vk-tunnel-config.json`. Если какое-то значение отсутствует в этом файле, используется переменная окружения. Если же и переменная не определена, то используется значение параметра по умолчанию.

## Возможные ошибки при запуске

#### `Error: connect ECONNREFUSED 127.0.0.1:10888`.

Убедитесь, что вы запустили свой локальный веб-сервер.

#### `Error: Пользователь не является создателем приложения`

Убедитесь, что вас добавили в администраторы мини-приложения или игры:
* [Администраторы (настройки мини-приложений)](mini-apps/settings/managers)
* [Администраторы (настройки игр)](games/settings/managers)

Если вы есть в списке администраторов приложения:

1. Удалите файл, содержащий токен утилиты:

    - На Windows:    
        `C:\Users\<папка-пользователя>\.config\configstore\@vkontakte\vk-tunnel.json`

    - На macOS и Linux:    
        `~/.config/configstore/@vkontakte/vk-tunnel.json`

1. Запустите VK Tunnel заново.
