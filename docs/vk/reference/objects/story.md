# История

> Источник: [https://dev.vk.ru/ru/reference/objects/story](https://dev.vk.ru/ru/reference/objects/story)
Объект, описывающий историю, содержит следующие поля:

## `id`
`integer`
Идентификатор истории. 

## `owner_id`
`integer`
Идентификатор владельца истории.

## `date`
`integer`
Дата добавления в Unixtime.

## `expires_at`
`integer`
Дата в Unixtime, когда история истечёт.

## `is_expired`
`boolean`
`true`, если срок хранения истории истёк. 
В этом случае объект истории содержит только поля `id`, `owner_id`, `date`, `expires_at`, `is_expired`.

## `is_deleted`
`boolean`
`true`, если история удалена или не существует.
В этом случае объект истории содержит только поля `id`, `owner_id`, `is_deleted`.

## `can_see`
`integer`
Информация о том, может ли пользователь просмотреть историю (`0` — нет, `1` — да). 
Если `can_see` = `0`, объект истории содержит только поля `id`, `owner_id`, `date`, `expires_at`, `can_see`, `type`.

## `seen`
`integer`
`1`, если история просмотрена текущим пользователем.

## `type`
`string`
Тип истории. Возможные значения:
* `photo` — фотография;
* `video` — видеозапись.

## `photo`
`object`
Фотография из истории, если тип истории — `photo`. Подробнее о полях объекта `photo` — в разделе [Фотография](reference/objects/photo).

## `video`
`object`
Видеозапись из истории, если тип истории — `video`. Подробнее о полях объекта `video` — в разделе [Видеозапись](reference/objects/video).

## `link`
`object`
Ссылка для перехода из истории. Объект, который содержит поля:
* `text` (`string`) — текст ссылки;
* `url` (`string`) — URL для перехода.

## `parent_story_owner_id`
`integer`
Идентификатор пользователя, загрузившего историю, ответом на которую является текущая.

## `parent_story_id`
`integer`
Идентификатор истории, ответом на которую является текущая.

## `parent_story`
`object`
Объект родительской истории.

## `replies`
`object`
Информация об ответах на текущую историю. Объект, который содержит поля:
* `count` (`integer`) — число ответов;
* `new` (`integer`) — число новых ответов. Возвращается только для историй текущего пользователя.
Получить истории-ответы можно методом [`stories.getReplies`](method/stories.getReplies).

## `can_reply`
`integer`
Информация о том, может ли пользователь ответить на историю (`0` — нет, `1` — да).

## `can_share`
`integer`
Информация о том, может ли пользователь расшарить историю (`0` — нет, `1` — да).

## `can_comment`
`integer`
Информация о том, может ли пользователь комментировать историю (`0` — нет, `1` — да).

## `clickable_stickers`
`object`
Объект [кликабельного стикера](reference/objects/clickable-sticker).

## `views`
`integer`
Число просмотров.

## `access_key`
`string`
Ключ доступа для приватного объекта.
