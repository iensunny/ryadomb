# Данные статистики

> Источник: [https://dev.vk.ru/ru/reference/objects/stats-format](https://dev.vk.ru/ru/reference/objects/stats-format)
## `activity`
`object`
Данные об активности. Объект, который содержит поля:
* `comments` (`integer`) — количество комментариев;
* `copies` (`integer`) — количество репостов;
* `hidden` (`integer`) — количество пользователей, скрывших записи из новостей;
* `likes` (`integer`) — количество отметок «нравится»;
* `subscribed` (`integer`) — количество подписавшихся пользователей на сообщество;
* `unsubscribed` (`integer`) — количество отписавшихся пользователей на сообщество.

## `period_from`
`integer`
Период начала отсчёта в формате Unixtime.

## `period_to`
`integer`
Период окончания отсчёта в формате Unixtime.

## `visitors`
`object`
Данные о посетителях и просмотрах. Объект, который содержит поля:
* `views` (`integer`) — число просмотров.
* `visitors` (`integer`) — число посетителей;

## `reach`
`object`
Данные об охвате. Объект, который содержит поля:
* `reach` (`integer`) — полный охват;
* `reach_subscribers` (`integer`) — охват подписчиков;
* `mobile_reach` (`integer`) — охват с мобильных устройств;
* `sex` (`array`) — статистика по полу. Массив объектов, каждый из которых содержит поля:
   * `value` (`string`) — пол (`m` — мужской, `f` — женский);
   * `count` (`integer`) — число посетителей.
* `age` (`array`) —  статистика по возрасту. Массив объектов, каждый из которых содержит поля:
   * `value` (`string`) — возрастной интервал (например, «12-18»). Возможные значения: 12-18, 18-21, 21-24, 24-27, 27-30, 30-35, 35-45, 45-100.
   * `count` (`integer`) — число посетителей;
* `sex_age` (`array`) — статистика по полу и возрасту. Массив объектов, каждый из которых содержит поля:
   * `value` (`string`) — пол и возрастной интервал (например, `f;12-18`);
   * `count` (`integer`) — число посетителей.
* `cities` (`array`) — статистика по городам. Массив объектов, каждый из которых содержит поля:
   * `name`  (`string`) — название города;
   * `value` (`integer`,`string`) —  идентификатор города или «other» для раздела «прочие города»;
   * `count` (`integer`) — число посетителей.
* `countries` (`array`) — статистика по странам. Массив объектов, каждый из которых содержит поля:
   * `name`  (`string`) — название страны;
   * `code` (`string`) — двухбуквенный код страны (например, `RU`);
   * `country_id` (`integer`) —  идентификатор страны;
   * `count` (`integer`) — число посетителей.
