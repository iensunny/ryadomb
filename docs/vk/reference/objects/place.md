# Место

> Источник: [https://dev.vk.ru/ru/reference/objects/place](https://dev.vk.ru/ru/reference/objects/place)
Объект, описывающий место, содержит следующие поля:

 ## `id`
`integer`
Идентификатор места. 

## `title`
`string`
Название места. 

## `latitude`
`integer`
Географическая широта, заданная в градусах (от -90 до 90). 

## `longitude`
`integer`
Географическая широта, заданная в градусах (от -90 до 90). 

## `created`
`integer`
Дата создания места в `Unixtime`. 

## `icon`
`string`
Иконка места, URL изображения. 

## `checkins`
`integer`
Число отметок в этом месте. 

## `updated`
`integer`
Дата обновления места в `Unixtime`. 

## `type`
`integer`
Тип места. 



## `city`
`integer`
Идентификатор города. 

## `address`
`string`
Адрес места.
