# Комментарий в обсуждении

> Источник: [https://dev.vk.ru/ru/reference/objects/comment-topic](https://dev.vk.ru/ru/reference/objects/comment-topic)
Объект, описывающий комментарий из обсуждения в сообществе, содержит следующие поля:

## `id`
`integer`
Идентификатор комментария.

## `from_id`
`integer`
Идентификатор автора комментария.

## `date`
`integer`
Дата создания (в формате Unixtime).

## `text`
`string`
Текст комментария.

## `attachments`
`array`
Медиавложения комментария (фотографии, ссылки и т.п.). Описание массива `attachments` находится [на отдельной странице](reference/objects/video).

## `likes`
`object`
Информация об отметках «Мне нравится» текущего комментария (если был задан параметр `need_likes`), объект с полями:
* `count` (`integer`) — число пользователей, которым понравился комментарий,
* `user_likes` (`integer`) — наличие отметки «Мне нравится» от текущего пользователя (`1` — есть, `0` — нет),
* `can_like` (`integer`) — информация о том, может ли текущий пользователь поставить отметку «Мне нравится» (`1` — может, `0` — не может).
