# Звонок

> Источник: [https://dev.vk.ru/ru/reference/objects/call](https://dev.vk.ru/ru/reference/objects/call)
Для версии API, начиная с 5.80.

Объект, описывающий звонок, содержит следующие поля:

### `duration`
`integer`
Продолжительность звонка в секундах. 

### `initiator_id`
`integer`
**Обязательное поле.** Идентификатор инициатора звонка. 

### `receiver_id`
`integer`
**Обязательное поле**. Идентификатор получателя звонка.

### `state`
`string`
Состояние, в котором завершился звонок.
Возможные значения:
* `canceled_by_initiator` — завершён инициатором на этапе дозвона.
* `canceled_by_receiver` — завершён получателем на этапе дозвона.
* `reached` — состоялся и завершён любой стороной.

### `time`
`integer`
**Обязательное поле**. Время начала звонка в формате [Unix Timestamp](https://www.unixtimestamp.com/).

### `video`
`boolean`
Инициирован как видеозвонок.

### `participants`
Для версии API, начиная с 5.130.

`object`
Участники звонка.

Объект содержит поля:
* `list` (`array`) — массив идентификаторов участников звонка. Формат: `int64`.
* `count` (`integer`) — количество участников.
