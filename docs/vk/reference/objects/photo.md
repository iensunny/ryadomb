# Фотография

> Источник: [https://dev.vk.ru/ru/reference/objects/photo](https://dev.vk.ru/ru/reference/objects/photo)
Объект, описывающий фотографию, содержит следующие поля:

## `id`&nbsp;
`integer`
Идентификатор фотографии. 

## `album_id`&nbsp;
`integer`
Идентификатор альбома, в котором находится фотография. 

## `owner_id`&nbsp;
`integer`
Идентификатор владельца фотографии. 

## `user_id`&nbsp;
`integer`
Идентификатор пользователя, загрузившего фото (если фотография размещена в сообществе). Для фотографий, размещенных от имени сообщества, `user_id` = `100`.

## `text`&nbsp;
`string`
Текст описания фотографии. 

## `date`&nbsp;
`integer`
Дата добавления в формате Unixtime. 

## `thumb_hash`&nbsp;
`string`
Компактное представление заполнителя изображения. Можно использовать для показа во время загрузки реального изображения.

## `has_tags`&nbsp;
`boolean`
Информация о том, имеет ли изображение теги.

## `sizes`&nbsp;
`array`
Массив с копиями изображения в разных размерах. Каждый объект массива содержит следующие поля:
* `type` (`string`) — тип копии. См. [Формат описания размеров фотографии](reference/objects/photo-sizes).
* `url` (`string`) — URL копии.
* `width` (`integer`) — высота в px.
* `height` (`integer`) — ширина в px.

## `width`*&nbsp;
`integer`
Ширина оригинала фотографии в пикселях. 

## `height`*&nbsp;
`integer`
Высота оригинала фотографии в пикселях.

`array`
Массив с копиями изображения в разных размерах. Описание объекта находится [на отдельной странице](reference/objects/photo-sizes). Поле возвращается только при передаче параметра `photo_sizes` = `1` в запросе. Если параметр не передан, вместо поля `sizes` возвращаются поля, описанные ниже.

### `photo_75`
`string`
URL копии фотографии с максимальным размером `75x75px`. 

### `photo_130`
`string`
URL копии фотографии с максимальным размером `130x130px`. 

### `photo_604`
`string`
URL копии фотографии с максимальным размером `604x604px`. 

### `photo_807`
`string`
URL копии фотографии с максимальным размером `807x807px`. 

### `photo_1280`
`string`
URL копии фотографии с максимальным размером `1280x1024px`. 

### `photo_2560`
`string`
URL копии фотографии с максимальным размером `2560x2048px`. 

### `width`*
`integer`
Ширина оригинала фотографии в пикселях. 

### `height`*
`integer`
Высота оригинала фотографии в пикселях. 

\* — Значения могут быть недоступны для фотографий, загруженных на сайт до 2012 года.
