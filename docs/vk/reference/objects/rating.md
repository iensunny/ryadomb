# Рейтинг продукта

> Источник: [https://dev.vk.ru/ru/reference/objects/rating](https://dev.vk.ru/ru/reference/objects/rating)
Объект `rating`, описывающий информацию о рейтинге продукта, содержит следующие поля:

## `stars`
Количество звезд у продукта.

## `reviews_count`
Количество отзывов о продукте.
