# Граффити

> Источник: [https://dev.vk.ru/ru/reference/objects/graffiti](https://dev.vk.ru/ru/reference/objects/graffiti)
Объект, описывающий граффити, содержит следующие поля:

## `id`
`integer`
Идентификатор граффити.

## `owner_id`
`integer`
Идентификатор пользователя, загрузившего графити.

## `url`
`string`
Адрес граффити, по которому его можно загрузить.

## `width`
`integer`
Ширина изображения в px.

## `height`
`integer`
Высота изображения в px.
