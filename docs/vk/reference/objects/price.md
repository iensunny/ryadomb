# Цена

> Источник: [https://dev.vk.ru/ru/reference/objects/price](https://dev.vk.ru/ru/reference/objects/price)
Объект `price`, описывающий цену, содержит следующие поля:

## `amount`
Целочисленное значение цены, умноженное на 100.

## `currency`
Объект `currency`.

## `text`
Строка с локализованной ценой и валютой.

## Объект `currency`

Объект `currency`, описывающий информацию о валюте, содержит следующие поля:

* `id` – идентификатор валюты.

* `name` – буквенное обозначение валюты.
