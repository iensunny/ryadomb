# Обсуждение

> Источник: [https://dev.vk.ru/ru/reference/objects/topic](https://dev.vk.ru/ru/reference/objects/topic)
Объект, описывающий обсуждение в сообществе, содержит следующие поля:

## `id`
`integer`
Идентификатор обсуждения. 

## `title`
`string`
Название обсуждения. 

## `created`
`integer`
Дата создания обсуждения в Unixtime.

## `created_by`
`integer`
Идентификатор создателя обсуждения.

## `updated`
`integer`
Дата последнего обновления обсуждения в Unixtime.

## `updated_by`
`integer`
Идентификатор автора последнего комментария в обсуждении.

## `is_closed`
`integer`
Информация о том, закрыто ли обсуждение. Возможные значения:
* `0` — не закрыто;
* `1` — закрыто.

## `is_fixed`
`integer`
Информация о том, закреплено ли обсуждение наверху списка. Возможные значения:
* `0` — не закреплено;
* `1` — закреплено.

## `comments`
`integer`
Число комментариев в обсуждении.

## `first_comment`
`string`
(для `preview` = `1`). Текст первого комментария в обсуждении.

## `last_comment`
`string`
(для `preview` = `2`). Текст последнего комментария в обсуждении.
