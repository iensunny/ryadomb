# Виджеты приложений сообществ

> Источник: [https://dev.vk.ru/ru/reference/objects/app-widget](https://dev.vk.ru/ru/reference/objects/app-widget)
Объект виджета содержит набор полей в зависимости от типа, который задаётся параметром в методе [`appWidgets.update`](method/appWidgets.update). Во втором параметре этого метода должен содержаться код для отображения виджета с нужными полями.

> Ограничение длины полей указано для текста в кодировке UTF-16. Некоторые объекты, например эмодзи, могут занимать несколько символов в UTF-16.



## Text

Выводит текст.

<!--/exclusions/_images/api/widgets/text.png -->

![](f33c2e1d4a8d49b4eb618573da61e5fc53bbe58a85666e4c1357ed70 "-7725870539193097140")

#### Пример объекта виджета в запросе

```JSON
{
      "title": "Цитата дня",
      "title_url": "https://link",
      "title_counter": 42,
      "more": "Читать все цитаты",
      "more_url": "https://link2",
      "text": "«Нам нужно гордиться»",
      "descr": "Дэвид Кэмерон о победе сторонников выхода страны\n из Евросоюза на референдуме",
}
```

### Поля объекта виджета в запросе

### `title`
`string`, обязательный
Заголовок виджета, до 100 символов.

### `title_url`
`string`
URL ссылки для заголовка.

### `title_counter`
`integer`
Счётчик для заголовка.

### `text`
`string`
Текст для отображения в виджете, до 200 символов.

### `descr`
`string`
Описание для отображения в виджете, до 200 символов.

### `more`
`string`
Текст в футере, до 100 символов.

### `more_url`
`object`
URL для футера. Обязателен, если указан `more`.

## List

Выводит список объектов с описанием и кнопками для действий. Список может содержать до 6 объектов, если не указан сопроводительный текст (поле `text`), и до 3 объектов, если текст указан.

<!--/exclusions/_images/api/widgets/list.png -->
![](5f5e8fc63364b653141dd44323e378f1b6edec1708b19633ebe37994 "-2882456706205206968")

#### Пример объекта виджета в запросе

```JSON
{
      "title": "Рестораны",
      "rows": [{
          "title": "Корюшка",
          "title_url": "https://link",
          "button": "Забронировать стол",
          "button_url": "https://link2",
          "icon_id": "3242346_8234324",
          "address": "Петропавловская крепость, д. 3",
          "time": "Каждый день с 12:00 до 1:00",
          "text": "Если бы Петр I решил построить ресторан, это была бы «Корюшка» — заведение с видом на стрелку Васильевского острова, прямо у Петропавловской вблизи шумных вод Невы."
        }, {
          "title": "Food Park",
          "title_url": "https://link3",
          "button": "Забронировать стол",
          "button_url": "https://link4",
          "icon_id": "3242346_23432432",
          "address": "Александровский парк, д. 4/3, лит. А",
          "time": "Каждый день с 12:00 до 1:00",
          "text": "Давно ли вы красиво, с чувством и толком ели в парке? Главное украшение Александровского парка — Food Park приглашает на еду со всех концов света на четвертый этаж ТРЦ «Великан»."
    }]
}
```

### Поля объекта виджета в запросе

### `title`
`string`, обязательный
Заголовок виджета, до 100 символов.

### `title_url`
`string`
URL ссылки для заголовка.

### `title_counter`
`integer`
Счётчик для заголовка.

### `rows`
`array`
Массив объектов — элементов списка. Каждый объект массива содержит следующие поля:
* `title` (`string`, обязательный) — заголовок элемента, без переносов строки;
* `title_url` (`string`) — ссылка для заголовка;
* `button` (`string`) — текст кнопки, до 50 символов. Должен быть указан у всех элементов или не указан ни у одного из них.
* `button_url` (`string`) — ссылка для кнопки. Обязательна, если указан `button`.
* `icon_id` (`string`) — идентификатор картинки 50x50, которая показывается слева от элемента. Должна быть указана у всех элементов или не указана ни у одного из них.
* `descr` (`string`) — краткое описание без переносов строки, до 100 символов. Выводится под заголовком элемента.
* `address` (`string`) — адрес, до 100 символов. Снабжается стандартной иконкой геопозиции.
* `time` (`string`) — время работы, до 100 символов. Снабжается стандартной иконкой часов.
* `text` (`string`) — подробное описание, допустимы переносы строк, до 300 символов.

### `more`
`string`
Текст в футере, до 100 символов.

### `more_url`
`object`
URL для футера. Обязателен, если указан `more`.

## Table

Выводит таблицу с данными. В первом столбце текст и ссылки могут сопровождаться иконками. Таблица может содержать от 1 до 6 столбцов и от 1 до 11 строк (включая строку с названиями колонок).

<!--/exclusions/_images/api/widgets/table.png -->

![](df3f74f5dc64257834e0f8fe58755229094f74710020d9c6161350ba "-4319460827666034964")

#### Пример объекта виджета в запросе

```JSON
{
    "title": "My Table",
    "title_url": "https://link",
    "title_counter": 31,
    "more": "Посмотреть все результаты",
    "more_url": "https://link2",
    "head": [{
        "text": "Название первой колонки"
    }, {
        "text": "Название второй колонки",
        "align": "center"
    }],
    "body": [
        [{
            "text": "Это первая ячейка первой строки",
            "icon_id": "3484735_23434324"
        },
        {
            "text": "Это вторая ячейка первой строки",
            "url": "https://vk.com/wall-12345_542321"
        }],
        [{
            "text": "Это первая ячейка второй строки",
            "icon_id": "3484735_23434324"
        },
        {
            "text": "Это вторая ячейка второй строки",
            "url": "https://vk.com/wall-12345_54321"
        }
        ]
    ]
}
```

### Поля объекта виджета в запросе

### `title`
`string`, обязательный
Название таблицы, до 100 символов.

### `title_url`
`object`
URL для названия.

### `title_counter`
`integer`
Счетчик в заголовке.

### `head`
`array`
Заголовок таблицы. Массив объектов, каждый из которых содержит поля:
* `text` (`string`) — заголовок колонки, до 50 символов;
* `align` (`string`) — выравнивание текста во всей колонке. Может принимать значения `right`, `center`, `left`.

### `body`
`array`
Тело таблицы. Массив объектов, описывающих строки таблицы. Строка является массивом объектов, описывающих ячейки. Каждый объект, описывающий ячейку, содержит следующие поля:
* `text` (`string`) — текст ячейки, до 100 символов;
* `url` (`string`) — URL ссылки;
* `icon_id` (`array`) — строковый идентификатор изображения-иконки размером 24x24px. Только для первой ячейки в строке.

### `more`
`string`
Текст в футере, до 100 символов.

### `more_url`
`object`
URL для футера. Обязателен, если указан `more`.

### `title`
`string`, обязательный
Заголовок виджета, до 100 символов.

### `title_url`
`string`
URL ссылки для заголовка.

### `title_counter`
`integer`
Счётчик для заголовка.

* `icon_id` (`string`) — идентификатор картинки для плитки 160x160 или 160x240 (размер должен быть одинаковым для всех элементов).

`string`
Текст в футере, до 100 символов.

### `more_url`
`object`
URL для футера. Обязателен, если указан `more`.

## Match

Выводит текущий результат спортивного матча. 

<!--/exclusions/_images/api/widgets/match.png -->

![](3f290acc673d40f2de457895cbd52a68c7c08f023ad1e39cc273f170 "-9094185484248718579")

#### Пример объекта виджета в запросе

```JSON
{
    "title": "My Match",
    "title_url": "https://vk.com/app123456#source=from_title",
    "more": "Перейти к трансляции",
    "more_url": "https://vk.com/app123456#source=from_footer",
    "match": {
        "state": "Идёт первый тайм",
        "team_a": {
            "name": "Зенит",
            "descr": "Санкт-Петербург",
            "icon_id": "3484735_23434324"
        },
        "team_b": {
            "name": "Спартак",
            "descr": "Москва",
            "icon_id": "3484735_23434324"
        },
        "score": {
            "team_a": 2,
            "team_b": 0
        },
        "events": {
            "team_a": [
                {
                    "event": "Иванов",
                    "minute": "3"
                },
                {
                    "event": "Петров",
                    "minute": "5"
                }
            ],
            "team_b": [
                {
                    "event": "Сидоров",
                    "minute": "2"
                }
            ]
        }
    }
}
```

### Поля объекта виджета в запросе

### `title`
`string`, обязательный
Название виджета, до 100 символов.

### `title_url`
`string`
URL ссылки для заголовка.

### `title_counter`
`integer`
Счётчик для заголовка.

### `match`
`object`
Информация о матче. Объект, который содержит следующие поля:
* `state` (`string`) — состояние матча (выводится под счётом), до 50 символов.
* `team_a` (`object`) — информация о первой команде. Объект, который содержит следующие поля:
   * `name` (`string`) — название команды, до 50 символов;
   * `descr` (`string`)— описание команды (например, город или страна), до 50 символов;
   * `icon_id` (`array`) — строковый идентификатор изображения-иконки 50x50px. Флаг или логотип команды, указывается для каждой или не указывается для обеих команд.
* `team_b` (`object`) — информация о второй команде, поля идентичны `team_a`.
* `score` (`object`) — счёт матча. Содержит следующие поля:
   * `team_a` (`integer`) — счёт первой команды (`-999 - 999`);
   * `team_b` (`integer`) — счёт  второй команды (`-999 - 999`);
* `events` (`object`) — ключевые события. Содержит следующие поля:
   * `team_a` (`array`) — события первой команды. Массив объектов (максимум 6), каждый из которых содержит поля:
      * `event` (`string`) — фамилия игрока, до 50 символов.
      * `minute` (`integer`)  — номер минуты.
   * `team_b` (`array`) — события второй команды, поля аналогичны.

### `more`
`string`
Текст в футере, до 100 символов.

### `more_url`
`object`
URL для футера. Обязателен, если указан `more`.

`object`
Период сбора. Объект, который содержит поля: 
* `start` (`integer`) — дата начала сбора в Unixtime (не ранее, чем год назад от текущей); 
* `end` (`integer`) — дата окончания сбора в Unixtime (не позднее, чем через 10 лет от текущей).

### `goal`
`integer`
Сумма сбора. Максимальное значение: 99999999.

### `funded`
`integer`
Собранная сумма. Максимальное значение: 99999999.

### `backers`
`integer`
Число пожертвовавших. Максимальное значение: 99999999.

### `currency`
`string`
Валюта сбора. Возможные значения: `RUB`, `USD`, `UAH`, `BYR`, `EUR`, `MDL`, `AZN`, `GEL`, `AMD`, `ILS`, `GBP`, `TMT`, `BYN`, `KZS`, `KZT`.

### `more`
`string`
Текст футера.

### `more_url`
`string`
URL для футера.
