# Прикреплённая ссылка

> Источник: [https://dev.vk.ru/ru/reference/objects/link](https://dev.vk.ru/ru/reference/objects/link)
Объект, описывающий прикреплённую ссылку в сообщении, комментарии или записи на стене, содержит следующие поля:

## `url`
`string`
URL ссылки.

## `title`
`string`
Заголовок ссылки.

## `caption`
`string`
Подпись ссылки (если имеется).

## `description`
`string`
Описание ссылки.

## `photo`
`object`
Изображение превью, объект [фотографии](reference/objects/photo) (если имеется).

## `product`
`object`
Информация о продукте (если имеется). Поле возвращается для ссылок на магазины, например, AliExpress. Объект с единственным полем `price` (`object`), которое описано [на отдельной странице](reference/objects).

## `button`
`object`
Информация о кнопке для перехода (если имеется). Объект описан [на отдельной странице](reference/objects).

## `preview_page`
`string`
Идентификатор вики-страницы с контентом для предпросмотра содержимого страницы. Возвращается в формате `"owner_id_page_id"`.

## `preview_url`
`string`
URL страницы с контентом для предпросмотра содержимого страницы.
