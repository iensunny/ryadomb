# Приложение из магазина

> Источник: [https://dev.vk.ru/ru/reference/objects/application](https://dev.vk.ru/ru/reference/objects/application)
Объект `application`, описывающий информацию о приложении из магазина, содержит следующие поля:

## `store`
Объект `store`.

## `app_id`
Идентификатор приложения в магазине.

## Объект `store`

Объект `store`, описывающий информацию о магазине, содержит следующие поля:

* `id` – идентификатор магазина.

* `name` – название магазина.
