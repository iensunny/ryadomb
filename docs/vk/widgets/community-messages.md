## Как работает виджет

Виджет добавляет на веб-страницу кнопку. Кнопка открывает всплывающее окно, в котором пользователь может задать вопросы компании.

![alt=Пример работы виджета;title=Пример работы виджета](ef3dc3875c19f809120dc0af83a3f93173bdaa7df169058a459ac0fb "-2041031736181108686")

Пользователям не надо дополнительно регистрироваться или сообщать свои данные: в начале разговора достаточно авторизоваться при помощи своего аккаунта ВКонтакте.

Общение идёт от лица сообщества вашей компании. Вы можете ответить клиенту, даже если он покинет сайт — сообщения будут отправлены от имени сообщества, и клиент увидит их в чате ВКонтакте. Если администратор длительное время не отвечает на сообщения, например в ночное время, пользователь увидит предупреждение о том, что ответ займёт больше времени.

По умолчанию виджет располагается в правом нижнем углу страницы. При его создании вы можете указать, как он будет запускаться: сразу после загрузки страницы или по нажатию на кнопку.

К сообщениям в диалоге можно прикреплять изображения, видео и документы.

## Как создать

Для подключения виджета вы можете использовать одну из библиотек: [SuperAppKit SDK](#Способ%201.%20С%20помощью%20SuperAppKit%20SDK) либо [Open API](#Способ%202.%20С%20помощью%20Open%20API).

Мы рекомендуем использовать SuperAppKit SDK, потому что некоторые браузеры не поддерживают Open API.

Вне зависимости от того, какой способ вы выберете, сначала надо подготовить сообщество к работе с виджетом.

## Подготовка

Для работы виджета настройте сообщество, от лица которого вы будете общаться с пользователями. Сделать это могут администраторы сообщества.

> **Совет.** Мы рекомендуем выбрать публичное сообщество. Чтобы отправлять сообщения в виджете частного сообщества, пользователь должен состоять в этом сообществе.

Чтобы настроить сообщество:

1. Перейдите в сообщество в интерфейсе ВКонтакте. В меню справа выберите **Управление**.

    ![alt=Переход к настройкам сообщества;title=Переход к настройкам сообщества](760a9fad0434879e19875e2a42f066c8adbf31bb1a70c4b4107cf31f "184984007722316222")

1. В меню открывшейся страницы выберите **Сообщения** и затем включите сообщения.

    ![alt=Включение сообщений в настройках сообщества;title=Включение сообщений в настройках сообщества](352e70ba8ccd90bbd981f154ca8e9e70a398ee1f7ce969a6495cf6ef "-6518034507036330183")

1. Установите галочку **Виджет сообщений** и укажите настройки виджета.

    ![alt=Включение виджета и настройка его параметров;title=Включение виджета и настройка его параметров](4b43cbd8528ec23d3821bc6512df11537578c00100b33f60b7e80d53 "7788581876672982833")

    Сохраните изменения.

Теперь вы можете добавить виджет к вашему сайту с помощью библиотеки SuperAppKit SDK или Open API.

## Способ 1. С помощью SuperAppKit SDK

### О библиотеке

SuperAppKit SDK — npm-библиотека для использования в веб-приложениях. Распространяется свободно. Написана на TypeScript. Декларации используемых в ней объектов, функций и типов данных можно просмотреть на следующей странице:

&nbsp;&nbsp;&nbsp;&nbsp;► https://www.npmjs.com/package/@vkontakte/superappkit

### Шаги подключения

#### 1. Зарегистрируйте приложение на платформе ВКонтакте

Откройте следующую страницу и создайте приложение, которое будет соответствовать вашему сайту:

&nbsp;&nbsp;&nbsp;&nbsp;► https://id.vk.ru/business/go/

Подробная инструкция — в [документации сервиса авторизации VK ID](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application). В качестве платформы при создании выберите **Web**.

#### 2. Установите библиотеку SuperAppKit

Чтобы добавить библиотеку в свой проект, откройте окно командной строки, перейдите в папку проекта и выполните следующую команду:

```Командная&nbsp;строка
npm install @vkontakte/superappkit
— или —
yarn add @vkontakte/superappkit
```

После настройки необходимо проинициализировать библиотеку и написать код, который будет готовить ключи доступа и виджет к работе.

#### 3. Проинициализируйте библиотеку

Для инициализации вызовите метод `Config.init(params: ConfigInitParams)`:

```TypeScript
import { Config } from '@vkontakte/superappkit';
 
// Вызов метода
Config.init({ 
    appId: 12345678, // ID вашего приложения на платформе
}); 
```

Метод `Config.init(...)` в качестве параметра принимает объект `ConfigInitParams`. Он содержит следующие поля:

```TypeScript
type ConfigInitParams = {
  appId: number;    // ID вашего приложения на платформе. 
                    // Назначается автоматически 
                    // при регистрации приложения.

  appSettings?: AppSettings; // Необязательные дополнительные 
                             // параметры для инициализации.

  superAppToken?: string;    // SuperApp-токен приложения. 
                             // Необязательный параметр.
                             // Его можно указать, если вы получили токен 
                             // до инициализации библиотеки.
}
```

Подробнее ознакомиться с используемыми значениями можно в [коде библиотеки](https://www.npmjs.com/package/@vkontakte/superappkit).

#### 4. Создайте код для аутентификации и работы с ключами доступа

Чтобы получить и обновить ключи доступа, которые необходимы для работы виджета, создайте обработчики событий [`Config.onAuth`](#Config.onAuth) и [`Config.onRequestSuperAppToken`](#Config.onRequestSuperAppToken).

#### Config.onAuth

Возникает, когда пользователь нажимает кнопку входа на первой странице виджета. Обработчик не использует какие-либо параметры.

**Важно.** В обработчике события необходимо выполнить следующие действия:

1. Вызвать метод `Connect.userVisibleAuth()`. Он отобразит на экране форму ввода аккаунта и пароля.

    Если браузер работает в полноэкранном режиме, форма откроется в новой вкладке. Если браузер работает в обычном режиме, форма откроется во всплывающем окне. Если в браузере заблокированы всплывающие окна, пользователь увидит уведомление об этом на экране.

1. Сгенерировать ключ доступа. `Connect.userVisibleAuth()` возвращает ключ доступа вида [Silent-токен](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/tokens/silent-token). Однако для работы библиотеки нужен ключ другого вида — [SuperApp-токен](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/tokens/superapp-token). Напишите код, который преобразует один вид ключа в другой:

    * Этот код сначала должен обменять Silent-токен на [Access token](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/tokens/access-token). Подробности — в [описании ключа Access token](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/tokens/access-token).

    * Затем код должен сгенерировать SuperApp-токен из полученного ключа Access token. Подробности — в [описании ключа SuperApp token](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/tokens/superapp-token).

Ниже — пример обработчика события `Config.onAuth()`:

```TypeScript
// Функция для создания SuperApp-токена
function generateSuperAppToken(data) {
    // Код для обмена и получения токенов
    // ....

    // Установка SuperApp-токена
    Config.setSuperAppToken(superAppToken);
} 

// Обработчик события
Config.onAuth(() => {
  // Показывает форму аутентификации
  Connect.userVisibleAuth()  
    .then( (data) => {
        // Вызов вашей функции для создания SuperApp-токена
        generateSuperAppToken(data);
    })     
    .catch( (err) => { 
        console.log('Ошибка', err)
    });
});
```

#### Config.onRequestSuperAppToken

Это событие происходит, когда ключ доступа отсутствует или устаревает. Обновите ключ в обработчике события.

Обработчик события не использует какие-либо параметры. Ниже — пример его кода.

```TypeScript
Config.onRequestSuperAppToken((params, options) => {
  // params.refresh указывает, что токен надо обновить
  if (params.refresh) {
    // С помощью параметра action можно скрыть форму входа, 
    // если можно авторизоваться бесшовно
    Connect.userVisibleAuth({ action: { name: 'login_silent_user' } })
      .then( (data) = {
        // Вызываем функцию для обновления и 
        // установки SuperApp-токена 
        generateSuperAppToken(data); 
      })
      .catch( (err) => { 
        console.log('Ошибка', err);
      });
  } else {
    // Если событие произошло, но param.refresh == false, 
    // устанавливаем существующий SuperApp-токен
    Config.setSuperAppToken(superAppToken, options);
  }
});
```

:::note
**Обратите внимание**. Обработчик должен вызывать метод `Config.setSuperAppToken(...)`, чтобы установить SuperApp-токен. Если токен устарел, то его надо получить заново. Для этого в примере выше мы вызываем функцию `generateSuperAppToken()`, которая использовалась в обработчике `onAuth()`.
:::

Обработчик использует два параметра: `params` и `options`. Описание их типов данных вы можете найти в [коде библиотеки](https://www.npmjs.com/package/@vkontakte/superappkit).

#### 5. Добавьте виджет

Создайте объект `Messenger`, который предоставляет программный интерфейс для работы с виджетом:

```JavaScript
import { Messenger } from '@vkontakte/superappkit';

const messenger = new Messenger({
// Параметры расположения виджета
    styles: {
    right: '15px',  
    bottom: '15px', 
    zIndex: 1     
    }
});
```

В блоке `styles` указаны параметры расположения виджета. Их указывать необязательно.

|Параметр|Тип|Описание|
|---|---|---|
|`right`|`string`|Расстояние от правой границы окна виджета до правой границы экрана.|
|`bottom`|`string`|Расстояние от нижней границы окна виджета до низа экрана.|
|`zIndex`|`integer`|z-index атрибут всплывающего окна виджета. По умолчанию — 1.|



Далее откройте окно обмена сообщениями:

```JavaScript
messenger.open({
  peer_id: id,            
  scheme: 'bright_light', 
  expanded: true,         
  messageSound: true,    
  openSound: false,      
  mode: 'extended',    
  expandTimeout: 0,      
  chatJoinHash: '...',  
  customActions: 
    ['to_convo_list',
     'common_dropdown',
     'close'],          
});
```

###### Параметры виджета

|Параметр|Тип|Описание|
|---|---|---|
|`peer_id`|`number`|Идентификатор сообщества, от которого будут отправляться сообщения. Должен быть указан со знаком минус.|
|`scheme`|`string`|Визуальная тема виджета. Возможные значения `bright_light` и `space_gray`.|
|`expanded`|`boolean`|Будет ли виджет раскрыт сразу. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `true` — виджет будет раскрыт сразу.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `false` — виджет будет раскрыт позже. &#x0d;&#x0a;&#x0d;&#x0a;Значение по умолчанию `true`.|
|`messageSound`|`string`|Проигрывать ли звук при получении сообщения. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `true` — звук включен,&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `false` — звук выключен. &#x0d;&#x0a;&#x0d;&#x0a;Значение по умолчанию — `true`.|
|`openSound`|`boolean`|Проигрывать ли звук при автоматическом раскрытии виджета. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `true` — звук включен,&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `false` — звук выключен. &#x0d;&#x0a;&#x0d;&#x0a;Значение по умолчанию — `true`.|
|`mode`|`string`|Вид боковой панели со списком пользователей, на которой отображаются сообщества с непрочитанными сообщениями. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `default` — без аватаров пользователей.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `extended` — с аватарами. &#x0d;&#x0a;&#x0d;&#x0a;Значение по умолчанию — `default`.|
|`expandTimeout`|`string`| Количество миллисекунд до открытия виджета. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `0` открывается сразу.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `5`, `10`, `15`, `30`, `40`, `50`, `60`, `120` — открывается через указанное количество милисекунд.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `undefined` — раскрывать окно обмена сообщениями не нужно.|
|`chatJoinHash`|`string`|Хеш (символы после `https://vk.me/join/`)в ссылке-приглашении в чат.|
|`customActions`|`integer`|Кнопки в верхней части виджета. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `to_convo_list` — кнопка перехода к списку чатов.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `to_full_messenger` — кнопка перехода в VK Мессенджер ([vk.ru/im](https://vk.ru/im)).&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `common_dropdown` — кнопка выпадающего меню.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `close` — кнопка закрытия окна виджета. &#x0d;&#x0a;&#x0d;&#x0a;Если в массиве больше трёх значений, будут использованы последние три. Если не указать это поле, виджет будет содержать кнопки `to_full_messenger`, `common_dropdown` и `close`.|

#### Обработка событий

Установите обработчик событий с помощью метода `Messenger.on(event_name, handler)`. Названия событий определены в объектах `CommonSDKEvents` и `MessengerEvents`.

В коде ниже перечислены все доступные события.

```TypeScript
// Ошибка загрузки мессенджера
messenger.on(CommonSDKEvents.ERROR, () => {
  // Обработка события
})
 
// Закрытие конкретного чата 
messenger.on(MessengerEvents.CLOSE_CHAT, () => {
  // Обработка события
});

// Закрытие мессенджера
messenger.on(CommonSDKEvents.CLOSE, () => {
// Обработка события
});
```





#### Обработка выхода из виджета

Окно с перепиской содержит кнопку «Выйти». С её помощью пользователь может выйти из диалога.

Чтобы обработать нажатие на эту кнопку, используйте событие `Config.onLogout`. В обработчике события вызовите метод `Connect.logout()`. При успешном выполнении этот метод вернёт объект [`Promise`](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Global_Objects/Promise), с помощью которого вы можете выполнить необходимую обработку, например удалить SuperApp-токен из памяти вашего приложения.

Ниже — пример обработчика события.

```JavaScript
Сonfig.onLogout( () => {
  Connect.logout().then(() => {
    // Удаление ключа доступа
  });
});
```

## Способ 2. С помощью Open API

### О&nbsp;библиотеке

OpenAPI — JavaScript-библиотека для подключения и использования на веб-страницах. Её можно получить по этому адресу:

&nbsp;&nbsp;&nbsp;&nbsp;► https://vk.ru/js/api/openapi.js?169

Исходный код библиотеки не предоставляется.

:::note
**Важно!** Подключение виджета с помощью библиотеки Open API не работает в браузерах Safari и Firefox.
:::

### Шаги&nbsp;подключения

1. Добавьте библиотеку [Open API](api/open-api/getting-started) на каждую страницу вашего сайта, которая будет использовать виджет.

    Чтобы сделать это, добавьте следующий код в элемент `<head>` страницы:

    ```HTML
    <head>
      ...
      <script src="https://vk.ru/js/api/openapi.js?169" type="text/javascript"></script>
      ...
    </head>
    ...
    ```

1. В элемент `<body>` добавьте `<div>`, который будет использоваться для отображения виджета. Вставить его можно в конец `<body>`. Обязательно укажите `id` для этого `div`-элемента:

    ```HTML
    <div id="vk_community_messages"></div>
    ```

1. Добавьте на страницу код вызова виджета:

    ```HTML
    <script type="text/javascript">
    VK.Widgets.CommunityMessages("vk_community_messages", 20003922);
    </script>
    ```

    Здесь —

    * `VK` — объект, который библиотека OpenAPI.js добавляет на страницу.

    * Свойство `VK.Widget` содержит объект, который используется для работы с виджетами.

    * Метод `CommunityMessages(...)` выполняет инициализацию виджета. Его параметры рассмотрены ниже.

### Описание метода CommunityMessages

Метод `CommunityMessages` создаёт и возвращает объект, который предоставляет программный интерфейс виджета. Подробнее о методах объекта — [ниже](#Методы%20объекта-виджета).

#### Параметры метода

| Параметр | Тип | Описание |
| --- | --- | --- |
| `element_id`&#x0d;&#x0a;*обязательный* |  `string` | Идентификатор HTML-элемента, в котором будет отображаться кнопка виджета. |  
| `group_id`&#x0d;&#x0a;*обязательный* | `integer` | Идентификатор сообщества, от лица которого будут приходить сообщения пользователю. [Где найти идентификатор сообщества?](https://vk.ru/faq18062) |
| `options`&#x0d;&#x0a;*необязательный* | [Объект `Options`](#Объект%20Options) | Объект, который содержит дополнительные параметры виджета. |

#### Методы объекта-виджета

Метод `VK.Widgets.CommunityMessages(...)` создаёт и возвращает объект, который предоставляет программный интерфейс для работы с виджетом. Этот объект содержит следующие методы:

| Метод | Описание |
| --- | --- |
| `destroy(element_id)` | Удаляет виджет.&#x0d;&#x0a;&#x0d;&#x0a;Параметр `element_id` — обязательный. Укажите в нём строку — идентификатор HTML-элемента, который использовался для отображения кнопки виджета. |
| `expand([noSaveSate])` | Разворачивает виджет из кнопки.&#x0d;&#x0a;&#x0d;&#x0a;Параметр `noSaveState` — необязательный. Принимает значение `true` или `false`. Если параметр `false`, виджет сохраняет своё состояние в [localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) и при последующем открытии страницы или её обновлении автоматически развернётся или свернётся. Если `true`, состояние не будет сохранено. По умолчанию используется `false`. &#x0d;&#x0a;&#x0d;&#x0a;Метод не возвращает какое-либо значение. |
| `minimize()` | Сворачивает виджет.&#x0d;&#x0a;&#x0d;&#x0a;Метод не использует параметры и не возвращает какое-либо значение. |
| `stopTitleAnimation()` | Отключает смену заголовка виджета после прихода нового сообщения.&#x0d;&#x0a;&#x0d;&#x0a;Метод не использует параметры и не возвращает какое-либо значение. |

#### Объект Options

С помощью объекта `Options` вы можете указать параметры виджета. При использовании библиотеки Open API вы указываете этот объект в третьем параметре при вызове метода [`VK.Widgets.CommunityMessages(...)`](#Способ%202.%20С%20помощью%20Open%20API).

| Поле | Тип | Описание |
| --- | --- | --- |
| `welcomeScreen` | `integer` | Нужно ли показывать экран приветствия. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bull; `1` — показывать.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `0` — не показывать. |
| `expanded` | `integer` | Нужно ли раскрыть виджет сразу при создании. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bull; `1` — раскрывать (используется по умолчанию).&#x0d;&#x0a; &nbsp;&nbsp; &bull; `0` — не раскрывать.&#x0d;&#x0a;&#x0d;&#x0a;Если вы укажете `0`, виджет можно раскрыть в любое время позже с помощью метода [`expand()`](#Методы%20объекта-виджета) объекта-виджета. |
| `expandTimeout` | `integer` | Интервал до раскрытия виджета в миллисекундах.&#x0d;&#x0a;&#x0d;&#x0a;Обратите внимание, что при обновлении страницы сохраняется состояние виджета. Если он уже раскрыт, этот параметр игнорируется. |
| `widgetPosition` | `string` | Положение кнопки виджета по горизонтали на странице. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bull; `left` — слева.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `right` — справа (используется по умолчанию).&#x0d;&#x0a;&#x0d;&#x0a;По вертикали кнопка всегда находится внизу страницы. |
| `buttonType` | `string` | Внешний вид кнопки. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bull; `blue_circle` — используется стандартная кнопка виджета, то есть та, которая определяется библиотекой.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `no_button` — стандартная кнопка виджета не отображается. Страница использует другой HTML-элемент для открытия виджета, например кнопку или ссылку, определяемую пользователем.&#x0d;&#x0a;Значение `no_button` влияет только на кнопку открытия виджета. Всплывающее окно с сообщениями остаётся таким же, как при использовании стандартной кнопки. Для работы с виджетом вы используете [объект](#Методы%20объекта-виджета), который возвращает метод `VK.Widgets.CommunityMessages(...)`.&#x0d;&#x0a;&#x0d;&#x0a;По умолчанию применяется `blue_circle`. |
| `disableButtonTooltip` | `integer` | Отключение всплывающей подсказки, которая показывается при наведении на кнопку виджета. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bull; `1` — отключить.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `0` — не отключать (используется по умолчанию). |
| `tooltipButtonText` | `string` | Текст всплывающей подсказки. |
| `disableNewMessagesSound` | `integer` | Отключить ли звук о новом сообщении. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bull; `1` — отключить.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `0` — не отключать (используется по умолчанию). |
| `disableExpandChatSound` |  `integer` | Отключить ли звук при раскрытии виджета. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bull; `1` — отключить (используется по умолчанию).&#x0d;&#x0a; &nbsp;&nbsp; &bull; `0` — проиграть звук. |
| `disableTitleChange` | `integer` | Изменять ли заголовок HTML-страницы при получении нового сообщения. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bull; `1` — не изменять.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `0` — изменять (используется по умолчанию). |
| `chatJoinHash` | `string` | Хеш, то есть символы после `https://vk.me/join/`, в ссылке-приглашении в чат. |
| `onCanNotWrite` | `function` | Функция, которая будет вызвана, если пользователь по каким-то причинам не может отправить сообщения в виджете.&#x0d;&#x0a;&#x0d;&#x0a;Функция принимает строковый параметр `reason`, который описывает причину ошибки. Этот параметр может принимать одно из следующих значений:&#x0d;&#x0a; &nbsp;&nbsp; &bull; `no_access` — у пользователя нет доступа к сообщениям в сообществе. Это может произойти, например, потому что аккаунт пользователя заблокирован.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `disabled_messages` — в сообществе отключены сообщения.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `cant_write` — у пользователя нет прав, чтобы отправить сообщение. Например, сообщество — частное, и пользователь в нём не состоит.&#x0d;&#x0a; &nbsp;&nbsp; &bull; `offline` — пользователь не вошёл ВКонтакте.&#x0d;&#x0a;&#x0d;&#x0a;Возвращаемое значение функции не используется. |
