# VKWebAppShowInviteBox

`VKWebAppShowInviteBox` открывает диалоговое окно приглашения друзей в [игру](games/overview).

Окно показывает друзей, которые ещё не играют в игру. Пользователь может выбрать, кому из них отправить [приглашение](games/promotion/game-mechanics/invites).

## Пример

```JavaScript
bridge.send('VKWebAppShowInviteBox', {
  requestKey: "key-12345" //  Ключ приглашения
  })
  .then( (data) => {
    if (data.success) {
      // Пользователь нажал «Пригласить» 
      // ...
  
      // Этим выбранным пользователям 
      // не удалось отправить приглашения 
      console.log('Приглашения не отправлены', data.notSentIds);
    }
  })
  .catch( (error) => {
    console.log(error); // Ошибка 
  });
```

## Параметры

| Поле | Тип | Описание |
| --- | --- | --- |
| `requestKey`&#x0d;&#x0a;*необязательное* | `string` | Ключ приглашения. Это строка, которая будет передана игре как параметр `vk_request_key` при запуске из приглашения. Его можно использовать, чтобы предусмотреть в игре сценарий, соответствующий приглашению, и для отслеживания конверсии. [Подробнее о параметрах](games/development/parameters).&#x0d;&#x0a;&#x0d;&#x0a;Обратите внимание: в настоящее время параметр `requestKey` работает только в играх, запущенных в десктопной или мобильной версии сайта. |
| `message`&#x0d;&#x0a;*обязательное* | `string` | Текст сообщения. Параметр используется только в десктопной и мобильной версии сайта Одноклассники. |

## Результат

Проверить результат можно:

* Используя объект [`Promise`](#Объект%20Promise), который возвращается вызовом `bridge.send(...)`.

* С помощью [событий](#События) `VKWebAppShowInviteBoxResult` и `VKWebAppShowInviteBoxFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](bridge/getting-started#Обработка%20результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `success` | `boolean` | Возможные значения: &#x0d;&#x0a; &nbsp;&nbsp; &bullet; `true` — игрок выбрал одного или нескольких друзей в списке и нажал на кнопку «Пригласить». Приглашение было отправлено хотя бы одному из выбранных пользователей.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `false` — в ином случае. |
| `notSentIds` | `array` | Список идентификаторов пользователей, которые были выбраны в диалоговом окне, но которым приглашение не было отправлено по какой-либо причине. |

Если при обращении к платформе произошла ошибка или если пользователь нажал на кнопку «Отмена» в диалоговом окне, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех событий VK Bridge.

### События

#### `VKWebAppShowInviteBoxResult`

Сигнализирует, что пользователь нажал «Пригласить» в диалоговом окне и приглашение было отправлено одному или нескольким выбранным пользователям. В обработчик события передаются следующие данные:  

```JSON
{
  "type": "VKWebAppShowInviteBoxResult",
  "data": {
    "success": true,
    "notSentIds": []
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект%20Promise).

#### `VKWebAppShowInviteBoxFailed`

Происходит при ошибке, которая произошла при взаимодействии с платформой, либо если пользователь нажал на кнопку «Отмена» в диалоговом окне.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех методов VK Bridge.

#### Пример обработки событий

Подробнее — в разделе [Обработка результата](bridge/getting-started#Обработка%20результата).

## Примечания

Игры, не добавленные в [каталог ВКонтакте](games/catalog/overview), могут присылать приглашения только своим администраторам.

Обратите внимание, что диалоговое окно покажет имя пользователя-администратора, только если он не запускал игру ранее. Если он уже запускал игру, то для тестирования события ему надо [удалить игру из списка своих игр](games/promotion/game-mechanics/invites#Особенности%20использования).
