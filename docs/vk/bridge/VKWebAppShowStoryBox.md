# VKWebAppShowStoryBox

`VKWebAppShowStoryBox` открывает редактор историй. Параметры события задают элементы, которые появятся в редакторе при открытии. Пользователь может изменить их, удалить и добавить новые перед публикацией истории.

## Пример

#### Пример вызова события

```JavaScript
bridge.send('VKWebAppShowStoryBox', {
  background_type: 'image',
  url: 'https://sun9-65.userapi.com/c850136/v850136098/1b77eb/0YK6suXkY24.jpg',
  attachment: {
    text: 'book',
    type: 'photo',
    owner_id: 743784474,
    id: 12345678
  }})
  .then((data) => {
    if (data.code_data) {
      // Редактор историй открыт
      console.log(data);
    }})
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Параметры

| Поле | Тип | Описание |
| --- | --- | --- |
| `background_type` &#x0d;&#x0a;*обязательное* | `string` | Тип фонового изображения или видео. Допустимые значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `image` — фоном истории будет статичное изображение, которое можно указать с помощью параметра `url` (ссылка на картинку в формате PNG или JPEG) или `blob` (двоичные данные). Этот тип фона можно использовать в мобильных приложениях для Android и iOS, в мобильной или десктопной версии сайта.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `video` — фоном истории будет видео, адрес которого указан параметром `url`. Такой тип фона работает в историях, создаваемых в мобильном приложении для Android (WEBM и MP4) и iOS (MP4).&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `none` — фоном истории будет видео с камеры мобильного устройства. Этот тип фона применим только в историях, создаваемых в мобильном приложении для Android и iOS.&#x0d;&#x0a;&#x0d;&#x0a; Оптимальное разрешение видео — 720&times;1280.&#x0d;&#x0a;&#x0d;&#x0a;В Одноклассниках поле поддерживает только значение `image`.|
| `camera_type`&#x0d;&#x0a;*необязательное* | `string` | Тип камеры, используемой в редакторе историй: `back` (задняя) или `front` (фронтальная). Редактор учитывает это значение, только если `"background_type": "none"`. Значение по умолчанию: `back`.|
| `url` &#x0d;&#x0a;*необязательное* | `string` | Прямая ссылка на изображение или видео. Медиафайлы должны быть загружены на сервера ВКонтакте. &#x0d;&#x0a;Подробнее — в разделе [Загрузка историй в профиль](api/upload/story-in-profile). |
| `blob` &#x0d;&#x0a;*необязательное* | `string` | Используется, когда `"background_type": "image"`, а поле `url` отсутствует. Содержит данные изображения, закодированные как Base64-строка. Перед этими данными необходимо добавить один из префиксов `data:image/...` в зависимости от типа изображения, например:&#x0d;&#x0a;&nbsp; &bullet; PNG: &nbsp;&nbsp; `data:image/png;base64,<base64-image-data>`&#x0d;&#x0a;&nbsp; &bullet; JPEG:&nbsp; `data:image/jpeg;base64,<base64-image-data>` &#x0d;&#x0a;&#x0d;&#x0a;&#x0d;&#x0a;В Одноклассниках поле поддерживает типы изображений: JPEG, PNG, SVG. |
| `locked` &#x0d;&#x0a;*необязательное* | `boolean` | Информация о том, можно ли перемещать изображение в истории (`true`) или нет (`false`). |
| `attachment` &#x0d;&#x0a;*обязательное* | [`attachment`](#attachment) | Объект, который описывает дополнительный ресурс: ссылку, видео или изображение, прикреплённые к истории. Кнопка с ресурсом появится в нижней части экрана. &#x0d;&#x0a;В Одноклассниках параметр `type` поддерживает только значение `url`. |
| `stickers` &#x0d;&#x0a;*необязательное* | `array` <[`sticker_`](#sticker_container)&#x0d;&#x0a;[`container`](#sticker_container)> | Массив стикеров, которые будут добавлены в историю. Пользователь может изменить или удалить их перед публикацией. Каждый стикер представлен объектом [`sticker_container`](#sticker_container). |
| `service_info` &#x0d;&#x0a;*необязательное* | [`service_info`](#service_info) | Дополнительные данные, которые могут использоваться для создания истории. |

## Результат

Проверить результат можно:

* Используя объект [`Promise`](#Объект%20Promise), который возвращается вызовом `bridge.send(...)`.

* С помощью [событий](#События) `VKWebAppShowStoryBoxResult`, `VKWebAppShowStoryBoxLoadFinish` и `VKWebAppShowStoryBoxFailed`.

Возможные ошибки:

* `This action cannot be performed in the background`, если мини-приложение запущено в фоновом режиме.
* `User denied`, если пользователь закрыл окно создания истории.

Подробнее — в разделе [Обработка результата](bridge/getting-started#Обработка%20результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующим полем:

| Поле | Тип | Описание |
| --- | --- | --- |
| `result` | `boolean` | `true`, если история начала загружаться. |

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех событий VK Bridge.

### События

#### `VKWebAppShowStoryBoxResult`

Сигнализирует, что история начала загружаться. В обработчик события на стороне пользователя передаются следующие данные:  

```JavaScript
{
  detail: {
    type: "VKWebAppShowStoryBoxResult",
    data: {
      result: true
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект%20Promise).

#### `VKWebAppShowStoryBoxLoadFinish`

Сигнализирует, что история была успешно опубликована. В качестве ответа платформа возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `story_owner_id` | `integer` | Идентификатор владельца истории. |
| `story_id` | `integer` | Идентификатор истории. |

В обработчик события на стороне пользователя передаются следующие данные:  

```JavaScript
{
  detail: {
    type: "VKWebAppShowStoryBoxLoadFinish",
    data: {
      story_owner_id: 743784474,
      story_id: 456239018,
    }
  }
}
```

#### `VKWebAppShowStoryBoxFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех методов VK Bridge.

#### Пример обработки событий

Смотрите раздел [Обработка результата](bridge/getting-started#Обработка%20результата).

## Объекты

### `attachment`

Описывает дополнительный ресурс: ссылку, изображение или видео, прикреплённое к истории. Кнопка с ресурсом появится в нижней части экрана.

| Поле | Тип | Описание |
| --- | --- | --- |
| `text` &#x0d;&#x0a;*обязательное* | `string` | Текст кнопки для открытия ресурса. Возможные значения — такие же, как значения параметра `link_text` в API-методе [`stories.getVideoUploadServer`](method/stories.getVideoUploadServer). |
| `type` &#x0d;&#x0a;*обязательное* | `string` | Тип ресурса. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `url` — ссылка.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `video` — видео.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `photo` — изображение.&#x0d;&#x0a;&#x0d;&#x0a;В Одноклассниках параметр `type` поддерживает только значение `url`. |
| `url` &#x0d;&#x0a;*необязательное* | `string` | Ссылка на объект.&#x0d;&#x0a;&#x0d;&#x0a;Этот параметр используется, если параметр `type` равен `url`. |
| `owner_id` &#x0d;&#x0a;*обязательное* | `integer` | Идентификатор пользователя или сообщества, которому принадлежит видео или изображение. &#x0d;&#x0a;&#x0d;&#x0a;Этот параметр используется, если параметр `type` равен `video` либо `photo`. &#x0d;&#x0a;&#x0d;&#x0a;Идентификатор пользователя — положительное число, идентификатор сообщества — отрицательное. &#x0d;&#x0a;&#x0d;&#x0a;[Как получить идентификаторы `owner_id` и `id`](#Как%20получить%20owner_id%20и%20id) |
| `id` &#x0d;&#x0a;*обязательное* | `integer` | Идентификатор видео или изображения. &#x0d;&#x0a;&#x0d;&#x0a;Этот параметр используется, если параметр `type` равен `video` либо `photo`.&#x0d;&#x0a;&#x0d;&#x0a;[Как получить идентификаторы `owner_id` и `id`](#Как%20получить%20owner_id%20и%20id) |
| `access_key` &#x0d;&#x0a;*необязательное* | `string` | Ключ доступа к ресурсу. Может потребоваться, когда для доступа к ресурсу нужны специальные права. |

#### Как получить `owner_id` и `id`

Чтобы получить значения для параметров `owner_id ` и `id`, откройте изображение или видео в десктопной версии сайта. В адресной строке браузера появится URL изображения или видео.

![alt=Значения owner_id и id в адресе ресурса;title=Значения owner_id и id в адресе ресурса](933a4de03ab11e5b13e8b92a19b3ed5532ec96c98d7316ce7fbac5f4 "-1040904329322334069")

Значение, которое идёт сразу после слова `photo` или `video` в URL, — это `owner_id`. Обратите внимание, что идентификатор сообщества — отрицательное число. Копируйте его вместе со знаком минус.

Значение, которое следует за `owner_id` после знака подчёркивания, — это `id` изображения или видео.

### `native_sticker`

Тип стикера описывается полем `action_type`, данные — полем `action`. Эти поля работают в связке. Например, если `action_type` равно `text`, то `action` должно содержать объект [`action_text`](#action_text), а если `action_type` равно `mention`, то `action`&nbsp;— [`action_mention`](#action_mention).

### `renderable_sticker`

Объект `renderable_sticker` описывает произвольное изображение, которое будет добавлено в создаваемую историю как объект-стикер. На этом изображении можно размещать дополнительные объекты — ссылки и хештеги.

| Поле | Тип | Описание |
| --- | --- | --- |
| `content_type` &#x0d;&#x0a;*обязательное* | `string` | Тип объекта-стикера. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `image` — изображение. Поддерживается в историях, создаваемых в мобильных приложениях для Android и iOS, а также в десктопной версии сайта. &#x0d;&#x0a; &nbsp;&nbsp; &bullet; `gif` — анимация в формате WebP. Поддерживается на платформе Android. Используйте это значение для включения в историю анимированных GIF-изображений. В историю можно добавить не более 4 таких картинок. |
| `url` &#x0d;&#x0a;*необязательное* | `string` | Ссылка на картинку, например, `https://mysite.com/img1.png`. **Обязательна**, если не указано поле `blob`. |
| `blob` &#x0d;&#x0a;*необязательное* | `string` | Данные изображения, закодированные как Base64-строка. Перед этими данными необходимо добавить один из префиксов `data:image/...` в зависимости от типа изображения:&#x0d;&#x0a;&nbsp; &bullet; PNG: &nbsp;&nbsp; `data:image/png;base64,<base64-image-data>`&#x0d;&#x0a;&nbsp; &bullet; JPEG:&nbsp; `data:image/jpeg;base64,<base64-image-data>`&#x0d;&#x0a;&#x0d;&#x0a;Поле **обязательно**, если `url` не указано. |
| `transform` &#x0d;&#x0a;*необязательное* | [`transform`](#transform) | Параметры, описывающие поворот или смещение стикера в создаваемой истории. |
| `clickable_zones` &#x0d;&#x0a;*необязательное* | `array` <[`clickable_zone`](#clickable_zone)> | Массив областей в стикере, нажатие на которые может вызвать какое-либо действие. Каждая область описывается объектом [`clickable_zone`](#clickable_zone). |
| `can_delete` &#x0d;&#x0a;*необязательное* | `boolean` | Информация о том, может ли пользователь удалить стикер из истории. Значение по умолчанию: `true`. |

### `clickable_zone`

Задаёт параметры области, нажатие на которую приведёт к тем или иным действиям, например к запуску приложения или открытию карточки товара.

Тип области описывается полем `action_type`, данные — полем `action`. Эти поля работают в связке. Например, если `action_type` равно `text`, то `action` должно содержать объект [`action_text`](#action_text), а если `action_type` равно `mention`, то `action`&nbsp;— [`action_mention`](#action_mention).

| Поле | Тип | Описание |
| --- | --- | --- |
| `action_type` &#x0d;&#x0a;*обязательное* | `string` | Тип области. Возможные значения:  &#x0d;&#x0a; &nbsp;&nbsp; &bullet; `app` &mdash; запуск мини-приложения. * В стикерах `native_sticker` поддерживается на платформе Android.
* В стикерах `renderable_sticker` поддерживается на платформе Android.
* Максимальное количество в истории: 1.

#### Поля

| Поле | Тип | Описание |
| --- | --- | --- |
| `style` &#x0d;&#x0a;*необязательное* | `string` |  Стиль текста и фона. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `black` &mdash; тёмные символы, сплошной светлый фон, показывается только время.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `white` &mdash; белые символы, прозрачный фон, показывается только время.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `green` &mdash; зелёные символы, тёмный фон, показывается только время.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `text` &mdash; показывается только время текстом, белыми буквами на прозрачном фоне в белой рамке.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `date` &mdash; белые символы, показываются дата и время либо, если используется поле `title`, только дата. Если не указаны `timestamp_ms` и `date`, то используются дата и время, когда редактор был открыт.&#x0d;&#x0a;&#x0d;&#x0a;Значение по умолчанию: `date`.|
| `title` &#x0d;&#x0a;*необязательное* | `string` | Верхний заголовок стикера. Значение только для стиля со значением `date`. |
| `timestamp_ms` &#x0d;&#x0a;*необязательное* | `long` | Дата и время для отображения. Задаётся в виде длинного целого числа ([Unix Timestamp](https://www.unixtimestamp.com/)), которое обозначает количество миллисекунд прошедших с 00:00:00 1 января 1970 года. Параметр используется только для `"style": "date"`. |
| `date` &#x0d;&#x0a;*необязательное* | `string` | Дата и время для отображения в формате `yyyy:MM:dd HH:mm:ss.ms`. Альтернатива для `timestamp_ms`. Используется только для `"style": "date"`. |

#### `action_app`

:::note
Объект `action_app` устарел и больше не доступен для использования.
:::
