# VKWebAppGetUserInfo

`VKWebAppGetUserInfo` получает данные о пользователе из его профиля ВКонтакте или в Одноклассниках.

## Пример

```JavaScript
bridge.send('VKWebAppGetUserInfo', {
  user_id: 743784474
  })
  .then((data) => { 
    if (data.id) {
      // Данные пользователя получены
      console.log(data);      
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Совместимость

| Площадки | Платформы |
| --- | --- |
| ВКонтакте | Android, iOS, Mobile Web, Web |
| Одноклассники | Android, iOS, Mobile Web, Web |

## Параметры

В качестве параметра передайте объект, содержащий одно из следующих полей:

| Поле | Тип | Описание |
| --- | --- | --- |
| `user_id`&#x0d;&#x0a;*необязательное* | `integer` | Идентификатор пользователя, информацию о котором вы хотите получить. |
| `user_ids`&#x0d;&#x0a;*необязательное* | `string` | Идентификатор или идентификаторы пользователей, информацию о которых вы хотите получить. Указывайте идентификаторы через запятую.|
| `use_local` | `boolean` | Определяет, с какой площадки нужно получить данные. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `true` — с площадки, которая использует SDK, например Одноклассники.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `false` — Вконтакте. Значение по умолчанию. |

:::note
При вызове события используйте только одно поле: `user_id` или `user_ids`.
Если ни одно из них не указано, событие вернёт информацию о текущем пользователе.
:::

## Результат

Проверить результат можно:

* Используя объект [`Promise`](#Объект%20Promise), который возвращается вызовом `bridge.send(...)`.

* С помощью [событий](#События) `VKWebAppGetUserInfoResult` и `VKWebAppGetUserFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](bridge/getting-started#Обработка%20результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`.

#### Если в запросе один идентификатор

Если в запросе вы указали только один идентификатор, то есть указали поле `user_id` либо указали `user_ids`, но в нём было только одно значение, то в качестве ответа платформа вернёт объект, [содержащий информацию о пользователе](#Объект%20с%20информацией%20о%20пользователе) с указанным идентификатором.

```JavaScript
bridge.send('VKWebAppGetUserInfo', {
  user_id: 743784474
  })
  .then((data) => { 
      // data — объект с информацией о пользователе
  })
  .catch((error) => {
    console.log(error); // Ошибка
  });
```

Если идентификатор не был найден в базе или произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех событий VK Bridge.

#### Если в запросе несколько идентификаторов

Если в запросе вы указали несколько идентификаторов в `user_ids`, то в качестве ответа платформа вернёт объект, который содержит следующее поле:

| Поле | Тип | Описание |
| --- | --- | --- |
| `result` | [`object[]`](#Объект%20с%20информацией%20о%20пользователе)  | Массив объектов, с [информацией о пользователях](#Объект%20с%20информацией%20о%20пользователе). |

Массив содержит данные пользователей, чьи идентификаторы были найдены. Массив не содержит данных по несуществующим идентификаторам или указанным с ошибкой.  

```JavaScript
bridge.send('VKWebAppGetUserInfo', {
  user_ids: '743784474, 743784479' 
  })
  .then((data) => { 
      // data.result — массив объектов с информацией о пользователях
    }
  })
  .catch((error) => {
    console.log(error); // Ошибка
  });
```

Если при обращении к платформе произошла ошибка или не был найден ни один идентификатор, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех событий VK Bridge.

### Объект с информацией о пользователе

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `integer` | Идентификатор пользователя. |
| `bdate` | `string` | Дата рождения пользователя. Например `10.4.1990` или `10.4` (если год рождения скрыт). Если дата рождения скрыта целиком, поле в ответе отсутствует. |
| `bdate_visibility` | `integer` | Информация о том, отображается ли дата рождения пользователя. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `1` — дата рождения открыта целиком.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `2` — открыты только день и месяц даты рождения.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `0` — дата рождения скрыта. |
| `city` | `object` | Информация о городе пользователя. Объект, который содержит поля:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `id` (`integer`) — идентификатор города.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `title` (`string`) — название города. |
| `country` | `object` | Информация о стране пользователя. Объект, который содержит поля:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `id` (`integer`) — идентификатор страны.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `title` (`string`) — название страны. |
| `photo_200` | `string` | URL квадратной фотографии пользователя с шириной 200 пикселей. Если у пользователя отсутствует фотография, возвращается `https://vk.com/images/camera_200.png`. |
| `photo_max_orig` | `string` | URL фотографии максимального размера. Может быть возвращена фотография, имеющая ширину как 400, так и 200 пикселей. Если у пользователя отсутствует фотография, возвращается `https://vk.com/images/camera_400.png`. |
| `sex` | `integer` | Пол пользователя. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `1` — женский.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `2` — мужской.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `0` — пол не указан. |
| `photo_100` | `string` | URL квадратной фотографии пользователя с шириной 100 пикселей. Если у пользователя отсутствует фотография, возвращается `https://vk.com/images/camera_100.png`. |
| `first_name` | `string` | Имя пользователя. |
| `last_name` | `string` | Фамилия пользователя. |
| `can_access_closed` | `boolean` | Информация о том, может ли пользователь, который открыл мини-приложение, видеть закрытый профиль пользователя. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `true` — пользователь может видеть профиль.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `false` — пользователь не может видеть профиль. |
| `is_closed` | `boolean` | Информация о том, закрыт ли профиль пользователя. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `true` — профиль закрыт.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `false` — профиль открыт. |

### События

      id: 743784474,
      bdate: "21.12.2000",
      bdate_visibility: 1,
      city: {
        id: 2,
        title: "Санкт-Петербург"
      },
      country: {
        id: 1,
        title: "Россия"
      },
      photo_200: "https://sun1-91.userapi.com/s/v1/ig2/Dcf-SWu7nVYDDldq9oQegiC06VqsSa43-HpDxzPjrvFCUUk9nSevY2Uf9xzm0bxvLfgsTOH6XiiW-zeLcDhPDj_w.jpg?size=200x200&quality=96&crop=26,26,204,204&ava=1",
      photo_max_orig: "https://sun1-91.userapi.com/s/v1/ig2/trHNebJQhG4BmLxC8h4hOpDU6bKRy6uJi586wcyFcCj5fzrwYk7AtoNab-RSil0Bp9b569VQyGK_skG9e6oK7Ap7.jpg?size=256x256&quality=96&crop=0,0,256,256&ava=1",
      sex": 2,
      photo_100: "https://sun1-91.userapi.com/s/v1/ig2/M4vtl7tcmeP6ANUgE0vU7JZWuJszbHaN5QcCcK2xD66EIc6SeSA1NyFVLTSOt2iLOkFhJSJ4DawEJGOjzKtszMpR.jpg?size=100x100&quality=96&crop=26,26,204,204&ava=1",
      first_name: "Персик",

#### `VKWebAppGetUserInfoFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех методов VK Bridge.

## Особенности использования

Событие `VKWebAppGetUserInfo` возвращает информацию, которую пользователь отметил доступной в своём профиле.

Для вызова события какие-либо права доступа не требуются.
