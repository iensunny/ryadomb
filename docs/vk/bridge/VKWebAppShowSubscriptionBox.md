# VKWebAppShowSubscriptionBox

`VKWebAppShowSubscriptionBox` открывает диалоговое окно покупки [подписки](api/payments/overview#Виды%20платежей), отказа от неё или восстановления подписки в [игре](games/overview) или [мини-приложении](mini-apps/overview). Выполняемое действие и внешний вид окна задаются [параметрами](#Параметры) события.

## Пример

### Продажа подписки

```JavaScript
bridge.send('VKWebAppShowSubscriptionBox', 
  { 
    action: 'create',
    item: 'subscription_in-app_id',
  })
  .then( (data) => { 
    if (data.success) {
      // Списание голосов прошло успешно
      // ...
  }) 
  .catch( (e) => { 
    console.log(error);   // Ошибка
  });
```

### Отмена подписки

```JavaScript
bridge.send('VKWebAppShowSubscriptionBox', 
  { 
    action: 'cancel',
     subscription_id: '25', // Идентификатор подписки, полученный от площадки 
  })
  .then( (data) => { 
    if (data.success) {
      // Подписка отменена
      // ...
  }) 
  .catch( (e) => { 
    console.log(error);   // Ошибка
  });
```

### Восстановление подписки

```JavaScript
bridge.send('VKWebAppShowSubscriptionBox', 
    { 
      action: 'resume',
      subscription_id: '25', // Идентификатор подписки, полученный от площадки
    })
    .then( (data) => { 
      if (data.success) {
        // Подписка восстановлена
        // ...
    }) 
    .catch( (e) => { 
      console.log(error);   // Ошибка
    })
```

| Площадки | Платформы |
| --- | --- |
| ВКонтакте | Android, iOS, Mobile Web, Web |
| Одноклассники | Android, iOS, Mobile Web, Web |

## Параметры

| Поле | Тип | Описание |
| --- | --- | --- |
| `action`&#x0d;&#x0a;*обязательное* | `string` | Выполняемое действие. Допустимые значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `create` — покупка подписки.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `cancel` — отмена подписки.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `resume` — восстановление отменённой подписки. |
| `item`&#x0d;&#x0a;*обязательное при продаже подписки*| `string` | Параметр используется при продаже подписки. Указывает внутренний идентификатор подписки в приложении. Сервер приложения использует это значение, чтобы вернуть информацию о подписке, которая будет показана в диалоговом окне покупки.&#x0d;&#x0a;&#x0d;&#x0a;Операции отмены и восстановления подписки должны проходить с использованием другого идентификатора — того, который приложение получает от площадки. |
| `subscription_id`&#x0d;&#x0a;*обязательное при отмене и восстановлении подписки* | `integer` | Параметр используется при отмене или восстановлении подписки. Указывает идентификатор экземпляра подписки, проданного пользователю. Приложение получает этот идентификатор от площадки при продаже подписки пользователю. |

## Результат

Проверить результат можно:

* Используя объект [`Promise`](#Объект%20Promise), который возвращается вызовом `bridge.send(...)`.

* С помощью [событий](#События) `VKWebAppShowSubscriptionBoxResult` и `VKWebAppShowSubscriptionBoxFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](bridge/getting-started#Обработка%20результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. Во всех вариантах работы, то есть и при продаже, и при отмене, и при восстановлении подписки, в качестве ответа платформа возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `success` | `boolean` | `true`, если операция была выполнена успешно, `false` — в противном случае. |
| `subscriptionId` | `integer` | Идентификатор экземпляра подписки, с которым производится операция.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; При продаже подписки площадка создаёт этот идентификатор автоматически. Используйте его для отмены и восстановления подписки в дальнейшем.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; При отмене или восстановлении подписки это будет тот же самый идентификатор, который был передан в параметре `subscription_id` события `VKWebAppShowSubscriptionBox`. |

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех событий VK Bridge.

### События

#### `VKWebAppShowSubscriptionBoxResult`

Сигнализирует об успешном выполнении операции. В обработчик события на стороне пользователя передаются следующие данные:  

```JavaScript
{
  detail: {
    type: "VKWebAppShowSubscriptionBoxResult",
    data: {
      success: true,
      subscriptionId: 25
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект%20Promise).

#### `VKWebAppShowSubscriptionBoxFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех методов VK Bridge.

#### Пример обработки событий

Подробнее — в разделе [Обработка результата](bridge/getting-started#Обработка%20результата).

## Примечания

* Полная информация о продаже, отмене и восстановлении подписок — в разделе [Продажа подписок](api/payments/subscriptions/vk).

* Пользователи могут отменять и восстанавливать подписки не только в приложении, но и в настройках своего аккаунта.

* Если пользователь приложения добавлен в список тестировщиков платежей этого приложения, все покупки подписок, сделанные этим пользователем, работают в тестовом режиме. Подробнее — в разделе [Тестирование платежей](api/payments/testing).
