# VKWebAppShowLeaderBoardBox

`VKWebAppShowLeaderBoardBox` открывает диалоговое окно, которое показывает результаты пользователя в [игре](games/overview) относительно его друзей или всех пользователей.

Тип данных таблицы: полученные очки, пройденные уровни или заработанные баллы миссий — указывается в настройках игры: [Настройки &rarr; Дополнительные &rarr; Таблица результатов](games/settings/general/additional#Таблица%20результатов).

## Пример

```JavaScript
bridge.send("VKWebAppShowLeaderBoardBox", {
  user_result: 100
  })
  .then( (data) => {
    if (data.success) {
        // Диалоговое окно было показано
        // ...
    }
  })
  .catch( (error) => {
    console.log(error); // Ошибка
  });
```

## Параметры

| Поле | Тип | Описание |
| --- | --- | --- |
| `app_id`&#x0d;&#x0a;*необязательное* | `integer` | Идентификатор игры. |
| `user_result`&#x0d;&#x0a;*необязательное* | `integer` | Результат игрока, который будет показан в таблице: заработанные очки, номер пройденного уровня или баллы за пройденную миссию. Тип передаваемого значения: очки, уровни или баллы миссий — зависит от типа таблицы, который указан в настройках игры в разделе [Таблица результатов](games/settings/general/additional#Таблица%20результатов).&#x0d;&#x0a;&#x0d;&#x0a;Значение используется только для отображения в таблице. Оно не сохраняется на стороне игровой платформы. Чтобы указать или обновить сохранённое значение, используйте API-запрос [`secure.addAppEvent`](method/secure.addAppEvent).&#x0d;&#x0a;&#x0d;&#x0a;|
| `global`&#x0d;&#x0a;*необязательное* | `integer` | Наполнение таблицы: 0 — показать только друзей, 1 — показать всех пользователей. |

Чтобы показать результаты, сохранённые ранее, вызовите событие без параметров.

## Результат

Проверить результат можно:

* Используя объект [`Promise`](#Объект%20Promise), который возвращается вызовом `bridge.send(...)`.

* С помощью [событий](#События) `VKWebAppShowLeaderBoardResult` и `VKWebAppShowLeaderBoardFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](bridge/getting-started#Обработка%20результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующим полем:

| Поле | Тип | Описание |
| --- | --- | --- |
| `data.success` | `boolean` | Равен `true`. Сигнализирует о том, что таблица была показана. |

Если при обращении к платформе произошла ошибка или таблица не была показана по другой причине, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех событий VK Bridge.

### События

#### `VKWebAppShowLeaderBoardResult`

Сигнализирует, что таблица была показана. В обработчик события передаются следующие данные:  

```JSON
{
  "type": "VKWebAppShowLeaderBoardResult",
  "data": {
    "success": true
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект%20Promise).

#### `VKWebAppShowLeaderBoardFailed`

Сигнализирует об ошибке, которая произошла при вызове события.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех методов VK Bridge.

#### Пример обработки событий

Подробнее — в разделе [Обработка результата](bridge/getting-started#Обработка%20результата).

## Примечания

* Параметр `user_result` — необязательный. Его удобно использовать, если вы показываете таблицу сразу после изменения результата пользователя в игре. Это значение не добавляется к общему результату игрока, сохранённому на стороне игровой платформы ВКонтакте.

    Чтобы указать или обновить сохранённое значение, используйте API-запрос [`secure.addAppEvent`](method/secure.addAppEvent).

    Будьте внимательны. Отображаемое значение должно совпадать с общим результатом после начисления. Если пользователь увидит в таблице одно значение, а в реальности на стороне платформы будет другое, то тем самым игра вызовет недовольство пользователя.

* Для достижений пользователя на платформе действуют ограничения:

    * Номер уровня — от 1 до 15&nbsp;000.
    * Количество очков — от 1 до 10&nbsp;000&nbsp;000.
    * Баллы миссий — от 1 до 2&nbsp;000. 
    
    Событие `VKWebAppShowLeaderBoardBox` не проверяет значение параметра `user_result` на соответствие этим ограничениям.
