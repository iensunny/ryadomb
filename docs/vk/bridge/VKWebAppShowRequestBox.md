# VKWebAppShowRequestBox

`VKWebAppShowRequestBox` открывает диалоговое окно для отправки запроса о помощи в [игре](games/overview) какому-либо пользователю.

Механика запросов от друзей позволяет привлечь новых пользователей в игру или вернуть неактивных игроков. Подробнее о ней можно узнать в разделе [Запросы](games/promotion/game-mechanics/requests).

## Пример

```JavaScript
bridge.send("VKWebAppShowRequestBox", {
  uid: 142918399, // Идентификатор пользователя — получателя сообщения
  message:    "Мне нужна помощь! Пжл, вышли 20 талеров и алмазную кирку.", // Текст запроса 
  requestKey: "key-12345" //  Ключ запроса
  })
  .then( (data) => {
    if (data.success) {
      // Запрос отправлен.
      // ...

      // Ключ
      console.log('Ключ переданного запроса: ', data.requestKey);
  })  
  .catch( (error) => { 
    console.log(error); // Ошибка 
  });
```

## Параметры

| Поле | Тип | Описание |
| --- | --- | --- |
| `uid`&#x0d;&#x0a;*обязательное* | `integer`| Идентификатор пользователя, которому будет отправлен запрос.&#x0d;&#x0a;&#x0d;&#x0a;Чтобы получить идентификатор, выполните API-запрос [`friends.getAppUsers`](method/friends.getAppUsers) или [`friends.get`](method/friends.get). |
| `message`&#x0d;&#x0a;*обязательное* | `string` | Текст запроса. В общем случае это может быть произвольная строка.&#x0d;&#x0a;&#x0d;&#x0a;Игра может предлагать вводить текст запроса, но пользователям будет удобнее и быстрее воспользоваться уже готовыми фразами. Мы рекомендуем подумать над хорошо сформулированными запросами, которые подходят вашей игре, и использовать их. |
| `requestKey`&#x0d;&#x0a;*необязательное* | `string` | Ключ запроса. Это строка, которая будет передана игре как параметр `vk_request_key` при запуске из запроса. Его можно использовать, чтобы предусмотреть в игре сценарий, соответствующий запросу, и для отслеживания конверсии. Подробнее — в разделе [Параметры запуска игр](games/development/parameters). |

## Результат

Проверить результат можно:

* Используя объект [`Promise`](#Объект%20Promise), который возвращается вызовом `bridge.send(...)`.

* С помощью [событий](#События) `VKWebAppShowRequestBoxResult` и `VKWebAppShowRequestBoxFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](bridge/getting-started#Обработка%20результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `data.success` | `boolean` | Равен `true`. Сигнализирует о том, что пользователь нажал на кнопку «Отправить». |
| `data.requestKey` | `string` | Ключ отправленного запроса. |

Если при обращении к платформе произошла ошибка или если пользователь нажал на кнопку «Отмена» в диалоговом окне, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех событий VK Bridge.

### События

#### `VKWebAppShowRequestBoxResult`

Сигнализирует, что пользователь нажал «Отправить» в диалоговом окне и приглашение было отправлено одному или нескольким выбранным пользователям. В обработчик события передаются следующие данные:  

```JSON
{
  "type": "VKWebAppShowRequestBoxResult",
  "data": {
    "success": true,
    "requestKey": "key-12345"
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект%20Promise).

#### `VKWebAppShowRequestBoxFailed`

Происходит при ошибке, которая произошла при взаимодействии с платформой, либо если пользователь нажал на кнопку «Отмена» в диалоговом окне.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех методов VK Bridge.

#### Пример обработки событий

Подробнее — в разделе [Обработка результата](bridge/getting-started#Обработка%20результата).

## Примечания

Запросы отправляются отдельно каждому пользователю. Подтверждение у отправителя запрашивается при каждом запросе.
