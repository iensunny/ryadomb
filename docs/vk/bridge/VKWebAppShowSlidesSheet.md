# VKWebAppShowSlidesSheet

`VKWebAppShowSlidesSheet` показывает [информационные экраны (слайды)](mini-apps/development/information-screens), которые используются для онбординга пользователя и знакомства с новыми возможностями мини-приложения или игры. 

![alt=Пример использования информационного экрана для онбординга;title=Пример использования информационного экрана для онбординга](fe4ff8f2c68e311f2aed8e40fa766a7a610c983a65a127f24d480184 "-4333346481610723793")

## Пример

```JavaScript
bridge.send('VKWebAppShowSlidesSheet', {
  slides: [
    {
      media: {
        blob: 'data:image/png;base64,[IMAGE_DATA]',
        type: 'image'
      },
      title: 'Заголовок слайда',
      subtitle: 'Описание слайда под заголовком'
    }
   ]})
  .then((data) => { 
    if (data.result) {
      // Слайды показаны
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Параметры

### Параметры события

| Поле | Тип | Описание |
| --- | --- | --- |
| `slides` &#x0d;&#x0a;*обязательное* | `array[object]` | Слайды. Каждый элемент массива — [объект, экран (слайд)](#Параметры%20слайда). Максимальное количество элементов в массиве:&nbsp;10. |

### Параметры слайда

| Поле | Тип | Описание |
| --- | --- | --- |
| `title` &#x0d;&#x0a;*обязательное* | `string` | Заголовок слайда. Занимает две строки.|
| `subtitle` &#x0d;&#x0a;*обязательное* | `string` | Короткое описание слайда. Занимает три строки.|
| `media` &#x0d;&#x0a;*обязательное* | `object` | Информация об изображении, которое будет показано на слайде. Изображение имеет фиксированное соотношение сторон:&nbsp;1,5:1. Если указанное изображение имеет другое соотношение, то оно будет обрезано до нужного соотношения. &#x0d;&#x0a;Минимальный рекомендуемый размер изображения:&nbsp;832&times;555&nbsp;px. Максимальный размер файла изображения: 500&nbsp;Кбайт.&#x0d;&#x0a;&#x0d;&#x0a;Поля объекта:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `type` (`string`) — тип изображения. В настоящий момент поддерживается только значение `image`.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `blob` (`string`) — cодержит данные изображения, закодированные как [Base64](https://vk.cc/5mpsES)-строка. Перед этими данными необходимо добавить один из префиксов `data:image/...` в зависимости от типа изображения, например: &#x0d;&#x0a; &nbsp;&nbsp;&nbsp; &nbsp;&nbsp; &bullet; `data:image/png;base64,<base64-image-data>`.&#x0d;&#x0a; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp; &bullet; `data:image/jpeg;base64,<base64-image-data>`.&#x0d;&#x0a;&#x0d;&#x0a;|

## Результат

Проверить результат можно:

* Используя объект [`Promise`](#Объект%20Promise), который возвращается вызовом `bridge.send(...)`.

* С помощью [событий](#События) `VKWebAppShowSlidesSheetResult` и `VKWebAppShowSlidesSheetFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](bridge/getting-started#Обработка%20результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующим полем:

| Поле | Тип | Описание |
| --- | --- | --- |
| `result` | `boolean` | `true`, слайды показаны. |
| `action` | `string` | Действие, которое совершил пользователь по отношению к слайдам. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `confirm` — пользователь просмотрел все слайды.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `reject` — пользователь нажал кнопку отмены на любом слайде.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `cancel` — пользователь закрыл просмотр слайдов любым другим способом, например нажал кнопку возврата. |
| `slide_index` | `integer` | Индекс слайда. Нумерация начинается с `0`.&#x0d;&#x0a;&#x0d;&#x0a; Поле возвращается, если параметр `action` имеет значение `reject`. |

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех событий VK Bridge.

### События

#### `VKWebAppShowSlidesSheetResult`

Сигнализирует, что экраны показаны. В обработчик события на стороне пользователя передаются следующие данные:  

```JavaScript
{
  detail: {
    type: "VKWebAppShowSlidesSheetResult",
    data: {
      result: true,
      action: "confirm"
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект%20Promise).

#### `VKWebAppShowSlidesSheetFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех методов VK Bridge.
