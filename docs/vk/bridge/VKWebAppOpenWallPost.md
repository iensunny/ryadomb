# VKWebAppOpenWallPost

`VKWebAppOpenWallPost` открывает в отдельном окне (поверх мини-приложения или игры) запись, опубликованную на стене пользователя или сообщества.

## Пример

```JavaScript
bridge.send('VKWebAppOpenWallPost', {
  owner_id: -166562603,
  post_id: 4604
  })
  .then((data) => { 
    if (data.result) {
      // Окно с записью открыто
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Совместимость

| Площадки | Платформы |
| --- | --- |
| ВКонтакте | Web |
| Одноклассники | iOS, Mobile Web, Web |

## Параметры

| Поле | Тип | Описание |
| --- | --- | --- |
| `owner_id` &#x0d;&#x0a;*обязательное* | `integer` | Идентификатор сообщества (отрицательное число) или пользователя (положительное число), на стене которого опубликована запись. Одноклассники: если запись опубликована пользователем, то нужно указать идентификатор пользователя. Если запись опубликована в группе, то нужно указать значение `0`.|
| `post_id` &#x0d;&#x0a;*обязательное* | `integer` | Идентификатор записи на стене (положительное число). |

## Результат

Проверить результат можно:

* Используя объект [`Promise`](#Объект%20Promise), который возвращается вызовом `bridge.send(...)`.

* С помощью [событий](#События) `VKWebAppOpenWallPosttResult` и `VKWebAppOpenWallPostFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](bridge/getting-started#Обработка%20результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующим полем:

| Поле | Тип | Описание |
| --- | --- | --- |
| `result` | `boolean` | `true`, если окно с записью открыто. |

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех событий VK Bridge.


### События

#### `VKWebAppOpenWallPostResult`

Сигнализирует, что окно с записью открыто. В обработчик события на стороне пользователя передаются следующие данные:  

```JavaScript
{
  detail: {
    type: "VKWebAppOpenWallPostResult",
    data: {
      result: true
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект%20Promise).

#### `VKWebAppOpenWallPostFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](bridge/getting-started#Обработка%20ошибок), общий для всех методов VK Bridge.
