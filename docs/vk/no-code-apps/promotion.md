# Запуск и продвижение

> Источник: [https://dev.vk.ru/ru/no-code-apps/promotion](https://dev.vk.ru/ru/no-code-apps/promotion)
## Как включить приложение

По умолчанию no-code приложение доступно только его [администраторам](no-code-apps/settings/managers).
Чтобы оно стало доступно любому пользователю ВКонтакте, приложение нужно включить.
Сделать это можно в разделе настроек [Публикация](no-code-apps/settings/publishing).
В блоке **Размещение на платформах** переведите **Состояние для пользователей** во **Включено**.

## Как пользователи будут запускать приложение

В общем случае пользователи запускают no-code приложение по его адресу.
Вы можете найти этот адрес в [панели управления](no-code-apps/settings/overview) приложением, в разделе [Публикация](no-code-apps/settings/publishing).

![alt=Адрес для запуска в панели управления no-code приложением;title=Адрес для запуска в панели управления no-code приложением](20b742fbc6c0763bac4cbcd509e92e5af8b2e886019b550400777257 "-5579779207920319691")

Чтобы запустить приложение, пользователям достаточно открыть адрес в браузере. Такой способ ещё называют «запуском по ссылке».

Вы можете указывать этот адрес на визитках, в рекламных материалах, на своём сайте, в переписке с друзьями и в других местах.

## Как продвигать приложение

Когда no-code приложение включено, пользователи могут запускать его по ссылке.
Но чтобы приложение набирало аудиторию и приносило заказы, его необходимо сделать более видимым пользователям.
<!-- Давайте рассмотрим некоторые возможности для продвижения no-code приложений. -->
Один из способов это сделать — [добавить приложение в каталог мини-приложений](#Добавьте%20приложение%20в%20каталог).
Ещё один способ — использовать [рекламные объявления в интернете](#Создайте%20рекламное%20объявление).

### Добавьте приложение в каталог

Чтобы сделать no-code приложение видимым большому числу пользователей, добавьте его в [каталог мини-приложений](https://vk.com/services) ВКонтакте.

#### Преимущества

* Каталог всегда под рукой, поэтому мини-приложения из него доступны самой широкой аудитории.

* Приложения в каталоге объединены в подборки. Некоторые подборки пользователи видят в новостной ленте, на страницах поиска и на вкладке «Сервисы» на мобильных устройствах.
Это позволяет привлечь пользователей, которые редко заходят в каталог.

* После добавления в каталог приложение появится в результатах поиска по платформе, что также позволяет привлечь дополнительный трафик.

#### Как попасть в каталог

Перед тем как попасть в каталог, no-code приложение должно пройти проверку нашими модераторами.

1. Подготовьте приложение. В [панели управления](no-code-apps/settings/overview) заполните разделы [Настройки](no-code-apps/settings/general) и [Контент](no-code-apps/settings/contents). Готовность к модерации можно оценить по блоку **Прогресс заполнения**. Все пункты должны быть отмечены как выполненные.

   ![alt=Блок «Прогресс заполнения» в панели управления;title=Блок «Прогресс заполнения» в панели управления](ff6df23b808d45c4c4334a8514b0e8d1069d82392a544b8fe59dca0e "8530596124263803070")

   :::note
   **Важно!** Материалы вашего no-code приложения не должны нарушать [правила размещения приложений](mini-apps-rules) и законодательство Российской Федерации.
   :::

2. Когда всё готово, перейдите в раздел настроек [Публикация](no-code-apps/settings/publishing) и отправьте заявку на модерацию. Дождитесь решения модераторов.

   Проверка занимает несколько дней. Результаты отображаются в разделе **Публикация**.

   > Воздержитесь от изменения настроек приложения, пока оно проходит модерацию.

   Если приложение пройдёт модерацию успешно, оно будет сразу добавлено в каталог.

### Создайте рекламное объявление

No-code приложение можно запускать по URL. В этом оно похоже на любое другое веб-приложение или сайт.
Поэтому продвигать его можно с помощью рекламных объявлений, как продвигают другие сайты и веб-приложения.

Вы можете воспользоваться услугами любой рекламной сети.
Один из вариантов — создать рекламное объявление ВКонтакте. Его можно настроить и запустить самостоятельно для нужной вам целевой аудитории.
Сделать это можно так же, как и для любого другого мини-приложения.
Подробности — в разделе [Рекламные объявления (документация мини-приложений)](mini-apps/promotion/ad).
