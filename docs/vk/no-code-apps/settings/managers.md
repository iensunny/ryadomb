# Администраторы

> Источник: [https://dev.vk.ru/ru/no-code-apps/settings/managers](https://dev.vk.ru/ru/no-code-apps/settings/managers)
Администраторы no-code приложения — это пользователи ВКонтакте, которые наполняют приложение, тестируют и поддерживают его работу. Они могут менять настройки, запускать его, когда оно отключено для остальных пользователей, и обрабатывать заявки.

После создания приложения в разделе **Администраторы** вы можете добавить своих коллег в администраторы, чтобы совместно наполнять приложение контентом и обрабатывать заявки.

## Как открыть

[Откройте панель управления no-code приложением](no-code-apps/settings/overview) и в меню слева выберите **Администраторы**.

## Кому доступно

Раздел доступен всем администраторам no-code приложения.

## Виды администраторов

У приложения есть два вида администраторов: создатель и администратор с полным доступом. 

### Создатель

**Создатель** — это главный администратор приложения. Он обладает доступом ко всем настройкам. 

В списке администраторов может быть только один пользователь с правами создателя. Изначально это пользователь, который зарегистрировал приложение на платформе.

Удалить создателя из списка администраторов нельзя. Однако создатель может [передать свои права](#Передача%20управления%20создателем) другому администратору и после этого выйти из управления либо попросить нового создателя об удалении.

### Администратор с полным доступом

Администратор этого типа обладает всеми доступами к настройкам, что и создатель приложения, кроме возможности удалить или переназначить [создателя](#Создатель).

Ниже — пояснения о выполняемых действиях.  

### Кто может редактировать список администраторов

Добавлять новых администраторов или удалять их может [создатель](#Создатель) и [администратор с полным доступом](#Администратор%20с%20полным%20доступом).

Администратор с полным доступом не может удалить или переназначить создателя приложения.

### Добавление администратора

* При добавлении нового администратора вам нужно указать ссылку на его страницу ВКонтакте. Подойдёт как обычная ссылка вида `https://vk.com/id743784474`, так и ссылка с [никнеймом](https://vk.com/faq18038) (коротким адресом), например `https://vk.com/persik_ryzhiy`.

* После того как вы подтвердите своё намерение добавить администратора, платформа отправит ему приглашение. Пользователь станет администратором только после того, как примет приглашение.

### Удаление администраторов

Удалять администраторов из списка могут создатель или администратор с полным доступом.

Удалить создателя из списка администраторов нельзя. Если создатель хочет выйти из администрирования, он должен [передать свои права](#Передача%20управления%20создателем) кому-либо из администраторов с полным доступом и затем отказаться от администрирования самостоятельно либо попросить нового создателя об удалении.

### Выход из администрирования

Администраторы с полным доступом могут отказаться от администрирования самостоятельно. Чтобы сделать это, просто нажмите **Отказаться от доступа** напротив своего имени в списке администраторов.

![alt=Выход из администрирования для администраторов с полным доступом;title=Выход из администрирования для администраторов с полным доступом](5254a9440191048c53e67f3fbbe5f8bcd5463d34c9ab7ffee19c8a4a "657684362368393404")

Создатель no-code приложения выйти из администрирования не может. Предварительно он должен сложить с себя обязанности создателя, [передав управление](#Передача%20управления%20создателем) кому-либо из администраторов с полным доступом.

### Передача управления создателем

[Создатель](#Создатель) может передать права кому-либо из администраторов с полным доступом. Чтобы сделать это, в разделе **Администраторы** он должен нажать **Передать доступ** и выбрать администратора с полным доступом для передачи прав.

![alt=Передача прав создателя;title=Передача прав создателя](d8c52dd127c640cc6d4b23ec87327b9d55ae41601e27565733a2b5ed "-4176835754610657355")

После подтверждения передачи прав создателем приложения будет назначен новый пользователь. Когда это произойдёт, предыдущий создатель сможет отказаться от администрирования.
