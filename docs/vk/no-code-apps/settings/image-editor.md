# Редактор изображений

> Источник: [https://dev.vk.ru/ru/no-code-apps/settings/image-editor](https://dev.vk.ru/ru/no-code-apps/settings/image-editor)
Во время настройки приложения вам нужно загружать изображения в разделах [Настройки](no-code-apps/settings/general) и [Контент](no-code-apps/settings/contents). Каждый раз при добавлении открывается редактор изображений. С его помощью вы можете обрезать картинку под нужные размеры, не используя сторонние редакторы.

## Как добавить изображение

1. В разделах **Настройки** или **Контент** нажмите **Загрузить**. Обратите внимание на тип поддерживаемых файлов: PNG, JPG и JPEG.

    ![alt=Загрузка изображения;title=Загрузка изображения](9e186b63f7a123a7c7fad6cc06033c5837b678c88bac24b2bbcfc7a1 "-4881646826668708008")

2. В открывшемся окне выберите изображение на вашем устройстве. Откроется редактор изображения.

    ![alt=Редактор изображения;title=Редактор изображения](06411b2810642f277b70440dd4d4e442439f3f6f1177480b58a7e684 "2954817736661326712")

3. Чтобы изменить область, которая будет обрезана, перемещайте уголки зоны с помощью мышки. При этом отношение высоты к ширине будет сохраняться.

     ![alt=Редактор изображения;title=Редактор изображения](fd1ed165305d975f8fd5216cc2eaa375890cf123d8d659322e504e00 "-1683335617454215942")

4. Если вы хотите поменять изображение, нажмите **Удалить** и загрузите новое изображение.

Некоторые настройки предусматривают загрузку нескольких изображений. Для этого нажмите кнопку **Добавить ещё** под загруженным изображением.
