# Приложения без кода — Панель управления

> Источник: [https://dev.vk.ru/ru/no-code-apps/settings/overview](https://dev.vk.ru/ru/no-code-apps/settings/overview)
Для создания и настройки приложений без кода используйте панель управления, которая доступна по адресу:

&nbsp;&nbsp;&nbsp;&nbsp;► https://dev.vk.com/admin/apps-list

Созданные без кода приложения отображаются в общем списке игр и приложений.
В меню слева доступны:

* Раздел **Созданные без кода**. В списке отображаются только те приложения, которые были созданы с помощью no-code конструктора. Чтобы перейти к [разделам](#Разделы) настройки приложения, нажмите **Настройки** напротив названия.
* Кнопка **Создать без кода**. Откроется форма для создания приложения. Подробнее о создании — в разделе [Как создать no-code приложение](no-code-apps/create).

## Вопросы и ответы

#### Кто может видеть настройки приложения?

Все [администраторы](no-code-apps/settings/managers) приложения.

#### Где найти ID и адрес приложения?

В панели управления в разделе [Публикация](no-code-apps/settings/publishing).

![alt=ID и адрес приложения;title=ID и адрес приложения](1739d04e3cff7736963d9d3e888aec93aad39e5cdb542dd3cb57d5b3 "6106742796777879980")

Адрес приложения имеет вид `https://vk.com/app12345`, где `12345` — ID вашего приложения, который присваивается автоматически при создании. Изменить идентификатор нельзя.

#### Можно ли изменить адрес приложения?

В настоящий момент такая возможность не предусмотрена. Используйте специальные сервисы для сокращения ссылок, чтобы получить более простой адрес.

#### Как запустить приложение со страницы настроек?

* Перейдите в панель управления и нажмите на иконку приложения.

    ![alt=Список приложений;title=Список приложений](7ef832e500164b22e26f7dfdf5700416f5fd8523e5110067064be7cd "-1010799544816062336")

    — или — 

* Откройте настройки приложения и перейдите на вкладку **Публикация**. Скопируйте URL приложения и откройте адрес в браузере.

    ![alt=URL приложения;title=URL приложения](66bd3f1de776faccbf598496da6de091e0fc1733e1ccdcaceaabbe4e "-8004190336317309016")

#### Можно ли выйти из управления?

Да. Это можно сделать в разделе [Администраторы](no-code-apps/settings/managers).

Создатель приложения должен сначала [передать права создателя](no-code-apps/settings/managers#Передача%20управления%20создателем) другому администратору и только потом выйти из управления.
