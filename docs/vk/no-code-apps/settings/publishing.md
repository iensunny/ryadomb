# Публикация

> Источник: [https://dev.vk.ru/ru/no-code-apps/settings/publishing](https://dev.vk.ru/ru/no-code-apps/settings/publishing)
В этом разделе можно настроить доступ пользователей к мини‑приложению, изменить видимость и отправить заявку на размещение приложения в каталоге.

## Как открыть

[Откройте панель управления no-code приложением](no-code-apps/settings/overview) и в меню слева выберите **Публикация**.

## Кому доступно

Раздел доступен всем [администраторам](no-code-apps/settings/managers) no-code приложения.

## Настройки

### Состояние приложения

Вы можете скопировать адрес приложения и настроить доступ:

* Включено — приложение доступно по ссылке. Все пользователи, у которых есть ссылка, могут открыть ваше приложение.
Подробнее о запуске — в разделе [Запуск и продвижение](no-code-apps/promotion#Как%20пользователи%20будут%20запускать%20приложение)
* Отключено — приложение недоступно по ссылке.

### Публикация в каталоге ВКонтакте

Перед подачей заявки убедитесь, что заполнили все обязательные поля и что приложение соответствует [правилам платформы](https://dev.vk.com/rules).

После размещения в каталоге приложение станет доступным для всех пользователей ВКонтакте.

### Статус заявки

Статус заявки отображается в этом же разделе. Чтобы посмотреть детали и переписку с модератором, нажмите **В тикет**.
