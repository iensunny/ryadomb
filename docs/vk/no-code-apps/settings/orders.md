# Заявки

> Источник: [https://dev.vk.ru/ru/no-code-apps/settings/orders](https://dev.vk.ru/ru/no-code-apps/settings/orders)
В этом разделе отображаются все заявки, которые пользователи оставляют в вашем приложении.

## Как открыть

[Откройте панель управления no-code приложением](no-code-apps/settings/overview) и в меню слева выберите **Заявки**.

## Кому доступно

Раздел доступен всем [администраторам](no-code-apps/settings/managers) no-code приложения.

## Действия с заявками

В разделе вы можете:

* Отфильтровать заявки по времени создания.

* Обработать заявки и пометить как просмотренные.

* Выгрузить в файл.

Подробнее о работе с заявками — в разделе [Обработка заявок](no-code-apps/orders).
