# Как создать no-code приложение

> Источник: [https://dev.vk.ru/ru/no-code-apps/create](https://dev.vk.ru/ru/no-code-apps/create)
Для создания [no-code приложений](no-code-apps/overview) не нужны специальные знания и опыт разработки. Все настройки выполняются визуально в специальной [панели управления](no-code-apps/settings/overview).

1. Войдите [ВКонтакте](https://vk.com).

2. Перейдите на портал разработчиков [dev.vk.com](https://dev.vk.com) и нажмите **Создать приложение**.

   В появившемся окне ничего не вводите, а в меню слева выберите **Создать без кода**. Откроется экран для создания приложения без кода.

   ![alt=Создание no-code приложения, первые шаги;title=Создание no-code приложения, первые шаги](f651c07a6b257771b3a2aebd4f47e8056ce9f54f1f3beedd91756851 "-8142159609993674513")

3. На экране создания приложения введите название приложения и выберите его категорию.

   ![alt=Ввод названия и категории приложения;title=Ввод названия и категории приложения](3359ad5100bd5e01834d87e373546d09a6beef4ca7216acfdcd641f2 "5402563391656445145")

   Название может совпадать с названием вашего предприятия или названием проводимой акции. Категория — это область работы вашей компании. В [каталоге мини-приложений](https://vk.com/services) приложения сгруппированы по категориям.

   На этом этапе вы можете ввести любые значения и изменить их позже.

   После ввода нажмите **Создать**. Платформа откроет панель управления приложением.

4. Используйте экраны панели управления, чтобы настроить приложение.

   ![alt=Пример панели управления с заполненными настройками;title=Пример панели управления с заполненными настройками](4e145b6bb7ae79df7b79e68e9dd0e283d2ec31b9f27b9cd81581deed "-8187086032321208638")

   Чтобы задать содержимое экрана приложения, используйте параметры в разделах [Настройки](no-code-apps/settings/general) и [Контент](no-code-apps/settings/contents). При необходимости вы можете скрыть блоки с главного экрана вашего приложения, кроме названия, описания и кнопки для отправки заявки.

   Описание настроек и рекомендации по заполнению — в [документации о панели управления](no-code-apps/settings/overview).

   При загрузке картинок открывается [редактор изображений](no-code-apps/settings/image-editor), в котором вы можете выбрать нужную область или использовать изображение целиком.

   **Совет.** При вводе данных и загрузке картинок время от времени пользуйтесь функцией предпросмотра. Это поможет понять, как ваше приложение будет выглядеть на мобильном устройстве и в десктопной версии сайта ВКонтакте.

   ![alt=Предпросмотр no-code приложения;title=Предпросмотр no-code приложения](197c3726e559d9f408c1ea65b406ae1e258061533e243552674c89d3 "-3533834323352993402")

5. По умолчанию приложение видно только его [администраторам](no-code-apps/settings/managers). Чтобы сделать его видимым всем пользователям ВКонтакте, перейдите в раздел [Публикация](no-code-apps/settings/publishing) и в блоке **Размещение на платформах** выберите **Состояние для пользователей &rarr; Включено**.

   ![alt=Включение приложения для пользователей;title=Включение приложения для пользователей](c5626a05c0c86937e5c0f6ef8903131026048c78f8b685ae2556fa55 "-3584454063570897651")

   Чтобы запустить приложение, пользователям надо открыть его адрес в браузере. URL для запуска отображается тут же, в разделе **Публикация**.

   ![alt=ID и адрес приложения;title=ID и адрес приложения](46de89dcc3c23a892fbe1cbc6181a94948e710995a9ea981b44274c4 "5772025130487845511")

   Вы можете указывать этот адрес на визитках, в рекламных материалах, на своём сайте, в переписке с друзьями и в других местах.

   Обратите внимание, что включение приложения не означает его размещение в [каталоге мини-приложений](https://vk.com/services). Добавление в каталог делает мини-приложение доступным широкому кругу пользователей ВКонтакте и видимым в поиске. Чтобы попасть в каталог, приложение должно пройти проверку нашими модераторами. Отправить заявку на добавление в каталог вы можете на странице настроек [Публикация](no-code-apps/settings/publishing).
