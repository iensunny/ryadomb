# Обработка заявок

> Источник: [https://dev.vk.ru/ru/no-code-apps/orders](https://dev.vk.ru/ru/no-code-apps/orders)
Все заявки, которые пользователи отправляют в [no-code приложении](no-code-apps/overview), отображаются в [панели управления](no-code-apps/settings/overview) этого приложения, в разделе [Заявки](no-code-apps/settings/orders). Этот раздел доступен всем [администраторам](no-code-apps/settings/managers) no-code приложения.

![alt=Раздел «Заявки» в панели управления;title=Раздел «Заявки» в панели управления](780094d4da8919aee6cf4cfbe19936337ec349ee1e95b1e82c30e9ac "2201481243658488151")

Когда пользователь оставляет заявку в приложении, платформа отправляет администратору с правами [создателя приложения](no-code-apps/settings/managers#Создатель) сообщение в мессенджере от Администрации ВКонтакте. <!-- Это сообщение является дополнительным уведомлением создателю.--> Другие администраторы такого уведомления не получают, но могут просматривать заявки в панели управления.

Администраторы могут обрабатывать заявки по списку, например позвонить пользователю или отправить ему email.

Если заявка была обработана, поставьте напротив неё галочку. Такие заявки называются «просмотренными». Необработанные заявки называются «новыми».

Для поиска нужной заявки укажите условия в начале страницы.

![alt=Условия отображения заявок;title=Условия отображения заявок](8858bf220893ef332f28bd737c7ddb72cb70537cc2045a4f5699164f "8269824916274223355")

## Экспорт заявок в файл

Ещё один способ работы с заявками — экспорт в файл и обработка в специальной системе работы с заявками (CRM) или в приложениях для работы с электронными таблицами, таких как Google Sheets или Microsoft Excel.

Чтобы экспортировать заявки:

1. В разделе настроек [Заявки](no-code-apps/settings/orders) укажите параметры для выбора заявок. Будут экспортированы только заявки, которые подпадают под выбранные условия.

2. Нажмите **Экспорт**. В последующем диалоговом окне выберите разделитель данных и нажмите **Экспортировать CSV**.

   ![alt=Экспорт заявок в файл;title=Экспорт заявок в файл](64ec3fe5d242667afd726e90fea0fd4da6b54bb99bb242ad3f233ca4 "-4027576813776376244")

   Платформа сгенерирует файл с данными и начнёт его загрузку. Вы можете найти его в папке на вашем устройстве, в котором расположены другие файлы, загруженные в браузере.

## О формате файла

* Каждая строка в файле соответствует одной заявке. Исключение — первая строка. Она содержит названия колонок.

* Данные заявки в строке: имя пользователя, телефон и другие — разделены символом, который вы выбрали при экспорте. Такие файлы называются CSV-файлами (comma-separated values).

  Каждое значение заключено в кавычки.

Если при открытии скачанного файла происходит ошибка, попробуйте экспортировать данные ещё раз, но выберите другой разделитель.
