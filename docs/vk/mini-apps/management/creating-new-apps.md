# Создание новых приложений

Регистрация новых приложений в старой панели управления невозможна. Используйте эту панель для просмотра и работы с настройками приложений, если новая панель управления по какой-либо причине вам не подходит.

## Чтобы зарегистрировать новое приложение

Воспользуйтесь следующими ссылками:

| Новая панель управления | Сервис авторизации VK ID |
| --- | --- |
| ► [**Мини-приложение** или **игра**](https://dev.vk.com/admin/create-app "Переход в новую панель управления")&#x0d;&#x0a;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Запускаются в UI ВКонтакте. | ► [**Standalone-приложение**](https://id.vk.com/business/go?utm_source=vk_editapp&utm_medium=referral&utm_campaign=seo_auth_con_serv "Переход в сервис авторизации VK ID")&#x0d;&#x0a;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Стороннее приложение, которое&#x0d;&#x0a;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;будет работать с API ВКонтакте. |
| ► [**No-code приложение**](https://dev.vk.com/ru/admin/create-app?nocode=true  "Переход в новую панель управления")&#x0d;&#x0a;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Запускается в UI ВКонтакте.&#x0d;&#x0a;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Не требует написания кода. | ► [**Сайт**](https://id.vk.com/business/go?utm_source=vk_editapp&utm_medium=referral&utm_campaign=seo_auth_con_serv  "Переход в сервис авторизации VK ID")&#x0d;&#x0a;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Сайт или веб-приложение, которое будет работать&#x0d;&#x0a;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;с API ВКонтакте или использовать виджеты ВКонтакте. |
| ► [**Скилл Маруси**](https://dev.vk.com/admin/apps-list "Переход в новую панель управления")&#x0d;&#x0a;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Приложение, которое будет&#x0d;&#x0a;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;добавлено в базу скиллов Маруси. | |

Подробнее о типах приложений, поддерживаемых на платформе, и разнице между ними — в разделе [Типы приложений](general/app-types).
