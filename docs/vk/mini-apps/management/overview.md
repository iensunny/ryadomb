# Старая панель управления — Обзор

Этот раздел описывает настройки мини-приложения в старой панели управления. Чтобы открыть их, перейдите по ссылке [Мои приложения](https://vk.com/apps?act=manage) и нажмите **Редактировать** напротив названия мини-приложения. В левом меню вы увидите следующие разделы:

* [Информация](mini-apps/management/information)
* [Настройки](mini-apps/management/settings)
* [Хранимые процедуры](mini-apps/management/procedures)
* [Статистика](mini-apps/management/statistics)
* [Платежи](mini-apps/management/payments)
* [Руководство](mini-apps/management/admin)
* [Тестирование](mini-apps/management/testing)
* [Модерация](mini-apps/management/moderation)
* [Уведомления](mini-apps/management/notifications) (только в мини-приложениях из каталога)
* [Помощь](mini-apps/management/support)

&nbsp;

Описание новых настроек - [в новом разделе документации](mini-apps/settings/overview).
