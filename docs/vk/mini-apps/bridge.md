# Библиотека VK Bridge

Платформа мини-приложений VK Mini Apps использует для взаимодействия с ВКонтакте библиотеку VK Bridge. Подробнее о том, как подключить и использовать библиотеку, читайте в разделе [VK Bridge | Первые шаги](bridge/getting-started). 

## События VK Bridge

Библиотека VK Bridge включает события для реализации различных механик в мини-приложении: управления доступом, монетизации, взаимодействия с пользователями, работы с датчиками мобильных устройств и многого другого. Эти механики обеспечивают широкие возможности для создания функциональных и удобных мини-приложений на платформе ВКонтакте.

Подробнее обо всех событиях, которые доступны в библиотеке, – в разделе [VK Bridge | Обзор](bridge/overview).
