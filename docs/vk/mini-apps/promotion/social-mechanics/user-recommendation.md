# Механика пользовательских рекомендаций

> Источник: [https://dev.vk.ru/ru/mini-apps/promotion/social-mechanics/user-recommendation](https://dev.vk.ru/ru/mini-apps/promotion/social-mechanics/user-recommendation)
После того как мини-приложение попало в каталог, для него начинает работать механика пользовательских рекомендаций. Пользователь, который запустил приложение, может порекомендовать его своим друзьям одним из способов:

* [Из модального окна](#Рекомендация%20приложения%20из%20модального%20окна)
* [Из меню приложения](#Рекомендация%20приложения%20из%20меню)

Друзья пользователя получат push-уведомление в колокольчик.

:::note
**Важно!** Механика пользовательских рекомендаций доступна только мини-приложениям из [каталога](mini-apps/catalog/getting-started).
:::

## Ограничения

* Уведомления получат только те пользователи, которые не запускали приложение более 30 дней.
* Уведомление о рекомендации приложения приходит 1 раз от одного пользователя. Если уже три друга порекомендовали приложение, а пользователь так и не запустил его, то повторное уведомление придёт через 7 дней, затем через 180 дней.
* Для одного приложения уведомление приходит не чаще 1 раза в день.
* Механика не работает для [плагинов](plugins/overview).

## Рекомендация приложения из модального окна

Вы можете показать модальное окно с предложением порекомендовать мини-приложение с помощью события библиотеки [VK Bridge](bridge/overview).

<!--exclusions\_images\mini-apps\promotion\modal-android-2.png-->
![alt=Модальное окно;title=Модальное окно](9fbec02b70015246d68ab02e8ea29ba419feb19929736744b2192d12 "-7690944557749306050")

Используйте событие [`VKWebAppRecommend`](bridge/VKWebAppRecommend).

```JavaScript
bridge.send('VKWebAppRecommend')
  .then((data) => { 
    if (data.result) {
      // Мини-приложение порекомендовано
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

* Не показывайте окно с предложением рекомендовать мини-приложение слишком часто. Продумайте алгоритм показа, чтобы не надоедать пользователю.
* Учитывайте значение параметра запуска [`vk_is_recommended`](mini-apps/development/launch-params), чтобы не показывать окно тем пользователям, которые уже порекомендовали приложение.

## Рекомендация приложения из меню

Пользователь может порекомендовать приложение, используя пункт меню. У каждого мини-приложения из каталога есть кнопка **Рекомендовать**.

Чтобы отравить рекомендацию друзьям, пользователю нужно:

1. Запустить мини-приложение.
1. Нажать на &bull;&bull;&bull; в правом верхнем углу.
1. Нажать на кнопку **Рекомендовать**.

Когда мини-приложение уже рекомендовано, надпись на кнопке меняется на **Вы рекомендуете**. Повторным нажатием пользователь может отозвать рекомендацию.

## Если приложение порекомендовано

10 лучших друзей пользователя получат push-уведомление в колокольчик о том, что их друг рекомендует мини-приложение. На количество и частоту отправок уведомлений действуют [ограничения](#Ограничения).

## Как пользователь может отключить уведомления

Если пользователь не хочет получать уведомления о рекомендованных приложениях, ему нужно:

1. В десктопной версии сайта ВКонтакте нажать на **Мой профиль** и выбрать **Настройки**.

    ![alt=Настройки профиля;title=Настройки профиля](0bd3efb66c1fee542b44d01698b4d4d6986412b0319d2cbe13ac555e "-6538885797241486086")

1. Нажать на **Уведомления** и в блоке **Другое** изменить видимость уведомлений.

    ![alt=Настройка уведомлений;title=Настройка уведомлений](b95c08685c7210b39a19eac3cd3549162e5ea5f3be137432ef67d6ca "4308621257371805442")
