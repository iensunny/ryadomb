# Размещение (настройки мини-приложений)

> Источник: [https://dev.vk.ru/ru/mini-apps/settings/general/placement](https://dev.vk.ru/ru/mini-apps/settings/general/placement)
Раздел содержит настройки, которые необходимы для запуска мини-приложения из интерфейса площадок ВКонтакте и Одноклассники.

:::note
**Важно!** Если настройки размещения не указаны, мини-приложение не будет работать.
:::

**Чтобы открыть раздел:**

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).
1. Откройте настройки нужного мини-приложения.
1. В меню слева выберите **Размещение**.

## Доступ

Редактировать настройки размещения может:

* Создатель мини-приложения.
* Администратор с полным доступом.
* Администратор с частичным доступом, с правом «Редактирование».

Подробнее о правах — в разделе [Администраторы](mini-apps/settings/managers).

## Состояние для пользователей

Настройка указывает, кому доступно мини-приложение

|  Состояние | Описание |
| --- | --- |
| **Отключено** | Состояние мини-приложения сразу после создания. Приложение с таким состоянием доступно только администраторам. Они могут запускать мини-приложение по прямой ссылке `https://vk.com/app{id}`.&#x0d;&#x0a;&#x0d;&#x0a;Чтобы опубликовать приложение в Одноклассниках, нужно привязать OK ID в разделе [Другие площадки](mini-apps/settings/general/other-sites). Мини-приложение станет доступно в Одноклассниках в течение 15 минут. |
| **Включено** | Мини-приложение ВКонтакте станет доступно по ссылке всем пользователям.&#x0d;&#x0a;&#x0d;&#x0a;В Одноклассниках доступ будет только у создателя приложения. Чтобы приложение стало доступно всем пользователям, нужно пройти [модерацию](mini-apps/settings/moderation). |

Подробнее о размещении приложения в Одноклассниках — в разделе [Публикация в Одноклассниках](ok/publishing).

## Настройки платформ

Раздел содержит настройки запуска мини-приложения для различных платформ ВКонтакте. Вы можете настроить запуск приложения на всех доступных платформах или выбрать только необходимые.

| Раздел | Описание |
| --- | --- |
| **Мобильное приложение** | Настройки для запуска мини-приложения из мобильного приложения ВКонтакте и Одноклассники для Android и iOS.&#x0d;&#x0a;&#x0d;&#x0a;Приложение будет открываться в элементе управления WebView и будет выглядеть похожим на обычные приложения для Android и iOS. |
| **Десктопная&nbsp;версия&nbsp;сайта** | Настройки для запуска мини-приложения из десктопной версии сайта ВКонтакте ([vk.com](https://vk.com)) и Одноклассники ([ok.ru](https://ok.ru)).&#x0d;&#x0a;&#x0d;&#x0a;В браузере у пользователя будет открыта страница сайта vk.com, а приложение будет загружено в HTML-элемент `<iframe>` на этой странице. |
| **Мобильная версия сайта** | Настройки для запуска мини-приложения из мобильной версии сайта ВКонтакте ([m.vk.com](https://m.vk.com)) и Одноклассники ([m.ok.ru](https://m.ok.ru)).&#x0d;&#x0a;&#x0d;&#x0a;Приложение будет открываться в элементе управления WebView и будет выглядеть похожим на обычные приложения для Android и iOS. |

### URL

Адрес для запуска мини-приложения. Платформа отправит этот адрес в WebView или в `<iframe>` для загрузки.

Чтобы передать параметры, укажите их в URL после символа `?`, например `https://my-app.com/start?param1=value1`.

### Режим разработки

Используйте эту настройку, чтобы включить или отключить режим разработки. В поле укажите адрес, по которому будет доступна версия игры только для администраторов.

Режим разработки полезен, когда мини-приложение уже опубликовано в каталоге, но вам надо проверить изменения в нём. Этот режим работает для всех [администраторов](mini-apps/settings/managers) мини-приложения. Когда они запустят мини-приложение, платформа ВКонтакте загрузит его из адреса, указанного в настройке **Режим разработки**, а не из настройки **URL**. Для остальных пользователей мини-приложение продолжит открываться по **URL**, для них подмены не произойдёт.

### Приоритеты URL для загрузки мини-приложения

Когда администратор запускает мини-приложение, URL для загрузки определяется в следующем порядке. 

1. URL, указанный в настройках [тестовой группы](mini-apps/settings/test-groups), если администратор включён в какую-либо тестовую группу. Этот URL имеет наивысший приоритет относительно остальных.

1. URL, указанный для режима разработки, если режим разработки включён для выбранной платформы.

1. URL, указанный в настройке [URL](#URL). Приоритет этого URL ниже адресов, указанных в тестовой группе или в режиме разработки.

## Удалить приложение

Чтобы удалить мини-приложение с платформы VK Mini Apps, в правом нижнем углу страницы нажмите **Удалить приложение**. Кнопка доступна только [создателю](mini-apps/settings/managers#Создатель) мини-приложения.

> Удалённое мини-приложение нельзя восстановить. Можно создать новое с другим идентификатором.
