# Подключение (настройки мини-приложений)

Мини-приложения могут предоставлять [виртуальные ценности](mini-apps/glossary#Виртуальная%20ценность) за [голоса ВКонтакте](mini-apps/glossary#Голос) и [ОКи в Одноклассниках](mini-apps/glossary#ОКи).

В разделе **Подключение** вы можете указать параметры для выполнения платежей. Кроме того, здесь можно просмотреть журнал платёжных уведомлений.

Если вы планируете предоставлять виртуальные ценности за голоса и ОКи, зарегистрируйтесь в [кабинете выплат](https://cashout.vk.com/).

Подробнее:

* О регистрации в кабинете выплат и получении вознаграждения — в разделе [Вывод средств](mini-apps/monetization/withdrawal/overview).
* О продаже виртуальных ценностей — в разделе [Платежи виртуальной валютой](api/payments/overview).

**Чтобы открыть раздел:**

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).
2. Откройте настройки нужного мини-приложения.
3. В меню слева выберите **Платежи**&nbsp;&rarr; **Подключение**.

## Доступ

Получить доступ к разделу может:

* Создатель мини-приложения.
* Администратор с полным доступом.
* Администратор с частичным доступом, с правом «Платежи».

Подробнее о правах — в разделе [администраторы](mini-apps/settings/managers).

## Настройки

Эта вкладка содержит настройки, необходимые для работы платежей.

:::note
**Важно!** Для плагинов сообществ в разделе **Платежи** можно настроить только параметры платежей ВКонтакте. Приложение для групп в Одноклассниках вы можете создать непосредственно на сайте ok.ru. Подробнее — в документации [API Одноклассники](https://apiok.ru/apps/groups).
:::

### URL для платёжных уведомлений ВКонтакте

При продаже виртуальных ценностей площадка запрашивает у мини-приложения информацию о товарах, а также отправляет уведомления о покупке или возврате. 

Эта настройка указывает URL на сервере приложения, на который будут отправляться запросы о товарах и уведомления о платежах. Сервер мини-приложения должен обрабатывать запросы, поступающие на этот адрес, и предоставлять ответы.

<!-- exclusions/_images/mini-apps/settings/payments/url-vk.png -->
![alt=URL для платёжных уведомлений ВКонтакте;title=URL для платёжных уведомлений ВКонтакте](1e9b890d41d3bcc42ff43af1a3c23ce5b398482bfbefe7407c02d7d9 "2936798697402240986")

* Для мини-приложений ВКонтакте на этот URL оправляются все уведомления для получения информации о товаре и подписке, а также уведомления о покупке. Подробнее — в разделе [Обработка платёжных уведомлений ВКонтакте](api/payments/notifications/vk).
* Для мини-приложений в Одноклассниках на этот URL оправляется только уведомление [`get_item`](api/payments/notifications/get-item) для получения информации о виртуальном товаре. Подробнее — в разделе [Обработка платёжных уведомлений в Одноклассниках](api/payments/notifications/ok).

### URL для платёжных уведомлений Одноклассников

Эта настройка указывает URL на сервере мини-приложения, на который будут отправляться запросы о покупке товаров и подписок в Одноклассниках. Подробнее — в разделе [Обработка платёжных уведомлений в Одноклассниках](api/payments/notifications/ok).

### Тестировщики платежей

Список [администраторов мини-приложения](mini-apps/settings/managers), для которых платежи будут работать в тестовом режиме. Платформа ВКонтакте не будет списывать средства со счетов этих пользователей при выполнении платежей.

Если мини-приложение не прошло модерацию, то платежи доступны только пользователям, указанным в списке **Тестировщики платежей**. После прохождения модерации платежи становятся доступны всем пользователям, но для тестировщиков платежей они продолжают работать в тестовом режиме.

Подробнее о тестировании платежей ВКонтакте и в Одноклассниках — в разделе [Тестирование платежей](api/payments/testing).

### Версия API

Формат платёжных уведомлений может меняться при изменении API ВКонтакте. Используйте эту настройку, чтобы указать версию API ВКонтакте, ожидаемую сервером мини-приложения. Платформа ВКонтакте будет отправлять серверу мини-приложения уведомления в формате, который поддерживается в указанной версии.

> Настройка доступна для мини-приложений, которые были зарегистрированы на платформе до января 2024 года. Мини-приложения, зарегистрированные позже, используют формат платёжных уведомлений, принятый в версии 5.132 API ВКонтакте. Описание формата — в разделе [Платежи виртуальной валютой](api/payments/overview).

## Логи

При продаже товаров и подписок платформа ВКонтакте отправляет серверу мини-приложения запросы для получения информации о товарах и уведомления об оплате или возврате.

Вкладка **Логи** содержит журнал таких сообщений. Используйте эту информацию для отладки платежей в вашем мини-приложении и проверки обмена данными.

<!-- exclusions/_images/mini-apps/settings/payments/logs.png -->
![alt=Пример уведомлений на вкладке «Логи»;title=Пример уведомлений на вкладке «Логи»](d8272928cdf3543936b30bc56f9ec9e0a29e47cc11eb4e492d8ff812 "18661123226343681")

**Запрос** — это данные, которые пришли от ВКонтакте вашему серверу. **Ответ** — это данные, которые ваш сервер отправил платформе ВКонтакте. Параметры запросов и формат ответов зависят от типа уведомления, который указан в параметре `notification_type` запроса. Описание параметров и форматов данных — в разделе [Платежи виртуальной валютой](api/payments/notifications/vk).

## Оплата голосами

Чтобы мини-приложение могло работать с голосами, отправьте его на проверку модераторам ВКонтакте. Подробнее — в разделе [Модерация](mini-apps/settings/moderation).

:::note
**Важно.** До отправки заявки убедитесь, что зарегистрировались в [кабинете выплат](https://cashout.vk.com/) и что платежи работают правильно. Они заработают для всех пользователей сразу после прохождения модерации.

Подробнее о регистрации в кабинете выплат и получении вознаграждения — в разделе [Вывод средств](mini-apps/monetization/withdrawal/overview).
:::
