# Ключи доступа (настройки мини-приложений)

В этом разделе вы можете просмотреть и обновить ключи доступа, необходимые для работы с мини-приложением. Значения ключей генерируются автоматически при создании мини-приложения.

**Чтобы открыть раздел**

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).
1. Откройте настройки нужного приложения.
1. В меню слева выберите **Разработка&nbsp;&rarr; Ключи доступа**.

## Доступ

Редактировать ключи доступа может:

* Создатель мини-приложения.

* Администратор с полным доступом.

* Администратор с частичным доступом, с правом «Редактирование».

Подробнее о правах — в разделе [Администраторы](mini-apps/settings/managers).

## Защищённый ключ

Библиотеки ВКонтакте могут использовать защищённый ключ на стороне пользователя для различных целей. Например, для [проверки подписи параметров запуска](mini-apps/development/launch-params-sign) или для [проверки подлинности данных](mini-apps/development/protect-with-signature).

## Сервисный ключ

[Сервисный ключ](api/access-token/getting-started) используется для отправки запросов API VK из серверной части мини-приложения, например запросов группы [secure](method/secure).

:::note
**Важно!** Не передавайте и не используйте сервисный ключ в коде на стороне пользователя. Это небезопасно. Работайте с сервисным ключом доступа только в серверной части мини-приложения.
:::

## Публичный ключ

Публичный ключ используется совместно с [защищённым ключом](#Защищённый%20ключ) для взаимодействия с методами [API Одноклассников](https://apiok.ru/dev/methods/rest/) от имени приложения. Ключ отобразится после того, как мини-приложение будет подключено к Одноклассникам в разделе [Другие площадки](mini-apps/settings/general/other-sites).

Подробнее об использовании ключа – в разделе [Вызовы API на стороне сервера](ok/development/api#Вызовы%20API%20на%20стороне%20сервера).

## Работа с ключами

### Скопировать ключ

Чтобы скопировать ключ, нажмите **Показать** → **Просмотреть** и затем подтвердите действие предложенным способом.

### Изменить ключ

Чтобы обновить значение ключа, нажмите **Создать новый** → **Сменить** и затем подтвердите действие предложенным способом.

После создания нового ключа старый будет восстановить невозможно. Обновите значение ключа в коде вашего мини-приложения.
