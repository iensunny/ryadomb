# Урок 1. Планирование тестирования: выявление приоритетов

:::vkvideo
https://vk.com/video-166562603_456239261
:::

## Главное в уроке

* В приложении много функций, поэтому можно не успеть протестировать всё. Чтобы расставить приоритеты, определите ключевые функции.
* Ключевые функции приложения помогают достичь целей пользователей и заказчиков.
* Даже если в приложении работает каждая функция — это не значит, что пользователь сможет достигнуть цели. Перечислите ключевые функции и сформируйте из них сценарии использования приложения.
