:::vkvideo

## Главное в уроке

* Чтобы запустить мини-приложение локально:

    * Перейдите в директорию, в которой хранится код.
    * Выполните в терминале команду `npm run start`.
    * Откройте в браузере адрес [https://localhost:10888](https://localhost:10888).

* На этом этапе удобно отслеживать все вносимые в код мини-приложения изменения, так как можно:

    * Взаимодействовать с интерфейсом приложения, а не только с кодом.
    * Видеть, как будет выглядеть приложение на разных разрешениях экрана.
    * Понимать, как будут вести себя интегрированные изображения и видео.

* Используйте библиотеку vk-bridge-mock, чтобы протестировать работу событий библиотеки VK Bridge локально.
