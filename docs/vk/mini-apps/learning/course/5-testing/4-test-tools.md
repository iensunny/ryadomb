## Главное в уроке

* Сhrome — самый популярный браузер, поэтому при создании приложения стоит ориентироваться именно на корректную работу в нём.
* Сhrome DevTools позволяет отображать код и сообщения об ошибках, редактировать HTML и CSS, измерять скорость загрузки страницы. 
* Аналог DevTools на iOS — веб-инспектор в Safari.
* Eruda — это консоль с инструментами разработчика для отладки приложений, которая работает подобно консоли браузера, удобна для работы с мобильным вебом.
* Приложение должно запускаться менее чем за 5 секунд, чтобы пользователи не уходили раньше, чем оно откроется.
* LightHouse — инструмент, который поможет проанализировать скорость открытия и работы приложения.
