# Урок 7. Тестирование ODR в VK Mini Apps

:::note
Технология ODR использовалась в мини-приложениях, работающих на iOS. C 13 августа 2024 года поддержка ODR больше не требуется.

Мини-приложения и игры, которые опубликованы в каталоге на iOS, открываются [напрямую](mini-apps/development/iframe-webview) ВКонтакте и для пользователей выглядят как часть мобильного приложения ВКонтакте для iOS. Мини-приложения и игры, которые не опубликованы в каталоге на iOS, открываются в мобильной версии сайта ВКонтакте ([m.vk.com](https://m.vk.com)).

Раздел настроек «ODR» был удалён из панели управления мини-приложения. Параметр запуска `odr_enabled` больше не передаётся мини-приложению или игре при старте.
:::

## Главное в уроке

* Основная цель ODR — оптимизация использования ресурсов устройства, снижение объёма загружаемых данных и улучшение производительности.
* Наличие ODR обязательно для прохождения модерации ВКонтакте, нативного отображения вашего приложения на iPhone и iPad и попадания вашего приложения в каталог мини-приложений для iOS.
* При тестировании ODR необходимо проверить, что:

   * Приложение открылось и загрузилось.
   * Разделы работают корректно.
   * Можно пройти пользовательский сценарий.
   * Внутри приложения работает навигация.
   * Корректно отображается медиа.
   * Открываются внешние ссылки.
   * Мини-приложение есть на вкладке **Сервисы**.
   * Внешние ресурсы работают.
