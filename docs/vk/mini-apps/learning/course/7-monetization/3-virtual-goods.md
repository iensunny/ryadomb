# Урок 3. Продажа виртуальных ценностей за голоса

:::vkvideo
https://vk.com/video-166562603_456239259
:::

## Главное в уроке

* Виртуальные ценности — это то, что пользователь может использовать в рамках вашего мини-приложения: игровая валюта, дополнительные функции, улучшение персонажа, отключение рекламы.
* Вы можете использовать два варианта платежей: разовые и периодические (подписки). В зависимости от логики вашего мини-приложения, определите, какая модель вам подходит больше, или используйте обе.
*  Продажа и покупка виртуальных товаров удобна для всех участников процесса: разработчику не нужно думать, как вывести средства из приложения — об этом позаботится ВКонтакте, а у пользователей есть много вариантов приобретения голосов для оплаты виртуальных ценностей.
* Обратите внимание на правила использования этого способа монетизации: 

    * Чтобы продавать товары за голоса, нужно пройти [модерацию](mini-apps/settings/moderation).
    * Вывод средств доступен только главному администратору.
    * Нельзя продавать товары за голоса и товары за денежные средства в одном приложении.
