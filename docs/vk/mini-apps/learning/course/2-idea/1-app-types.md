## Главное в уроке

* Мини-приложения ВКонтакте — это встраиваемые мини-приложения, которые помогают решать прикладные задачи.
* Перейти в мини-приложение пользователи могут из каталога, поиска, со страницы другого пользователя, из мессенджера или другого мини-приложения.
* Вы можете создать:
  * Открытое приложение. Оно будет доступно в каталоге любому пользователю.
  * Приложение с доступом только по ссылке. Такие приложения в каталоге не отображаются.
  * Плагин для сообщества. Это отдельный вид приложений, которые работают только внутри сообщества.
* В каталоге мини-приложений ВКонтакте более 20 категорий. Наиболее популярные среди пользователей ― «Развлечения», «Общение», «Образ жизни» и «Инструменты».
