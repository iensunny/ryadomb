:::vkvideo

## Главное в уроке

Перед созданием мини-приложения проведите анализ рынка, чтобы определить, где может взлететь ваш продукт.
- Изучите отрасль. Определите, где ваше мини-приложение может быть полезно.
- Проанализируйте целевую аудиторию.
- Изучите конкурентов. Определите, кто предоставляет подобные услуги.
- Определите, какие задачи целевой аудитории и каким образом может решить ваш продукт.
- Решите, каким образом будет монетизироваться ваш продукт.
- Обработайте всю собранную информацию.
- Оцените риски проекта.
