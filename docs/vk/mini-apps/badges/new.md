# Бейдж New для новых мини-приложений

На мини-приложениях, которые добавлены в [подборку «Новые»](mini-apps/promotion/featured#Новые), автоматически рисуется бейдж **New**.

Бейдж **New** показывается на [иконке мини-приложения в каталоге](mini-apps/settings/general/design#Иконка%20для%20каталога%20и%20сниппетов).

В самой подборке «Новые» бейдж не рисуется.

![alt=Подборка «Новые»;title=Подборка «Новые»;](34d60acd4811295f00d57e7422a17de5048b39b3942919509bbba7e6 "8730072806586354078")

* После того как пользователь в первый раз откроет мини-приложение, бейдж **New** для него перестанет отображаться на иконке приложения.
* Программно подключить или отключить бейдж нельзя.
* Бейдж показывается только в десктопной и мобильной версиях ВКонтакте.
