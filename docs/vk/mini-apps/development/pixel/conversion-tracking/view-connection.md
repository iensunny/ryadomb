# Проверка, что событие установлено корректно

> Источник: [https://dev.vk.ru/ru/mini-apps/development/pixel/conversion-tracking/view-connection](https://dev.vk.ru/ru/mini-apps/development/pixel/conversion-tracking/view-connection)
Для диагностики:

1. Откройте страницу сайта, на которой установлен пиксель.
1. Откройте **Console** в браузере. Для этого просмотрите код страницы; можно воспользоваться комбинацией клавиш:
    
    * `Ctrl + Shift + I` для Windows.
    * `⌥ + ⌘ + I` для macOS.

1. Перейдите на вкладку **Cеть** (**Network**).
1. Отфильтруйте вызовы по слову `rtrg`. В результате вы будете наблюдать все вызовы пикселя в конверсии.

    * Название события, в данном случае «Конверсия».
