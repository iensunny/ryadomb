# Обзор

> Источник: [https://dev.vk.ru/ru/mini-apps/development/pixel/conversion-tracking/overview](https://dev.vk.ru/ru/mini-apps/development/pixel/conversion-tracking/overview)
Конверсия — это целевые действия, которые совершают посетители на вашем сайте. Данные о конверсиях позволяют анализировать эффективность рекламы и её окупаемость.

Например, конверсией может быть просмотр контактной информации о компании, регистрация, отправка контактных данных пользователя для звонка или оформление заказа.

С помощью [пикселя](mini-apps/development/pixel/overview) вы можете отслеживать конверсионные действия пользователей на сайте прямо в рекламном кабинете.

После настройки отслеживания конверсий вы можете оптимизировать рекламу для максимального увеличения их числа.

Отслеживание конверсий доступно для всех рекламных форматов ВКонтакте и считается в течение 7 дней с момента перехода по рекламе.
