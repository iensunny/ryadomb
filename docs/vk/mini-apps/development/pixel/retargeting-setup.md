# Настройка ретаргетинга по событиям на сайте

> Источник: [https://dev.vk.ru/ru/mini-apps/development/pixel/retargeting-setup](https://dev.vk.ru/ru/mini-apps/development/pixel/retargeting-setup)
С помощью событий можно выполнять гибкую настройку ретаргетинга на сайте и создавать продвинутые условия для сбора пользователей. Несколько простых примеров:

* Нажатие по кнопке.
* Взаимодействие с формой.
* Использование поиска.
* Регистрация на сайте.

Список событий ограничен только вашей фантазией. Например, вы можете собирать в аудиторию ретаргетинга пользователей из Нижневартовска, которые начали заполнять заявку или оформлять заказ, но не завершили действие. Любые последовательности, которые вы можете выявить на своём сайте, можно использовать в ретаргетинге. Чтобы использовать события на своём сайте нужно обладать минимальными знаниями HTML и JavaScript. События могут быть  интегрированы с [Google Tag Manager](mini-apps/development/pixel/faq/#Можно%20ли%20добавить%20пиксель%20через%20Google%20Tag%20Manager?) для удобной работы.

:::note
**Примечание.** Эти события подходят только для сбора аудиторий ретрагетинга. 
:::

## Настройка правил событий

После того как вы разметили события на сайте, вам нужно настроить правила для аудиторий ретаргетинга, по которым будут собираться пользователи.

Без правил ваши пользователи будут учитываться пикселем ВКонтакте, но не будут сохраняться в аудитории, а значит, вы не сможете использовать их в рекламе.

Чтобы настроить правила для событий, используйте инструкцию [Создание аудитории](mini-apps/development/pixel/audience-work#Создание%20аудитории).
