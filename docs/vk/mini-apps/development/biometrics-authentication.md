# Аутентификация с помощью биометрии

> Источник: [https://dev.vk.ru/ru/mini-apps/development/biometrics-authentication](https://dev.vk.ru/ru/mini-apps/development/biometrics-authentication)
Для доступа пользователей в мини-приложение вы можете использовать вход по их биометрическим данным: отпечатку пальца или изображению лица. Реализовать такую аутентификацию помогут [события](#Как%20реализовать) библиотеки VK Bridge.

Использование аутентификации по биометрическим данным поможет вам защитить персональные данные пользователей и добавить дополнительную проверку перед входом в мини-приложение.

## На каких устройствах доступна

* Аутентификация будет работать только на тех устройствах, на которых доступно использование биометрии: отпечатка пальца, изображения лица или и того, и другого.
* Использовать вход по биометрическим данным можно только на устройствах с операционной системой iOS или Android.
* На некоторых устройствах с операционной системой Android, которые поддерживают биометрические данные, аутентификация по лицу может быть недоступна.

## Как это работает

Процесс аутентификации выглядит так.

### Если аутентификация не подключена

1. Мини-приложение должно запросить разрешение пользователя на вход с использованием биометрических данных: отпечатку пальца или лицу, в зависимости от того, какой способ доступен и выбран пользователем для доступа к устройству.
    ![alt=Окно подтверждения использования биометрии;title=Окно подтверждения использования биометрии](7c9f6af24aab1491e95e95b30c7822fdeb5aafe4e7dd9d17d256a07b "3783887181111224005")

    В этот момент мини-приложение запрашивает разрешение на использование биометрии и [создаёт](#Создание%20ключа%20доступа) ключ доступа — в защищённое хранилище на устройстве записывается произвольная строка, заданная разработчиком. 
1. После этого при каждом входе пользователь авторизуется в мини-приложении с помощью биометрии. Строка, сохранённая на устройстве, [возвращается из хранилища](#Получение%20ключа%20доступа) по отпечатку пальца или изображению лица.
1. Разработчик использует полученное значение в качестве ключа доступа к данным.

    Чтобы авторизовать пользователя в мини-приложении, нужно сравнить полученный ключ доступа с тем, который хранится в мини-приложении. Мы рекомендуем сравнивать ключи в серверной части мини-приложения.

### Если аутентификация подключена

1. Пользователь запускает мини-приложение и подтверждает вход с помощью биометрии. Строка, сохранённая на устройстве, [возвращается из хранилища](#Получение%20ключа%20доступа) по отпечатку пальца или изображению лица.
1. Разработчик использует полученное значение в качестве ключа доступа к данным.

    Чтобы авторизовать пользователя в мини-приложении, нужно сравнить полученный ключ доступа с тем, который хранится в мини-приложении. Мы рекомендуем сравнивать ключи в серверной части мини-приложения.

## Как реализовать

Чтобы добавить аутентификацию пользователей в ваше мини-приложение, используйте события библиотеки [VK Bridge](bridge/overview).

### Создание ключа доступа

1. Запросите у пользователя разрешение на использование биометрии с помощью события [`VKWebAppSecureTokenRequestAccess`](bridge/VKWebAppSecureTokenRequestAccess).
1. Создайте ключ доступа с помощью события [`VKWebAppSecureTokenSet`](bridge/VKWebAppSecureTokenSet) — произвольную строку, уникальную для мини-приложения.

### Получение ключа доступа

1. Используйте событие [`VKWebAppSecureTokenGetInfo`](bridge/VKWebAppSecureTokenGetInfo), чтобы проверить, сохранён ли ключ доступа на устройстве. 
2. Получите ключ доступа с помощью события [`VKWebAppSecureTokenGet`](bridge/VKWebAppSecureTokenGet).

### Получение сведений

Используйте событие [`VKWebAppSecureTokenGetInfo`](bridge/VKWebAppSecureTokenGetInfo), чтобы проверить, доступна ли биометрия на устройстве и запрашивалось ли разрешение пользователя для аутентификацию по биометрии в мини-приложении.

### Удаление ключа доступа

Чтобы удалить ключ доступа из хранилища, используйте событие [`VKWebAppSecureTokenRemove`](bridge/VKWebAppSecureTokenRemove).
