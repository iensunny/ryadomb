# Интеграция звонков в мини-приложения

У разработчиков есть возможность интегрировать VK Звонки в свои мини-приложения и  [игры](games/overview). Это даёт пользователям возможность созваниваться прямо внутри мини-приложения, не открывая профиль пользователя, список друзей или раздел звонков.

Создавать звонки внутри мини-приложения удобно, когда есть совместная активность и нужно созвониться с другими участниками: членами своей команды в игре, друзьями для составления списка покупок в поход, коллегами для заказа обеда в офис.

В качестве примера можно рассмотреть мини-приложение для покупки билетов. Предположим, что компания друзей хочет выбрать и купить билеты на места, расположенные рядом. Для этого один из них приглашает друзей в мини-приложение и начинает звонок. Пользователи переходят по ссылке и присоединяются к звонку. Находясь внутри мини-приложения и видя доступные места, участники звонка выбирают их и оплачивают.

Интеграция звонков поможет расширить функциональность вашего мини-приложения, увеличить вовлечённость пользователей и среднее время сессии. А ваши пользователи смогут разнообразить совместные действия внутри мини-приложения.

## Ограничения

* Пользователи могут созваниваться только в режиме аудиозвонка.
* Интеграция звонков в мини-приложения доступна только в мобильных приложениях для Android и iOS и в десктопной версии сайта.

## Как это работает 

Рассмотрим интеграцию со звонками на примере игрового мини-приложения [«Патигеймы»](https://vk.com/app51617500), в котором пользователи могут объяснять слова и угадывать персонажей вместе со своими друзьями.

![alt=Игровое мини-приложение;title=Игровое мини-приложение;](d81d48dfe221c6f37d127490439c251ba97a6a2b2836d375b8f1affe "-4402376561222874191")

Пользователь во время создания новой игры может начать звонок. Другие участники совместного действия, приглашённые по ссылке, увидят, что звонок начат, и смогут к нему присоединиться. Создатель в любой момент может покинуть игру, звонок из-за этого не прервётся. 

Также звонок не завершается, если:

* Пользователь вернулся на домашний экран мобильного устройства или свернул браузер в десктопной версии сайта.
* Пользователь вернулся в мобильное приложение ВКонтакте или перешёл в другой раздел в десктопной версии сайта.

Если же создатель звонка нажмёт на кнопку **Завершить для всех**, то звонок прекратится для всех.

Посмотрим, как будет выглядеть мини-приложение для каждого участника звонка.

### Для создателя звонка

Пользователь при создании игры может начать звонок — в нашем примере он выбирает **Начать звонок для участников**. При этом он может присоединиться к звонку позже.

![alt=Пользователь создаёт звонок;title=Пользователь создаёт звонок;](3e3c993d4533f43dadfa0091d8c1a4715e9e22fa8e7788aaec34ecce "-5802579533564691061")

В созданной игре звонок отображается в виде picture-in-picture — окна поверх мини-приложения. Так звонок будет отображаться для всех участников.

![alt=Звонок внутри мини-приложения;title=Звонок внутри мини-приложения;](efa003d541d50f34dc105727e27c7da22e260656866462378410f7d0 "1025797571061216441")

Создатель звонка может покинуть звонок либо завершить звонок для всех. Если пользователь покинул звонок, то он может вернуться в него позже.

### Для пользователя, который присоединился к звонку

Пользователь, который зашёл в игру по ссылке, увидит, что звонок начат — появилась кнопка **Подключиться к звонку**.

![alt=Кнопка подключения к звонку;title=Кнопка подключения к звонку;](03ca9ecfa6acf7a01a2fee722d7229176020ec4db214c91b8cd83a31 "8043430989523136340")

Для него звонок также отображается в виде picture-in-picture — поверх экрана приложения. Пользователь может покинуть звонок, а затем вернуться к нему. 

## Как реализовать

Продумайте логику вашего мини-приложения, в каких случаях пользователи смогут создавать звонки и созваниваться с другими людьми.

Реализовать интеграцию звонков помогут события библиотеки [VK Bridge](bridge/overview):

* Событие [`VKWebAppCallStart`](bridge/VKWebAppCallStart) создаёт звонок и возвращает ссылку, по которой к нему можно подключить других участников. Вызывайте это событие, когда пользователь, создавший совместное действие, хочет инициировать звонок. 
* [`VKWebAppCallJoin`](bridge/VKWebAppCallJoin) подключает пользователя к звонку по ссылке, полученной с помощью события [`VKWebAppCallStart`](bridge/VKWebAppCallStart). Участник видит окно, где ему предлагают присоединиться к звонку или сделать это позже.
     
     ![alt=Окно подключения к звонку;title=Окно подключения к звонку;](5c3b3d4e389fb91a1c48982dd0df516b61baf65032a6fa86388c3147 "-3197411902833050106")

* Событие [`VKWebAppCallGetStatus`](bridge/VKWebAppCallGetStatus) возвращает информацию о текущем активном звонке. 

    Участник звонка может свернуть мини-приложение или переключиться в другое.

    Когда пользователь возвращается в мини-приложение, платформа ВКонтакте отправляет мини-приложению событие  [`VKWebAppViewRestore`](bridge/VKWebAppViewRestore). Рекомендуем вызывать [`VKWebAppCallGetStatus`](bridge/VKWebAppCallGetStatus) и проверять статус звонка в обработчике `VKWebAppViewRestore`, так как за время отсутствия пользователя звонок мог быть завершён. 
 

Чтобы обрабатывать события завершения звонка, [подпишитесь](bridge/getting-started#Метод%20bridge.subscribe) на следующие события:

* [`VKWebAppCallLeft`](bridge/VKWebAppCallLeft) — отправляется платформой, если пользователь вышел из звонка.
* [`VKWebAppCallFinished`](bridge/VKWebAppCallFinished) — отправляется платформой, если звонок завершён. Вам нужно передать эту информацию в серверную часть вашего мини-приложения и больше не отправлять пользователям ссылку на завершившийся звонок.
