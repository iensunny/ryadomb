# Перевод на другой язык

> Источник: [https://dev.vk.ru/ru/mini-apps/development/translate](https://dev.vk.ru/ru/mini-apps/development/translate)
Число пользователей как ВКонтакте, так и мини-приложений растёт, аудитория становится всё более многонациональной. Поэтому при создании мини-приложений важно обеспечить перевод текстов в нём на разные языки.

<!-- При создании приложения для многонациональной аудитории важно обеспечить перевод текстов на разные языки. -->

Для решения этой задачи ВКонтакте предлагает использовать автоматический перевод, который выполняют специальные сервисы, разработанные в компании. С их помощью вы можете:

* В режиме реального времени переводить тексты, не известные на момент разработки, например сообщения пользователей друг другу.

* Переводить подписи и тексты на лету, без создания текстовых констант и ресурсов на целевом языке.

* Ускорить перевод текстов в интерфейсе своего мини-приложения.

Если вы уже применяете автоматизированные переводы в своём приложении, переход на этот сервис позволит вам освободиться от использования сторонних библиотек и уменьшить зависимости в проекте.

## Как реализовать

Вы можете отправлять тексты на перевод как из серверной части вашего приложения, так и из кода, который работает на стороне пользователя. 

### На стороне пользователя

Для выполнения перевода в коде, который работает на стороне пользователя, используйте событие [`VKWebAppTranslate`](bridge/VKWebAppTranslate) библиотеки [VK Bridge](bridge/overview).

```JavaScript
bridge.send('VKWebAppTranslate', {
    texts: [
        'Привет! Как дела?',
        'Расскажи про пятничные соревнования.'
    ], 
    translation_language: 'ru-en'
})
.then( (data) => {
    // Переведённые тексты
    console.log('Тексты: ', data.result.texts);
     })
.catch( (err) => {
    // Ошибка
    console.log('Ошибка', err);
});
```

> Если вы подключили библиотеку VK Bridge [в HTML-коде страницы](bridge/getting-started#Включение%20скрипта%20в%20HTML-код%20страницы), то в вызове надо использовать имя объекта `vkBridge` вместо `bridge`.

Событие использует два параметра:

* `texts` — массив строк для перевода. На размер строк и количество элементов массива накладываются [ограничения](#Ограничения).

* `translation_language` — [целевой язык](#На%20какие%20языки%20возможен%20перевод) для перевода, например `en`, либо языковая пара, которая указывает язык исходного текста и язык, на который будет выполнен перевод, например `ru-en`.

    Вы можете указать только целевой язык для перевода, например `en`. В этом случае наш сервис попытается определить исходный язык автоматически.

    Обратите внимание, что автоматическое определение может работать ненадёжно на коротких фразах. В таких случаях указывайте языковую пару.

В качестве результата платформа вернёт массив переведённых строк, каждая из которых соответствует элементу в массиве `texts`.

### На стороне сервера приложения

Используйте API-запрос [`translations.translate`](method/translations.translate).

Параметры запроса и результат аналогичны [параметрам и результату](#На%20стороне%20пользователя) события `VKWebAppTranslate`.

## На какие языки возможен перевод

Языковой сервис ВКонтакте умеет переводить со следующих языков и на них:

* Английский (`en`)

* Испанский (`es`)

* Португальский (`pt`)

* Русский (`ru`)

Вы можете указать любую языковую пару для перевода. Наиболее часто используются `en-ru` и `ru-en`.

## Сколько это стоит

Наше решение бесплатно. Однако есть ограничения на объём текста, который будет переведён за один вызов, и на частоту вызовов.

## Ограничения

* Массив строк, который передаётся в параметре `texts`, может содержать не более 10 элементов. Размер каждой строки — не более 1024 символов.

* Событие и запрос разрешается вызывать не чаще 10 раз в минуту.

* Сейчас автоматические переводы работают только с текстом: сохранение разметки Markdown и HTML не гарантируется. Поддержка разметки будет реализована позднее.
