# API-вызовы в мини-приложениях

> Источник: [https://dev.vk.ru/ru/mini-apps/development/api-calls](https://dev.vk.ru/ru/mini-apps/development/api-calls)
Мини-приложения запрашивают данные и получают уведомления от платформы ВКонтакте.

> Для работы с API используйте протокол HTTPS.

Для обмена данными и отправки запросов мы рекомендуем использовать [события библиотеки VK Bridge](bridge/overview). 
Однако эта библиотека работает в клиентской части мини-приложения, кроме того, она не покрывает всех возможностей, которые предоставляет [API ВКонтакте](reference). Поэтому в некоторых случаях мини-приложения отправляют и API-запросы.

API-cерверы используют адрес `api.vk.ru`.

Мы не рекомендуем указывать эти фиксированные значения в коде. Адрес сервера лучше определять динамически. 

Чтобы сделать это, вызовите событие [`VKWebAppGetConfig`](bridge/VKWebAppGetConfig). Оно возвращает информацию об используемой платформе и рабочем окружении. Поле `api_host` в данных ответа содержит адрес сервера для API-запросов.

Кроме того, мы также рекомендуем подписаться на событие [`VKWebAppUpdateConfig`](bridge/VKWebAppUpdateConfig). Платформа отправляет его мини-приложению при изменении параметров среды. Ответ события также содержит поле `api_host`, в котором указан адрес сервера для API-запросов.

Для вызова некоторых API-методов можно использовать событие [`VKWebAppCallAPIMethod`](bridge/VKWebAppCallAPIMethod). Оно отправляет запросы на адрес сервера `api.vk.ru`, который используется вашим мини-приложением. Не вызывайте с помощью этого события API-методы, которые используют [сервисный ключ доступа](api/access-token/getting-started#Сервисный%20ключ%20доступа). Передавать и хранить этот ключ в клиентской части приложения небезопасно.
