# bugtracker.getBugreportById

> Источник: [https://dev.vk.ru/ru/method/bugtracker.getBugreportById](https://dev.vk.ru/ru/method/bugtracker.getBugreportById)
Возвращает информацию об отчёте.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `bugreport_id` | `integer` | да | Идентификатор отчёта. Его можно найти в ссылке на страницу отчёта, например:<br>`https://vk.com/bug1309341`<br> |
| `extended` | `checkbox` | нет |  |
| `fields` | `string` | нет |  |

## Результат

Метод возвращает объект отчёта при успешном выполнении.
