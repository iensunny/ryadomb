# leadForms.delete

> Источник: [https://dev.vk.ru/ru/method/leadForms.delete](https://dev.vk.ru/ru/method/leadForms.delete)
Удаляет форму сбора заявок.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор группы, из которой надо удалить форму. |
| `form_id` | `integer` | да | Идентификатор удаляемой формы. |

## Результат

Возвращает идентификатор удалённой формы.

## Права доступа

`groups`
