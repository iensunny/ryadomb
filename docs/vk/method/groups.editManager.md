# groups.editManager

> Источник: [https://dev.vk.ru/ru/method/groups.editManager](https://dev.vk.ru/ru/method/groups.editManager)
Позволяет назначить/разжаловать руководителя в сообществе или изменить уровень его полномочий.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | Идентификатор сообщества (указывается без знака «минус»). |
| `user_id` | `positive` | да | Идентификатор пользователя, чьи полномочия в сообществе нужно изменить. |
| `role` | `string` | нет | Уровень полномочий:<br>* `moderator` — модератор;<br>* `editor` — редактор;<br>* `administrator` — администратор.<br>* `advertiser` — рекламодатель<br>Если параметр не задан, с пользователя `user_id` снимаются полномочия руководителя. |
| `is_contact` | `checkbox` | нет | Отображать ли пользователя в блоке контактов сообщества. |
| `contact_position` | `string` | нет | Должность пользователя, отображаемая в блоке контактов. |
| `contact_phone` | `string` | нет | Телефон пользователя, отображаемый в блоке контактов. |
| `contact_email` | `string` | нет | Email пользователя, отображаемый в блоке контактов. |

## Результат

В случае успешного выполнения возвращает `1`.
