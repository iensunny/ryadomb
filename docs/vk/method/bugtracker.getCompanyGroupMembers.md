# bugtracker.getCompanyGroupMembers

> Источник: [https://dev.vk.ru/ru/method/bugtracker.getCompanyGroupMembers](https://dev.vk.ru/ru/method/bugtracker.getCompanyGroupMembers)
Возвращает список [сотрудников](vk-testers/employees) из группы доступа [компании](vk-testers/company).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `company_id` | `positive` | да | Идентификатор компании. Его можно найти в ссылке на страницу компании, например:<br>`https://vk.com/bugs_mng?company_id=3`<br> |
| `company_group_id` | `positive` | да | Идентификатор группы доступа. Его можно найти в ссылке на страницу группы, например:<br>`https://vk.com/bugs_mng?act=group_members&company_id=3&group_id=65`<br> |
| `count` | `positive` | нет | **Необязательный параметр**. Количество возвращаемых результатов. Максимальное значение: `100`. Значение по умолчанию: `10`. |
| `offset` | `positive` | нет | **Необязательный параметр**. Количество пропущенных результатов. |
| `filter_name` | `string` | нет | **Необязательный параметр**. Устанавливает имя пользователя, по которому нужно отфильтровать результаты. |
| `extended` | `checkbox` | нет | **Необязательный параметр**. Устанавливает, возвращать ли подробную информацию о профиле пользователя. Возможные значения:<br>* `0` — не возвращать.<br>* `1` — возвращать. |
| `fields` | `string` | нет | **Необязательный параметр**. Устанавливает список полей профиля пользователя, которые нужно возвращать. |

## Результат

Возвращает список идентификаторов пользователей. Если указаны параметры `extended` и `fields`, то передаётся расширенная информация о пользователях в зависимости от полей, указанных в `fields`.

## Типы ключа

`user_access_hidden`
