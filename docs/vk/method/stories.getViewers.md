# stories.getViewers

> Источник: [https://dev.vk.ru/ru/method/stories.getViewers](https://dev.vk.ru/ru/method/stories.getViewers)
Возвращает список пользователей, просмотревших историю.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца истории. |
| `story_id` | `positive` | да | Идентификатор истории. |
| `count` | `positive` | нет | Максимальное число результатов в ответе. |
| `offset` | `positive` | нет | Сдвиг для получения определённого подмножества результатов. |
| `extended` | `checkbox` | нет | `1`  — возвращать в ответе расширенную информацию о пользователях. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов в поле `items` (`array`). В объекте есть следующие поля: `is_liked` (`bool`) и `user_id` (`int`).
Если `extended = 1`, поле `items` (`array`) содержит массив объектов [пользователей](reference/objects/user).

## Права доступа

`ex`, `stories`

## Типы ключа

`group_access`, `vk_apps`, `is_standalone`
