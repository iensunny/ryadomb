# market.editPropertyVariant

> Источник: [https://dev.vk.ru/ru/method/market.editPropertyVariant](https://dev.vk.ru/ru/method/market.editPropertyVariant)
Редактирует вариант свойства.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор сообщества. |
| `variant_id` | `positive` | да | Идентификатор варианта. |
| `title` | `string` | да | Название варианта. |

## Результат

В случае успешного выполнения возвращает 1.

## Права доступа

`market`
