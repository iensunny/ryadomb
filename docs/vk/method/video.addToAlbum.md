# video.addToAlbum

> Источник: [https://dev.vk.ru/ru/method/video.addToAlbum](https://dev.vk.ru/ru/method/video.addToAlbum)
Позволяет добавить видеозапись в альбом.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `target_id` | `integer` | нет | Идентификатор владельца альбома, в который нужно добавить видео.<br>> Обратите внимание, идентификатор сообщества в параметре `target_id` необходимо указывать со знаком «-» — например, `target_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `album_id` | `string` | нет | Идентификатор альбома, в который нужно добавить видео.<br>Для добавления видео в общий альбом «Добавленные» передавайте `-2`. |
| `album_ids` | `string` | нет | Идентификаторы альбомов, в которые нужно добавить видео. |
| `owner_id` | `integer` | да | Идентификатор владельца видеозаписи.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `video_id` | `positive` | да | Идентификатор видеозаписи. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`video`
