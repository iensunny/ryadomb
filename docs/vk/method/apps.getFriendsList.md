# apps.getFriendsList

> Источник: [https://dev.vk.ru/ru/method/apps.getFriendsList](https://dev.vk.ru/ru/method/apps.getFriendsList)
Создает список друзей, который будет использоваться при отправке пользователем приглашений в приложение и игровых запросов.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `extended` | `checkbox` | нет | Параметр, определяющий необходимость возвращать расширенную информацию о пользователях. <br>Возможные значения:<br>* `0` — возвращаются только идентификаторы;<br>* `1` — будут дополнительно возвращены имя и фамилия.<br>По умолчанию: `0`. |
| `count` | `positive` | нет | Количество пользователей в создаваемом списке. |
| `offset` | `positive` | нет | Смещение относительно первого пользователя для выборки определенного подмножества. |
| `type` | `string` | нет | Тип создаваемого списка друзей. <br>Возможные значения:<br>* `invite` — доступные для приглашения (не играют в игру);<br>* `request` — доступные для отправки запроса (уже играют).<br>По умолчанию: `invite`. |
| `fields` | `string` | нет | Список дополнительных полей профилей, которые необходимо вернуть. См. [подробное описание](reference/objects/user). |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив [объектов, описывающих пользователей](reference/objects/user), в поле `items`.
