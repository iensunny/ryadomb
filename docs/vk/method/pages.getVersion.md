# pages.getVersion

> Источник: [https://dev.vk.ru/ru/method/pages.getVersion](https://dev.vk.ru/ru/method/pages.getVersion)
Возвращает текст одной из старых версий страницы.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `version_id` | `string` | да | Идентификатор версии. |
| `group_id` | `string` | нет | Идентификатор сообщества, которому принадлежит вики-страница. |
| `user_id` | `string` | нет | Идентификатор пользователя, который создал страницу. |
| `need_html` | `checkbox` | нет | Определяет, требуется ли в ответе HTML-представление вики-страницы. |

## Результат

Возвращает объект [вики-страницы](reference/objects/wiki-page).
