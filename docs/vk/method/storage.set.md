# storage.set

> Источник: [https://dev.vk.ru/ru/method/storage.set](https://dev.vk.ru/ru/method/storage.set)
Метод задаёт значение переменной, название которой передано. Переменные хранятся бессрочно. Может быть создано не более 1&nbsp;000 переменных для каждого пользователя. Не более 1&nbsp;000 вызовов в час на каждого пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `key` | `string` | да | Название переменной. Допустимые символы названия переменной: `[a-zA-Z_\-0-9]`.  |
| `value` | `text` | нет | Значение переменной. Сохраняются только первые 4&nbsp;096 символов, для сериализованной строки — 4&nbsp;096 символов.<br>Чтобы удалить переменную, передайте пустую строку.  |
| `user_id` | `positive` | нет | Идентификатор пользователя, переменная которого устанавливается в случае, если данные запрашиваются серверным методом. |

## Результат

Метод возвращает `1`, если переменная задана, и `0` в случае ошибки.

```JSON
{
  "response":1
}
```

## Типы ключа

`allow_from_server`, `group_access`

## Ошибки

- 103

Чтобы получить переменные и их значения, используйте методы:

* [`storage.get`](method/storage.get)
* [`storage.getKeys`](method/storage.getKeys)

## Возможности

Если один разработчик создал переменные с помощью этого метода, ими сможет пользоваться любой разработчик приложения. Вы можете отказаться от `localStorage` в пользу `storage.set`.
