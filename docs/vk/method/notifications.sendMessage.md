# notifications.sendMessage

> Источник: [https://dev.vk.ru/ru/method/notifications.sendMessage](https://dev.vk.ru/ru/method/notifications.sendMessage)
Метод отправляет [уведомление](mini-apps/promotion/social-mechanics/notifications/overview) пользователю мини-приложения.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_ids` | `integer` | да | **Обязательный параметр**. Идентификаторы пользователей, которым нужно отправить уведомление, перечисленные через запятую. Пример: `"743784474, 743784490"`.<br>Нужно передать хотя бы один идентификатор. Максимально можно передать 100 идентификаторов. |
| `message` | `string` | да | **Обязательный параметр**. Текст уведомления. Максимальная длина — 254 символа. |
| `fragment` | `string` | нет | Содержимое хеша — часть URL в ссылке на мини-приложение вида `vk.com/app123456#fragment`. Максимальная длина — 2047 символов. |
| `group_id` | `positive` | нет | **Необязательный параметр**. Идентификатор сообщества. |
| `random_id` | `integer` | нет | **Необязательный параметр**. Уникальный (в привязке к `API_ID` и `ID` отправителя) идентификатор, предназначенный для предотвращения повторной отправки одинакового сообщения.  <br>Заданный `random_id` используется для проверки уникальности уведомления в течение часа после отправки.<br>Разрешён с версии 5.107. |
| `sending_mode` | `string` | нет |  |

## Результат

Метод возвращает массив объектов.

Параметры объекта в массиве:

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_id` | `integer` | Идентификатор пользователя. |
| `status` | `boolean` | Статус отправки уведомления пользователю. |
| `error` | `object` | Объект ошибки. Отправляется, если статус отправки имеет значение `false`.&#x0d;&#x0a;&#x0d;&#x0a; Параметры объекта:&#x0d;&#x0a; &bullet; `code` (`integer`) — код ошибки;&#x0d;&#x0a; &bullet; `description` (`string`) — описание ошибки.&#x0d;&#x0a;&#x0d;&#x0a; Возможные значения параметра `code`:&#x0d;&#x0a; &bullet; `1` — уведомления приложения отключены;&#x0d;&#x0a; &bullet; `2` — превышен лимит уведомлений за последний час;&#x0d;&#x0a; &bullet; `3` — превышен лимит уведомлений за последние сутки;&#x0d;&#x0a; &bullet; `4` — приложение не установлено. |

Пример ответа для мини-приложения, когда одному пользователю уведомление было отправлено, а при отправке второму возникла ошибка:

```JSON
{
  "response": [
    {
      "user_id": 743784474,
      "status": true
    },
    {
      "user_id": 743784490,
      "status": false,
      "error": {
        "code": 1,
        "description": "string"
      }
    }
  ]
}
```
