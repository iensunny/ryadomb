# pages.getTitles

> Источник: [https://dev.vk.ru/ru/method/pages.getTitles](https://dev.vk.ru/ru/method/pages.getTitles)
Возвращает список вики-страниц в группе.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | нет | Идентификатор сообщества, которому принадлежит вики-страница. |

## Результат

Возвращает массив объектов [вики-страниц](reference/objects/wiki-page).

## Права доступа

`pages`
