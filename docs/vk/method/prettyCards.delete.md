# prettyCards.delete

> Источник: [https://dev.vk.ru/ru/method/prettyCards.delete](https://dev.vk.ru/ru/method/prettyCards.delete)
Удаляет карточку.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца карточки. |
| `card_id` | `string` | да | Идентификатор карточки. |

## Результат

Возвращает структуру с информаций об удалённой карточке.
*  `owner_id` — идентификатор владельца карточки;
*  `card_id` — идентификатор карточки.

## Права доступа

`ads`
