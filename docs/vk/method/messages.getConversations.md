# messages.getConversations

> Источник: [https://dev.vk.ru/ru/method/messages.getConversations](https://dev.vk.ru/ru/method/messages.getConversations)
Возвращает список бесед пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества бесед. |
| `count` | `positive` | нет | Количество бесед, которое необходимо получить (но не более 200). |
| `filter` | `string` | нет | Типы бесед, которые нужно вернуть, перечисленные через запятую. <br>Может принимать следующие значения:<br>* `all ` — все беседы;<br>* `important ` —  беседы, отмеченные важными (доступно только в сообщениях сообществ);<br>* `unanswered ` —  беседы, отмеченные непрочтенными (доступно только в сообщениях сообществ);<br>* `unread ` —  беседы, в которых есть непрочтенные сообщения.<br>* `archive ` —  беседы, находящиеся в архиве.<br>По умолчанию будут возвращены все беседы. |
| `extended` | `checkbox` | нет | Если указать в качестве этого параметра 1, то будет возвращена информация о пользователях и сообществах.  |
| `start_message_id` | `positive` | нет | Идентификатор сообщения, начиная с которого нужно вернуть историю переписки. |
| `fields` | `string` | нет | Список дополнительных полей для [пользователей](reference/objects/user) и [сообществ](reference/objects/group). |
| `group_id` | `integer` | нет | Идентификатор сообщества (доступно с токеном сообщества). |

## Результат

Возвращает объект, который содержит следующие поля:

`count`
`integer`
Число результатов.

`items`
`array`
Беседы. Массив объектов, каждый из которых содержит поля: 
* `conversation` (`object`) — объект [беседы](reference/objects/conversation). 
* `last_message` (`object`) — объект, описывающий [последнее сообщение в беседе](reference/objects/message).

`unread_count`
`integer`
Число непрочитанных бесед.

`profiles`
`array`
Массив объектов [пользователей](reference/objects/user).

`groups`
`array`
Массив объектов [сообществ](reference/objects/group).
