## Параметры

> Источник: [https://dev.vk.ru/ru/method/wall.search](https://dev.vk.ru/ru/method/wall.search)
| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «-» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1).  |
| `domain` | `string` | нет | Короткий адрес пользователя или сообщества. |
| `query` | `string` | нет | Поисковой запрос. Для точного результата запрос необходимо передавать в двойных кавычках. |
| `owners_only` | `checkbox` | нет | `1` — возвращать только записи от имени владельца стены. |
| `count` | `positive` | нет | Количество записей, которые необходимо вернуть.<br>Положительное число, по умолчанию  — `20`, максимальное значение `100`.  |
| `offset` | `positive` | нет | Смещение, необходимо для получения определенного подмножества результатов. |
| `extended` | `checkbox` | нет | `1` — в ответе будут возвращены дополнительные поля `profiles` и `groups`, содержащие информацию о пользователях и сообществах. По умолчанию: `0`. |
| `fields` | `string` | нет | Список дополнительных полей для профилей и групп, которые необходимо вернуть. См. [описание полей объекта user](reference/objects/user) и [описание полей объекта `group`](reference/objects/group).<br>Обратите внимание, этот параметр учитывается только при `extended`=`1`. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [записей на стене](reference/objects/post) в поле `items`.

Если был задан параметр `extended`=`1`, возвращает число результатов в поле `count`, отдельно массив объектов [записей на стене](reference/objects/post) в поле `items`, [пользователей](reference/objects/user) в поле `profiles` и [сообществ](reference/objects/group) в поле `groups`.
