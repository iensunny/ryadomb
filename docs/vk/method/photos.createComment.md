# photos.createComment

> Источник: [https://dev.vk.ru/ru/method/photos.createComment](https://dev.vk.ru/ru/method/photos.createComment)
Создает новый комментарий к фотографии.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `string` | нет | Идентификатор пользователя или сообщества, которому принадлежит фотография.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `photo_id` | `string` | да | Идентификатор фотографии. |
| `message` | `string` | нет | Текст комментария (является обязательным, если не задан параметр `attachments`).<br>Максимальное количество символов: **2048**. |
| `attachments` | `string` | нет | Список объектов, приложенных к комментарию и разделённых символом `«,»`. Поле `attachments` представляется в формате:<br>```<br><type><owner_id>_<media_id>,<type><owner_id>_<media_id><br>```<br>`<type>` — тип медиа-вложения:<br>* `photo` — фотография <br>* `video` — видеозапись <br>* `audio` — аудиозапись <br>* `doc` — документ<br>`<owner_id>` — идентификатор владельца медиа-вложения <br>`<media_id>` — идентификатор медиа-вложения. <br>Например:<br>```<br>photo100172_166443618,photo66748_265827614<br>```<br>Параметр является обязательным, если не задан параметр `message`. |
| `from_group` | `checkbox` | нет | Данный параметр учитывается, если `owner_id` <`0` (комментарий к фотографии группы). <br>Возможные значения:<br>* `1` — комментарий будет опубликован от имени группы;<br>* `0` — комментарий будет опубликован от имени пользователя.<br>По умолчанию: `0`. |
| `reply_to_comment` | `string` | нет | Идентификатор комментария, в ответ на который нужно оставить текущий. |
| `sticker_id` | `positive` | нет | Идентификатор стикера, который нужно прикрепить к комментарию. |
| `access_key` | `string` | нет | Ключ доступа. |
| `guid` | `string` | нет | Уникальное значение для предотвращения повторной отправки одного и того же комментария. |

## Результат

После успешного выполнения возвращает идентификатор созданного комментария.
