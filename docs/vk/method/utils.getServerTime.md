# utils.getServerTime

> Источник: [https://dev.vk.ru/ru/method/utils.getServerTime](https://dev.vk.ru/ru/method/utils.getServerTime)
Возвращает текущее время на сервере ВКонтакте в `unixtime`.

## Результат

Возвращает число, соответствующее времени в `unixtime`.

## Типы ключа

`allow_from_server`, `group_access`
