# prettyCards.create

> Источник: [https://dev.vk.ru/ru/method/prettyCards.create](https://dev.vk.ru/ru/method/prettyCards.create)
Метод создаёт карточку карусели.

> Созданную карточку необходимо вручную добавить в карусель.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | **Обязательный параметр.** Идентификатор владельца карточки — идентификатор сообщества со знаком `-`. Пример: `-166562603`. |
| `photo` | `string` | да | **Обязательный параметр.** Изображение на карточке.<br>Используйте значение, полученное после загрузки фотографии на сервер с помощью:<br>* Метода [`prettyCards.getUploadURL`](method/prettyCards.getUploadURL).<br>* Раздела [Загрузка фотографии для товара](api/upload/photo-in-market).<br>Также можно переиспользовать существующую фотографию из другой карточки. Используйте значение поля `photo`, которое возвращает метод [`prettyCards.get`](method/prettyCards.get) или [`prettyCards.getById`](method/prettyCards.getById). |
| `title` | `string` | да | **Обязательный параметр.** Заголовок карточки. |
| `link` | `string` | да | **Обязательный параметр.** Ссылка на карточку. Кроме HTTPS-ссылок, можно указывать телефонные номера в виде `tel:+79111234567`. |

## Результат

Метод возвращает объект. Параметры объекта:

| Параметр | Тип | Описание |
|---|---|---|
| `owner_id` | `integer` | Идентификатор владельца карточки. |
| `card_id` | `integer` | Идентификатор карточки. |

Пример ответа:

```JSON
{
  "response": {
    "owner_id": -166562603,
    "card_id": 1234444
  }
}
```
