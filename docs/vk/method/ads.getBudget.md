# ads.getBudget

> Источник: [https://dev.vk.ru/ru/method/ads.getBudget](https://dev.vk.ru/ru/method/ads.getBudget)
Возвращает текущий бюджет рекламного кабинета.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | Идентификатор рекламного кабинета. |

## Результат

Возвращает единственное число — оставшийся бюджет в указанном рекламном кабинете.

## Права доступа

`ads`

- 601
