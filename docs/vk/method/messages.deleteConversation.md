# messages.deleteConversation

> Источник: [https://dev.vk.ru/ru/method/messages.deleteConversation](https://dev.vk.ru/ru/method/messages.deleteConversation)
Удаляет беседу.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `integer` | нет | Идентификатор пользователя. Если требуется очистить историю беседы, используйте `peer_id`. |
| `peer_id` | `integer` | нет | Идентификатор назначения.<br>Для групповой беседы:<br>* `2000000000` + `id` беседы.<br>Для сообщества:<br>* `-id` сообщества. |
| `offset` | `positive` | нет | Начиная с какого сообщения нужно удалить переписку (по умолчанию удаляются все сообщения начиная с первого). |
| `count` | `positive` | нет | Сколько сообщений нужно удалить. Обратите внимание, что на метод наложено ограничение, за один вызов нельзя удалить больше 10000 сообщений, поэтому если сообщений в переписке больше — метод нужно вызывать несколько раз. |
| `group_id` | `integer` | нет | Идентификатор сообщества (для сообщений сообщества с ключом доступа пользователя). |

## Результат

После успешного выполнения возвращает поле `last_deleted_id`, содержащее идентификатор последнего удалённого сообщения в переписке.
