# utils.deleteFromLastShortened

> Источник: [https://dev.vk.ru/ru/method/utils.deleteFromLastShortened](https://dev.vk.ru/ru/method/utils.deleteFromLastShortened)
Удаляет сокращенную ссылку из списка пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `key` | `string` | да | Сокращённая ссылка (часть URL после «vk.cc/»). |

## Результат

После успешного выполнения возвращает `1`.
