# market.get

> Источник: [https://dev.vk.ru/ru/method/market.get](https://dev.vk.ru/ru/method/market.get)
Возвращает список товаров в сообществе.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `string` | да | Идентификатор владельца товаров.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `album_id` | `positive` | нет | Идентификатор подборки, товары из которой нужно вернуть. |
| `count` | `positive` | нет | Количество возвращаемых товаров. Положительное число, максимальное значение 200, по умолчанию 100. |
| `offset` | `positive` | нет | Смещение относительно первого найденного товара для выборки определенного подмножества. |
| `extended` | `checkbox` | нет | `1` — будут возвращены дополнительные поля `likes`, `can_comment`, `can_repost`, `photos`, `views_count`, `videos`. По умолчанию эти поля не возвращается. |
| `date_from` | `string` | нет | Начальная дата для фильтрации списка возвращаемых товаров по дате обновления. Формат: `YYYY-MM-DD`.  |
| `date_to` | `string` | нет | Конечная дата для фильтрации списка возвращаемых товаров по дате обновления. Формат: `YYYY-MM-DD`.  |
| `need_variants` | `checkbox` | нет | Получить дополнительные варианты товара. Возможные значения:<br>* `1` — получить варианты товара.<br>* `0` — не получать варианты товара.<br>> Чтобы в магазине вашего сообщества отображались варианты товаров, перейдите в **Настройки магазина** и в разделе **Товары** выберите вариант **Расширенные**. |
| `with_disabled` | `checkbox` | нет | Добавить в список возвращаемых товаров те, которые отмечены как недоступные. Возможные значения:<br>* `1` — добавить недоступные товары.<br>* `0` — не добавлять недоступные товары. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [товаров](reference/objects/market-item) в поле `items`.

## Права доступа

`market`
