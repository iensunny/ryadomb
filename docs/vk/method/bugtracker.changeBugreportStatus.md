# bugtracker.changeBugreportStatus

> Источник: [https://dev.vk.ru/ru/method/bugtracker.changeBugreportStatus](https://dev.vk.ru/ru/method/bugtracker.changeBugreportStatus)
Изменяет статус отчёта в соответствии с правилами смены статусов.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `bugreport_id` | `positive` | да | Идентификатор отчёта. Его можно найти в ссылке на страницу отчёта, например:<br>`https://vk.com/bug1309341`<br> |
| `status` | `positive` | нет | **Необязательный параметр**. Новый статус. |
| `comment` | `string` | нет | **Необязательный параметр**. Текст комментария к смене статуса. |
| `from_statuses` | `integer` | нет | **Необязательный параметр**. Список статусов через запятую. Если параметр задан, то отчёт сменит статус только если текущий статус находится в списке. |
| `not_in_statuses` | `integer` | нет | **Необязательный параметр**. Список числовых обозначений статусов, перечисленных через запятую. Если параметр задан, то отчёт сменит статус только если текущий статус НЕ находится в списке. |

Полный список статусов:

* `0` – Открыт.
* `1` – В работе.
* `2` – Исправлен.
* `3` – Отклонён.
* `4` – На рассмотрении.
* `5` – Закрыт.
* `6` – Заблокирован.
* `7` – Переоткрыт.
* `8` – Не воспроизводится.
* `9` – Отложен.
* `10` – Требует корректировки.
* `11` – Готов к тестированию.
* `12` – Верифицирован.
* `13` – Не будет исправлен.
* `14` – Неактуален.
* `15` – Дубликат.

Смотрите описание значений статусов в [статье](https://vk.com/@testpool-bug-tracker?anchor=statusy-otch-tov).

## Результат

Метод возвращает `1` после успешного выполнения, и `0` в случае ошибки.

Пример ответа:

```JSON
{
  "response": 1
}
```
