# donut.getFriends

> Источник: [https://dev.vk.ru/ru/method/donut.getFriends](https://dev.vk.ru/ru/method/donut.getFriends)
Возвращает список донов, которые подписаны на определенные сообщества, из числа друзей пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор сообщества.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества друзей. |
| `count` | `positive` | нет | Количество друзей, информацию о которых необходимо вернуть. |
| `fields` | `string` | нет | Список дополнительных полей профилей, которые необходимо вернуть. См. [подробное описание](reference/objects/user). |

## Результат

После успешного выполнения возвращает объект, содержащий число друзей в поле `count` и массив объектов [пользователей](reference/objects/user) в поле `items`.

## Права доступа

`friends`, `groups`
