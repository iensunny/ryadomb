# ads.shareTargetGroup

> Источник: [https://dev.vk.ru/ru/method/ads.shareTargetGroup](https://dev.vk.ru/ru/method/ads.shareTargetGroup)
Предоставляет доступ к аудитории ретаргетинга другому рекламному кабинету. В результате выполнения метода возвращается идентификатор аудитории для указанного кабинета.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | Идентификатор рекламного кабинета. |
| `client_id` | `integer` | нет | **Только для рекламных агентств**. <br>ID клиента, в рекламном кабинете которого находится исходная аудитория. |
| `target_group_id` | `integer` | да | Идентификатор исходной аудитории. |
| `share_with_client_id` | `integer` | нет | ID клиента, рекламному кабинету которого необходимо предоставить доступ к аудитории. |

## Результат

Возвращает объект со следующими полями:
* `id` — идентификатор аудитории.

## Права доступа

`ads`
