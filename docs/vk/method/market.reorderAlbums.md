# market.reorderAlbums

> Источник: [https://dev.vk.ru/ru/method/market.reorderAlbums](https://dev.vk.ru/ru/method/market.reorderAlbums)
Изменяет положение подборки с товарами в списке.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца альбома.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «`-`» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `album_id` | `integer` | да | Идентификатор подборки. <br>> Обратите внимание, двигается только подборка по данному идентификатору, перестановка выполняется одна (если запрошенную позицию не получается повторить одной перестановкой, то выполнится только первая) |
| `before` | `positive` | нет | Идентификатор подборки, после которой следует поместить текущую. |
| `after` | `positive` | нет | Идентификатор подборки, перед которой следует поместить текущую. |

## Результат

После успешного выполнения возвращает `1`.
