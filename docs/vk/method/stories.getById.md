# stories.getById

> Источник: [https://dev.vk.ru/ru/method/stories.getById](https://dev.vk.ru/ru/method/stories.getById)
Возвращает информацию об истории по её идентификатору.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `stories` | `string` | да | Перечисленные через запятую идентификаторы, которые представляют собой идущие через знак подчеркивания идентификаторы владельцев историй и идентификаторы самих историй.<br>Пример значения `stories`:<br>```<br>93388_21539,93388_20904<br>``` |
| `extended` | `checkbox` | нет | `1` — возвращать в ответе дополнительную информацию о пользователях. |
| `fields` | `string` | нет | Дополнительные поля [профилей](reference/objects/user) и [сообществ](reference/objects/group), которые необходимо вернуть в ответе. |

## Результат

После успешного выполнения возвращает объект, содержащий число историй в поле `count` и массив объектов [историй](reference/objects/story-feed-item) в поле `items`.

Если был задан параметр `extended = 1`, дополнительно возвращает массив объектов  [пользователей](reference/objects/user) в поле `profiles` и объектов [сообществ](reference/objects/group) в поле `groups`

## Права доступа

`ex`, `stories`, `vkui`

## Типы ключа

`group_access`, `vk_apps`, `is_standalone`
