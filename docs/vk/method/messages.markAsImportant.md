# messages.markAsImportant

> Источник: [https://dev.vk.ru/ru/method/messages.markAsImportant](https://dev.vk.ru/ru/method/messages.markAsImportant)
Помечает сообщения как важные либо снимает отметку.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `message_ids` | `integer` | нет | Список идентификаторов сообщений, которые необходимо пометить. |
| `cmids` | `integer` | нет | Список идентификаторов сообщения в беседе, которые необходимо пометить. |
| `peer_id` | `integer` | нет | Идентификатор беседы.<br>Для пользователя:<br>* `id` пользователя.<br>Для групповой беседы:<br>* `2000000000` + `id` беседы.<br>Для сообщества:<br>* `-id` сообщества. |
| `important` | `positive` | нет | `1`, если сообщения необходимо пометить, как важные;<br>`0`, если необходимо снять пометку. |

## Результат

До версии 5.217 возвращает массив идентификаторов успешно помеченных сообщений.
С версии 5.217 возвращает массив с объектами, в которых `message_id`, `cmids`, `peer_id`
