# photos.copy

> Источник: [https://dev.vk.ru/ru/method/photos.copy](https://dev.vk.ru/ru/method/photos.copy)
Позволяет скопировать фотографию в альбом "Сохраненные фотографии"

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца фотографии. |
| `photo_id` | `positive` | да | Индентификатор фотографии. |
| `access_key` | `string` | нет | [Специальный код доступа](reference/objects) для приватных фотографий. |

## Результат

Возвращает идентификатор созданной фотографии.

## Права доступа

`photos_ex`

## Типы ключа

`vk_apps`, `is_standalone`
