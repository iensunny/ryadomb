# video.getComments

> Источник: [https://dev.vk.ru/ru/method/video.getComments](https://dev.vk.ru/ru/method/video.getComments)
Возвращает список комментариев к видеозаписи.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества, которому принадлежит видеозапись.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «-» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `video_id` | `positive` | да | Идентификатор видеозаписи. |
| `need_likes` | `checkbox` | нет | `1` — будет возвращено дополнительное поле `likes`. По умолчанию поле `likes` не возвращается. |
| `start_comment_id` | `integer` | нет | Идентификатор комментария, начиная с которого нужно вернуть список (подробности см. ниже). |
| `offset` | `integer` | нет | Смещение, необходимое для выборки определенного подмножества комментариев. По умолчанию: `0`. |
| `count` | `positive` | нет | Количество комментариев, информацию о которых необходимо вернуть. |
| `sort` | `string` | нет | Порядок сортировки комментариев. Возможные значения:<br>* `asc` — от старых к новым;<br>* `desc` — от новых к старым. |
| `extended` | `checkbox` | нет | `1` — в ответе будут возвращены дополнительные поля `profiles` и `groups`, содержащие информацию о пользователях и сообществах. По умолчанию: `0`. |
| `fields` | `string` | нет | **Необязательный параметр.** Дополнительная информация о полях `profiles` и `groups`. Учитывается, если передан параметр `extended` со значением `1`. |
| `comment_id` | `integer` | нет |  |
| `thread_items_count` | `positive` | нет |  |

Если был передан параметр `start_comment_id`, будет найдена позиция комментария в списке (или ближайший к нему более ранний). Начиная с этой позиции будет возвращено `count` комментариев. Смещение `offset` в этом случае будет отсчитываться от этой позиции (оно может быть отрицательным).

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов комментариев в поле `items`. Каждый объект, описывающий комментарий, содержит следующие поля:
* `id` — идентификатор комментария;
* `from_id` — идентификатор автора комментария;
* `date` — дата добавления комментария в формате `unixtime`;
* `text` — текст комментария;
* `likes` — информация об отметках **Нравится** текущего комментария (если был задан параметр `need_likes`), объект с полями:
   * `count` — число пользователей, которым понравился комментарий,
   * `user_likes` — наличие отметки **Нравится** от текущего пользователя (`1` — есть, `0` — нет),
   * `can_like` — информация о том, может ли текущий пользователь поставить отметку **Нравится** (`1` — может, `0` — не может). 

Если был задан параметр `extended`=`1`, возвращает число результатов в поле `count`, отдельно массив объектов комментариев в поле `items`, [пользователей](reference/objects/user) в поле `profiles` и [сообществ](reference/objects/group
) в поле `groups`.

Если был передан параметр `start_comment_id`, будет также возвращено поле `real_offset` – итоговое смещение данного подмножества комментариев (оно может быть отрицательным, если был указан отрицательный `offset`).
