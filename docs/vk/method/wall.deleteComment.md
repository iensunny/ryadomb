# wall.deleteComment

> Источник: [https://dev.vk.ru/ru/method/wall.deleteComment](https://dev.vk.ru/ru/method/wall.deleteComment)
Удаляет комментарий к записи на стене.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор пользователя, на чьей стене находится комментарий к записи. <br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «-» — например, `owner_id` = `-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1) |
| `comment_id` | `positive` | да | Идентификатор комментария. |

## Результат

После успешного выполнения возвращает `1`.

`wall_ex`
