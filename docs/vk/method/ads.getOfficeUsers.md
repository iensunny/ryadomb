# ads.getOfficeUsers

> Источник: [https://dev.vk.ru/ru/method/ads.getOfficeUsers](https://dev.vk.ru/ru/method/ads.getOfficeUsers)
Возвращает список администраторов и наблюдателей рекламного кабинета.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | Идентификатор рекламного кабинета. |

## Результат

Возвращает массив объектов-описаний пользователей рекламного кабинета. Каждый объект содержит массив описаний прав доступа к конкретным клиентам. Описание содержит два поля: 
* `client_id` — id клиента;
* `role` — строка `admin`, `manager` или `reports`. 

Для `admin` `client_id` не указывается.

## Права доступа

`ads`
