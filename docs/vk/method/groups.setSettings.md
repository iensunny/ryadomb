# groups.setSettings

> Источник: [https://dev.vk.ru/ru/method/groups.setSettings](https://dev.vk.ru/ru/method/groups.setSettings)
Устанавливает настройки сообщества

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор сообщества. |
| `messages` | `checkbox` | нет | Сообщения сообщества. Возможные значения:<br>* `0` — выключены;<br>* `1` — включены. |
| `bots_capabilities` | `checkbox` | нет | Возможности ботов (использование клавиатуры, добавление в беседу). <br>Возможные значения:<br>* `0` — выключены;<br>* `1` — включены. |
| `bots_start_button` | `checkbox` | нет | Кнопка «Начать» в диалоге с сообществом. <br>Работает, в случае если `bots_capabilities`=`1`.<br>Если эта настройка включена, то при заходе в беседу с Вашим сообществом в первый раз пользователь увидит кнопку с командой «Начать», которая отправляет команду `start`. [Payload](api/bots/development/keyboard) этого сообщения будет выглядеть так: <br>```<br>{"command":"start"}<br>```<br>Возможные значения:<br>* `0` — выключена;<br>* `1` — включена. |
| `bots_add_to_chat` | `checkbox` | нет | Добавление бота в беседы. <br>Работает, в случае если `bots_capabilities`=`1`.<br>Возможные значения:<br>* `0` — запрещено;<br>* `1` — разрешено. |
| `docs` | `positive` | нет |  |

## Результат

В случае успеха возвращает `1`.

## Права доступа

`groups_ex`

## Типы ключа

`group_access`, `is_standalone`
