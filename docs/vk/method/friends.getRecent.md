# friends.getRecent

> Источник: [https://dev.vk.ru/ru/method/friends.getRecent](https://dev.vk.ru/ru/method/friends.getRecent)
Возвращает список идентификаторов недавно добавленных друзей текущего пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `count` | `positive` | нет | Максимальное количество недавно добавленных друзей, которое необходимо получить. |

## Результат

После успешного выполнения возвращает отсортированный в антихронологическом порядке список идентификаторов (`id`) недавно добавленных друзей текущего пользователя.

## Права доступа

`friends`
