# ads.getMusiciansByIds

> Источник: [https://dev.vk.ru/ru/method/ads.getMusiciansByIds](https://dev.vk.ru/ru/method/ads.getMusiciansByIds)
Возвращает информацию о музыкантах на слушателей, для которых доступно таргетирование.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `ids` | `integer` | да | Идентификаторы музыкантов.  |

## Результат

Возвращает массив музыкантов с соответствующими идентификаторами из запроса.

`id`
`integer` 
Идентификатор музыканта. 

`name` 
`string` 
Полный псевдоним музыканта. 
 
`avatar` 
`string` 
Аватарка музыканта.

## Права доступа

`ads`
