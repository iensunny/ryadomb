# ads.getMusicians

> Источник: [https://dev.vk.ru/ru/method/ads.getMusicians](https://dev.vk.ru/ru/method/ads.getMusicians)
Возвращает информацию о музыкантах, на слушателей которых доступно таргетирование.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `artist_name` | `text` | да | Имя музыканта. |

## Результат

Возвращает массив всех подходящих под запрос `artist_name` музыкантов.

`name`
`string`
Полный псевдоним музыканта.

`avatar`
`string`
Аватарка музыканта.

## Права доступа

`ads`
