# board.createComment

> Источник: [https://dev.vk.ru/ru/method/board.createComment](https://dev.vk.ru/ru/method/board.createComment)
Добавляет новый комментарий в обсуждении.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор сообщества, в котором находится обсуждение. |
| `topic_id` | `positive` | да | Идентификатор темы, в которой необходимо оставить комментарий. |
| `message` | `string` | нет | Текст комментария. Обязательный параметр, если не передано значение `attachments`. |
| `attachments` | `string` | нет | Список объектов, приложенных к комментарию и разделённых символом `«,»`. Поле `attachments` представляется в формате:<br>```<br><type><owner_id>_<media_id>,<type><owner_id>_<media_id><br>```<br>`<type>` — тип медиа-вложения:<br>* `photo` — фотография;<br>* `video` — видеозапись;<br>* `audio` — аудиозапись;<br>* `doc` — документ;<br>`<owner_id>` — идентификатор владельца медиа-вложения;<br>`<media_id>` — идентификатор медиа-вложения.<br>Например:<br>```<br>photo100172_166443618,photo66748_265827614<br>``` |
| `from_group` | `checkbox` | нет | `1` — сообщение будет опубликовано от имени группы, `0` — сообщение будет опубликовано от имени пользователя (по умолчанию). |
| `sticker_id` | `positive` | нет | Идентификатор стикера. |
| `guid` | `string` | нет | Уникальный идентификатор, предназначенный для предотвращения повторной отправки одинакового комментария. |

## Результат

В случае успеха возвращает идентификатор созданного комментария.
