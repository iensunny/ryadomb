# groups.getMembers

> Источник: [https://dev.vk.ru/ru/method/groups.getMembers](https://dev.vk.ru/ru/method/groups.getMembers)
Возвращает список участников сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `string` | нет | Идентификатор или короткое имя сообщества. |
| `sort` | `string` | нет | Сортировка, с которой необходимо вернуть список участников. Может принимать значения:<br>* `id_asc` — в порядке возрастания ID;<br>* `id_desc` — в порядке убывания ID;<br>* `time_asc` — в хронологическом порядке по вступлению в сообщество;<br>* `time_desc` — в антихронологическом порядке по вступлению в сообщество. <br>Сортировка по `time_asc` и `time_desc` возможна только при вызове от модератора сообщества. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определённого подмножества участников. По умолчанию `0`. |
| `count` | `positive` | нет | Количество участников сообщества, информацию о которых необходимо получить. |
| `fields` | `string` | нет | Список дополнительных полей, которые необходимо вернуть. <br>Доступные значения: <br>* `bdate`;<br>* `can_post`;<br>* `can_see_all_posts`;<br>* `can_see_audio`;<br>* `can_write_private_message`;<br>* `city`;<br>* `common_count`;<br>* `connections`;<br>* `contacts`;<br>* `country`;<br>* `domain`;<br>* `education`;<br>* `has_mobile`;<br>* `last_seen`;<br>* `lists`;<br>* `online`;<br>* `online_mobile`;<br>* `photo_100`;<br>* `photo_200`;<br>* `photo_200_orig`; <br>* `photo_400_orig`;<br>* `photo_50`;<br>* `photo_max`;<br>* `photo_max_orig`;<br>* `relation`;<br>* `relatives`;<br>* `schools`;<br>* `sex`;<br>* `site`;<br>* `status`;<br>* `universities`. |
| `filter` | `string` | нет | * `friends` — будут возвращены только друзья в этом сообществе.<br>* `unsure` — будут возвращены пользователи, которые выбрали «Возможно пойду» (если сообщество относится к мероприятиям).<br>* `managers` — будут возвращены только руководители сообщества (доступно при запросе с передачей `access_token` от имени администратора сообщества).<br>* `donut` — будут возвращены только доны (пользователи, у которых есть платная подписка VK Donut).<br>* `unsure_friends` — будут возвращены друзья в этом сообществе, которые выбрали «Возможно пойду» (если сообщество относится к мероприятиям).<br>* `invites` — будут возвращены пользователи, приглашенные в мероприятие. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` (`integer`) и массив идентификаторов пользователей в поле `items` (`integer`).

Если был передан параметр `filter`=`managers`, возвращается дополнительное поле `role` (`string`), которое содержит уровень полномочий руководителя:
* `advertiser` — рекламодатель;
* `moderator` — модератор;
* `editor` — редактор;
* `administrator` — администратор;
* `creator` — создатель сообщества.

## Типы ключа

`allow_from_server`, `group_access`
