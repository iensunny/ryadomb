# wall.editAdsStealth

> Источник: [https://dev.vk.ru/ru/method/wall.editAdsStealth](https://dev.vk.ru/ru/method/wall.editAdsStealth)
Позволяет отредактировать скрытую запись.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор владельца стены (идентификатор сообщества нужно указывать со знаком «минус»). |
| `post_id` | `positive` | да | Идентификатор записи. |
| `message` | `text` | нет | Текст записи. |
| `attachments` | `string` | нет | Список объектов, приложенных к записи и разделённых символом «`,`». Поле `attachments` представляется в формате:<br>```<br><type><owner_id>_<media_id>,<type><owner_id>_<media_id><br>```<br>`<type>` — тип медиа-приложения:<br>* `photo` — фотография; <br>* `video` — видеозапись ;<br>* `audio` — аудиозапись; <br>* `doc` — документ;<br>* `page` — wiki-страница;<br>* `note` — заметка;<br>* `poll` — опрос;<br>* `album` — альбом;<br>* `market` — товар;<br>* `market_album` — подборка товаров. <br>`<owner_id>` — идентификатор владельца медиа-приложения (обратите внимание, если объект находится в сообществе, этот параметр должен быть отрицательным). <br>`<media_id>` — идентификатор медиа-приложения. <br>Например:<br>```<br>photo100172_166443618,photo-1_265827614<br>```<br>Также в поле `attachments` может быть указана ссылка на внешнюю страницу, которую вы хотите разместить в записи, например:<br>```<br>photo66748_265827614,http://habrahabr.ru<br>```<br>В качестве ссылки может быть использован телефонный номер  в формате `tel:+71234567890`<br>При попытке приложить больше одной ссылки будет возвращена ошибка. <br>Параметр является обязательным, если не задан параметр `message`. |
| `signed` | `checkbox` | нет | `1` — у записи, размещенной от имени сообщества, будет добавлена подпись (имя пользователя, разместившего запись), `0` — без подписи. |
| `lat` | `string` | нет | Географическая широта отметки, заданная в градусах (от -90 до 90). |
| `long` | `string` | нет | Географическая долгота отметки, заданная в градусах (от -180 до 180). |
| `place_id` | `positive` | нет | Идентификатор места. |
| `link_button` | `string` | нет | Идентификатор кнопки, которую необходимо добавить к сниппету для ссылки. Подробнее см. документацию метода `wall.postAdsStealth`. |
| `link_title` | `string` | нет | Заголовок, который должен быть использован для сниппета. Если не указан, будет автоматически получен с целевой ссылки. Обязательно указывать в случае, если ссылка является номером телефона. |
| `link_image` | `string` | нет | Ссылка на изображение, которое должно быть использовано для сниппета. Минимальное разрешение: 537x240. Если не указана, будет автоматически загружена с целевой ссылки. Обязательно указывать в случае, если ссылка является номером телефона. Одновременно может быть указан либо параметр `link_image`, либо параметр `link_video`. |
| `link_video` | `string` | нет | Идентификатор видео в формате `<owner_id>_<media_id>`. Одновременно может быть указан либо параметр `link_image`, либо параметр `link_video`. Кроме того, параметр `link_video` может быть указан только вместе с параметрами `link_button`, `link_title`. |

При указании параметров `link_button`, `link_title`, `link_image`, `link_video`, необходимо указать целевую ссылку в поле `attachments`. Процесс формирования сниппета может занимать до нескольких минут после создания записи.

На рекламные записи с кнопками накладываются дополнительные ограничения:
*  В тексте записи не может быть других ссылок, кроме той, которая указана в поле `attachments`;
*  Максимальная длина текста записи составляет 220 символов;
*  В тексте записи может быть не более двух переводов строк;
*  Максимальная длина заголовка сниппета составляет 80 символов;
*  У записи не может быть других вложений, кроме ссылки.

## Результат

После успешного выполнения возвращает `1`.
