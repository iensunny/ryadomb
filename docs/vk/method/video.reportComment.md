# video.reportComment

> Источник: [https://dev.vk.ru/ru/method/video.reportComment](https://dev.vk.ru/ru/method/video.reportComment)
Позволяет пожаловаться на комментарий к видеозаписи.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца видеозаписи, к которой оставлен комментарий. |
| `comment_id` | `positive` | да | Идентификатор комментария. |
| `reason` | `positive` | нет | Тип жалобы. Возможные значения:<br>* `0` — это спам; <br>* `1` — детская порнография;<br>* `2` — экстремизм;<br>* `3` — насилие;<br>* `4` — пропаганда наркотиков;<br>* `5` — материал для взрослых;<br>* `6` — оскорбление. |

## Результат

После успешного выполнения возвращает `1`.

`video_ex`

## Типы ключа
