# ads.getUploadURL

> Источник: [https://dev.vk.ru/ru/method/ads.getUploadURL](https://dev.vk.ru/ru/method/ads.getUploadURL)
Возвращает URL-адрес для загрузки фотографии рекламного объявления.

Подробности о загрузке изображений для объявлений смотрите на [отдельной странице](method/ads/upload-photo-ads).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `ad_format` | `integer` | нет | Формат объявления:<br>* `1` — изображение и текст.<br>* `2` — большое изображение.<br>* `3` — эксклюзивный формат.<br>* `4` — продвижение сообществ или приложений, квадратное изображение.<br>* `5` — приложение в новостной ленте (устаревший).<br>* `6` — мобильное приложение.<br>* `11` — адаптивный формат.<br>Для формата объявления «запись в сообществе» этот метод не используется, т.к. фотографии являются частью записи со стены сообщества. Смотрите методы [`ads.createAds`](method/ads.createAds) и [`wall.postAdsStealth`](method/wall.postAdsStealth). |
| `icon` | `integer` | нет | `1` — получить URL для загрузки логотипа, а не основного изображения. Используется только для `ad_format = 11`. |



## Результат

Возвращает URL-адрес для загрузки изображения.

## Права доступа

`ads`
