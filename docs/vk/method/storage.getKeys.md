# storage.getKeys

> Источник: [https://dev.vk.ru/ru/method/storage.getKeys](https://dev.vk.ru/ru/method/storage.getKeys)
Возвращает названия всех переменных.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `positive` | нет | ID пользователя, названия переменных которого получаются, в случае если данные запрашиваются серверным методом. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества названий переменных. По умолчанию `0`. |
| `count` | `positive` | нет | Количество названий переменных, информацию о которых необходимо получить. |

## Результат

Возвращает массив названий переменных.

## Типы ключа

`allow_from_server`, `group_access`
