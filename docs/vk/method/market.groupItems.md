# market.groupItems

> Источник: [https://dev.vk.ru/ru/method/market.groupItems](https://dev.vk.ru/ru/method/market.groupItems)
Объединяет товары в группу товаров.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | идентификатор или короткое имя сообщества. |
| `item_ids` | `integer` | да | список товаров, которые нужно объединить. |
| `item_group_id` | `positive` | нет | опциональное поле, указывает на группу товаров, к которой <br>нужно добавить указанные item_ids. <br>Если не задано, создается новая группа. |

## Результат

В случае успеха возвращается идентификатор группы товаров.

## Права доступа

`market`
