# video.startStreaming

> Источник: [https://dev.vk.ru/ru/method/video.startStreaming](https://dev.vk.ru/ru/method/video.startStreaming)
Получает RTMP-адрес для трансляции видео.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `video_id` | `positive` | нет | идентификатор заранее созданной трансляции, в которую нужно пустить поток |
| `name` | `string` | нет | название трансляции. |
| `description` | `string` | нет | описание трансляции. |
| `wallpost` | `checkbox` | нет | _1_ — опубликовать трансляцию на стене. По умолчанию: _0_. |
| `group_id` | `integer` | нет | идентификатор сообщества, в котором будет вестись трансляция. |
| `privacy_view` | `string` | нет | настройки приватности просмотра видеозаписи в [специальном формате](reference/objects/privacy). |
| `privacy_comment` | `string` | нет | настройки приватности комментирования видеозаписи в [специальном формате](reference/objects/privacy). |
| `no_comments` | `checkbox` | нет | _1_ — отключить комментирование трансляции. По умолчанию: _0_. |
| `category_id` | `integer` | нет | идентификатор [категории](method/video.liveGetCategories). |
| `publish` | `checkbox` | нет | _1_ — опубликовать трансляцию, находящуюся в состоянии предпросмотра. По умолчанию: _0_. |

## Результат

Возвращает объект, который содержит следующие поля:
* **owner_id** (integer) — идентификатор владельца трансляции;
* **video_id** (integer) — идентификатор трансляции;
* **name** (string) — название трансляции;
* **description** (string) — описание трансляции;
* **access_key** (string) — [ключ доступа](reference/objects) к приватному объекту;
* **stream** (object) — данные для загрузки видео. Объект, который содержит следующие поля:
   * **url** (string) — rtmp-адрес трансляции, если **call = false**.
   * **key** (string) — ключ доступа (фрагмент адреса), если **call = false**.
* **post_id** (integer) — идентификатор записи на стене, в которой находится трансляция.

## Права доступа

`video`
