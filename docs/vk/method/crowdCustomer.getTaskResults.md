# crowdCustomer.getTaskResults

> Источник: [https://dev.vk.ru/ru/method/crowdCustomer.getTaskResults](https://dev.vk.ru/ru/method/crowdCustomer.getTaskResults)
Получение результатов разметки задачи

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `task_id` | `positive` | да | Id задачи |
| `token` | `string` | да | Токен |
| `limit` | `positive` | нет | Количество результатов |
| `last_id` | `positive` | нет | Последний id результата |
| `ids` | `string` | нет | Фильтр по id результатов |
