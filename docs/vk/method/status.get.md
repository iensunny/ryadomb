# status.get

> Источник: [https://dev.vk.ru/ru/method/status.get](https://dev.vk.ru/ru/method/status.get)
Получить текст статуса пользователя или сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `integer` | нет | Идентификатор пользователя, статус которого необходимо получить. |
| `group_id` | `integer` | нет | Идентификатор сообщества, статус которого необходимо получить. |

## Результат

В случае успеха возвращает объект, у которого в поле `text` содержится текст статуса пользователя или сообщества. 

Если у пользователя включена трансляция играющей музыки в статус и в данный момент воспроизводится аудиозапись, то также будет возвращён объект [`audio`](reference/objects/audio).

## Права доступа

`activity`
