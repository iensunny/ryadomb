# stories.banOwner

> Источник: [https://dev.vk.ru/ru/method/stories.banOwner](https://dev.vk.ru/ru/method/stories.banOwner)
Позволяет скрыть из ленты новостей истории от выбранных источников.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owners_ids` | `integer` | да | Список идентификаторов источников. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`ex`, `stories`

## Типы ключа

`is_standalone`
