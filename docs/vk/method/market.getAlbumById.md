# market.getAlbumById

> Источник: [https://dev.vk.ru/ru/method/market.getAlbumById](https://dev.vk.ru/ru/method/market.getAlbumById)
Возвращает данные подборки с товарами.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца подборки.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «`-`» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `album_ids` | `integer` | да | Идентификаторы подборок, данные о которых нужно получить. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [подборок](reference/objects/market-album) в поле `items`.

## Права доступа

`market`
