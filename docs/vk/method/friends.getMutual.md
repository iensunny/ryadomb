# friends.getMutual

> Источник: [https://dev.vk.ru/ru/method/friends.getMutual](https://dev.vk.ru/ru/method/friends.getMutual)
Возвращает список идентификаторов общих друзей между парой пользователей.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `source_uid` | `integer` | нет | Идентификатор пользователя, чьи друзья пересекаются с друзьями пользователя с идентификатором `target_uid`. Если параметр не задан, то считается, что `source_uid` равен идентификатору текущего пользователя. |
| `target_uid` | `integer` | нет | Идентификатор пользователя, с которым необходимо искать общих друзей. |
| `target_uids` | `string` | нет | Список идентификаторов пользователей, с которыми необходимо искать общих друзей. |
| `order` | `string` | нет | Порядок, в котором нужно вернуть список общих друзей. Допустимые значения: `random`— возвращает друзей в случайном порядке. По умолчанию — в порядке возрастания идентификаторов. |
| `count` | `positive` | нет | Количество общих друзей, которое нужно вернуть. (По умолчанию — `все общие друзья`). |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества общих друзей. |
| `need_common_count` | `checkbox` | нет |  |

## Результат

После успешного выполнения возвращает список идентификаторов (`id`) общих друзей между пользователями с идентификаторами `source_uid` и `target_uid`.

## Права доступа

`friends`
