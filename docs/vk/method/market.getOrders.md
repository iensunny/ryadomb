# market.getOrders

> Источник: [https://dev.vk.ru/ru/method/market.getOrders](https://dev.vk.ru/ru/method/market.getOrders)
Возвращает заказы.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `offset` | `positive` | нет | Смещение относительно первого найденного заказа для выборки определенного подмножества. |
| `count` | `positive` | нет | Число заказов, которые необходимо получить. |
| `extended` | `checkbox` | нет | `1` – вернуть в ответе дополнительное поле `groups` (`array`), содержащее список объектов [сообществ](reference/objects/group). |
| `date_from` | `string` | нет | Начальная дата для фильтрации списка возвращаемых заказов по дате обновления. Формат: YYYY-MM-DD. |
| `date_to` | `string` | нет | Конечная дата для фильтрации списка возвращаемых заказов по дате обновления. Формат: YYYY-MM-DD. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив заказов.

## Права доступа

`market`
