# wall.getReposts

> Источник: [https://dev.vk.ru/ru/method/wall.getReposts](https://dev.vk.ru/ru/method/wall.getReposts)
Позволяет получать список репостов заданной записи.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества, на стене которого находится запись. Если параметр не задан, то он считается равным идентификатору текущего пользователя.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «-» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `post_id` | `positive` | нет | Идентификатор записи на стене. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества записей. |
| `count` | `positive` | нет | Количество записей, которое необходимо получить. |

## Результат

После успешного выполнения возвращает объект, содержащий поля:
* `items` — содержит массив [записей-репостов](reference/objects/post);
* `profiles` — содержит объекты [пользователей](reference/objects/user) с дополнительными полями `sex`, `online`, `photo`, `photo_medium_rec`, `screen_name`;
* `groups` — содержит информацию о [сообществах](reference/objects/group).

## Типы ключа

`allow_from_server`
