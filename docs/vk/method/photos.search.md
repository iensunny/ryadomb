# photos.search

> Источник: [https://dev.vk.ru/ru/method/photos.search](https://dev.vk.ru/ru/method/photos.search)
Осуществляет поиск изображений по местоположению или описанию.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `q` | `string` | нет | Строка поискового запроса, например, `Nature`. |
| `lat` | `string` | нет | Географическая широта отметки, заданная в градусах (от -90 до 90). |
| `long` | `string` | нет | Географическая долгота отметки, заданная в градусах (от -180 до 180). |
| `start_time` | `positive` | нет | Время в формате `unixtime`, не раньше которого должны были быть загружены найденные фотографии. |
| `end_time` | `positive` | нет | Время в формате `unixtime`, не позже которого должны были быть загружены найденные фотографии. |
| `sort` | `positive` | нет | Сортировка результатов. Возможные значения:<br>* `1` — по количеству отметок «Мне нравится»;<br>* `0` — по дате добавления фотографии. |
| `offset` | `positive` | нет | Смещение относительно первой найденной фотографии для выборки определённого подмножества. |
| `count` | `positive` | нет | Количество возвращаемых фотографий.<br>> Обратите внимание, даже при использовании параметра `offset` для получения информации доступны не больше 3000 результатов. |
| `radius` | `positive` | нет | Радиус поиска в метрах. Работает очень приближенно, поэтому реальное расстояние до цели может отличаться от заданного. Может принимать значения: `10`, `100`, `800`, `6000`, `50000`. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [фотографий](reference/objects/photo) в поле `items`.

## Типы ключа

`allow_from_server`
