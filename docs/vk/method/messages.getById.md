# messages.getById

> Источник: [https://dev.vk.ru/ru/method/messages.getById](https://dev.vk.ru/ru/method/messages.getById)
Возвращает сообщения по их идентификаторам.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `message_ids` | `string` | нет | Идентификаторы сообщений. Максимум 100 идентификаторов. |
| `preview_length` | `positive` | нет | Количество символов, по которому нужно обрезать сообщение. Укажите `0`, если вы не хотите обрезать сообщение (по умолчанию сообщения не обрезаются). |
| `extended` | `checkbox` | нет | `1` — возвращать дополнительные поля. |
| `fields` | `string` | нет | Список дополнительных полей для [пользователей](reference/objects/user) и [сообществ](reference/objects/group). |
| `group_id` | `integer` | нет | Идентификатор сообщества (для сообщений сообщества с ключом доступа пользователя). |
| `cmids` | `integer` | нет | Массив идентификаторов сообщений из беседы. |
| `peer_id` | `integer` | нет | Идентификатор получателя сообщения:<br>* Для пользователя — `ИДЕНТИФИКАТОР_ПОЛЬЗОВАТЕЛЯ`.<br>* Для групповой беседы — `2000000000 + ИДЕНТИФИКАТОР_БЕСЕДЫ`.<br>* Для сообщества — `-ИДЕНТИФИКАТОР_СООБЩЕСТВА`. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов, описывающих [сообщения](reference/objects/message), в поле `items`.

## Права доступа

`messages_ex`

## Типы ключа

`group_access`, `is_standalone`
