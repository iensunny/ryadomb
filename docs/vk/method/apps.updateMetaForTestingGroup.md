# apps.updateMetaForTestingGroup

> Источник: [https://dev.vk.ru/ru/method/apps.updateMetaForTestingGroup](https://dev.vk.ru/ru/method/apps.updateMetaForTestingGroup)
Метод создает новую или обновляет существующую группу тестировщиков мини-приложения.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | нет | Идентификатор группы тестировщиков. Укажите значение параметра, чтобы создать группу тестировщиков с таким идентификатором или обновить существующую группу. Если создано 25 групп тестировщиков, метод вернёт ошибку `Out of limits`. |
| `webview` | `string` | да | URL, по которому доступна версия мини-приложения для тестирования. |
| `name` | `string` | да | Название группы тестировщиков. |
| `platforms` | `string` | да | Названия платформ, для которых доступна версия мини-приложения, перечисленные через запятую (например, `"mvk, web"`). Названия платформ:&#x0d;&#x0a; &bullet; `mobile` — мобильное приложение (Android, iOS);&#x0d;&#x0a; &bullet; `web` — десктопная версия сайта (vk.com);&#x0d;&#x0a; &bullet; `mvk` — мобильная версия сайта (m.vk.com). |
| `user_ids` | `string` | нет | Идентификаторы пользователей, которые входят в группу тестировщиков, перечисленные через запятую (например, `"11, 13"`). Если суммарное количество пользователей в группе тестировщиков превысит 1000, метод вернёт ошибку `Out of limits`. |

## Результат

Метод возвращает параметр идентификатор группы тестировщиков (`group_id`).

```JSON
{
  "response":{
    "group_id":11
  }
}
```

## Типы ключа

`allow_from_server`, `user_access_hidden`
