# video.report

> Источник: [https://dev.vk.ru/ru/method/video.report](https://dev.vk.ru/ru/method/video.report)
Позволяет пожаловаться на видеозапись.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор пользователя или сообщества, которому принадлежит видеозапись. |
| `video_id` | `positive` | да | Идентификатор видеозаписи. |
| `reason` | `positive` | нет | Тип жалобы. Возможные значения:<br>* `0` — это спам; <br>* `1` — детская порнография;<br>* `2` — экстремизм;<br>* `3` — насилие;<br>* `4` — пропаганда наркотиков;<br>* `5` — материал для взрослых;<br>* `6` — оскорбление. |
| `comment` | `string` | нет | Комментарий для жалобы. |
| `search_query` | `string` | нет | Поисковой запрос, если видеозапись была найдена через поиск. |

## Результат

После успешного выполнения возвращает `1`.
