# friends.getRequests

> Источник: [https://dev.vk.ru/ru/method/friends.getRequests](https://dev.vk.ru/ru/method/friends.getRequests)
Возвращает информацию о полученных или отправленных заявках на добавление в друзья для текущего пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества заявок на добавление в друзья. |
| `count` | `positive` | нет | Максимальное количество заявок на добавление в друзья, которые необходимо получить (не более **1000**). <br>По умолчанию — **100**. |
| `extended` | `checkbox` | нет | Определяет, требуется ли возвращать в ответе сообщения от пользователей, подавших заявку на добавление в друзья. И отправителя рекомендации при `suggested` = `1`. |
| `need_mutual` | `checkbox` | нет | Определяет, требуется ли возвращать в ответе список общих друзей, если они есть. Обратите внимание, что при использовании `need_mutual` будет возвращено не более `2` заявок. |
| `out` | `checkbox` | нет | `0` — возвращать полученные заявки в друзья (по умолчанию), `1` — возвращать отправленные пользователем заявки. |
| `sort` | `positive` | нет | `0` — сортировать по дате добавления, `1` — сортировать по количеству общих друзей. (Если `out` = `1`, этот параметр не учитывается). |
| `need_viewed` | `checkbox` | нет | `0` — не возвращать просмотренные заявки, `1` — возвращать просмотренные заявки. (Если `out` = `1`, данный параметр не учитывается). |
| `suggested` | `checkbox` | нет | `1` — возвращать рекомендованных другими пользователями друзей, `0` — возвращать заявки в друзья (по умолчанию). |
| `ref` | `string` | нет |  |
| `fields` | `string` | нет |  |

## Результат

* Если не установлен параметр `need_mutual`, то в случае успеха возвращает отсортированный в антихронологическом порядке по времени подачи заявки список идентификаторов (`id`) пользователей (кому или от кого пришла заявка).

* Если установлен параметр `need_mutual`, то в случае успеха возвращает отсортированный в антихронологическом порядке по времени подачи заявки массив объектов, содержащих информацию о заявках на добавление в друзья. Каждый из объектов содержит поле `uid`, являющийся идентификатором пользователя. При наличии общих друзей, в объекте будет содержаться поле `mutual`, в котором будет находиться список идентификаторов общих друзей.
