# wall.edit

> Источник: [https://dev.vk.ru/ru/method/wall.edit](https://dev.vk.ru/ru/method/wall.edit)
:::note
После обновления методов **4 июня 2026 года** изображения нестандартных размеров в карусели кадрируются автоматически. Чтобы задать свои значения, используйте параметр `photo_attachments_crop`.

[Подробнее](https://vk.com/@vkappsdev-obnovlenie-raboty-metodov-wallpost-i-walledit-kadrirovanie-i)
:::

Редактирует запись на стене.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества, на стене которого находится запись.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «минус» — например, `owner_id` = `-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1) |
| `post_id` | `positive` | да | Идентификатор записи на стене. |
| `friends_only` | `checkbox` | нет | `1` — запись будет доступна только друзьям, `0` — всем пользователям. <br>Параметр учитывается только при редактировании отложенной записи. |
| `message` | `text` | нет | Текст сообщения (является обязательным, если не задан параметр `attachments`). |
| `attachments` | `string` | нет | Список объектов, приложенных к записи и разделённых символом «`,`». Поле `attachments` представляется в формате:<br>```<br><type><owner_id>_<media_id>,<type><owner_id>_<media_id><br>```<br>* `type` — тип медиавложения:<br>    * `photo` — фотография.<br>    * `video` — видеозапись.<br>    * `audio` — аудиозапись.<br>    * `doc` — файл.<br>    * `poll` — опрос.<br>    * `audio_playlist` — плейлист с аудио.<br>`<owner_id>` — идентификатор владельца медиа-приложения;<br>`<media_id>` — идентификатор медиа-приложения.<br>Например:<br>```<br>photo100172_166443618,photo66748_265827614<br>```<br>Также в поле `attachments` может быть указана ссылка на внешнюю страницу, которую Вы хотите разместить в статусе, например:<br>```<br>photo66748_265827614,http://habrahabr.ru<br>```<br>При попытке приложить больше одной ссылки будет возвращена ошибка. <br>Параметр является обязательным, если не задан параметр `message`. |
| `photo_attachments_crop` | `text` | нет | Параметр обрезки для фото.<br>Формат: **массив объектов JSON**, где каждый объект состоит из:<br>* `photo_id` — идентификатор фотографии в формате `{owner_id}_{media_id}`<br>* `x` — смещение слева в пикселях<br>* `y` — смещение слева в пикселях<br>* `width` — ширина в пикселях<br>* `height` — высота в пикселях<br>Пример: <br>```<br>[<br>  {<br>    "photo_id": "11111111_23423421",<br>    "x": 10,<br>    "y": 10,<br>    "width": 300,<br>    "height": 300<br>  }<br>]<br>``` |
| `services` | `string` | нет | Список сервисов или сайтов, на которые необходимо экспортировать запись, в случае если пользователь настроил соответствующую опцию. Например, `twitter`, `facebook`. <br>Параметр учитывается только при редактировании отложенной записи. |
| `signed` | `checkbox` | нет | `1` — у записи, размещенной от имени сообщества будет добавлена подпись (имя пользователя, разместившего запись), `0` — подписи добавлено не будет. <br>Параметр учитывается только при редактировании записи на стене сообщества, опубликованной от имени группы. |
| `publish_date` | `positive` | нет | Дата публикации записи в формате `unixtime`. Если параметр не указан, отложенная запись будет опубликована.<br>Параметр учитывается только при редактировании отложенной записи. |
| `lat` | `string` | нет | Географическая широта отметки, заданная в градусах (от -90 до 90). |
| `long` | `string` | нет | Географическая долгота отметки, заданная в градусах (от -180 до 180). |
| `place_id` | `positive` | нет | Идентификатор места, в котором отмечен пользователь. |
| `mark_as_ads` | `checkbox` | нет | `1` — у записи, размещенной от имени сообщества, будет добавлена метка «это реклама», `0` — метки добавлено не будет/снять установленную метку. Метка может быть снята в течение пяти минут после её установки. В сутки может быть опубликовано не более пяти рекламных записей, из которых не более трёх — вне Биржи ВКонтакте. |
| `close_comments` | `checkbox` | нет | `1` — комментарии к записи отключены.<br>`0` — комментарии к записи включены. |
| `donut_paid_duration` | `integer` | нет | период времени в течение которого запись будет доступна для донов — платных подписчиков VK Donut. Возможные значения:<br>* `-1` —  исключительно для донов;<br>* `86400` — на 1 день;<br>* `172800` — на 2 дня;<br>* `172800` — на 3 дня;<br>* `345600` — на 4 дня;<br>* `432000` — на 5 дней;<br>* `518400` — на 6 дней;<br>* `604800` — на 7 дней. |
| `poster_bkg_id` | `positive` | нет | не используется, помечен для удаления |
| `poster_bkg_owner_id` | `integer` | нет | не используется, помечен для удаления |
| `poster_bkg_access_hash` | `string` | нет | не используется, помечен для удаления |
| `topic_id` | `positive` | нет |  |
| `primary_attachments_mode` | `string` | нет | Определяет формат отображения прикреплённых медиа файлов. По умолчанию они располагаются в виде карусели, где пользователь может просматривать их по одному как слайд-шоу. При установке значения `grid` медиа файлы будут представлены в формате сетки, где несколько медиа файлов показываются одновременно. |

## Результат

После успешного выполнения возвращает `post_id` — идентификатор отредактированного поста.

## Права доступа

`wall_ex`

## Типы ключа

`is_standalone`

## Ошибки

- 224
- 225

Ограничения на публикуемый контент:
* В пост можно добавить не более 10 медиа (фото, видео).
* В пост можно добавить не более 1 музыкального трека или 1 плейлист/альбом*
* Нельзя добавить в пост музыку, если в нем есть видео.
* Музыка может быть добавлена, если есть хотя бы 1 фотография.
* Может быть добавлен 1 файл.
