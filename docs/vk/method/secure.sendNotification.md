# secure.sendNotification

> Источник: [https://dev.vk.ru/ru/method/secure.sendNotification](https://dev.vk.ru/ru/method/secure.sendNotification)
Отправляет уведомление одному или нескольким пользователям.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_ids` | `string` | нет | **Необязательный параметр**. Перечисленные через запятую идентификаторы пользователей, которым отправляется уведомление. Максимально допустимое число идентификаторов в строке — 100.<br>Если этот параметр не указан, то будет использован `user_id`. Если указаны оба параметра, то будет использован `user_ids`. |
| `user_id` | `integer` | нет | **Необязательный параметр**. Идентификатор пользователя, которому будет отправлено уведомление.<br>Параметр используется, если не указан `user_ids`. |
| `message` | `string` | да | **Обязательный параметр**. Текст уведомления в кодировке UTF-8. Максимальная длина — 254 символа. |
| `notification_id` | `positive` | нет | **Необязательный параметр**. Идентификатор рассылки. Целое число в диапазоне от 1 до 9&thinsp;223&thinsp;372&thinsp;036&thinsp;854&thinsp;775&thinsp;807.<br>Если пользователь запустит игру, нажав на кнопку в уведомлении, то приложение получит URL-параметр `ref_notification_id`, который будет содержать идентификатор рассылки. Используйте это значение на стороне игры для проверки эффективности сообщений. |

## Результат

Возвращает перечисленные через запятую ID пользователей, которым было успешно отправлено уведомление.

## Права доступа

`notify_global`

## Типы ключа

`secure`

Уведомление будет видно в разделе **Игры &rarr; Профиль** в десктопной версии сайта ВКонтакте.  

> Обратите внимание, что нельзя отправлять пользователю более 1 уведомления в час и более 3 уведомлений в сутки. Кроме того, нельзя отправлять пользователю одинаковые уведомления подряд.
