# pages.getHistory

> Источник: [https://dev.vk.ru/ru/method/pages.getHistory](https://dev.vk.ru/ru/method/pages.getHistory)
Возвращает список всех старых версий вики-страницы.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `page_id` | `string` | да | Идентификатор вики-страницы. |
| `group_id` | `string` | нет | Идентификатор сообщества, которому принадлежит вики-страница. |
| `user_id` | `string` | нет | Идентификатор пользователя, создавшего вики-страницу. |

## Результат

Возвращает массив объектов `page_version`, имеющих следующую структуру:
* `id` — идентификатор версии страницы;
* `length`  длина версии страницы в байтах;
* `edited` — дата редактирования страницы;
* `editor_id` — идентификатор редактора;
* `editor_name` — имя редактора.

## Права доступа

`pages`
