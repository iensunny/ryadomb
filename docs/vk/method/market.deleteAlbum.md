# market.deleteAlbum

> Источник: [https://dev.vk.ru/ru/method/market.deleteAlbum](https://dev.vk.ru/ru/method/market.deleteAlbum)
Метод удаляет подборку с товарами.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | **Обязательный параметр.** Идентификатор владельца подборки, указанный со знаком `-`. |
| `album_id` | `positive` | да | **Обязательный параметр.** Идентификатор подборки. |

## Результат

Метод возвращает `1`, если подборка удалена, и `0` в случае ошибки.

Пример ответа:

```JSON
{
  "response": 1
}
```

## Права доступа

`market`
