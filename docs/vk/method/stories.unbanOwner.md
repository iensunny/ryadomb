# stories.unbanOwner

> Источник: [https://dev.vk.ru/ru/method/stories.unbanOwner](https://dev.vk.ru/ru/method/stories.unbanOwner)
Позволяет вернуть пользователя или сообщество в список отображаемых историй в ленте.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owners_ids` | `integer` | да | Список идентификаторов владельцев историй, разделённых запятой. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`ex`, `stories`

## Типы ключа

`is_standalone`
