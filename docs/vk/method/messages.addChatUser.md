# messages.addChatUser

> Источник: [https://dev.vk.ru/ru/method/messages.addChatUser](https://dev.vk.ru/ru/method/messages.addChatUser)
Добавляет в мультидиалог нового пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `chat_id` | `positive` | да | Идентификатор беседы. |
| `user_id` | `positive` | нет | Идентификатор пользователя, которого необходимо включить в беседу. |
| `visible_messages_count` | `positive` | нет |  |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`messages_ex`

## Типы ключа

`is_standalone`
