# market.search

> Источник: [https://dev.vk.ru/ru/method/market.search](https://dev.vk.ru/ru/method/market.search)
Метод получает товары из каталога сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор сообщества, которому принадлежат товары. |
| `album_id` | `positive` | нет | Идентификатор подборки, товары из которой нужно вернуть. |
| `q` | `string` | нет | Строка поискового запроса. Пример: `зелёные тапочки`. |
| `price_from` | `positive` | нет | Минимальная цена товаров в сотых долях единицы валюты. Пример: `100000`. |
| `price_to` | `positive` | нет | Максимальная цена товаров в сотых долях единицы валюты. Пример: `1410000`. |
| `sort` | `integer` | нет | Вид сортировки. Возможные значения:<br>* `0` — пользовательская расстановка.<br>* `1` — по дате добавления товара.<br>* `2` — по цене.<br>* `3` — по популярности. |
| `rev` | `positive` | нет | Информация о том, использовать ли обратный порядок выдачи. Возможные значения:<br>* `1` — использовать обратный порядок.<br>* `0` — не использовать обратный порядок. |
| `offset` | `positive` | нет | Смещение для возвращения товаров относительно начала списка. Если параметр не задан, его значение будет `0`. |
| `count` | `positive` | нет | Количество возвращаемых товаров. |
| `extended` | `checkbox` | нет | Информация о том, вернуть ли дополнительные поля. Возможные значения:<br>* `1` — вернуть дополнительные поля `likes`, `can_comment`, `can_repost`, `photos`, `views_count`.<br>* `0` — не возвращать дополнительные поля. Значение используется по умолчанию. |
| `status` | `integer` | нет | Фильтр по активности товара. Возможные значения:<br>* `"0"` — активные. Значение используется по умолчанию.<br>* `"2"` — неактивные.<br>* `"0, 2"` — активные и неактивные. |
| `need_variants` | `checkbox` | нет | Информация о том, нужно ли получить дополнительные варианты товара. Возможные значения:<br>* `1` — нужно получить варианты товара.<br>* `0` — не нужно получать варианты товара. |

## Результат

Метод возвращает объект. Поля объекта:

| Поле | Тип | Описание |
| --- | --- | --- |
| `count` | `integer` | Количество возвращаемых товаров. |
| `view_type` | `integer` | Тип отображения товара. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `1` — отображение в виде карточек.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `2` — отображение в виде рядов. |
| `items` | `array[object]` | Массив объектов [товаров](reference/objects/market-item). |
