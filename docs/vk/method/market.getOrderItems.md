# market.getOrderItems

> Источник: [https://dev.vk.ru/ru/method/market.getOrderItems](https://dev.vk.ru/ru/method/market.getOrderItems)
Возвращает товары в заказе.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `positive` | нет | ID пользователя, который сделал заказ. |
| `order_id` | `positive` | да | Идентификатор заказа. |
| `offset` | `positive` | нет | Смещение относительно первого найденного товара в заказе для выборки определенного подмножества. |
| `count` | `positive` | нет | Количество возвращаемых товаров в заказе. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [товаров](reference/objects/market-item) c дополнительным полем `quantity` в поле `items`.

## Права доступа

`market`

## Типы ключа

`group_access`
