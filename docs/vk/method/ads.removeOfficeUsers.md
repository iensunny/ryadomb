# ads.removeOfficeUsers

> Источник: [https://dev.vk.ru/ru/method/ads.removeOfficeUsers](https://dev.vk.ru/ru/method/ads.removeOfficeUsers)
Удаляет администраторов и/или наблюдателей из рекламного кабинета.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | Идентификатор рекламного кабинета. |
| `ids` | `text` | да | Сериализованный JSON-массив, содержащий `id` удаляемых администраторов. |

## Результат

Возвращает массив значений - ответов на каждый запрос в массиве `data`. Соответствующее значение в выходном массиве равно `true`, если администратор успешно удален, и `false` в другом случае.

## Права доступа

`ads`
