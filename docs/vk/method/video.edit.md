# video.edit

> Источник: [https://dev.vk.ru/ru/method/video.edit](https://dev.vk.ru/ru/method/video.edit)
Метод редактирует данные видеозаписи.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | **Необязательный параметр.** Идентификатор пользователя или сообщества, которому принадлежит видеозапись. Идентификатор сообщества должен начинаться со знака&nbsp;`-`. |
| `video_id` | `positive` | да | **Обязательный параметр.** Идентификатор видеозаписи.<br>Вы можете найти идентификатор в адресной строке открытой видеозаписи:<br>* После слова `video`.<br>* После знака `?`. |
| `name` | `string` | нет | **Необязательный параметр.** Новое название видеозаписи. Максимальное количество символов — 128. |
| `desc` | `string` | нет | **Необязательный параметр.** Новое описание видеозаписи. Максимальное количество символов — 5&nbsp;000. |
| `privacy_view` | `string` | нет | **Необязательный параметр.** Настройки приватности просмотра видеозаписи. Указывается в [специальном формате](reference/objects/privacy).<br>**Примечание.** Параметр соответствует настройкам [приватности сообществ](reference/objects/privacy/#Приватность%20просмотра%20(privacy_view)), если видеозапись принадлежит сообществу. |
| `privacy_comment` | `string` | нет | **Необязательный параметр.** Настройки приватности комментирования видеозаписи. Указывается в [специальном формате](reference/objects/privacy).<br>**Примечание.** Параметр соответствует настройкам [приватности сообществ](reference/objects/privacy/#Приватность%20комментирования%20(privacy_comment)), если видеозапись принадлежит сообществу. |
| `no_comments` | `checkbox` | нет | **Необязательный параметр.** Информация о том, отключить ли возможность комментирования видеозаписи из сообществ. Возможные значения:<br>* `1` — отключить возможность комментирования.<br>* `0` — не отключать возможность комментирования. Значение используется по умолчанию. |
| `repeat` | `checkbox` | нет | **Необязательный параметр.** Информация о том, зациклить ли воспроизведение видеозаписи. Возможные значения:<br>* `1` — зациклить видеозапись.<br>* `0` — не зацикливать видеозапись. |
| `ord_info` | `text` | нет | Информация для оператора рекламных данных (ОРД):<br>* `is_ads`. Передаётся `true`, если пользователь пометил видео как рекламу, но не заполнил данные для ОРД.<br>* `advertisers`. Данные, полученные из мини-приложения ОРД VK:<br>    * `er_id` — токен для отслеживания и учёта.<br>    * `ord_pred_id` — внутренний идентификатор. |

## Результат

Метод возвращает объект. Поля объекта:

| Поле | Тип | Описание |
| --- | --- | --- |
| `success` | `integer` | Статус успешного выполнения запроса. Всегда `1`. |
| `access_key` | `string` | Ключ доступа. Возвращается, когда выбрана приватность сообщества `by_link` (доступ по ссылке). Параметр доступен в версии API 5.195 и выше. |

:::note
**Примечание.** До версии API 5.195 после успешного выполнения возвращается только `1`.
:::
