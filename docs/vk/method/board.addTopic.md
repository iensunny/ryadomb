# board.addTopic

> Источник: [https://dev.vk.ru/ru/method/board.addTopic](https://dev.vk.ru/ru/method/board.addTopic)
Создает новую тему в списке обсуждений группы.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `string` | да | Идентификатор сообщества. |
| `title` | `string` | да | Название обсуждения. |
| `text` | `string` | нет | Текст первого сообщения в обсуждении. |
| `from_group` | `checkbox` | нет | `1` — тема будет создана от имени группы, `0` — тема будет создана от имени пользователя (по умолчанию). |
| `attachments` | `string` | нет | Список объектов, приложенных к записи, в формате:<br>```<br><type><owner_id>_<media_id>,<type><owner_id>_<media_id><br>```<br>`<type>` — тип медиа-приложения:<br>* `photo` — фотография; <br>* `video` — видеозапись ;<br>* `audio` — аудиозапись; <br>* `doc` — документ.<br>`<owner_id>` — идентификатор владельца медиа-приложения.<br>`<media_id>` — идентификатор медиа-приложения. <br>Например:<br>```<br>photo100172_166443618,photo66748_265827614<br>```<br>Параметр является обязательным, если не задан параметр `text`. |

## Результат

В случае успеха возвращает идентификатор созданной темы.

## Права доступа

`groups_ex`

## Типы ключа

`is_standalone`
