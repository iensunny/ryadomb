# wall.reportComment

> Источник: [https://dev.vk.ru/ru/method/wall.reportComment](https://dev.vk.ru/ru/method/wall.reportComment)
Позволяет пожаловаться на комментарий к записи.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор пользователя или сообщества, которому принадлежит комментарий. |
| `comment_id` | `positive` | да | Идентификатор комментария. |
| `reason` | `positive` | нет | Причина жалобы:<br>*  `0` — спам;<br>*  `1` — детская порнография;<br>*  `2` — экстремизм;<br>*  `3` — насилие;<br>*  `4` — пропаганда наркотиков;<br>*  `5` — материал для взрослых;<br>*  `6` — оскорбление;<br>*  `8` — призывы к суициду. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`wall_ex`

## Типы ключа

`is_standalone`
