# market.getOrderById

> Источник: [https://dev.vk.ru/ru/method/market.getOrderById](https://dev.vk.ru/ru/method/market.getOrderById)
Возвращает заказ по идентификатору.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `positive` | нет | Идентификатор пользователя (для получения заказов других пользователей при наличии прав в сообществе).<br>Если не указан, используется ID пользователя, вызвавшего метод. |
| `order_id` | `positive` | да | Идентификатор заказа. |
| `extended` | `checkbox` | нет | Если принимает значение `1`, в ответе возвращается дополнительная информация о стоимости заказа. |

## Результат

После успешного выполнения возвращает объект [заказа](reference/objects/market-order).

## Права доступа

`market`

## Типы ключа
