# photos.editAlbum

> Источник: [https://dev.vk.ru/ru/method/photos.editAlbum](https://dev.vk.ru/ru/method/photos.editAlbum)
Редактирует данные альбома для фотографий.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `album_id` | `string` | да | Идентификатор альбома. |
| `title` | `string` | нет | Новое название альбома. |
| `description` | `string` | нет | Новый текст описания альбома. |
| `owner_id` | `string` | нет | Идентификатор владельца альбома (пользователь или сообщество).<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `privacy` | `integer` | нет | Новый уровень доступа к альбому (только для альбома пользователя). <br>Возможные значения:<br>*  `0` — все пользователи,<br>*  `1` — только друзья,<br>*  `2` — друзья и друзья друзей,<br>*  `3` — только я. |
| `comment_privacy` | `integer` | нет | Новый уровень доступа к комментированию альбома (только для альбома пользователя).<br>Возможные значения:<br>*  `0` — все пользователи,<br>*  `1` — только друзья,<br>*  `2` — друзья и друзья друзей,<br>*  `3` — только я. |
| `privacy_view` | `string` | нет | Настройки приватности просмотра альбома в [специальном формате](reference/objects/privacy). |
| `privacy_comment` | `string` | нет | Настройки приватности комментирования альбома в [специальном формате](reference/objects/privacy). |
| `upload_by_admins_only` | `checkbox` | нет | Кто может загружать фотографии в альбом (только для альбома сообщества). <br>Возможные значения:<br>*  `0` — фотографии могут добавлять все пользователи;<br>*  `1` — фотографии могут добавлять только редакторы и администраторы. |
| `comments_disabled` | `checkbox` | нет | Отключено ли комментирование альбома (только для альбома сообщества).<br>Возможные значения:<br>*  `0` — комментирование включено;<br>*  `1` — комментирование отключено. |

## Результат

После успешного выполнения возвращает `1`.
