# groups.invite

> Источник: [https://dev.vk.ru/ru/method/groups.invite](https://dev.vk.ru/ru/method/groups.invite)
Позволяет приглашать друзей в группу.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | Идентификатор группы, в которую необходимо выслать приглашение. |
| `user_id` | `positive` | да | Идентификатор пользователя, которому необходимо выслать приглашение. |

## Результат

В случае успешного выполнения возвращает `1`.

## Права доступа

`groups_ex`

## Типы ключа

`is_standalone`

## Ошибки

- 1016
