# video.save

> Источник: [https://dev.vk.ru/ru/method/video.save](https://dev.vk.ru/ru/method/video.save)
Метод получает адрес сервера, на который необходимо [загрузить](api/upload/video-in-profile) видео, а также данные этого видео.

:::note
**Примечание.** Приложение может вызвать этот метод не более 5&nbsp;000 раз в сутки.
:::

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `name` | `string` | нет | **Необязательный параметр.** Название видеофайла. Максимальное количество символов — 128. |
| `description` | `string` | нет | **Необязательный параметр.** Описание видеофайла. Максимальное количество символов — 5&nbsp;000. |
| `is_private` | `checkbox` | нет | **Необязательный параметр.** Информация о том, можно ли будет отправлять загруженное видео личным сообщением. Возможные значения:<br>* `1` — загрузить видео, которое можно будет отправлять личным сообщением.<br>* `0` — загрузить видео, которое нельзя будет отправлять личным сообщением. Значение используется по умолчанию.<br>:::note<br>**Примечание.** Если загрузить видеофайл с этим параметром, видео не будет отображаться в списке видео пользователя и не будет доступно другим пользователям по идентификатору видео.<br>::: |
| `wallpost` | `checkbox` | нет | **Необязательный параметр.** Информация о том, опубликовать ли после сохранения запись с видео на стене. Возможные значения:<br>* `1` — опубликовать запись с видео на стене.<br>* `0` — не публиковать запись с видео на стене. |
| `link` | `string` | нет | **Необязательный параметр.** URL источника видеозаписи. Используется для встраивания видео с внешних сайтов, например с YouTube.<br>:::note<br>**Примечание.** Если вы передаёте этот параметр, отправьте `POST`-запрос на полученный в методе `video.save` параметр `upload_url` без прикрепления видеофайла. Достаточно просто обратиться по этому адресу.<br>::: |
| `group_id` | `integer` | нет | **Необязательный параметр.** Идентификатор сообщества, в список видео которого будет сохранён видеофайл. По умолчанию видео сохраняется в список видео текущего пользователя. |
| `album_id` | `positive` | нет | **Необязательный параметр.** Идентификатор альбома, в который будет загружено видео. |
| `privacy_view` | `string` | нет | **Необязательный параметр.** Настройки приватности просмотра видео. Указывается в [специальном формате](reference/objects/privacy). Параметр используется для видео, которые пользователь загрузил в свой профиль.<br>**Примечание.** Параметр может указывать настройки [приватности сообществ](reference/objects/privacy/#Приватность%20просмотра%20(privacy_view)), если видео принадлежит сообществу. |
| `privacy_comment` | `string` | нет | **Необязательный параметр.** Настройки приватности комментирования видео. Указывается в [специальном формате](reference/objects/privacy). Параметр используется для видео, которые пользователь загрузил в свой профиль.<br>**Примечание.** Параметр может указывать настройки [приватности сообществ](reference/objects/privacy/#Приватность%20комментирования%20(privacy_comment)), если видео принадлежит сообществу. |
| `no_comments` | `checkbox` | нет | **Необязательный параметр.** Информация о том, нужно ли отключить возможность комментирования видео из сообществ. Возможные значения:<br>* `1` — отключить возможность комментирования.<br>* `0` — не отключать возможность комментирования. Значение используется по умолчанию. |
| `repeat` | `checkbox` | нет | **Необязательный параметр.** Информация о том, нужно ли зациклить воспроизведения видео. Возможные значения:<br>* `1` — зациклить видео.<br>* `0` — не зацикливать видео. |
| `compression` | `checkbox` | нет |  |
| `ord_info` | `text` | нет |  |
| `auto_publish` | `checkbox` | нет |  |
| `donut_level_id` | `integer` | нет |  |

## Результат

Метод возвращает объект. Поля объекта:

| Поле | Тип | Описание |
| --- | --- | --- |
| `access_key` | `string` | Ключ доступа. |
| `description` | `string` | Описание видео. |
| `owner_id` | `integer` | Идентификатор владельца видео. |
| `title` | `string` | Название видео. |
| `upload_url` | `string` | Адрес сервера, куда нужно загрузить видео. |
| `video_id` | `integer` | Идентификатор видео. |

Пример ответа:

```JSON
{
  "response": {
    "access_key": "5fabc30767e1b98c90",
    "description": "Описание видео",
    "owner_id": 743784474,
    "title": "Заголовок видео",
    "upload_url": "https://example.com",
    "video_id": 123456
   }
}
```
