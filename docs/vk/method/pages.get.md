# pages.get

> Источник: [https://dev.vk.ru/ru/method/pages.get](https://dev.vk.ru/ru/method/pages.get)
Возвращает информацию о вики-странице.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `string` | нет | Идентификатор владельца вики-страницы. |
| `page_id` | `integer` | нет | Идентификатор вики-страницы. |
| `global` | `checkbox` | нет | `1` — требуется получить информацию о глобальной вики-странице. |
| `site_preview` | `checkbox` | нет | `1` — получаемая вики-страница является предпросмотром для прикреплённой ссылки. |
| `title` | `string` | нет | Название страницы. |
| `need_source` | `checkbox` | нет | `1` —  требуется вернуть содержимое страницы в вики-формате. |
| `need_html` | `checkbox` | нет | `1` —  требуется вернуть HTML-представление страницы. |

## Результат

Возвращает информацию о вики-странице в виде объекта [`page`](reference/objects/wiki-page).

Если был задан параметр `need_source` равный `1`, дополнительно будет возвращено поле `source`.
Если был задан параметр `need_html` равный **1**, дополнительно будет возвращено поле `html`.

## Права доступа

`pages`
