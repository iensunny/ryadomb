# market.addPropertyVariant

> Источник: [https://dev.vk.ru/ru/method/market.addPropertyVariant](https://dev.vk.ru/ru/method/market.addPropertyVariant)

> Добавляет вариант свойства. Всего у свойства может быть 50 вариантов. 
Добавляет вариант свойства. Всего у свойства может быть 50 вариантов.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор сообщества. |
| `property_id` | `positive` | да | Идентификатор свойства. |
| `title` | `string` | да | Название варианта |

## Результат

После успешного выполнения возвращает идентификатор добавленного варианта.

## Права доступа

`market`
