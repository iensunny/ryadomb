# prettyCards.get

> Источник: [https://dev.vk.ru/ru/method/prettyCards.get](https://dev.vk.ru/ru/method/prettyCards.get)
Возвращает неиспользованные карточки владельца.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца. |
| `offset` | `integer` | нет | Смещение относительно начала списка карточек. |
| `count` | `integer` | нет | Количество возвращаемых карточек. |

## Результат

Возвращает массив структур с описанием карточек (подробнее о структуре ответа см. метод [`prettyCards.getById`](method/prettyCards.getById)). Возвращаются только те карточки, которые не были прикреплены к рекламной записи.

## Права доступа

`ads`
