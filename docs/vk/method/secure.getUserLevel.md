# secure.getUserLevel

> Источник: [https://dev.vk.ru/ru/method/secure.getUserLevel](https://dev.vk.ru/ru/method/secure.getUserLevel)
Возвращает ранее выставленный игровой уровень одного или нескольких пользователей в приложении.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_ids` | `integer` | да |  |

## Результат

Возвращает значения игровых уровней пользователей в приложении.

## Типы ключа

`secure`
