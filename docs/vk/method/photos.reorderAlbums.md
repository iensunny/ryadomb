# photos.reorderAlbums

> Источник: [https://dev.vk.ru/ru/method/photos.reorderAlbums](https://dev.vk.ru/ru/method/photos.reorderAlbums)
Меняет порядок альбома в списке альбомов пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества, которому принадлежит альбом. <br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `album_id` | `integer` | да | Идентификатор альбома. |
| `before` | `integer` | нет | Идентификатор альбома, перед которым следует поместить альбом. |
| `after` | `integer` | нет | Идентификатор альбома, после которого следует поместить альбом. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`photos`
