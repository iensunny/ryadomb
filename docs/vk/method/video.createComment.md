# video.createComment

> Источник: [https://dev.vk.ru/ru/method/video.createComment](https://dev.vk.ru/ru/method/video.createComment)
Cоздает новый комментарий к видеозаписи.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества, которому принадлежит видеозапись.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «-» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `video_id` | `positive` | да | Идентификатор видеозаписи. |
| `message` | `string` | нет | Текст комментария. Обязательный параметр, если не задан параметр `attachments`. |
| `attachments` | `string` | нет | Список объектов, приложенных к комментарию и разделённых символом `«,»`. Поле `attachments` представляется в формате:<br>```<br><type><owner_id>_<media_id>,<type><owner_id>_<media_id><br>```<br>`<type>` — тип медиа-вложения:<br>* `photo` — фотография <br>* `video` — видеозапись <br>* `audio` — аудиозапись <br>* `doc` — документ<br>`<owner_id>` — идентификатор владельца медиа-вложения <br>`<media_id>` — идентификатор медиа-вложения. <br>Например:<br>```<br>photo100172_166443618,photo66748_265827614<br>```<br>Параметр является обязательным, если не задан параметр `message`. |
| `from_group` | `checkbox` | нет | Этот параметр учитывается, если `owner_id` < `0` (комментарий к видеозаписи группы). `1` — комментарий будет опубликован от имени группы, `0` — комментарий будет опубликован от имени пользователя. по умолчанию: `0`. |
| `reply_to_comment` | `positive` | нет | Идентификатор комментария, в ответ на который должен быть добавлен новый комментарий. |
| `sticker_id` | `positive` | нет | Идентификатор стикера. |
| `guid` | `string` | нет | Уникальный идентификатор, предназначенный для предотвращения повторной отправки одинакового комментария. |
| `track_code` | `string` | нет |  |

## Результат

После успешного выполнения возвращает идентификатор созданного комментария.
