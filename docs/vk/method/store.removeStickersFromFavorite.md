# store.removeStickersFromFavorite

> Источник: [https://dev.vk.ru/ru/method/store.removeStickersFromFavorite](https://dev.vk.ru/ru/method/store.removeStickersFromFavorite)
Удаляет стикер из избранных.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `sticker_ids` | `integer` | да | Идентификаторы стикеров. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`ex`

## Типы ключа

`is_standalone`
