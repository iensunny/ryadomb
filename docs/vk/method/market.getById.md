# market.getById

> Источник: [https://dev.vk.ru/ru/method/market.getById](https://dev.vk.ru/ru/method/market.getById)
Возвращает информацию о товарах по идентификаторам.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `item_ids` | `string` | да | Перечисленные через запятую идентификаторы — идущие через знак подчеркивания `id` владельцев товаров и `id` самих товаров. Если товар принадлежит сообществу, то в качестве первого параметра используется `-id` сообщества.<br>Пример значения `item_ids`:<br>```<br>-4363_136089719,13245770_137352259<br>``` |
| `extended` | `checkbox` | нет | `1` — будут возвращены дополнительные поля `likes`, `can_comment`, `can_repost`, `photos`, `views_count`. По умолчанию: `0`. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [товаров](reference/objects/market-item) в поле `items`.
