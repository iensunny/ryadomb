# market.searchItemsBasic

> Источник: [https://dev.vk.ru/ru/method/market.searchItemsBasic](https://dev.vk.ru/ru/method/market.searchItemsBasic)
Получение товаров по поисковому запросу для вкладки бизнес групп

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `q` | `string` | да | Поисковый запрос |
| `offset` | `integer` | нет | Смещение с начала поисковой выдачи, используется для пагинации. По умолчанию 0 |
| `count` | `positive` | нет | Количество элементов в поисковой выдаче |
| `category_id` | `positive` | нет | Идентификатор категории |
| `price_from` | `positive` | нет | Фильтр нижняя граница цены |
| `price_to` | `positive` | нет | Фильтр верхняя граница цены |
| `sort_by` | `integer` | нет | Тип сортировки. 1 - по дате, 2 - по цене, 3 - по релевантности. По умолчанию 3 |
| `sort_direction` | `integer` | нет | Направление сортировки. 0 - по возрастанию, 1 - по убыванию. По умолчанию 0 |
| `country` | `positive` | нет | Идентификатор страны |
| `city` | `positive` | нет | Идентификатор города |
| `only_my_groups` | `checkbox` | нет | Искать только по товарам в своих группах |

## Результат

Возвращает массив товаров (https://dev.vk.com/ru/reference/objects/market-item)

## Права доступа

`market`
