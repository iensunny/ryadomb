# bugtracker.setProductIsOver

> Источник: [https://dev.vk.ru/ru/method/bugtracker.setProductIsOver](https://dev.vk.ru/ru/method/bugtracker.setProductIsOver)
Отключает или включает приём отчётов в [продукте](vk-testers/product).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `product_id` | `positive` | да | Идентификатор продукта. Его можно найти в ссылке на страницу продукта, например:<br>`https://vk.com/bugs?act=product&id=17`<br> |
| `is_over` | `checkbox` | нет | Устанавливает, отключать ли приём отчётов. Возможные значения:<br>* `1` — отключить.<br>* `0` — включить приём отчётов. |

## Результат

При успешном выполнении возвращает `1`.

Пример ответа:

```JSON
{
  "response": 1
}
```

## Типы ключа

`user_access_hidden`

## Ошибки

- 104
- 106

> Работает с [ключом доступа](vk-testers/access-tokens) компании и продукта.

После отключения приёма отчётов работа с ранее созданными отчётами продолжается.
