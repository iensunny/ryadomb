# polls.getById

> Источник: [https://dev.vk.ru/ru/method/polls.getById](https://dev.vk.ru/ru/method/polls.getById)
Возвращает детальную информацию об опросе по его идентификатору.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества, которому принадлежит опрос. |
| `is_board` | `checkbox` | нет | `1` — опрос находится в обсуждении, `0` — опрос прикреплен к стене.<br>По умолчанию — `0`. |
| `poll_id` | `positive` | да | Идентификатор опроса. |
| `extended` | `checkbox` | нет | `1` — возвращать дополнительную информацию о профилях пользователей. |
| `friends_count` | `positive` | нет | Число идентификаторов проголосовавших друзей, которые необходимо вернуть в ответе. |
| `fields` | `string` | нет | Список дополнительных полей профилей. См. [список возможных значений](reference/objects/user) |
| `name_case` | `string` | нет | Падеж для склонения имени и фамилии пользователя. <br>Возможные значения: <br>* именительный – `nom`,<br>* родительный – `gen`,<br>* дательный – `dat`,<br>* винительный – `acc`,<br>* творительный – `ins`,<br>* предложный – `abl`.<br> По умолчанию `nom`. |

## Результат

После успешного выполнения возвращает [объект опроса](reference/objects/poll).
