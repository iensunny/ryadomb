# messages.joinChatByInviteLink

> Источник: [https://dev.vk.ru/ru/method/messages.joinChatByInviteLink](https://dev.vk.ru/ru/method/messages.joinChatByInviteLink)
Позволяет присоединиться к чату по ссылке-приглашению.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `link` | `string` | да | Ссылка-приглашение. |

## Результат

Возвращает идентификатор чата в поле `chat_id`.

## Права доступа

`messages_ex`

## Типы ключа

`is_standalone`

## Ошибки

- 917
- 103
- 1019
