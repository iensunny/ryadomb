# bugtracker.createComment

> Источник: [https://dev.vk.ru/ru/method/bugtracker.createComment](https://dev.vk.ru/ru/method/bugtracker.createComment)
Оставляет комментарий к отчёту.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `bugreport_id` | `positive` | да | Идентификатор отчёта. Его можно найти в ссылке на страницу отчёта, например:<br>`https://vk.com/bug1309341`<br> |
| `text` | `string` | нет | **Необязательный параметр**. Текст комментария (до 4&nbsp;000 символов). |
| `hidden` | `checkbox` | нет | **Необязательный параметр**. Устанавливает видимость комментария. Возможные значения:<br>* 0 – комментарий виден всем.<br>* 1 – комментарий виден только модераторам продукта. |
| `hidden_attachments` | `checkbox` | нет |  |
| `force` | `checkbox` | нет | **Необязательный параметр**. Определяет, публиковать ли в видимых комментариях ссылки на внутренние ресурсы. <br>В настройках компании можно указать список ссылок, при появлении которых в видимых комментариях к отчётам нужно предупреждать автора о том, что публикуется ссылка на внутренний ресурс. Если для параметра `force` установлено значение `1`, то комментарии, содержащие ссылки на внутренние ресурсы, будут публиковаться. |

## Результат

Метод возвращает объект комментария после успешного выполнения.

## Типы ключа

`user_access_hidden`

## Ошибки

- 104
- 122

> Работает с [ключом доступа](vk-testers/access-tokens) компании и продукта.

Автором созданного комментария отображается системный пользователь.
