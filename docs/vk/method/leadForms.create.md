# leadForms.create

> Источник: [https://dev.vk.ru/ru/method/leadForms.create](https://dev.vk.ru/ru/method/leadForms.create)
Создаёт форму сбора заявок.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор группы, в которой надо создать форму. |
| `name` | `string` | да | Название формы (видно только администратору). |
| `title` | `string` | да | Заголовок формы (видят пользователи). |
| `description` | `string` | да | Описание формы. |
| `questions` | `text` | да | Информация о вопросах формы. Массив структур следующего формата:<br>*  `type` — тип вопроса;<br>*  `label` — заголовок вопроса (только для нестандартных вопросов);<br>*  `key` — уникальный ключ вопроса (необязательно; только для нестандартных вопросов);<br>*  `options` — массив возможных ответов на вопрос (только для нестандартных вопросов типа `radio`, `select`, `checkbox`).<br>Типы стандартных вопросов:<br>*  `first_name` — имя;<br>*  `patronymic_name` — отчество;<br>*  `last_name` — фамилия;<br>*  `email` — адрес электронной почты;<br>*  `phone_number` — номер телефона;<br>*  `age` — возраст;<br>*  `birthday` — день рождения;<br>*  `location` — город и страна.<br>Типы нестандартных вопросов:<br>*  `input` — простое текстовое поле (строка);<br>*  `textarea` — большое текстовое поле (абзац);<br>*  `radio` — выбор одного из нескольких вариантов;<br>*  `checkbox` — выбор нескольких вариантов;<br>*  `select` — выбор одного варианта из выпадающего списка.<br>`options` должен быть массивом структур, описывающих варианты ответа:<br>*  `label` — текст ответа;<br>*  `key` — ключ ответа (необязательно).<br>Пример:<br>```JSON<br>[[<br>   {<br>      "type":"first_name"<br>   },<br>   {<br>      "type":"input",<br>      "label":"Кличка кота"<br>   },<br>   {<br>      "type":"select",<br>      "key":"favorite_color",<br>      "label":"Любимый цвет",<br>      "options":[{<br>        "key":"red",<br>        "label":"Красный"<br>      },{<br>        "key":"green",<br>        "label":"Зелёный"<br>      }]]<br>   },<br>   {<br>      "type":"radio",<br>      "label":"Я ношу часы...",<br>      "options":[[{<br>         "key":"left",<br>         "label":"на левой руке"<br>      },{<br>         "key":"right",<br>         "label":"на правой руке"<br>      }]]<br>   },<br>   {<br>      "type":"checkbox",<br>      "key":"visited_cities",<br>      "label":"Города, в которых я был",<br>      "options":[[{<br>         "label":"Екатеринбург"<br>      },{<br>         "label":"Волгоград"<br>      },{<br>         "label":"Санкт-Петербург"      <br>      }]]<br>   }<br>]<br>``` |
| `policy_link_url` | `string` | да | Ссылка на политику конфиденциальности. |
| `photo` | `string` | нет | Обложка формы.<br>Используйте значение, полученное после загрузки фотографии на сервер. См. метод [`leadForms.getUploadURL`](method/leadForms.getUploadURL).<br>Также можно переиспользовать существующую фотографию из другой формы. Используйте значение поля `photo`, которое возвращает метод [`leadForms.get`](method/leadForms.get) или [`leadForms.list`](method/leadForms.list). |
| `confirmation` | `string` | нет | Текст подтверждения, который увидит пользователь после отправки формы. |
| `site_link_url` | `string` | нет | Ссылка на сайт или сообщество автора формы. |
| `active` | `checkbox` | нет | Передайте `1`, чтобы активировать форму сразу после создания. Пользователи могут оставлять заявки только в активных формах. |
| `once_per_user` | `checkbox` | нет | Передайте `1`, чтобы разрешить каждому пользователю заполнять форму только один раз. |
| `pixel_code` | `string` | нет | Передайте код пикселя ретаргетинга ВКонтакте в виде `VK-RTRG-000000-XXXXX`. По этому пикселю будет собираться аудитория пользователей, открывших форму. Подробнее о пикселе см. [здесь](https://vk.com/faq12142). |
| `notify_admins` | `integer` | нет | Передайте список идентификаторов пользователей, которым будут отправлены оповещения о заполнении пользователями формы. Оповещения могут быть отправлены только администраторам сообщества. |
| `notify_emails` | `string` | нет | Передайте список email-адресов, разделённых запятой, на которые будут отправлены оповещения о заполнении пользователями формы. Можно указать до **10** адресов. |

## Результат

Возвращается структура с информацией о созданной форме:
*  `form_id` — идентификатор формы;
*  `url` — ссылка на форму.

## Права доступа

`groups`
