# ads.getTargetingStats

> Источник: [https://dev.vk.ru/ru/method/ads.getTargetingStats](https://dev.vk.ru/ru/method/ads.getTargetingStats)
Возвращает размер целевой аудитории таргетинга, а также рекомендованные значения CPC и CPM.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | нет | Идентификатор рекламного кабинета. |
| `client_id` | `integer` | нет | Обязательный параметр для агентских кабинетов. |
| `criteria` | `text` | нет | Сериализованный JSON-объект, описывающий параметры таргетинга. Описание объекта `criteria` см. ниже. Игнорируется, если задан параметр `ad_id`. |
| `ad_id` | `integer` | нет | Идентификатор рекламного объявления, чьи параметры таргетинга требуется анализировать. Если задан этот параметр, `criteria` игнорируется. |
| `ad_format` | `integer` | нет | Формат объявления:<br>* `1` — изображение и текст;<br>* `2` — большое изображение;<br>* `3` — эксклюзивный формат;<br>* `4` — продвижение сообществ или приложений, квадратное изображение;<br>* `7` — специальный формат приложений;<br>* `8` — специальный формат сообществ;<br>* `9` — запись в сообществе;<br>* `10` — витрина приложений;<br>* `11` — адаптивный формат. |
| `ad_platform` | `string` | нет | Рекламные площадки, на которых будет показываться объявление:<br>* (если `ad_format` равен `1`):<br>   * `0` — ВКонтакте и сайты-партнёры;<br>   * `1` — только ВКонтакте.<br>* (если `ad_format` равен `9`):<br>   * `all` — все площадки;<br>   * `desktop` — полная версия сайта;<br>   * `mobile` — мобильный сайт и приложения.<br>* (если `ad_format` равен `11`):<br>   * `all` — все площадки;<br>   * `desktop` — полная версия сайта;<br>   * `mobile` — мобильный сайт и приложения. |
| `ad_platform_no_wall` | `string` | нет | Для `ad_format` = `9` и `11`.<br>`1` — не показывать объявление на стенах сообществ. По умолчанию: `0`. |
| `ad_platform_no_ad_network` | `string` | нет | Для `ad_format` = `9` и `11`.<br>`1` — не показывать объявление в рекламной сети. По умолчанию: `0`. |
| `link_url` | `string` | да | Ссылка на рекламируемый объект. |
| `link_domain` | `string` | нет | Домен рекламируемого объекта. |
| `need_precise` | `checkbox` | нет | Если установлен, то дополнительно в ответе будут рекомендованные значения CPC и CPM для достижения 5, 10, 15... 95% охвата. |
| `impressions_limit_period` | `integer` | нет |  |

## `criteria`

`sex`
`integer`, [`0`,`1`,`2`]
Пол. Возможные значения:
* `0` — любой;
* `1` — женский;
* `2` — мужской.

`age_from`
`integer`
Нижняя граница возраста (`0` — не задано).

`age_to`
`integer`
Верхняя граница возраста (`0` — не задано).

`birthday`
`integer`
День рождения. Задаётся в виде суммы флагов:
* `+1` — сегодня;
* `+2` — завтра;
* `+4` — в течение недели.

`country`
`integer`
Идентификатор страны (`0` — не задано).

`cities`
`string`
Идентификаторы городов и регионов. Идентификаторы регионов необходимо указывать со знаком «минус».

`cities_not`
`string`
Идентификаторы городов и регионов, которые следует исключить из таргетинга. Идентификаторы регионов необходимо указывать со знаком «минус».

* `1000`, 
* `1500`, 
* `2000`, 
* `2500`, 
* `3000`, 
* `3500`, 
* `4000`, 
* `4500`, 
* `5000`, 
* `6000`, 
* `7000`, 
* `8000`, 
* `9000`, 
* `10000`, 
* `11000`, 
* `12000`, 
* `13000`, 
* `14000`, 
* `15000`, 
* `20000`, 
* `25000`, 
* `30000`, 
* `35000`, 
* `40000`, 
* `45000`, 
* `50000`, 
* `55000`, 
* `60000`, 
* `65000`, 
* `70000`, 
* `75000`, 
* `80000`, 
* `85000`, 
* `90000`, 
* `95000`, 
* `100000`.
Использование этого критерия несовместимо с критериями `country`, `cities` и `cities_not`.

`geo_point_type`
`string`
Тип мест гео-таргетинга. Возможные значения:
* `regular` — регулярно бывает;
* `home` — дом;
* `work` — работа или учёба;
* `online` — находится сейчас. Ограничивает максимальное значение радиуса в 5000м.
Используется только вместе с критерием `geo_near`.

`statuses`
`string`
Семейное положение (значения, перечисленные через запятую). Возможные значения:
* `1` — не женат или не замужем;
* `2` — есть подруга или есть друг;
* `3` — полмолвлен(а);
* `4` — женат или замужем;
* `5` — все сложно;
* `6` — в активном поиске;
* `7` — влюблен(а);
* `8` — в гражданском браке.

`string`

## Результат

Возвращает объект, описывающий целевую аудиторию и содержащий следующие поля:

 `audience_count` 
 `integer`
 Размер целевой аудитории.

 `recommended_cpc` 
 `number`
 Рекомендованная цена для объявлений за клики, указана в рублях с копейками в дробной части. 0 — для форматов, для которых недоступна оплата за клики. 
 
 `recommended_cpm` 
 `number`
 Рекомендованная цена для объявлений за показы, указана в рублях с копейками в дробной части.
 
 `recommended_cpc_50` 
 `number`
 Рекомендованная цена для объявлений за клики, с прогнозом на достижение 50% охвата за первую неделю.
 
 `recommended_cpm_50`
 `number`
 Рекомендованная цена для объявлений за показы, с прогнозом на достижение 50% охвата за первую неделю.
 
 `recommended_cpc_70`
 `number` 
 Рекомендованная цена для объявлений за клики, с прогнозом на достижение 70% охвата за первую неделю.
 
 `recommended_cpm_70`
 `number`
 Рекомендованная цена для объявлений за показы, с расчётом на достижение 70% охвата за первую неделю.
 
 `recommended_cpc_90`
 `number` 
 Рекомендованная цена для объявлений за клики, с прогнозом на достижение 90% охвата за первую неделю.
 
 `recommended_cpm_90`
 `number`
 Рекомендованная цена для объявлений за показы, с прогнозом на достижение 90% охвата за первую неделю.
 
 `recommended_cpm_precise`
 Если установлен  `need_precise`, то рекомендованная цена для объявлений за показы, с прогнозом на достижение 5, 10, 15... 95% охвата за первую неделю.
 
 `recommended_cpс_precise`
 Если установлен  `need_precise`, то рекомендованная цена для объявлений за клики, с прогнозом на достижение 5, 10, 15... 95% охвата за первую неделю.

> Обратите внимание, минимальный размер целевой аудитории — **100** человек. Если заданным критериям соответствует меньшее количество пользователей, размер аудитории будет считаться равным нулю.
