# photos.getMessagesUploadServer

> Источник: [https://dev.vk.ru/ru/method/photos.getMessagesUploadServer](https://dev.vk.ru/ru/method/photos.getMessagesUploadServer)
Метод получает адрес сервера для [загрузки фотографии в личное сообщение](api/upload/photo-in-message) пользователя или в сообщение сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `peer_id` | `integer` | нет |  |

## Результат

Метод возвращает объект. Поля объекта:

| Поле | Тип | Описание |
|---|---|---|
| `album_id` | `integer` | Идентификатор альбома, в который нужно загрузить фотографию. |
| `upload_url` | `string` | Адрес, по которому нужно загрузить фотографию. |
| `user_id` | `integer` | Идентификатор пользователя. |
| `group_id` | `integer` | Идентификатор сообщества, если используются сообщения сообщества. |

Пример ответа:

```JSON
{
  "response":{
    "album_id":-64,
    "upload_url":"https:\/\/pu.vk.com\/c231331\/ss2269\/upload.php?act=do_add&mid=743784474&aid=-64&gid=218252175&hash=2e60ee02a7dd5aaaf0bce3e034b1dc30&rhash=eda561bac91afb0270fc9ca741ac626b&swfupload=1&api=1&mailphoto=1",
    "user_id":0,
    "group_id":218252175
  }
}
```

## Права доступа

`photos_ex`

## Типы ключа

`group_access`, `is_standalone`

## Ошибки

- 901

:::note
**Примечание.** Убедитесь, что вы включили сообщения в сообществе. Для этого:

1. Войдите ВКонтакте под своей учётной записью.
1. Откройте сообщество, где вы являетесь администратором.
1. Нажмите на кнопку **Управление**.
1. Нажмите на кнопку **Сообщения**.
1. Убедитесь, что в блоке **Сообщения сообщества** включён режим **Включены**.
1. Нажмите на кнопку **Сохранить**.
:::
