# messages.createChat

> Источник: [https://dev.vk.ru/ru/method/messages.createChat](https://dev.vk.ru/ru/method/messages.createChat)
Создаёт чат с несколькими участниками.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_ids` | `string` | нет | Идентификаторы пользователей, которые будут участвовать в чате. Используйте запятую в качестве разделителя. <br>> Указанные пользователи должны находится в списке друзей у текущего пользователя. |
| `title` | `string` | нет | Название чата. |
| `group_id` | `integer` | нет | Идентификатор сообщества (для сообщений сообщества с ключом доступа пользователя). |

> Обратите внимание, что при создании чата с токеном сообщества, чат не будет отображаться в интерфейсе сообщества.
> Кроме того, в такой чат нельзя пригласить участников при создании. Добавить их можно позже с помощью API-метода [`messages.getInviteLink`](method/messages.getInviteLink).

## Результат

После успешного выполнения возвращает  идентификатор созданного чата (`chat_id`).
