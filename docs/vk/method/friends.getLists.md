# friends.getLists

> Источник: [https://dev.vk.ru/ru/method/friends.getLists](https://dev.vk.ru/ru/method/friends.getLists)
Возвращает список меток друзей пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `positive` | нет | Идентификатор пользователя. |
| `return_system` | `checkbox` | нет | Возвращать ли системный список публичных меток друзей пользователя. |

## Результат

После успешного выполнения возвращает список объектов, каждый из которых содержит следующие поля:
* `name` — название списка друзей;
* `id` — идентификатор списка друзей.

## Права доступа

`friends_ex`

## Типы ключа

`is_standalone`
