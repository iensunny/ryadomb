# photos.get

> Источник: [https://dev.vk.ru/ru/method/photos.get](https://dev.vk.ru/ru/method/photos.get)
Возвращает список фотографий в альбоме.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `string` | нет | Идентификатор владельца альбома.<br>> Идентификатор сообщества необходимо указывать со знаком «-». <br>> Например, для [сообщества ВКонтакте API](https://vk.com/club1) `owner_id=-1`. |
| `album_id` | `string` | нет | Идентификатор альбома. Для служебных альбомов используются следующие идентификаторы:<br>* `wall` — фотографии со стены,<br>* `profile` — фотографии профиля,<br>* `saved` — сохраненные фотографии. Возвращается только с ключом доступа пользователя. |
| `photo_ids` | `string` | нет | Идентификаторы фотографий, информацию о которых необходимо вернуть. |
| `rev` | `checkbox` | нет | Порядок сортировки фотографий. Возможные значения:<br>* `1` — антихронологический,<br>* `0` — хронологический. |
| `extended` | `checkbox` | нет | `1` — будут возвращены дополнительные поля `likes`, `comments`, `tags`, `can_comment`, `reposts`. По умолчанию: `0`. |
| `feed_type` | `string` | нет | Тип новости, получаемый в поле `type` метода [`newsfeed.get`](method/newsfeed.get), для получения только загруженных пользователем фотографий, либо только фотографий, на которых он был отмечен. Может принимать значения `photo`, `photo_tag`. |
| `feed` | `integer` | нет | Время в формате, который может быть получен методом [`newsfeed.get`](method/newsfeed.get) в поле `date`, для получения всех фотографий загруженных пользователем в определённый день либо на которых пользователь был отмечен. Также нужно указать параметр `uid` пользователя, с которым произошло событие.<br>Значение должно отличаться от текущего времени не более, чем на месяц. |
| `photo_sizes` | `checkbox` | нет | `1` — возвращать доступные размеры фотографии в [специальном формате](reference/objects/photo-sizes). По умолчанию: `0`. |
| `offset` | `positive` | нет | Отступ, необходимый для получения определенного подмножества записей. |
| `count` | `positive` | нет | Количество записей, которое будет получено. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [фотографий](reference/objects/photo) в поле `items`.

Если к фотографии прикреплено местоположение, также возвращаются поля `lat` и `long`, содержащие географические координаты отметки.

Если был задан параметр `extended`=`1`, возвращаются дополнительные поля:
* `likes` — количество отметок **Мне нравится** и информация о том, поставил ли лайк текущий пользователь,
* `comments` — количество комментариев к фотографии,
* `tags` — количество отметок на фотографии,
* `can_comment` — может ли текущий пользователь комментировать фото (`1` — может, `0` — не может),
* `reposts` — число репостов фотографии.

Если был задан параметр `photo_sizes`=`1`, вместо полей `width` и `height` возвращаются размеры копий фотографии в [специальном формате](reference/objects/photo-sizes).

## Типы ключа

`allow_from_server`
