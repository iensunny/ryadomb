# photos.createAlbum

> Источник: [https://dev.vk.ru/ru/method/photos.createAlbum](https://dev.vk.ru/ru/method/photos.createAlbum)
Создает пустой альбом для фотографий.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `title` | `string` | да | Название альбома. |
| `group_id` | `integer` | нет | Идентификатор сообщества, в котором создаётся альбом. |
| `description` | `string` | нет | Текст описания альбома. |
| `privacy` | `integer` | нет | Уровень доступа к альбому (только для альбома пользователя). <br>Возможные значения:<br>* `0` — все пользователи,<br>* `1` — только друзья,<br>* `2` — друзья и друзья друзей,<br>* `3` — только я. |
| `comment_privacy` | `integer` | нет | Уровень доступа к комментированию альбома (только для альбома пользователя).<br>Возможные значения:<br>* `0` — все пользователи,<br>* `1` — только друзья,<br>* `2` — друзья и друзья друзей,<br>* `3` — только я. |
| `privacy_view` | `string` | нет | Настройки приватности просмотра альбома в [специальном формате](reference/objects/privacy). |
| `privacy_comment` | `string` | нет | Настройки приватности комментирования альбома в [специальном формате](reference/objects/privacy). |
| `upload_by_admins_only` | `checkbox` | нет | Кто может загружать фотографии в альбом (только для альбома сообщества). <br>Возможные значения:<br>*  `0` — фотографии могут добавлять все пользователи;<br>*  `1` — фотографии могут добавлять только редакторы и администраторы. |
| `comments_disabled` | `checkbox` | нет | Отключено ли комментирование альбома (только для альбома сообщества).<br>Возможные значения:<br>*  `0` — комментирование включено;<br>*  `1` — комментирование отключено. |

## Результат

После успешного выполнения возвращает объект, который содержит следующие поля:
* `id` — идентификатор созданного альбома;
* `thumb_id` — идентификатор фотографии, которая является обложкой альбома  (`0`, если обложка отсутствует);
* `owner_id`  идентификатор пользователя или сообщества, которому принадлежит альбом;
* `title`— название альбома;
* `description` — описание альбома;
* `created` — дата создания альбома в формате `unixtime`;
* `updated` — дата обновления альбома в формате `unixtime`;
* `size` — количество фотографий в альбоме;
* `privacy_view` — настройки приватности для альбома в формате [настроек приватности](reference/objects/privacy) (только для альбома пользователя);
* `privacy_comment` — настройки приватности для альбома в формате [настроек приватности](reference/objects/privacy) (только для альбома пользователя);
* `upload_by_admins_only` — кто может загружать фотографии в альбом (только для альбома сообщества);
* `comments_disabled` — отключено ли комментирование альбома (только для альбома сообщества)`
* `can_upload` — может ли текущий пользователь добавлять фотографии в альбом.
