# wall.repost

> Источник: [https://dev.vk.ru/ru/method/wall.repost](https://dev.vk.ru/ru/method/wall.repost)
Метод позволяет сделать репост — скопировать запись на стену пользователя или сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `object` | `string` | да | Строковый идентификатор объекта, который необходимо разместить на стене, например, `wall66748_3675` или `wall-1_340364`.<br>Формируется из типа объекта (`wall`, `photo`, `video` и т.п.), идентификатора владельца объекта и идентификатора самого объекта.<br> |
| `message` | `string` | нет | Сопроводительный текст, который будет добавлен к записи с объектом. Максимальная длина — 4096 симоволов. |
| `group_id` | `positive` | нет | Идентификатор сообщества, на стене которого будет размещена запись с объектом. Если не указан, запись будет размещена на стене текущего пользователя. |
| `mark_as_ads` | `checkbox` | нет | `1` — пометить запись как рекламную. |
| `mute_notifications` | `checkbox` | нет | Информация о том, включены ли уведомления к публикации записи.<br>* `1` — уведомления к записи отключены.<br>* `0` — уведомления к записи включены. |



## Результат

После успешного выполнения возвращает объект со следующими полями:
* `success` — всегда содержит `1`;
* `post_id` — идентификатор созданной записи;
* `reposts_count` — количество репостов объекта с учётом осуществленного;
* `likes_count` — число отметок **Нравится** у объекта.
