# bugtracker.saveProductVersion

> Источник: [https://dev.vk.ru/ru/method/bugtracker.saveProductVersion](https://dev.vk.ru/ru/method/bugtracker.saveProductVersion)
Метод создаёт версию или сохраняет изменения версии [продукта](vk-testers/product).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `product_id` | `positive` | нет | Идентификатор продукта. Его можно найти в ссылке на страницу продукта, например:<br>`https://vk.com/bugs?act=product&id=3` |
| `version_id` | `integer` | нет | Идентификатор новой версии продукта. При сохранении существующей версии — идентификатор редактируемой версии. |
| `title` | `string` | да | Название версии. |
| `release_notes` | `string` | нет | **Необязательный параметр**. Описание версии. |
| `visible` | `checkbox` | нет | **Необязательный параметр**. Информация о том, показывать ли версию тестировщикам. Возможные значения:<br>* `1` – показывать версию тестировщикам.<br>* `0` – скрыть версию от тестировщиков.<br>При первом сохранении версии со значением `1` тестировщикам продукта выполняется отправка уведомлений о публикации новой версии. |
| `set_rft` | `checkbox` | нет | **Необязательный параметр**. Информация о том, перевести ли все отчёты продукта, находящиеся в статусе «Исправлен», в статус «Готов к тестированию». Возможные значения:<br>* `1` – перевести все отчёты продукта, находящиеся в статусе «Исправлен», в статус «Готов к тестированию».<br>Работает только если `visible=1`. |

## Результат

Метод возвращает `1` после успешного выполнения, и `0` в случае ошибки.

Пример ответа:

```JSON
{
  "response": 1
}
```

[Подробнее](vk-testers/product-versions) о публикации обновлений продуктов.
