# apps.getLeaderboard

> Источник: [https://dev.vk.ru/ru/method/apps.getLeaderboard](https://dev.vk.ru/ru/method/apps.getLeaderboard)
Возвращает рейтинг пользователей в игре.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `type` | `string` | да | Тип турнирной таблицы. Возможные значения:<br>* `level` — по уровням;<br>* `points` — по баллам, начисленным за выполнение миссий;<br>* `score` — по очкам, начисленным напрямую ([`apps.getScore`](method/apps.getScore)). |
| `global` | `checkbox` | нет | Тип рейтинга. Возможные значения:<br>* `1` — глобальный рейтинг по всем игрокам (возвращается не более **20** результатов);<br>* `0` — рейтинг по друзьям пользователя. |
| `extended` | `checkbox` | нет | `1` — возвращать дополнительную информацию о пользователе. |

## Результат

После успешного выполнения возвращает список друзей с количеством очков, баллов миссий или текущим уровнем в игре, отсортированный по убыванию.
