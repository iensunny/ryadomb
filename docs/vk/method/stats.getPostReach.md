# stats.getPostReach

> Источник: [https://dev.vk.ru/ru/method/stats.getPostReach](https://dev.vk.ru/ru/method/stats.getPostReach)
Возвращает статистику для записи на стене.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `string` | да | Идентификатор владельца записи (сообщества). Должен начинаться со знака&nbsp;`-`. |
| `post_ids` | `integer` | да |  |

## Результат

Метод возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `reach_subscribers` | `integer` | Охват подписчиков. |
| `reach_total` | `integer` | Суммарный охват. |
| `reach_ads` | `integer` | Рекламный охват, если запись продвигалась с помощью таргетированной рекламы. |
| `reach_viral` | `integer` | Виральный охват, если запись продвигалась с помощью таргетированной рекламы. |
| `links` | `integer` | Количество переходов по ссылке. |
| `to_group` | `integer` | Количество переходов в сообщество. |
| `join_group` | `integer` | Количество вступлений в сообщество. |
| `report` | `integer` | Количество жалоб на запись. |
| `hide` | `integer` | Количество участников, скрывших запись. |
| `unsubscribe` | `integer` | Количество отписавшихся участников. |

Пример ответа:

```JSON
{
  "response": [
    {
      "reach_subscribers": 11385,
      "reach_total": 21105,
      "links": 92,
      "to_group": 97,
      "join_group": 3,
      "report": 0,
      "hide": 58,
      "unsubscribe": 15
    }
  ]
}
```

## Ошибки

- 210

:::note
**Примечание.**

* Метод возвращает данные для 300 последних записей, опубликованных не ранее 9&nbsp;декабря 2015 года.

* Статистика записей в настоящий момент доступна только для сообществ с количеством участников от 5&nbsp;000.

* Пользователь, от имени которого вызывается метод, должен быть редактором или администратором сообщества.
:::
