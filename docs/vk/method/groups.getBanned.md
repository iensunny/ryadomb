# groups.getBanned

> Источник: [https://dev.vk.ru/ru/method/groups.getBanned](https://dev.vk.ru/ru/method/groups.getBanned)
Возвращает список забаненных пользователей и сообществ в сообществе.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | Идентификатор сообщества. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества черного списка. |
| `count` | `positive` | нет | Количество пользователей, которое необходимо вернуть. |
| `fields` | `string` | нет | Список дополнительных полей [профилей](reference/objects/user) и [сообществ](reference/objects/group), которые необходимо вернуть. |
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества из чёрного списка, информацию о котором нужно получить. |

## Результат

После успешного выполнения возвращает общее число результатов в поле `count` (`integer`) и информацию о пользователях и сообществах из чёрного списка в поле `items` (`array`). Каждый объект в массиве `items` содержит поля:
* `type` (`string`) — тип. Возможные значения:
   * `group` — сообщество;
   * `profile` — пользователь.
* `group` (`object`) — информация о сообществе (для `type` = `group`). Объект [сообщества](reference/objects/group).
* `profile` (`object`) — информация о пользователе (для `type` = `profile`). Объект [пользователя](reference/objects/user).
* `ban_info` (`object`) — информация о блокировке в сообществе. Объект, который содержит поля:

Объект `ban_info` — информация о внесении в черный список сообщества.

`admin_id`
`integer`
Идентификатор администратора, который добавил пользователя или сообщество в черный список.

`date`
`integer`
Дата добавления в черный список в формате `unixtime`.

`reason`
`integer`
Причина добавления в черный список. 
Возможные значения: 
* `0` — другое (по умолчанию); 
* `1` — спам; 
* `2` — оскорбление участников; 
* `3` — нецензурные выражения; 
* `4` — сообщения не по теме.

`comment`
`string`
Текст комментария.

`end_date`
`integer`
Дата окончания блокировки (`0` — блокировка вечная).
