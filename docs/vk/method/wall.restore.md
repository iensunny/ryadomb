# wall.restore

> Источник: [https://dev.vk.ru/ru/method/wall.restore](https://dev.vk.ru/ru/method/wall.restore)
Восстанавливает удалённую запись на стене пользователя или сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества, на стене которого находилась удалённая запись. <br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «-» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1).  |
| `post_id` | `positive` | нет | Идентификатор записи на стене. |

## Результат

После успешного выполнения возвращает `1`.
