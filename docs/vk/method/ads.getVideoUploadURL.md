# ads.getVideoUploadURL

> Источник: [https://dev.vk.ru/ru/method/ads.getVideoUploadURL](https://dev.vk.ru/ru/method/ads.getVideoUploadURL)
Возвращает URL-адрес для загрузки видеозаписи рекламного объявления.

Подробности о загрузке видеозаписей для объявлений смотрите на [отдельной странице](method/ads/upload-video-ads).

## Результат

Возвращает URL-адрес для загрузки видеоролика.

## Права доступа

`ads`
