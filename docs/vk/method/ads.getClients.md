# ads.getClients

> Источник: [https://dev.vk.ru/ru/method/ads.getClients](https://dev.vk.ru/ru/method/ads.getClients)
Метод возвращает список клиентов рекламного агентства. Доступен только для рекламных агентств.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | **Необязательный параметр**. Идентификатор рекламного кабинета. |

## Результат

Метод возвращает массив объектов.

Объект в массиве имеет следующие параметры:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `integer` | Идентификатор клиента. |
| `name` | `string` | Название клиента. Длина строки: от 3 до 60 символов. |
| `day_limit` | `integer` | Дневной лимит в рублях. |
| `all_limit` | `integer` | Общий лимит в рублях. |
| `ord_data` | `object` | Данные оператора рекламных данных ([`ord_data_specification`](#ord_data_specification)).&#x0d;&#x0a;&#x0d;&#x0a; Доступно с версии 5.194. |

### `ord_data_specification`

Объект описывает оператора рекламных данных.

| Поле | Тип | Описание |
| --- | --- | --- |
| `client_type` | `string` | Тип клиента. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `person` — физическое лицо.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `individual` — индивидуальный предприниматель.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `legal` — юридическое лицо. |
| `client_name` | `string` | Полное имя клиента или название организации клиента. |
| `contract_number` | `string` | Номер контракта. |
| `contract_date` | `string` | Дата контракта в формате `DD.MM.YYYY`. |
| `contract_type` | `string` | Тип контракта. Примеры:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `Договор оказания услуг`.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `Дополнительное соглашение`.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `Посреднический договор`. |
| `contract_object` | `string` | Предмет контракта. Вы можете скопировать информацию из текста договора — пункт «Предмет договора» — или кратко опишите суть договора (что должны сделать заказчик и исполнитель). |
| `with_vat` | `boolean` | Информация о том, подлежит ли НДС оплате в рамках этого контракта. |
| `inn` | `string` | ИНН клиента. Длина строки: 10 или 12 символов. |
| `phone` | `string` | Телефон клиента. Длина строки: от 7 до 20 символов. |
| `subagent` Необязательное поле  | `object` | Данные о подрядчике ([`ord_subagent`](#ord_subagent)). |

### `ord_subagent`

Объект описывает подрядчика.

| Поле | Тип | Описание |
| --- | --- | --- |
| `type` | `string` | Тип подрядчика. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `person` — физическое лицо.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `individual` — индивидуальный предприниматель.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `legal` — юридическое лицо. |
| `name` | `string` | Название подрядчика. |
| `inn` | `string` | ИНН подрядчика. Длина строки: 10 или 12 символов. |
| `phone` | `string` | Телефон подрядчика. Длина строки: от 7 до 20 символов. |
