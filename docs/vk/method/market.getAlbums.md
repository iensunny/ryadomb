# market.getAlbums

> Источник: [https://dev.vk.ru/ru/method/market.getAlbums](https://dev.vk.ru/ru/method/market.getAlbums)
Возвращает список подборок с товарами.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца товаров.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «`-`» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `offset` | `positive` | нет | Смещение относительно первой найденной подборки для выборки определенного подмножества. |
| `count` | `positive` | нет | Количество возвращаемых подборок. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [подборок](reference/objects/market-album) в поле `items`.

## Права доступа

`market`
