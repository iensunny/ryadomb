# messages.removeChatUser

> Источник: [https://dev.vk.ru/ru/method/messages.removeChatUser](https://dev.vk.ru/ru/method/messages.removeChatUser)
Исключает из мультидиалога пользователя, если текущий пользователь или сообщество является администратором беседы либо текущий пользователь пригласил исключаемого пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `chat_id` | `positive` | да | Идентификатор беседы. |
| `user_id` | `integer` | нет | Идентификатор пользователя, которого необходимо исключить из беседы. |
| `member_id` | `integer` | нет | Идентификатор участника, которого необходимо исключить из беседы. Для сообществ — идентификатор сообщества со знаком «минус». |

## Результат

После успешного выполнения возвращает `1`.
