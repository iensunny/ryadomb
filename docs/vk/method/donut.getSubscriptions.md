# donut.getSubscriptions

> Источник: [https://dev.vk.ru/ru/method/donut.getSubscriptions](https://dev.vk.ru/ru/method/donut.getSubscriptions)
Возвращает информацию о подписках пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `fields` | `string` | нет | Список дополнительных полей профиля, которые необходимо вернуть. См. [подробное описание](reference/objects/user). |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества подписок. |
| `count` | `positive` | нет | Количество подписок, информацию о которых необходимо вернуть. |

## Результат

После успешного выполнения возвращает массив объектов со следующими полями:
* `subscriptions` (`array`)  — массив объектов подписок со следующими полями:
   * `owner_id` (`integer`) — идентификатор сообщества, доном которого является пользователь;
   * `next_payment_date` (`integer`) — дата следующего платежа в формате `unixtime`;
   * `amount` (`integer`) — стоимость подписки в рублях;
   * `status` (`string`) — статус подписки.
* `count` (`integer`) — количество подписок;
* `profiles` (`array`) —  массив объектов [пользователей](reference/objects/user); 
* `groups` (`array`)  — массив объектов [сообществ](reference/objects/group).

## Права доступа

`groups`
