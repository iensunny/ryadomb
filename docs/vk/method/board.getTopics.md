# board.getTopics

> Источник: [https://dev.vk.ru/ru/method/board.getTopics](https://dev.vk.ru/ru/method/board.getTopics)
Возвращает список тем в обсуждениях указанной группы.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | Идентификатор сообщества, информацию об обсуждениях которого необходимо получить. Если сообщество закрытое или частное, для вызова метода потребуется право доступа `groups`. |
| `topic_ids` | `integer` | нет | Список идентификаторов тем, которые необходимо получить (не более **100**). По умолчанию возвращаются все темы. Если указан данный параметр, игнорируются параметры `order`, `offset` и `count` (возвращаются все запрошенные темы в указанном порядке). |
| `order` | `integer` | нет | Порядок, в котором необходимо вернуть список тем. Возможные значения:<br>* `1` — по убыванию даты обновления;<br>* `2` — по убыванию даты создания;<br>* `-1` — по возрастанию даты обновления;<br>* `-2` — по возрастанию даты создания.<br>По умолчанию темы возвращаются в порядке, установленном администратором группы. «Прилепленные» темы при любой сортировке возвращаются первыми в списке. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества тем. |
| `count` | `positive` | нет | Количество тем, которое необходимо получить (но не более **100**). По умолчанию — **40**. |
| `extended` | `checkbox` | нет | Если указать в качестве этого параметра `1`, то будет возвращена информация о пользователях, являющихся создателями тем или оставившими в них последнее сообщение. По умолчанию `0`. |
| `preview` | `integer` | нет | Набор флагов, определяющий, необходимо ли вернуть вместе с информацией о темах текст первых и последних сообщений в них. Является суммой флагов:<br>* `1` — вернуть первое сообщение в каждой теме (поле `first_comment`);<br>* `2` — вернуть последнее сообщение в каждой теме (поле `last_comment`). По умолчанию — `0` (не возвращать текст сообщений)` |
| `preview_length` | `positive` | нет | Количество символов, по которому нужно обрезать первое и последнее сообщение. Укажите `0`, если Вы не хотите обрезать сообщение. (по умолчанию — `90`). |

## Результат

После успешного выполнения возвращает объект, содержащий следующие поля:

`count` 
`integer`
Число результатов.

`items` 
`array`
Массив [объектов, описывающих обсуждения](reference/objects/topic).

`default_order` 
`integer`
Тип сортировки обсуждений в сообществе. 
Возможные значения: 
* `1` — по убыванию даты обновления;
* `2` — по убыванию даты создания; 
* `-1` — по возрастанию даты обновления;
* `-2` — по возрастанию даты создания.

`can_add_topics` 
`integer`, `[0,1]` 
Информация о том, может ли текущий пользователь создать обсуждение в сообществе.
Возможные значения: 
* `0` — не может; 
* `1` — может.

`profiles`
`array`
(только для `extended` = `1`). Массив [объектов, описывающих пользователей](reference/objects/user). Каждый из объектов содержит базовые поля, а также поля `sex`, `photo_50`, `photo_100`, `online` и `type` (`= profile`).
