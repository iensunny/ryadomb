# translations.translate

> Источник: [https://dev.vk.ru/ru/method/translations.translate](https://dev.vk.ru/ru/method/translations.translate)
Метод позволяет выполнить перевод переданных строк текста.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `texts` | `string` | да | **Обязательный параметр.** Массив строк для перевода.<br>Ограничения:<br>* Массив может содержат не более 10 строк.<br>* Размер каждой строки — не более 1024 символов.<br>В настоящее время сервис автоматических переводов работает только с текстом. Поддержка разметки Markdown и HTML не гарантируется.  |
| `translation_language` | `string` | да | **Обязательный параметр.** Язык, на который должен быть выполнен перевод, например `en`, либо языковая пара, которая указывает исходный и целевой язык, например `ru-en`.<br>Для обозначения языков используйте следующие константы (в нижнем регистре):<br>* `en` — английский.<br>* `es` — испанский.<br>* `pt` — португальский.<br>* `ru` — русский.<br>Если указан только целевой язык, ВКонтакте попытается определить исходный язык автоматически. Эта процедура может возвращать ошибочные результаты для коротких фраз. По возможности указывайте языковую пару. |

## Результат

При успешном выполнении метод возвращает объект со следующими полями:

| Поле | Тип | Описание |
|---|---|---|
| `texts` | `string[]` | Массив переведённых строк. Каждая строка соответствует исходной строке в параметре `texts`. |
| `source_lang` | `string` | Строковая константа, которая указывает язык исходного текста. Для обозначения языков используются такие же константы, которые указаны в описании параметра `translation_language`.  |

Пример ответа:

```JSON
{
    "response": {
        "texts": [
            "Hi.",
            "How are you?"
        ],
    "source_lang": "ru"
    }
}
```

## Типы ключа

`allow_from_server`
