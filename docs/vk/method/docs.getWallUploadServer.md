# docs.getWallUploadServer

> Источник: [https://dev.vk.ru/ru/method/docs.getWallUploadServer](https://dev.vk.ru/ru/method/docs.getWallUploadServer)
Метод получает адрес сервера для [загрузки документа](api/upload/document-in-profile) в папку **Отправленные** для последующей отправки документа на стену или личным сообщением.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | нет | **Необязательный параметр.** Идентификатор сообщества, если необходимо загрузить файл в список файлов сообщества. Если файл нужно загрузить в список пользователя, метод вызывается без дополнительных параметров. |

## Результат

Метод возвращает объект. Поля объекта:

| Поле | Тип | Описание |
|---|---|---|
| `upload_url` | `string` | Адрес, по которому нужно загрузить документ. |

Пример ответа:

```JSON
{
  "response":{
    "upload_url":"https:\/\/pu.vk.com\/c237331\/upload_doc.php?act=add_doc&mid=743784474&aid=-1&gid=0&type=0&hash=daa35bf01486462ac67b3cc424be5ec6&rhash=4b76e3c083de5aa6cf8bbc3f657b10c5&api=1"
  }
}
```

`docs`
