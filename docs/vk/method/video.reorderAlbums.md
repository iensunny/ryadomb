# video.reorderAlbums

> Источник: [https://dev.vk.ru/ru/method/video.reorderAlbums](https://dev.vk.ru/ru/method/video.reorderAlbums)
Позволяет изменить порядок альбомов с видео.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `string` | нет | Идентификатор пользователя или сообщества, которому принадлежит альбом.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `album_id` | `string` | да | Идентификатор альбома, который нужно переместить. |
| `before` | `positive` | нет | Идентификатор альбома, перед которым нужно поместить текущий. |
| `after` | `positive` | нет | Идентификатор альбома, после которого нужно поместить текущий. |

## Результат

После успешного выполнения возвращает `1`.
