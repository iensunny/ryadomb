# docs.getById

> Источник: [https://dev.vk.ru/ru/method/docs.getById](https://dev.vk.ru/ru/method/docs.getById)
Возвращает информацию о документах по их идентификаторам.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `docs` | `string` | да | Идентификаторы документов, информацию о которых нужно вернуть, в формате `<owner_id>_<doc_id>`.<br>Пример значения `docs`:<br>```<br>66748_91488,66748_91455<br>```<br>Метод поддерживает передачу [`access_key`](reference/objects). |
| `return_tags` | `checkbox` | нет | `1` — добавить в ответ массив меток документа. |

## Результат

После успешного выполнения возвращает объект, содержащий массив объектов [документов](reference/objects/doc).

## Права доступа

`docs`

## Типы ключа

`group_access`
