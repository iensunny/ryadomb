# video.getOembed

> Источник: [https://dev.vk.ru/ru/method/video.getOembed](https://dev.vk.ru/ru/method/video.getOembed)

> Метод возвращает код для встраивания видео в `iframe`. 
Метод возвращает код для встраивания видео в `iframe`.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `url` | `string` | да | Ссылка на видеозапись. |
| `maxwidth` | `integer` | нет | Максимальная ширина `iframe` в пикселях. |
| `maxheight` | `integer` | нет | Максимальная высота `iframe` в пикселях. |

> access_token не обязателен.

## Типы ключа

`allow_from_server`

## Ошибки

- 204
- 104
