# apps.getTestingGroups

> Источник: [https://dev.vk.ru/ru/method/apps.getTestingGroups](https://dev.vk.ru/ru/method/apps.getTestingGroups)
Метод возвращает группы тестировщиков мини-приложения.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | нет | **Необязательный параметр**. Идентификатор группы тестировщиков. Чтобы получить идентификаторы всех групп тестировщиков мини-приложения, оставьте параметр `group_id` пустым. Чтобы получить информацию о конкретной группе тестировщиков, укажите её идентификатор в параметре `group_id`. |

## Результат

Метод возвращает массив объектов.

Параметры объекта в массиве:

| Параметр | Тип | Описание |
| --- | --- | --- |
| `group_id` | `integer` | Идентификатор группы тестировщиков. |
| `user_ids` | `array[integer]` | Массив идентификаторов пользователей, которые входят в группу тестировщиков. |
| `name` | `string` | Название группы тестировщиков. |
| `webview` | `string` | URL, по которому доступна версия мини-приложения для тестирования. |
| `platforms` | `array[string]` | Массив с названиями платформ, для которых доступна тестовая версия мини-приложения. Названия платформ:&#x0d;&#x0a; &bullet; `mobile` — мобильное приложение (Android, iOS);&#x0d;&#x0a; &bullet; `web` — десктопная версия сайта (vk.com);&#x0d;&#x0a; &bullet; `mvk` — мобильная версия сайта (m.vk.com). |
