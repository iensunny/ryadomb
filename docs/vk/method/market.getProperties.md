# market.getProperties

> Источник: [https://dev.vk.ru/ru/method/market.getProperties](https://dev.vk.ru/ru/method/market.getProperties)
Возвращает список свойств для указанного сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | идентификатор сообщества, минимальное значение  1 |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле count и массив объектов cвойств.

## Права доступа

`market`
