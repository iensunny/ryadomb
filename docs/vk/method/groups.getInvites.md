# groups.getInvites

> Источник: [https://dev.vk.ru/ru/method/groups.getInvites](https://dev.vk.ru/ru/method/groups.getInvites)
Данный метод возвращает список приглашений в сообщества и встречи текущего пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `offset` | `positive` | нет | Смещение, необходимое для выборки определённого подмножества приглашений. |
| `count` | `positive` | нет | Количество приглашений, которое необходимо вернуть. |
| `extended` | `checkbox` | нет | `1` — вернуть дополнительную информацию о пользователях, отправлявших приглашения. По умолчанию — `0`. |

## Результат

После успешного выполнения возвращает количество результатов в поле `count` и массив [объектов](reference/objects/group), описывающих сообщества, с дополнительным полем `invited_by`, содержащим идентификатор пользователя, который отправил приглашение, в поле `items`.

Если был передан параметр `extended`=`1`, дополнительно будет возвращен список `profiles` пользователей, отправивших приглашения. Каждый объект в списке содержит поля `id`, `first_name`, `last_name`

## Права доступа

`groups_ex`

## Типы ключа

`is_standalone`
