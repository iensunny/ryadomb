# market.edit

> Источник: [https://dev.vk.ru/ru/method/market.edit](https://dev.vk.ru/ru/method/market.edit)
Метод редактирует информацию о товаре.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | **Обязательный параметр.** Идентификатор владельца товара. Идентификатор сообщества должен начинаться со знака&nbsp;`-`. |
| `item_id` | `positive` | да | **Обязательный параметр.** Идентификатор товара. |
| `name` | `string` | нет | **Необязательный параметр.** Новое название товара. |
| `description` | `text` | нет | **Необязательный параметр.** Новое описание товара. |
| `category_id` | `positive` | нет | **Необязательный параметр.** Идентификатор категории товара. |
| `price` | `string` | нет | **Необязательный параметр.** Цена товара. |
| `old_price` | `string` | нет | **Необязательный параметр.** Старая цена товара. |
| `deleted` | `checkbox` | нет | **Необязательный параметр.** Статус товара. Возможные значения:<br>* `1` — товар недоступен.<br>* `0` — товар доступен. |
| `main_photo_id` | `positive` | нет | **Необязательный параметр.** Идентификатор фотографии для обложки товара.<br>Фотография может быть загружена с помощью метода [`photos.getMarketUploadServer`](method/photos.getMarketUploadServer).<br>Идентификатор фотографии можно получить:<br>* [Загрузив фотографию товара](api/upload/photo-in-market).<br>* Вызвав методы [market.get](method/market.get) или [market.getById](method/market.getById), если вы хотите использовать существующую фотографию товара. |
| `photo_ids` | `integer` | нет | **Необязательный параметр.** Идентификаторы дополнительных фотографий товара.<br>Идентификатор фотографии можно получить, [загрузив фотографию товара](api/upload/photo-in-market). |
| `video_ids` | `integer` | нет | **Необязательный параметр.**  Идентификаторы видео товара.<br>Видео должно быть загружено в сообщество и быть доступным для просмотра, в UI отображается только один элемент. |
| `url` | `string` | нет | **Необязательный параметр.** Ссылка на сайт товара.<br>Игнорируется в расширенном магазине. |
| `variant_ids` | `integer` | нет | **Необязательный параметр.** Список id вариантов свойств товаров. Не более 2 значений разных свойств. Если товар уже в группе, порядок свойств всех товаров группы должен совпадать, а набор свойств должен быть уникален для каждого товара. |
| `is_main_variant` | `checkbox` | нет | **Необязательный параметр.** Признак, является ли товар главным в своей группе. |
| `dimension_width` | `positive` | нет | **Необязательный параметр.** Ширина в миллиметрах. |
| `dimension_height` | `positive` | нет | **Необязательный параметр.** Высота в миллиметрах. |
| `dimension_length` | `positive` | нет | **Необязательный параметр.** Глубина в миллиметрах. |
| `weight` | `positive` | нет | **Необязательный параметр.** Вес в граммах. |
| `sku` | `string` | нет | **Необязательный параметр.** Артикул товара (произвольная строка). |
| `stock_amount` | `integer` | нет | **Необязательный параметр.** Количество товара в наличии (для расширенного магазина).<br>* `-1` - неограниченное количество<br>* `0` - товар недоступен<br>* `> 0` - количество товара |

## Результат

Метод возвращает `1`, если информация товара изменена, и `0` в случае ошибки.

Пример ответа:

```JSON
{
  "response": 1
}
```
