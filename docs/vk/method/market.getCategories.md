# market.getCategories

> Источник: [https://dev.vk.ru/ru/method/market.getCategories](https://dev.vk.ru/ru/method/market.getCategories)
Возвращает список категорий для товаров.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | нет |  |
| `album_id` | `integer` | нет |  |
| `count` | `positive` | нет | Количество категорий, информацию о которых необходимо вернуть. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества категорий. |

## Результат

После успешного выполнения возвращает список объектов `category`. 

`id`
`integer`
Идентификатор категории. 

`name`
`string`
Название метки. 
 
`section`
`object`
Секция. Объект, содержащий поля: 
* `id` (`integer`) — идентификатор секции;
* `name` (`string`)  — название секции.

## Права доступа

`market`
