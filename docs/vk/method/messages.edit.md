# messages.edit

> Источник: [https://dev.vk.ru/ru/method/messages.edit](https://dev.vk.ru/ru/method/messages.edit)
Редактирует сообщение.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `peer_id` | `integer` | да | Идентификатор назначения.<br>Для пользователя:<br>* `id`  пользователя.<br>Для групповой беседы:<br>* `2000000000` + `id` беседы.<br>Для сообщества:<br>* `-id` сообщества. |
| `message` | `string` | нет | Текст сообщения. Обязательный параметр, если не задан параметр `attachment`. |
| `lat` | `string` | нет | Географическая широта (от -90 до 90). |
| `long` | `string` | нет | Географическая долгота (от -180 до 180). |
| `attachment` | `string` | нет | Медиавложения к личному сообщению, перечисленные через запятую. Каждое прикрепление представлено в формате:<br>```<br><type><owner_id>_<media_id><br>```<br>`<type>` — тип медиавложения:<br>* `photo` — фотография;<br>* `video` — видеозапись;<br>* `audio` — аудиозапись;<br>* `doc` — документ;<br>* `wall` — запись на стене;<br>* `market` — товар.<br>`<owner_id>` — идентификатор владельца медиавложения (обратите внимание, если объект находится в сообществе, этот параметр должен быть отрицательным).<br>`<media_id>` — идентификатор медиавложения.<br>Например:<br>```<br>photo100172_166443618<br>```<br>Параметр является обязательным, если не задан параметр `message`.<br>В случае, если прикрепляется объект, принадлежащий другому пользователю следует добавлять к вложению его [access_key](reference/objects) в формате `<type><owner_id>_<media_id>_<access_key>`, Например:<br>```<br>video85635407_165186811_69dff3de4372ae9b6e<br>``` |
| `keep_forward_messages` | `checkbox` | нет | `1`, чтобы сохранить прикреплённые пересланные сообщения. |
| `keep_snippets` | `checkbox` | нет | `1`, чтобы сохранить прикреплённые внешние ссылки (сниппеты). |
| `group_id` | `integer` | нет | Идентификатор сообщества (для сообщений сообщества с ключом доступа пользователя). |
| `dont_parse_links` | `checkbox` | нет | `1` — не создавать сниппет ссылки из сообщения. |
| `disable_mentions` | `checkbox` | нет | `1` — отключить уведомление об упоминании в сообщении.<br> |
| `message_id` | `positive` | нет | Идентификатор сообщения. |
| `cmid` | `positive` | нет | conversation_message_id сообщения. |
| `template` | `text` | нет | Объект, описывающий [шаблоны сообщений](api/bots/development/messages). |
| `keyboard` | `text` | нет | Объект, описывающий [клавиатуру бота](api/bots/development/keyboard). |

## Результат

После успешного выполнения возвращает `1`.
