# video.removeFromAlbum

> Источник: [https://dev.vk.ru/ru/method/video.removeFromAlbum](https://dev.vk.ru/ru/method/video.removeFromAlbum)
Позволяет убрать видеозапись из альбома.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `target_id` | `integer` | нет | Идентификатор владельца альбома.<br>> Обратите внимание, идентификатор сообщества в параметре `target_id` необходимо указывать со знаком `«-»` — например, `target_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `album_id` | `integer` | нет | Идентификатор альбома, из которого нужно убрать видео. |
| `album_ids` | `integer` | нет | Идентификаторы альбомов, из которых нужно убрать видео. |
| `owner_id` | `integer` | да | Идентификатор владельца видеозаписи.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `video_id` | `positive` | да | Идентификатор видеозаписи. |

## Результат

После успешного выполнения возвращает `1`.
