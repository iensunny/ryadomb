# messages.getChatPreview

> Источник: [https://dev.vk.ru/ru/method/messages.getChatPreview](https://dev.vk.ru/ru/method/messages.getChatPreview)
Получает данные для превью чата с приглашением по ссылке.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `peer_id` | `positive` | нет | Идентификатор получателя сообщения:<br>* Для пользователя — `ИДЕНТИФИКАТОР_ПОЛЬЗОВАТЕЛЯ`.<br>* Для групповой беседы — `2000000000 + ИДЕНТИФИКАТОР_БЕСЕДЫ`.<br>* Для сообщества — `-ИДЕНТИФИКАТОР_СООБЩЕСТВА`. |
| `link` | `string` | нет | Ссылка-приглашение. |
| `fields` | `string` | нет | Список полей профилей, данные о которых нужно получить. Полный список смотрите [на этой странице](reference/objects/user). |

## Результат

Возвращает объект, который содержит следующие поля:
`preview`
`object`
Информация о чате. Объект, который содержит поля:
* `admin_id` (`object`) — идентификатор создателя чата; 
* `members` (`array`) — массив идентификаторов участников чата; 
* `title` (`string`) — название чата; 
* `local_id` (`integer`) — идентификатор чата для текущего пользователя.
* `photo` (`object`) — обложка чата. Объект, который содержит поля:   
    * `photo_50` (`string`) — URL копии фотографии с шириной 50 px;    
    * `photo_100` (`string`) — URL копии фотографии с шириной 100 px;
    * `photo_200` (`string`) — URL копии фотографии с шириной 200px.
    * `photo_base` (`string`) — URL копии фотографии с шириной 400px. добавив GET-параметр `cs=<size>x<size>`, где size=`50`|`100`|`200` можно получить изображение соответствующего размера;
    
`profiles`
`array`
Массив объектов [пользователей](reference/objects/user); 

`groups`
`array`
Массив объектов [сообществ](reference/objects/group); 

`emails`
`array`
Массив объектов, описывающих e-mail. Каждый из объектов содержит поля: 
* `id` (`integer`) — идентификатор e-mail; 
* `address` (`string`) — адрес e-mail.
