# orders.getAmount

> Источник: [https://dev.vk.ru/ru/method/orders.getAmount](https://dev.vk.ru/ru/method/orders.getAmount)
Возвращает стоимость голосов в валюте пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `positive` | да | Идентификатор пользователя. |
| `votes` | `string` | да | Список голосов. <br>Например: `1`, `7`, `77`. |

## Результат

Возвращает валюту пользователя и массив результатов для каждого значения из `votes`.
