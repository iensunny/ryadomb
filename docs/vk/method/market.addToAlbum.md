# market.addToAlbum

> Источник: [https://dev.vk.ru/ru/method/market.addToAlbum](https://dev.vk.ru/ru/method/market.addToAlbum)
Добавляет товар в одну или несколько выбранных подборок.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца товара.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «`-`» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `item_ids` | `integer` | да | Идентификаторы товаров, если нужно добавить сразу несколько. |
| `album_ids` | `integer` | да | Идентификаторы подборок, в которые нужно добавить товар. |

## Результат

После успешного выполнения возвращает `1`.

Начиная с версии 5.221 в случае ошибки возвращает подробную информацию по каждому элементу
```JSON
{
  "failed_ids": [
     {
       "item_id": 250407,
       "album_id": 2,
       "error_message": "1403;Item not found"
     },
 ...]
}
```
