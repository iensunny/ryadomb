# video.getAlbums

> Источник: [https://dev.vk.ru/ru/method/video.getAlbums](https://dev.vk.ru/ru/method/video.getAlbums)
Возвращает список альбомов видеозаписей пользователя или сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор владельца альбомов, пользователя или сообщества. По умолчанию — идентификатор текущего пользователя. Чтобы указать идентификатор сообщества, поставьте перед идентификатором знак -. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определённого подмножества альбомов. По умолчанию: `0`. |
| `count` | `positive` | нет | Количество альбомов, информацию о которых нужно вернуть. По умолчанию: не больше `50`, максимальное значение: `100`. |
| `extended` | `checkbox` | нет | `1`— возвращать дополнительные поля `count`, `updated_time` и массив объектов `image` для каждого альбома. Если альбом пустой, то массив объектов `image` для него возвращен не будет. По умолчанию: `0`.<br>Поля объекта `image`:<br>* `"height"` (`integer`) — высота изображения.<br>* `"url"` (`string`) — ссылка на изображение.<br>* `"width"` (`integer`) — ширина изображения.<br>* `"with_padding"` (`integer`) — поле возвращается, если изображение с отбивкой, всегда содержит `1`. |
| `need_system` | `checkbox` | нет | `1` — возвращать системные альбомы. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов альбомов в поле `items`. Каждый из объектов, описывающих альбом, содержит следующие поля:
* `id` — идентификатор альбома;
* `owner_id` — идентификатор владельца альбома;
* `title` — название альбома;
* `response_type` — тип ответа: `min` — если в запросе параметр `extended` = 0, ответ содержит только перечисленные выше поля; `full` — если `extended` = 1, ответ содержит  дополнительные поля.
