# groups.get

> Источник: [https://dev.vk.ru/ru/method/groups.get](https://dev.vk.ru/ru/method/groups.get)
Возвращает список сообществ указанного пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `integer` | нет | Идентификатор пользователя, информацию о сообществах которого требуется получить. |
| `extended` | `checkbox` | нет | Если указать в качестве этого параметра `1`, то будет возвращена полная информация о группах пользователя. По умолчанию `0`. |
| `filter` | `string` | нет | Список фильтров сообществ, которые необходимо вернуть, перечисленные через запятую.    <br>Возможные значения:<br>* `admin`<br>* `editor`<br>* `moder`<br>* `advertiser`<br>* `groups`<br>* `publics`<br>* `events`<br>* `hasAddress`<br>По умолчанию возвращаются все сообщества пользователя.<br>При указании фильтра `hasAddress` вернутся сообщества, в которых указаны адреса в соответствующем блоке, `admin` будут возвращены сообщества, в которых пользователь является администратором, `editor` — администратором или редактором, `moder` — администратором, редактором или модератором, `advertiser` — рекламодателем. Если передано несколько фильтров, то их результат объединяется. |
| `fields` | `string` | нет | Список дополнительных полей, которые необходимо вернуть.    <br>Возможные значения:<br>* `activity`<br>* `can_create_topic`<br>* `can_post`<br>* `can_see_all_posts`<br>* `city`<br>* `contacts`<br>* `counters`<br>* `country`<br>* `description`<br>* `finish_date`<br>* `fixed_post`<br>* `links`<br>* `members_count`<br>* `place`<br>* `site`<br>* `start_date`<br>* `status`<br>* `verified`<br>* `wiki_page`<br>Подробнее см. [описание полей объекта `group`](reference/objects/group).<br>Обратите внимание, этот параметр учитывается только при `extended`=`1`. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определённого подмножества сообществ. |
| `count` | `positive` | нет | Количество сообществ, информацию о которых нужно вернуть.    <br>Максимально возможное значение &mdash; 1&thinsp;000. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` (`integer`) и массив идентификаторов сообщества в поле `items` (`integer`).

Если был задан параметр `extended`=`1`, возвращает объект, содержащий число результатов в поле `count` (`integer`) и массив [объектов](reference/objects/group), описывающих сообщества, в поле `items`.
