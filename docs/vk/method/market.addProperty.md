# market.addProperty

> Источник: [https://dev.vk.ru/ru/method/market.addProperty](https://dev.vk.ru/ru/method/market.addProperty)
Добавляет новое свойство, которое может быть задано для товаров сообщества (например, «цвет», «размер» и т.д.).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор сообщества. |
| `title` | `string` | да | Название свойства. |

## Результат

После успешного выполнения возвращает идентификатор добавленного свойства.

## Права доступа

`market`
