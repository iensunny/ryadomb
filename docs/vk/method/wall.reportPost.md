# wall.reportPost

> Источник: [https://dev.vk.ru/ru/method/wall.reportPost](https://dev.vk.ru/ru/method/wall.reportPost)
Позволяет пожаловаться на запись.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор пользователя или сообщества, которому принадлежит запись. |
| `post_id` | `positive` | да | Идентификатор записи. |
| `reason` | `positive` | да | Причина жалобы:<br>*  `0` — спам.<br>*  `1` — детская порнография.<br>*  `2` — экстремизм.<br>*  `3` — насилие.<br>*  `4` — пропаганда наркотиков.<br>*  `5` — материалы для взрослых.<br>*  `6` — оскорбление.<br>*  `8` — призывы к суициду.<br>* `11` — торговля оружием. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`wall_ex`

## Типы ключа

`is_standalone`
