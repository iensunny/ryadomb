# video.add

> Источник: [https://dev.vk.ru/ru/method/video.add](https://dev.vk.ru/ru/method/video.add)
Метод добавляет видеозапись в список видеозаписей пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `target_id` | `integer` | нет | **Необязательный параметр.** Идентификатор пользователя или сообщества, в список видеозаписей которого нужно добавить видеозапись. Чтобы указать идентификатор сообщества, поставьте перед идентификатором знак `-`. |
| `video_id` | `positive` | да | **Обязательный параметр.** Идентификатор видеозаписи.<br>Вы можете найти идентификатор в адресной строке открытого видео:<br>* После слова `video`.<br>* После знака `?`. |
| `owner_id` | `integer` | да | **Обязательный параметр.** Идентификатор пользователя или сообщества, которому принадлежит видеозапись. Чтобы указать идентификатор сообщества, поставьте перед идентификатором знак `-`. |

## Результат

Метод возвращает `1`, если видеозапись добавлена, и `0` в случае ошибки.

Пример ответа:

```JSON
{
  "response": 1
}
```

## Права доступа

`video`

## Ошибки

- 204
- 800
