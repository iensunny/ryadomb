# groups.tagDelete

> Источник: [https://dev.vk.ru/ru/method/groups.tagDelete](https://dev.vk.ru/ru/method/groups.tagDelete)
Позволяет удалить тег сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | Идентификатор группы. |
| `tag_id` | `positive` | да | Идентификатор удаляемого тега. |

## Права доступа

`groups_ex`

## Типы ключа

`group_access`, `is_standalone`
