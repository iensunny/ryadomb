# utils.checkLink

> Источник: [https://dev.vk.ru/ru/method/utils.checkLink](https://dev.vk.ru/ru/method/utils.checkLink)
Возвращает информацию о том, является ли внешняя ссылка заблокированной на сайте ВКонтакте.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `url` | `string` | да | Внешняя ссылка, которую необходимо проверить.<br>Например, `https://google.com`. |

## Результат

После успешного выполнения возвращает объект, который содержит следующие поля:

### `status`
`string`
Статус ссылки. Возможные значения:
   *  `not_banned` – ссылка не заблокирована;
   *  `banned` – ссылка заблокирована;
   *  `processing` – ссылка проверяется, необходимо выполнить повторный запрос через несколько секунд.

### `link`
`string`
Исходная ссылка (`url`) либо полная ссылка (если в `url` была передана сокращённая ссылка).

## Типы ключа

`allow_from_server`, `group_access`
