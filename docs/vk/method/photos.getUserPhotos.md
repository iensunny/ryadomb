# photos.getUserPhotos

> Источник: [https://dev.vk.ru/ru/method/photos.getUserPhotos](https://dev.vk.ru/ru/method/photos.getUserPhotos)
Возвращает список фотографий, на которых отмечен пользователь

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `positive` | нет | Идентификатор пользователя, список фотографий для которого нужно получить. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества фотографий. По умолчанию — `0`. |
| `count` | `positive` | нет | Количество фотографий, которое необходимо получить. |
| `extended` | `checkbox` | нет | `1` — будут возвращены дополнительные поля `likes`, `comments`, `tags`, `can_comment`. Поля `comments` и `tags` содержат только количество объектов. По умолчанию данные поля не возвращается. |
| `sort` | `string` | нет | Сортировка результатов (`0` — по дате добавления отметки в порядке убывания, `1` — по дате добавления отметки в порядке возрастания). |

## Результат

После успешного выполнения возвращает список объектов [`photo`](reference/objects/photo).

Если был задан параметр `extended`=`1`, возвращаются дополнительные поля:
* `likes` — количество отметок «Мне нравится» и информация о том, поставил ли лайк текущий пользователь;
* `comments` — количество комментариев к фотографии;
* `tags` — количество отметок на фотографии;
* `can_comment` — может ли текущий пользователь комментировать фото (`1` — может, `0` — не может).

Если был задан параметр `photo_size`=`1`, вместо полей `width` и `height` возвращаются размеры копий фотографии в [специальном формате](reference/objects/photo-sizes).
