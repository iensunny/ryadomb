# friends.get

> Источник: [https://dev.vk.ru/ru/method/friends.get](https://dev.vk.ru/ru/method/friends.get)
Возвращает список идентификаторов друзей пользователя или расширенную информацию о друзьях пользователя (при использовании параметра `fields`).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `integer` | нет | Идентификатор пользователя, для которого необходимо получить список друзей. Если параметр не задан, то считается, что он равен идентификатору текущего пользователя (справедливо для вызова с передачей `access_token`). |
| `order` | `string` | нет | Порядок, в котором нужно вернуть список друзей. Допустимые значения:<br>* `hints` — сортировать по рейтингу, аналогично тому, как друзья сортируются в разделе **Мои друзья**.<br>> Это значение доступно только для Standalone-приложений с ключом доступа, полученным по схеме Implicit Flow.<br>* `random` — возвращает друзей в случайном порядке.<br>* `name` — сортировать по имени. Данный тип сортировки работает медленно, так как сервер будет получать всех друзей, а не только указанное количество `count`. (работает только при переданном параметре `fields`).<br>По умолчанию список сортируется в порядке возрастания идентификаторов пользователей. |
| `list_id` | `positive` | нет | Идентификатор списка друзей, полученный методом [`friends.getLists`](method/friends.getLists), друзей из которого необходимо получить. Данный параметр учитывается, только когда параметр `user_id` равен идентификатору текущего пользователя.<br>> Этот параметр доступен только для Standalone-приложений с ключом доступа, полученным по схеме Implicit Flow. |
| `count` | `positive` | нет | Количество друзей, которое нужно вернуть. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества друзей. |
| `fields` | `string` | нет | Список дополнительных полей, которые необходимо вернуть.<br>Доступные значения:<br>* `bdate`;<br>* `can_post`;<br>* `can_see_all_posts`;<br>* `can_write_private_message`;<br>* `city`;<br>* `contacts`;<br>* `country`;<br>* `domain`;<br>* `education`;<br>* `has_mobile`;<br>* `timezone`;<br>* `last_seen`;<br>* `nickname`;<br>* `online`;<br>* `photo_100`;<br>* `photo_200_orig`;<br>* `photo_50`;<br>* `photo_id`;<br>* `relation`;<br>* `sex`;<br>* `status`;<br>* `universities`. |
| `name_case` | `string` | нет | Падеж для склонения имени и фамилии пользователя. <br>Возможные значения: <br>* именительный – `nom`;<br>* родительный – `gen`;<br>* дательный – `dat`;<br>* винительный – `acc`; <br>* творительный – `ins`; <br>* предложный – `abl`.<br>По умолчанию `nom`. |
| `ref` | `string` | нет |  |

## Результат

После успешного выполнения возвращает список идентификаторов (`id`) друзей пользователя, если параметр `fields` не использовался. 
При использовании параметра `fields`  возвращает список объектов [пользователей](reference/objects/user), но не более 5000.

## Типы ключа

`allow_from_server`
