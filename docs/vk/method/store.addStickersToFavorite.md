# store.addStickersToFavorite

> Источник: [https://dev.vk.ru/ru/method/store.addStickersToFavorite](https://dev.vk.ru/ru/method/store.addStickersToFavorite)
Добавляет стикер в избранные.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `sticker_ids` | `integer` | да | Идентификаторы стикеров. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`ex`

## Типы ключа

`is_standalone`

## Ошибки

- 2100
- 2101
