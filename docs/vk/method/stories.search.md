# stories.search

> Источник: [https://dev.vk.ru/ru/method/stories.search](https://dev.vk.ru/ru/method/stories.search)
Возвращает результаты поиска по историям.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `q` | `string` | нет | Поисковый запрос. |
| `place_id` | `positive` | нет | Идентификатор места. |
| `latitude` | `string` | нет | Географическая широта точки, в радиусе которой необходимо производить поиск, заданная в градусах (от -90 до 90). |
| `longitude` | `string` | нет | Географическая долгота точки, в радиусе которой необходимо производить поиск, заданная в градусах (от -180 до 180). |
| `radius` | `positive` | нет | Радиус зоны поиска в метрах. |
| `mentioned_id` | `integer` | нет | Идентификатор упомянутого в истории пользователя или сообщества. |
| `count` | `integer` | нет | Количество историй, информацию о которых необходимо вернуть. |
| `extended` | `checkbox` | нет | Параметр, определяющий необходимость возвращать расширенную информацию о владельце истории. Возможные значения:<br>* `0` — возвращаются только идентификаторы;<br>* `1` — будут дополнительно возвращены имя и фамилия.<br>По умолчанию: `0`. |
| `fields` | `string` | нет | Список дополнительных полей профилей, которые необходимо вернуть. См. [подробное описание](reference/objects/user). |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [блока ленты историй](reference/objects/story-feed-item) в поле `items`. 

Если был задан параметр `extended=1`, возвращает объекты `profiles`  и `groups`, содержащие массивы объектов, описывающих [пользователей](reference/objects/user) и [сообщества](reference/objects/group).

## Права доступа
