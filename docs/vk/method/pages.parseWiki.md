# pages.parseWiki

> Источник: [https://dev.vk.ru/ru/method/pages.parseWiki](https://dev.vk.ru/ru/method/pages.parseWiki)
Метод получает HTML-представление вики-разметки.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `text` | `text` | да | **Обязательный параметр.** Текст в вики-формате. |
| `group_id` | `positive` | нет | **Необязательный параметр.** Идентификатор сообщества, в контексте которого интерпретируется переданный текст. |

## Результат

Метод возвращает объект. Поля объекта:

| Поле | Тип | Описание |
| --- | --- | --- |
| `wiki` | `string` | Экранированный HTML-текст, соответствующий вики-разметке. |

## Права доступа

`photos`
