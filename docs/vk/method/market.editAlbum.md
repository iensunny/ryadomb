# market.editAlbum

> Источник: [https://dev.vk.ru/ru/method/market.editAlbum](https://dev.vk.ru/ru/method/market.editAlbum)
Метод редактирует подборку с товарами в сообществе.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца подборки. Идентификатор сообщества должен начинаться со знака&nbsp;`-`. |
| `album_id` | `positive` | да | Идентификатор подборки.<br>Идентификатор находится в адресной строке открытой подборки после знака `_`. |
| `title` | `string` | да | Название подборки. |
| `photo_id` | `positive` | нет | Идентификатор фотографии подборки.<br>Чтобы получить идентификатор, [загрузите фотографию товара](api/upload/main-photo-in-market). |
| `main_album` | `checkbox` | нет | Информация о том, назначить ли подборку основной. Возможные значения:<br>* `1` — назначить подборку основной.<br>* `0` — не назначать подборку основной. Значение используется по умолчанию. |
| `is_hidden` | `checkbox` | нет | Информация о том, нужно ли скрывать подборку из общего списка подборок сообщества. Возможные значения:<br>* `1` — скрыть подборку. <br>* `0` — не скрывать подборку. Значение используется по умолчанию.<br> |

## Результат

Метод возвращает `1`, если подборка изменена, и `0` в случае ошибки.

Пример ответа:

```JSON
{
  "response": 1
}
