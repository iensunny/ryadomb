# groups.search

> Источник: [https://dev.vk.ru/ru/method/groups.search](https://dev.vk.ru/ru/method/groups.search)
Осуществляет поиск сообществ по заданной подстроке.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `q` | `string` | да | Текст поискового запроса. |
| `type` | `string` | нет | Тип сообщества. Возможные значения: `group`, `page`, `event`. |
| `country_id` | `positive` | нет | Идентификатор страны. |
| `city_id` | `positive` | нет | Идентификатор города. При передаче этого параметра поле `country_id` игнорируется. |
| `future` | `checkbox` | нет | При передаче значения `1` будут выведены предстоящие события. Учитывается только при передаче в качестве `type` значения `event`. |
| `market` | `checkbox` | нет | При передаче значения `1` будут выведены сообщества с включёнными товарами. |
| `sort` | `integer` | нет | * `0` — сортировать по умолчанию (аналогично результатам поиска в полной версии сайта);<br>* `6` — сортировать по количеству пользователей.<br> |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определённого подмножества результатов поиска. По умолчанию — `0`. |
| `count` | `positive` | нет | Количество результатов поиска, которое необходимо вернуть.<br>> Обратите внимание, даже при использовании параметра `offset` для получения информации доступны только первые 1000 результатов. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` (`integer`) и массив объектов [`group`](reference/objects/group) в поле `items`.
