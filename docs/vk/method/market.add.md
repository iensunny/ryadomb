# market.add

> Источник: [https://dev.vk.ru/ru/method/market.add](https://dev.vk.ru/ru/method/market.add)
Метод добавляет новый товар.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца товара. Идентификатор сообщества должен начинаться со знака `-`. |
| `name` | `string` | да | Название товара. Ограничение по длине считается в кодировке `cp1251`. |
| `description` | `text` | да | Описание товара. |
| `category_id` | `positive` | да | Идентификатор категории товара. Если вы не знаете идентификатор нужной категории, укажите значение `1`. |
| `price` | `string` | нет | Цена товара. |
| `old_price` | `string` | нет | Старая цена товара. |
| `deleted` | `checkbox` | нет | Статус товара. Возможные значения:<br>* `1` — товар недоступен.<br>* `0` — товар доступен. |
| `main_photo_id` | `positive` | нет | Идентификатор фотографии обложки товара.<br>Фотография должна быть загружена согласно инструкции в разделе [Загрузка фотографии для товара](api/upload/photo-in-market). |
| `photo_ids` | `integer` | нет | Идентификаторы дополнительных фотографий товара, перечисленные через запятую. Максимальное количество дополнительных фотографий — 4.<br>Фотографии должны быть загружены согласно инструкции в разделе [Загрузка фотографии для товара](api/upload/photo-in-market). |
| `video_ids` | `integer` | нет | Идентификаторы видео товара.<br>Видео должно быть загружено в сообщество и быть доступным для просмотра, в UI отображается только один элемент. |
| `url` | `string` | нет | Ссылка на сайт товара. |
| `variant_ids` | `integer` | нет | Список id вариантов свойств товаров. Не более 2 значений.<br>Чтобы товар добавить в группу, порядок свойств всех товаров группы должен совпадать, а набор свойств должен быть уникален для каждого товара. |
| `is_main_variant` | `checkbox` | нет | Признак, будет ли товар главным в своей группе. |
| `dimension_width` | `positive` | нет | Ширина в миллиметрах. |
| `dimension_height` | `positive` | нет | Высота в миллиметрах. |
| `dimension_length` | `positive` | нет | Глубина в миллиметрах. |
| `weight` | `positive` | нет | Вес в граммах. |
| `sku` | `string` | нет | Артикул товара (произвольная строка). |
| `stock_amount` | `integer` | нет | Количество товара в наличии (для расширенного магазина).<br>* `-1` - неограниченное количество<br>* `0` - товар недоступен<br>* `> 0` - количество товара |

## Результат

Метод возвращает идентификатор добавленного товара (`string`).

Пример ответа:

```JSON
{
  "response": "1"
}
```
