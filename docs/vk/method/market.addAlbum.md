# market.addAlbum

> Источник: [https://dev.vk.ru/ru/method/market.addAlbum](https://dev.vk.ru/ru/method/market.addAlbum)
Метод добавляет новую подборку с товарами в сообщество.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца подборки. Идентификатор сообщества должен начинаться со знака&nbsp;`-`. |
| `title` | `string` | да | Название подборки. |
| `photo_id` | `positive` | нет | Идентификатор фотографии подборки.<br>Чтобы получить идентификатор, [загрузите фотографию товара](api/upload/main-photo-in-market). |
| `main_album` | `checkbox` | нет |  Информация о том, назначить ли подборку основной. Возможные значения:<br>* `1` — назначить подборку основной.<br>* `0` — не назначать подборку основной. Значение используется по умолчанию. |
| `is_hidden` | `checkbox` | нет | Информация о том, нужно ли скрывать подборку из общего списка подборок сообщества. Возможные значения:<br>* `1` — сделать подборку скрытой.<br>* `0` — не делать подборку скрытой. Значение используется по умолчанию. |

## Результат

Метод возвращает объект. Поля объекта:

| Поле | Тип | Описание |
|---|---|---|
| `market_album_id` | `integer` | Идентификатор альбома подборки, в который нужно загрузить фотографии. |
| `albums_count` | `integer` | Количество альбомов подборок в сообществе. |

Пример ответа:

```JSON
{
  "response":{
    "market_album_id":2,
    "albums_count":2
  }
}
```
