# wall.restoreComment

> Источник: [https://dev.vk.ru/ru/method/wall.restoreComment](https://dev.vk.ru/ru/method/wall.restoreComment)
Восстанавливает удаленный комментарий к записи на стене.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества, на стене которого находится комментарий к записи. <br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «-» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1) |
| `comment_id` | `integer` | да | Идентификатор комментария на стене. |

> **Обратите внимание.** Для восстановления комментария надо использовать ключ доступа пользователя, который удалял этот комментарий. Если удаление произошло в сообществе, другие администраторы не смогут восстановить комментарий.

## Результат

После успешного выполнения возвращает `1`.
