# photos.reportComment

> Источник: [https://dev.vk.ru/ru/method/photos.reportComment](https://dev.vk.ru/ru/method/photos.reportComment)
Позволяет пожаловаться на комментарий к фотографии.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца фотографии к которой оставлен комментарий. |
| `comment_id` | `positive` | да | Идентификатор комментария. |
| `reason` | `positive` | нет | Причина жалобы:<br>*  `0` — спам;<br>*  `1` — детская порнография;<br>*  `2` — экстремизм;<br>*  `3` — насилие;<br>*  `4` — пропаганда наркотиков;<br>*  `5` — материал для взрослых;<br>*  `6` — оскорбление. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`photos_ex`

## Типы ключа

`is_standalone`
