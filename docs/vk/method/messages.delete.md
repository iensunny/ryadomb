# messages.delete

> Источник: [https://dev.vk.ru/ru/method/messages.delete](https://dev.vk.ru/ru/method/messages.delete)
Удаляет сообщение.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `message_ids` | `integer` | нет | Список идентификаторов сообщений, разделённых через запятую. |
| `spam` | `checkbox` | нет | Пометить сообщения как спам (доступен только с ключом доступа пользователя). |
| `reason` | `integer` | нет | Идентификатор причины блокировки |
| `group_id` | `integer` | нет | Идентификатор сообщества (для сообщений сообщества с ключом доступа пользователя). |
| `delete_for_all` | `checkbox` | нет | `1` — если сообщение нужно удалить для получателей. |
| `peer_id` | `integer` | нет | Идентификатор беседы, из которого необходимо удалить сообщения по `cmids`.<br>Для пользователя:<br>* `id` пользователя.<br>Для групповой беседы:<br>* `2000000000` + `id` беседы.<br>Для сообщества:<br>* `-id` сообщества. |
| `cmids` | `integer` | нет | Массив идентификаторов сообщений из беседы. |

## Результат

После успешного выполнения возвращает `1` для каждого удалённого сообщения.

## Права доступа

`messages_ex`

## Типы ключа

`group_access`, `is_standalone`
