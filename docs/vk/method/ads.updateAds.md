# ads.updateAds

> Источник: [https://dev.vk.ru/ru/method/ads.updateAds](https://dev.vk.ru/ru/method/ads.updateAds)
Редактирует рекламные объявления.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | **Обязательный параметр**. Идентификатор рекламного кабинета. |
| `data` | `text` | да | **Обязательный параметр**. Сериализованный JSON-массив объектов, описывающих изменения в объявлениях. Описание объектов `ad_edit_specification` см. ниже.<br>Максимальное допустимое количество объявлений, редактируемых  с помощью одного запроса — **5**. Если нужно больше, то можно использовать [execute](method/execute). |

## `ad_edit_specification`

### `ad_id`
**Обязательный параметр**. 
`integer`.
Идентификатор редактируемого объявления.

### `cpc`
**Необязательный параметр**
`number`
Если `cost_type` равен `0` — цена за переход. Цена указывается в рублях с копейками в дробной части.

### `cpm`
**Необязательный параметр**
`number`
Если `cost_type` равен `1` — цена за 1000 показов. Цена указывается в рублях с копейками в дробной части.

### `ocpm`
**Необязательный параметр**
`number`
Если `cost_type` равен `3` — цена за действие для oCPM. Цена указывается в рублях с копейками в дробной части.

### `impressions_limit`
**Необязательный параметр**
`integer` (числовое значение).
Если `ad_format` = `9` или `11` и `cost_type` = `1` — ограничение количества показов данного объявления на одного пользователя.
Допустимые значения: `1`, `2`, `3`, `5`, `10`, `15`, `20`.

### `impressions_limited`
**Необязательный параметр**
Флаг, может принимать значения `0` или `1`.
Если `cost_type` равен `1` и `impressions_limit` не может быть задан — признак того, что количество показов объявления на одного пользователя ограничено.
* `0` — нет ограничения.
* `1` — не более 100 показов на одного пользователя.

### `impressions_limit_period`
**Необязательный параметр**
`integer` (числовое значение).
Если `ad_format` = `9` или `11` и `cost_type` = `1` — может быть задан период ограничения на количество показов на одного пользователя.
Значение задается в секундах, должно быть кратно суткам (86400 секунд), максимум 90 суток
При наступлении нового периода счетчик показов сбрасывается.
*  `0` — отключает сброс счетчика показов.

### `ad_platform`
**Необязательный параметр**
Рекламные площадки, на которых будет показываться объявление:
* (если `ad_format` равен `1` и `cost_type` равен `0`):
   * `0` — ВКонтакте и сайты-партнёры.
   * `1` — только ВКонтакте.
* (если `ad_format` равен `9`):
   * `all` — все площадки.
   * `desktop` — полная версия сайта.
   * `mobile` — мобильный сайт и приложения.
* (если `ad_format` равен `11`):
   * `all` — все площадки.
   * `desktop` — полная версия сайта.
   * `mobile` — мобильный сайт и приложения.

### `ad_platform_no_wall`
**Необязательный параметр**
Только для `ad_format` = `9` или `11`. `1` — не показывать объявление на стенах сообществ (по умолчанию `0`). 

### `ad_platform_no_ad_network`
**Необязательный параметр**
`integer`, `[0,1]`
Только для `ad_format` = `9` или `11`. `1` — не показывать объявление в рекламной сети (по умолчанию `0`). 

### `publisher_platforms`
**Необязательный параметр**
Только для `ad_format` = `9` или `11`
На каких площадках будет показываться объявление:

* `all` — все площадки (по умолчанию).
* `social` — все соцсети (ВКонтакте и Одноклассники).
* `vk` — только ВКонтакте.

### `day_limit`
**Необязательный параметр**
Положительное число.
Дневной лимит в рублях.

### `all_limit`
**Необязательный параметр**
Положительное число.
Общий лимит в рублях.

### `category1_id`
**Необязательный параметр**
Положительное число.
ID тематики или подраздела тематики объявления. Если объявление имеет несколько тематик, то дополнительную можно задать в параметре `category2_id`. Смотрите [`ads.getCategories`](method/ads.getCategories).

### `category2_id`
**Необязательный параметр**
положительное число
Идентификатор тематики или подраздела тематики объявления.

### `age_restriction`
**Необязательный параметр**
Отображение отметки возрастного ограничения на объявлении.
* `0` — не отображать отметку.
* `1` — использовать отметку **0+**.
* `2` — использовать отметку **6+**.
* `3` — использовать отметку **12+**.
* `4` — использовать отметку **16+**.
* `5` — использовать отметку **18+**.

### `status`
**Необязательный параметр**
Флаг, может принимать значения `0` или `1`
Статус рекламного объявления (`0` — остановлено, `1` — запущено).

### `name`
**Необязательный параметр**
Строка длиной от **3** до **60** символов.
Название объявления (для использования в рекламном кабинете).

### `title`
**Необязательный параметр**
Строка длиной от **3** до **33** символов. Для `ad_format` = `11` — до **25** символов.
Заголовок объявления. Может быть задан только для некоторых рекламных форматов.

### `description`
**Необязательный параметр**
Строка длиной от **3** до **70** символов. Для `ad_format` = `11` — до **90** символов.
Описание объявления. Может быть задано только для некоторых рекламных форматов.

### `link_url`
**Необязательный параметр**
Обязательный параметр, строка.
Ссылка на рекламируемый объект в формате:
* `http://yoursite.com`
* `https://vk.com/wall-22822305_383737`
* `http://vk.cоm/club1`

Если в ссылке содержатся строки `{ad_id}` или `{campaign_id}`, то они заменяются соответственно на идентификатор объявления и идентификатор кампании в момент перехода пользователя по такой ссылке.

### `link_domain`
**Необязательный параметр**
Строка.
Домен рекламируемого объекта в формате `yoursite.com`.

### `link_title`
**Необязательный параметр**
Строка длиной от **3** до **25** символов.
Заголовок рядом с кнопкой/ссылкой. Может быть задан только для некоторых рекламных форматов.

### `link_button`
**Необязательный параметр**
Идентификатор кнопки объявления. Может быть задан только для некоторых рекламных форматов.Смотрите список возможных значений на [отдельной странице](method/ads/link-buttons).

### `photo`
**Необязательный параметр**
Основное изображение. Может быть передано только для некоторых рекламных форматов. В качестве значения должен быть передан результат [загрузки изображения на сервер](method/ads.getUploadURL).

### `photo_icon`
**Необязательный параметр**
Логотип. Может быть передано только для некоторых рекламных форматов. В качестве значения должен быть передан результат [загрузки изображения на сервер](method/ads.getUploadURL).

### `video`
**Необязательный параметр**
Основное видео. Может быть передано только для адаптивного формата. В качестве значения должен быть передан результат [загрузки видео на сервер](method/ads.getVideoUploadURL).

### `repeat_video`
**Необязательный параметр**
Флаг, может принимать значения `0` или `1`.
Зацикливание видео. Возможные значения:
* 0 — не зацикливать видео.
* 1 — зацикливать видео.

### `disclaimer_medical`
**Необязательный параметр**
Флаг, может принимать значения `0` или `1`.
Отображение предупреждения:
«Есть противопоказания. Требуется консультация специалиста.»
* 1 — включить отображение.

### `disclaimer_specialist`
**Необязательный параметр**
Флаг, может принимать значения `0` или `1`.
Отображение предупреждения:
«Необходима консультация специалистов.»
* 1 — включить отображение.

### `disclaimer_supplements`
**Необязательный параметр**
Флаг, может принимать значения `0` или `1`.
Отображение предупреждения:
«БАД. Не является лекарственным препаратом.»
* 1 — включить отображение.

### `start_time`
**Необязательный параметр**
`integer`
Время запуска объявления в формате Unixtime. Укажите `0` для сброса времени запуска.

###  `stop_time`
**Необязательный параметр**
`integer`
Время остановки объявления в формате Unixtime. Укажите `0` для сброса времени остановки.

### `weekly_schedule_hours`
**Необязательный параметр**
`array`
Расписание показа объявления по часам. Массив из семи строк. Каждая из строк соответствует дню недели и содержит последовательность символов `0` или `1`. `0` — не показывать объявление в час, номер которого равен позиции символа. `1` — показывать.

### `weekly_schedule_use_holidays`
**Необязательный параметр**
Флаг, может принимать значения `0` или `1`.
Использовать ли расписание воскресенья в праздничные дни.

### `stats_url`
**Необязательный параметр**
Пиксель внешней статистики. Доступно в избранных кабинетах.

### `stats_url2`
**Необязательный параметр**
Дополнительный пиксель внешней статистики. Доступно в избранных кабинетах.

### `autobidding`
**Необязательный параметр**
Флаг, может принимать значения `0` или `1`.
Автоматическое управление ценой:
* `0` — выключено.
* `1` — включено.

### `autobidding_max_cost`
**Необязательный параметр**
`integer`, `string`
Максимальное ограничение автоматической ставки в рублях с копейками, `0` — снятие ограничения.

### `Настройки таргетинга`
**Необязательный параметр**
Набор полей, соответствующих настройкам таргетинга. Смотрите описание возможных полей на [отдельной странице](method/ads/targeting).

## Результат

Возвращает массив ответов на каждый запрос в массиве `data`. Соответствующий объект в выходном массиве содержит идентификатор изменяемого объявления и, в случае возникновения ошибки, поля `error_code` и `error_desc`.
