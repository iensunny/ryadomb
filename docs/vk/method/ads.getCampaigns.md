# ads.getCampaigns

> Источник: [https://dev.vk.ru/ru/method/ads.getCampaigns](https://dev.vk.ru/ru/method/ads.getCampaigns)
Возвращает список кампаний рекламного кабинета.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | Идентификатор рекламного кабинета. |
| `client_id` | `integer` | нет | **Обязателен для рекламных агентств, в остальных случаях не используется**. <br>Идентификатор клиента, у которого запрашиваются рекламные кампании. |
| `include_deleted` | `checkbox` | нет | Флаг, задающий необходимость вывода архивных объявлений.<br>* `0` — выводить только активные кампании;<br>* `1` — выводить все кампании. |
| `campaign_ids` | `text` | нет | Фильтр выводимых рекламных кампаний.<br>Сериализованный JSON-массив, содержащий `id` кампаний. Выводиться будут только кампании, присутствующие в `campaign_ids` и являющиеся кампаниями указанного рекламного кабинета. Если параметр равен строке `null`, то выводиться будут все кампании. |
| `fields` | `string` | нет | Добавляет дополнительные поля в ответ.<br>Поддерживаемые значения:<br>* `ads_count` — количество объявлений в кампании. |

## Результат

Возвращает массив объектов `campaign`, каждый из которых содержит следующие поля:
* `id` — идентификатор кампании;
* `type` — тип кампании;
   * `normal` — обычная кампания, в которой можно создавать любые объявления, кроме описанных в следующих пунктах;
   * `vk_apps_managed` — кампания, в которой можно рекламировать только администрируемые Вами приложения и у которой есть отдельный бюджет;
   * `mobile_apps` — кампания, в которой можно рекламировать только мобильные приложения;
   * `promoted_posts` — кампания, в которой можно рекламировать только записи в сообществе;
   * `adaptive_ads` — кампания, в которой можно рекламировать только объявления адаптивного формата.
* `name` — название кампании;
* `status` — статус кампании;
   * `0` — кампания остановлена;
   * `1` — кампания запущена;
   * `2` — кампания удалена.
* `day_limit` — дневной лимит кампании в рублях;
   * `0` — лимит не задан.
* `all_limit` — общий лимит кампании в рублях;
   * `0` — лимит не задан.
* `start_time` — время запуска кампании в формате `unixtime`;
   * `0` — время не задано.
* `stop_time` — время остановки кампании в формате `unixtime`;
   * `0` — время не задано.
