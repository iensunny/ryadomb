# store.getProducts

> Источник: [https://dev.vk.ru/ru/method/store.getProducts](https://dev.vk.ru/ru/method/store.getProducts)
Возвращает список продуктов.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `type` | `string` | нет | Тип продуктов:<br>*  `stickers` — стикеры;<br>*  `votes` — голоса. |
| `merchant` | `string` | нет | Магазин:<br>*  `google`.<br>*  `apple`.<br>*  `microsoft`. |
| `section` | `string` | нет |  |
| `product_ids` | `integer` | нет | Идентификаторы продуктов, информацию о которых необходимо получить. Если используется этот параметр, параметр `type` является обязательным. |
| `filters` | `string` | нет | Определяет статусы, по которым необходимо отфильтровать продукты:<br>*  `purchased` — купленные;<br>*  `active` — активные;<br>*  `promoted` — рекламные.<br>Является обязательным, если не используется параметр `product_ids`. |
| `extended` | `checkbox` | нет | Если указать в качестве этого параметра `1`, то будет возвращена расширенная информация о продуктах. |

## Результат

Возвращает список объектов продуктов, содержащие поля:
*  `id` — идентификатор продукта;
*  `type` — тип продукта;
*  `purchased` — куплен ли продукт: 
    *  `0` - не куплен, 
    *  `1` - куплен.
*  `active` — состояние продукта: 
    *  `0` - скрыт, 
    *  `1` - активен.
*  `promoted` — возвращает `1`, если продукт является рекламным;
*  `purchase_date` — дата покупки (только если `purchased` равен `1`).

Если был задан параметр `extended`=`1`, дополнительно возвращаются поля:
*  `title` — название продукта;
*  `base_url` — URL папки с изображениями для данного продукта;
*  `%type%` — объект с дополнительной информацией о продукте данного типа.

Если `type` равен `stickers`, то в поле `stickers` будет возвращен объект с полями:
*  `base_url` — URL папки с изображениями стикеров;
*  `sticker_ids` — массив с идентификаторами стикеров.
