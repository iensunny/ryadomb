# bugtracker.getDownloadVersionUrl

> Источник: [https://dev.vk.ru/ru/method/bugtracker.getDownloadVersionUrl](https://dev.vk.ru/ru/method/bugtracker.getDownloadVersionUrl)
Возвращает одноразовую ссылку для скачивания сборки, прикреплённой к указанной версии приложения в [продукте](vk-tersters/product).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `product_id` | `positive` | да | Идентификатор продукта. Его можно найти в ссылке на страницу продукта, например:<br>`https://vk.com/bugs?act=product&id=17`<br> |
| `version_id` | `positive` | да | Идентификатор версии продукта, сборку которой нужно скачать. |
| `ttl` | `positive` | нет | **Необязательный параметр**. Время жизни одноразовой ссылки в секундах. Значение в диапазоне от 1 до 31 536 000 (365 суток), по умолчанию 600 (10 минут). |

## Результат

При успешном выполнении в поле `url` возвращает ссылку для скачивания сборки.

Пример ответа:

```JSON
{
  "url":"{ссылка_для_скачивания_сборки}",
  "bundle_name":"{бандл_сборки}",
  "build_id":"{номер_билда_сборки}",
  "build_name":"{название_сборки}",
  "app_title":"{название_продукта}"
}
```

## Типы ключа

`user_access_hidden`
