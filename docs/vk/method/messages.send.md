# messages.send

> Источник: [https://dev.vk.ru/ru/method/messages.send](https://dev.vk.ru/ru/method/messages.send)
Метод отправляет сообщение.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `integer` | нет | **Обязательный параметр.** Идентификатор пользователя, которому отправляется сообщение. Вместо него можно использовать `peer_id`. |
| `random_id` | `integer` | нет | **Обязательный параметр.** Уникальный (в привязке к идентификатору приложения и идентификатору отправителя) идентификатор, предназначенный для предотвращения повторной отправки одного и того же сообщения. Сохраняется вместе с сообщением и доступен в истории сообщений. Возможные значения:<br>* `0` — проверка на уникальность не нужна.<br>* Любое другое число в пределах `int32` — проверка на уникальность нужна.<br>Переданный в запросе `random_id` используется для проверки уникальности сообщений в заданном диалоге за последний час (но не более 100 последних сообщений). |
| `peer_id` | `integer` | нет | **Необязательный параметр.** Идентификатор получателя сообщения:<br>* Для пользователя — `ИДЕНТИФИКАТОР_ПОЛЬЗОВАТЕЛЯ`.<br>* Для групповой беседы — `2000000000 + ИДЕНТИФИКАТОР_БЕСЕДЫ`.<br>* Для сообщества — `-ИДЕНТИФИКАТОР_СООБЩЕСТВА`. |
| `peer_ids` | `string` | нет | **Необязательный параметр.** Идентификаторы получателей сообщения, перечисленные через запятую. Максимальное количество идентификаторов — 100.<br>:::note<br>**Примечание.** Доступно только для ключа доступа сообщества.<br>::: |
| `domain` | `string` | нет | **Необязательный параметр.** Короткий адрес пользователя. Пример: `persik_ryzhiy`. |
| `chat_id` | `positive` | нет | **Необязательный параметр.** Идентификатор беседы, в которую отправляется сообщение. |
| `user_ids` | `string` | нет | **Необязательный параметр.** Идентификаторы получателей сообщения, перечисленные через запятую. Максимальное количество идентификаторов — 100.<br>:::note<br>**Примечание.** Доступно только для ключа доступа сообщества.<br>::: |
| `message` | `string` | нет | **Необязательный параметр.** Текст личного сообщения.  **Обязательный параметр**, если не задан параметр `attachment`. |
| `lat` | `string` | нет | **Необязательный параметр.** Географическая широта в градусах. Диапазон значений: от `-90` до `90`. |
| `long` | `string` | нет | **Необязательный параметр.** Географическая долгота в градусах. Диапазон значений: от `-180` до `180`. |
| `attachment` | `string` | нет | **Необязательный параметр.** Объект или несколько объектов, приложенных к записи. **Обязательный параметр**, если не задан параметр `message`.<br>К записи можно приложить медиа или ссылку на внешнюю страницу. Если объектов несколько, укажите их через запятую `,`.<br>Формат описания медиавложения: `{type}{owner_id}_{media_id}`, где:<br>* `type` — тип медиавложения:<br>    * `photo` — фотография.<br>    * `video` — видеозапись.<br>    * `audio` — аудиозапись.<br>    * `doc` — файл.<br>    * `wall` — запись на стене.<br>    * `market` — товар.<br>    * `poll` — опрос.<br>    * `question` — вопрос.<br>* `owner_id` — идентификатор владельца медиавложения. Идентификатор сообщества должен начинаться со знака&nbsp;`-`.<br>* `media_id` — идентификатор медиавложения.<br>Если прикрепляется медиавложение, которое принадлежит другому пользователю, добавьте к формату описания медиавложения ключ доступа: `{type}{owner_id}_{media_id}_{access_key}`. |
| `reply_to` | `integer` | нет | **Необязательный параметр.** Идентификатор сообщения, на которое требуется ответить. |
| `forward_messages` | `integer` | нет | **Необязательный параметр.** Идентификаторы пересылаемых сообщений, перечисленные через запятую. Пересылаемые сообщения отправителя будут отображаться в теле сообщения у получателя.<br>Ограничения:<br>* Не более 100 значений на верхнем уровне.<br>* Максимальный уровень вложенности — 45.<br>* Максимальное количество пересылаемых сообщений — 500. |
| `forward` | `text` | нет | **Необязательный параметр.** JSON-объект со следующими полями:<br>* `owner_id` — владелец сообщений. Укажите это поле, если вы хотите переслать сообщения из сообщества в личный диалог.<br>* `peer_id` — идентификатор места, из которого необходимо переслать сообщения.<br>* `conversation_message_ids` — массив `conversation_message_id` сообщений, которые необходимо переслать. В параметр можно передать сообщения, которые:<br>    * Находятся в личном диалоге с ботом.<br>    * Являются исходящими сообщениями бота.<br>    * Написаны после того, как бот вступил в беседу и появился доступ к сообщениям.<br>* `message_ids` — массив идентификаторов сообщений.<br>* `is_reply` — ответ на сообщения. Укажите это поле, если вы хотите ответить на сообщения в том чате, в котором находятся сообщения. При этом в `conversation_message_ids` или `message_ids` должен находиться только один элемент. |
| `sticker_id` | `positive` | нет | **Необязательный параметр.** Идентификатор стикера. |
| `group_id` | `integer` | нет | **Необязательный параметр.** Идентификатор сообщества для сообщений сообщества с ключом доступа пользователя. |
| `keyboard` | `text` | нет | **Необязательный параметр.** Объект, описывающий [клавиатуру бота](api/bots/development/keyboard). |
| `template` | `text` | нет | **Необязательный параметр.** Объект, описывающий [шаблон сообщения](api/bots/development/messages#Шаблоны%20сообщений). |
| `payload` | `text` | нет | **Необязательный параметр.** Полезные данные. |
| `content_source` | `text` | нет | **Необязательный параметр.** Объект в формате JSON, описывающий [источник пользовательского контента для чат-ботов](api/bots/development/messages#Сообщения%20с%20пользовательским%20контентом). |
| `dont_parse_links` | `checkbox` | нет | **Необязательный параметр.** Информация о том, создать ли сниппет ссылки из сообщения. Возможные значения:<br>* `1` — не создавать сниппет ссылки из сообщения.<br>* `0` — создать сниппет ссылки из сообщения. |
| `disable_mentions` | `checkbox` | нет | **Необязательный параметр.** Информация о том, отключить ли уведомление об упоминании в сообщении. Возможные значения:<br>* `1` — отключить уведомление об упоминании в сообщении.<br>* `0` — не отключать уведомление об упоминании в сообщении. |
| `intent` | `string` | нет | **Необязательный параметр.** Строка, описывающая интенты. |
| `subscribe_id` | `positive` | нет | **Необязательный параметр.** Число, которое будет использоваться для работы с интентами в будущем. |

## Результат

Метод возвращает идентификатор отправленного сообщения. Если передан параметр `peer_ids`, метод возвращает массив объектов. Поля объекта:

| Поле | Тип | Описание |
|---|---|---|
| `peer_id` | `integer` | Идентификатор назначения. |
| `message_id` | `integer` | Идентификатор сообщения. |
| `conversation_message_id` | `integer` | Идентификатор сообщения в диалоге. |
| `error` | `string` | Сообщение об ошибке, если сообщение не было доставлено получателю. |

Пример ответа:

```JSON
{
  "response":5
}
```
