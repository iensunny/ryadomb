# pages.clearCache

> Источник: [https://dev.vk.ru/ru/method/pages.clearCache](https://dev.vk.ru/ru/method/pages.clearCache)
Позволяет очистить кеш отдельных внешних страниц, которые могут быть прикреплены к записям ВКонтакте. После очистки кеша при последующем прикреплении ссылки к записи, данные о странице будут обновлены.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `url` | `string` | да | Адрес страницы, закешированную версию которой необходимо очистить.  |

## Результат

При удачной очистке кеша – метод возвращает `1`.

## Типы ключа

`allow_from_server`
