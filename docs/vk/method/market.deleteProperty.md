# market.deleteProperty

> Источник: [https://dev.vk.ru/ru/method/market.deleteProperty](https://dev.vk.ru/ru/method/market.deleteProperty)
Удаляет свойство товара.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | Идентификатор сообщества. |
| `property_id` | `positive` | да | Идентификатор свойства. |

## Результат

В случае успешного выполнения возвращает 1.

## Права доступа

`market`
