# messages.pin

> Источник: [https://dev.vk.ru/ru/method/messages.pin](https://dev.vk.ru/ru/method/messages.pin)
Закрепляет сообщение.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `peer_id` | `integer` | да | Идентификатор назначения.<br>Для групповой беседы:<br>* `2000000000` + `id` беседы.<br>Для сообщества:<br>* `-id` сообщества. |
| `message_id` | `positive` | нет | Идентификатор сообщения, которое нужно закрепить. |
| `conversation_message_id` | `positive` | нет | Идентификатор сообщения беседы, которое нужно закрепить. |

## Результат

Возвращает объект [закреплённого сообщения](reference/objects/pinned-message).

## Права доступа

`messages_ex`

## Типы ключа

`group_access`, `is_standalone`
