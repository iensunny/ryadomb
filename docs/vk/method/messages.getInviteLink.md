# messages.getInviteLink

> Источник: [https://dev.vk.ru/ru/method/messages.getInviteLink](https://dev.vk.ru/ru/method/messages.getInviteLink)
Получает ссылку для приглашения пользователя в беседу.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `peer_id` | `positive` | да | Идентификатор назначения.<br>Для групповой беседы:<br>* `2000000000` + `id` беседы. |
| `reset` | `checkbox` | нет | `1` — сгенерировать новую ссылку, сбросив предыдущую. `0` — получить предыдущую ссылку. |
| `group_id` | `positive` | нет | Идентификатор сообщества (для сообщений сообщества с ключом доступа пользователя). |

## Результат

Возвращает объект с единственным полем `link` (`string`), которое содержит ссылку для приглашения в беседу.

## Права доступа

`messages_ex`

## Типы ключа

`group_access`, `is_standalone`
