# board.restoreComment

> Источник: [https://dev.vk.ru/ru/method/board.restoreComment](https://dev.vk.ru/ru/method/board.restoreComment)
Метод восстанавливает в сообществе удалённое из обсуждения сообщение.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | **Обязательный параметр.** Идентификатор сообщества, в котором размещено обсуждение. |
| `topic_id` | `positive` | да | **Обязательный параметр.** Идентификатор обсуждения. |
| `comment_id` | `positive` | да | **Обязательный параметр.** Идентификатор сообщения. |

## Результат

Метод возвращает `1`, если сообщение восстановлено, и `0` в случае ошибки.

Пример ответа:

```JSON
{
  "response": 1
}
```

## Права доступа

`groups_ex`

## Типы ключа

`group_access`, `is_standalone`
