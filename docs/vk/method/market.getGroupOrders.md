# market.getGroupOrders

> Источник: [https://dev.vk.ru/ru/method/market.getGroupOrders](https://dev.vk.ru/ru/method/market.getGroupOrders)
Возвращает заказы сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `string` | нет | Идентификатор или короткое имя сообщества. |
| `offset` | `positive` | нет | Смещение относительно первого найденного заказа для выборки определенного подмножества. |
| `count` | `positive` | нет | Количество возвращаемых заказов. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [заказов](reference/objects/market-order)  в поле `items`.

## Права доступа

`market`

## Типы ключа

`group_access`
