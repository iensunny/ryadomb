# market.getProductPhotoUploadServer

> Источник: [https://dev.vk.ru/ru/method/market.getProductPhotoUploadServer](https://dev.vk.ru/ru/method/market.getProductPhotoUploadServer)
Возвращает адрес для [загрузки изображений товаров в сообщество](api/upload/photo-in-market).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор сообщества, которому принадлежит желаемый товар.&#x0d;&#x0a;[Где найти идентификатор сообщества?](https://vk.com/faq18062)<br> |
| `bulk` | `checkbox` | нет | Указывает, нужно ли загрузить несколько файлов. Если передаётся `true`, то в ответе вернётся адрес сервера, на который можно загрузить до 5 фотографий. |

## Результат

Возвращает объект с полем `upload_url`, которое содержит адрес для [загрузки изображений](api/upload/photo-in-market).

```JSON
{
  "response":{
    "upload_url":"https://pu.vk.com/c857008/ss2158/upload.php?act=do_add&mid=743784474&aid=-53&gid=218252175&hash=39db9a3676d5ecc9b39bc7ab79a50ca7&rhash=4c9dc359457c26d9ecc32c94272f3239&swfupload=1&api=1&market_photo=1"
  }
}
```

## Права доступа

`market`

## Ошибки

- 1438

:::note
**Примечание.** Для успешной работы метода включите раздел **Товары** в сообществе:

1. Войдите ВКонтакте под своими учётными данными.

1. Откройте сообщество, в котором являетесь администратором.

1. В меню справа перейдите в **Управление &rarr; Разделы**.

1. На следующей странице, в блоке **Товары**, включите режим **Базовые** или **Расширенные**.

1. Нажмите **Сохранить**.
:::
