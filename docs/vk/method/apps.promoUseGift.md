# apps.promoUseGift

> Источник: [https://dev.vk.ru/ru/method/apps.promoUseGift](https://dev.vk.ru/ru/method/apps.promoUseGift)
Метод отмечает подарок, полученный пользователем в промоакции, как использованный.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `promo_id` | `positive` | да | Идентификатор акции.<br>:::note<br>**Примечание.** Идентификатор акции будет сообщён администрацией заранее при планировании проведения акции.<br>::: |
| `user_id` | `positive` | нет | Идентификатор пользователя. Используется только при запросе с [сервисным ключом доступа](mini-apps/settings/development/keys#Сервисный%20ключ). |

Идентификатор акции будет сообщен администрацией заранее при планирование проведения акции.

## Результат

Метод возвращает `1`, если подарок отмечен как использованный, и `0` в случае ошибки.

Пример ответа:

```JSON
{
  "response": 1
}
```
