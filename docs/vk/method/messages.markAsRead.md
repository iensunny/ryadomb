# messages.markAsRead

> Источник: [https://dev.vk.ru/ru/method/messages.markAsRead](https://dev.vk.ru/ru/method/messages.markAsRead)
Метод помечает сообщения как прочитанные.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `message_ids` | `string` | нет | :::note<br>**Примечание.** Параметр больше не поддерживается.<br>:::<br>**Необязательный параметр.** Идентификаторы сообщений. |
| `peer_id` | `string` | нет | **Необязательный параметр.** Идентификатор назначения. Возможные значения:<br>* Для пользователя — идентификатор пользователя.<br>* Для групповой беседы — `2000000000` + идентификатор беседы.<br>* Для сообщества — идентификатор сообщества со знаком `-`. |
| `start_message_id` | `positive` | нет | **Необязательный параметр.** Идентификатор сообщения, начиная с которого все сообщения будут помечены как прочитанные. |
| `group_id` | `integer` | нет | **Необязательный параметр.** Идентификатор сообщества (для сообщений сообщества с ключом доступа пользователя). |
| `mark_conversation_as_read` | `checkbox` | нет |  |
| `up_to_cmid` | `positive` | нет |  |



## Результат

Метод возвращает `1`, если сообщения помечены как прочитанные, и `0` в случае ошибки.

Пример ответа:

```JSON
{
  "response": 1
}
```
