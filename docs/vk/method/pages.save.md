# pages.save

> Источник: [https://dev.vk.ru/ru/method/pages.save](https://dev.vk.ru/ru/method/pages.save)
Сохраняет текст вики-страницы.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `text` | `text` | нет | Новый текст страницы в вики-формате. |
| `page_id` | `integer` | нет | Идентификатор вики-страницы. Вместо `page_id` может быть передан параметр `title`. |
| `group_id` | `integer` | нет | Идентификатор сообщества, которому принадлежит вики-страница. |
| `user_id` | `integer` | нет | Идентификатор пользователя, создавшего вики-страницу. |
| `title` | `string` | нет | Название вики-страницы. |

## Результат

В случае успеха возвращает `id` созданной страницы.
