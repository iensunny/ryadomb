# ads.createLookalikeRequest

> Источник: [https://dev.vk.ru/ru/method/ads.createLookalikeRequest](https://dev.vk.ru/ru/method/ads.createLookalikeRequest)
Создаёт запрос на поиск похожей аудитории.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | Идентификатор рекламного кабинета. |
| `client_id` | `integer` | нет | **Только для рекламных агентств**. <br>Идентификатор клиента, для которого будет создаваться аудитория. |
| `source_type` | `string` | да | Тип источника исходной аудитории. На данный момент может принимать единственное значение `retargeting_group`. |
| `retargeting_group_id` | `integer` | нет |  |

## Результат

Поле `request_id`, в котором указан идентификатор созданного запроса на поиск похожей аудитории.

## Права доступа

`ads`
