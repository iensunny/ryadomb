# friends.areFriends

> Источник: [https://dev.vk.ru/ru/method/friends.areFriends](https://dev.vk.ru/ru/method/friends.areFriends)
Метод возвращает информацию о том, добавлен ли текущий пользователь в друзья указанных пользователей.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_ids` | `integer` | да | **Обязательный параметр.** Идентификаторы пользователей, статус дружбы с которыми нужно проверить, перечисленные через запятую. |
| `need_sign` | `checkbox` | нет | **Необязательный параметр.** Информация о том, вернуть ли в ответе поле `sign`. Возможные значения:<br>* `1` – вернуть поле `sign`. Поле имеет значение `md5("{id}_{user_id}_{friend_status}_{application_secret}`, где:<br>    * `id` — идентификатор пользователя, для которого выполняется запрос. Поле позволяет убедиться на сервере, что данные не были подделаны на клиенте.<br>    * `user_id` — идентификатор пользователя, дружбу с которым необходимо проверить.<br>    * `friend_status` — статус дружбы с пользователем.<br>    * `application_secret` — ключ доступа.<br>* `0` — поле `sign` возвращать не нужно. |
| `extended` | `checkbox` | нет | **Необязательный параметр.** Информация о том, вернуть ли в ответе поле `is_request_unread`. Возможные значеня:<br>* `1` – необходимо вернуть поле `is_request_unread`, если есть непросмотренная заявка в друзья.<br>* `0` — поле `is_request_unread` возвращать не нужно. |

## Результат

Метод возвращает массив объектов. Поля объекта массива:

| Поле | Тип | Описание |
| --- | --- | --- |
| `user_id` | `integer` | Идентификатор пользователя. |
| `friend_status` | `integer` | Статус дружбы с пользователем. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `0` — пользователь не является другом.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `1` — заявка отправлена пользователю.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `2` — имеется входящая заявка от пользователя.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `3` — пользователь является другом. |
| `is_request_unread` | `boolean` | Информация о том, есть ли непросмотренная заявка в друзья от пользователя. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `true` — непросмотренная заявка в друзья есть.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `false` — непросмотренной заявки в друзья нет.&#x0d;&#x0a;Поле возвращается, только если передан параметр `extended` и параметр `friend_status` имеет значение `2`. |

Пример ответа:

```JSON
{
  "response":[
    {
      "friend_status":3
      "user_id":743784474
    }
    {
      "friend_status":3
      "user_id":743784479
    }
    {
      "friend_status":3
      "user_id":743784486
    }
  ]
}
```
