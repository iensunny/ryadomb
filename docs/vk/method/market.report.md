# market.report

> Источник: [https://dev.vk.ru/ru/method/market.report](https://dev.vk.ru/ru/method/market.report)
Позволяет отправить жалобу на товар.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца товаров.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «`-`» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `item_id` | `positive` | да | Идентификатор товара |
| `reason` | `positive` | нет | Причина жалобы:<br>*  `0` — спам;<br>*  `1` — детская порнография;<br>*  `2` — экстремизм;<br>*  `3` — насилие;<br>*  `4` — пропаганда наркотиков;<br>*  `5` — материал для взрослых;<br>*  `6` — оскорбление. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`market`
