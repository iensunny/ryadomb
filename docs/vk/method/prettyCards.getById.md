# prettyCards.getById

> Источник: [https://dev.vk.ru/ru/method/prettyCards.getById](https://dev.vk.ru/ru/method/prettyCards.getById)
Возвращает информацию о карточке.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца карточки. |
| `card_ids` | `integer` | да | Список идентификаторов карточек, которые необходимо вернуть. Строка с числами, разделёнными запятой. |

## Результат

Возвращает массив структур со следующими полями:
*  `card_id` — идентификатор карточки;
*  `link_url` — целевая ссылка;
*  `title` — заголовок;
*  `button` — идентификатор кнопки (см. метод [`prettyCards.create`](method/prettyCards.create));
*  `button_text` — текст кнопки;
*  `photo` — идентификатор фотографии;
*  `images` — массив структур с разными размерами фотографии:
   *  `url` — URL фотографии;
   *  `width` — ширина фотографии;
   *  `height` — высота фотографии. 
*  `price` — цена;
*  `price_old` — старая цена.

## Права доступа

`ads`
