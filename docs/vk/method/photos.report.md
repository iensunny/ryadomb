# photos.report

> Источник: [https://dev.vk.ru/ru/method/photos.report](https://dev.vk.ru/ru/method/photos.report)
Позволяет пожаловаться на фотографию.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор пользователя или сообщества, которому принадлежит фотография. |
| `photo_id` | `positive` | да | Идентификатор фотографии. |
| `reason` | `positive` | нет | Причина жалобы:<br>*  `0` — спам;<br>*  `1` — детская порнография;<br>*  `2` — экстремизм;<br>*  `3` — насилие;<br>*  `4` — пропаганда наркотиков;<br>*  `5` — материал для взрослых;<br>*  `6` — оскорбление. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`photos_ex`

## Типы ключа

`is_standalone`
