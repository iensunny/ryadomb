# utils.resolveScreenName

> Источник: [https://dev.vk.ru/ru/method/utils.resolveScreenName](https://dev.vk.ru/ru/method/utils.resolveScreenName)
Определяет тип объекта (пользователь, сообщество, приложение) и его идентификатор по короткому имени `screen_name`.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `screen_name` | `string` | да | Короткое имя пользователя, группы или приложения. Например, `apiclub`, `andrew` или `rules_of_war`. |

## Результат

После успешного выполнения возвращает объект с полями:

### `type` 
`string`
Тип объекта. Возможные значения:
 * `user` — пользователь.
 * `group` — сообщество.
 * `event` — мероприятие (для коротких имён вида `event1`).
 * `page` — публичная страница (для коротких имён вида `public1`).
 * `application` — игра.
 * `vk_app` — мини-приложение.

### `object_id`
`integer`
Идентификатор объекта.

Для ссылок на [плагины для сообществ](mini-apps/development/community-apps) вида `app12345_-87654321` возвращается:
 * `type` — тип объекта, `community_application`.
 * `object_id` — идентификатор плагина, `12345`.
 * `group_id` — идентификатор сообщества, `87654321`.

Если короткое имя `screen_name` не занято, то возвращается пустой массив.

## Типы ключа

`allow_from_server`, `group_access`
