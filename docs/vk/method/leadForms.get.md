# leadForms.get

> Источник: [https://dev.vk.ru/ru/method/leadForms.get](https://dev.vk.ru/ru/method/leadForms.get)
Возвращает информацию о форме сбора заявок.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор группы, в которой находится форма. |
| `form_id` | `integer` | да | Идентификатор формы. |

## Результат

Возвращает структуру с информацией о форме. Значения полей см. в методе [`leadForms.create`](method/leadForms.create). 

Дополнительно возвращает следующие поля:
*  `form_id` — идентификатор формы;
*  `leads_count` — количество заявок;
*  `url` — ссылка на форму.

## Права доступа

`groups`
