# database.getCitiesById

> Источник: [https://dev.vk.ru/ru/method/database.getCitiesById](https://dev.vk.ru/ru/method/database.getCitiesById)
Возвращает информацию о городах и регионах по их идентификаторам.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `city_ids` | `string` | нет | Идентификаторы городов и регионов. |

## Результат

Возвращает массив объектов, описывающих города. 

Каждый объект содержит следующие поля:

`id`
`integer`
Идентификатор города или региона,

`title`
`string`
Название города или региона.

## Типы ключа

`allow_from_server`
