# secure.checkToken

> Источник: [https://dev.vk.ru/ru/method/secure.checkToken](https://dev.vk.ru/ru/method/secure.checkToken)
Метод проверяет, что ключ доступа пользователя (`access_token`) выдан именно тому приложению, которому выдан переданный сервисный ключ доступа. Подходит для проверки ключа доступа iFrame и Standalone-приложений.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `token` | `string` | нет | **Обязательный параметр**. Ключ доступа пользователя (`access_token`). Если не передать значение параметра, метод вернёт ошибку `Access denied: Incorrect token invalid_token`. |
| `ip` | `string` | нет | **Необязательный параметр**. IP-адрес пользователя. Если пользователь обращается через IPv6, передавать параметр обязательно. Если параметр не передан, IP-адрес проверен не будет. |

## Результат

Метод вернёт объект. Параметры объекта:

| Параметр | Тип | Описание |
| --- | --- | --- |
| `success` | `integer` | Индикатор, что метод выполнился успешно (всегда `1`). |
| `user_id` | `integer` | Идентификатор пользователя. |
| `date` | `integer` | Дата и время в секундах, когда `access_token` был сгенерирован ([Unix Timestamp](https://www.unixtimestamp.com/)). |
| `expire` | `integer` | Дата и время секундах, когда время жизни `access_token` истечёт ([Unix Timestamp](https://www.unixtimestamp.com/)). |

Пример ответа:

```JSON
{
  "success": 1,
  "user_id": 1,
  "date": 1659077806,
  "expire": 1659164206
}
```
