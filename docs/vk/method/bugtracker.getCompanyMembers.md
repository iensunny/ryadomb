# bugtracker.getCompanyMembers

> Источник: [https://dev.vk.ru/ru/method/bugtracker.getCompanyMembers](https://dev.vk.ru/ru/method/bugtracker.getCompanyMembers)
Возвращает список [сотрудников](vk-testers/employees) [компании](vk-testers/company).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `company_id` | `positive` | да | Идентификатор компании. Его можно найти в ссылке на страницу компании, например:<br>`https://vk.com/bugs_mng?company_id=3`<br> |
| `count` | `positive` | нет | **Необязательный параметр**. Количество возвращаемых результатов. Максимальное значение: `100`. Значение по умолчанию: `10`. |
| `offset` | `positive` | нет | **Необязательный параметр**. Количество пропущенных результатов. |
| `filter_name` | `string` | нет | **Необязательный параметр**. Имя пользователя, по которому нужно отфильтровать результаты. |
| `filter_role` | `positive` | нет | **Необязательный параметр**. Название роли, по которой нужно отфильтровать результаты. |
| `filter_not_group` | `positive` | нет | **Необязательный параметр**. Идентификатор группы доступа, участников которой нужно исключить из результатов. |
| `filter_member_ids` | `string` | нет |  |
| `extended` | `checkbox` | нет | **Необязательный параметр**. Устанавливает, возвращать ли подробную информацию о профиле пользователя. Возможные значения:<br>* `0` — не возвращать.<br>* `1` — возвращать. |
| `fields` | `string` | нет | **Необязательный параметр**. Устанавливает список полей профиля пользователя, которые нужно возвращать. |
| `extra` | `checkbox` | нет | **Необязательный параметр**. Устанавливает, возвращать ли дополнительную информацию по продуктам и группам доступа для каждого сотрудника.<br>* `0` — не возвращать.<br>* `1` — возвращать. |

## Результат

В результате возвращается объект со следующими полями:

* `count` — количество пользователей, подходящих под переданные фильтры.
* `company_members` — список объектов с данными о пользователях.
* `profiles` — данные о пользователях. В зависимости от того, установлены ли поля `extended` и `fields`, передаётся дополнительная информация о профилях пользователей.

Каждый объект `company_member` состоит из полей:

* `user_id` — идентификатор пользователя.
* `company_id`— идентификатор компании.
* `role` — идентификатор роли в компании (`0` — участник, `1` — руководитель).
* `ts` — дата добавления в компанию (timestamp).
* `reporter_url` — ссылка на карточку пользователя в VK Testers.

Если передан параметр `extra=1`, то в каждый объект `company_member` добавляются поля:

* `groups_count` — счётчик групп пользователя.
* `products_count` — счётчик продуктов пользователя.
* `groups` — массив с идентификаторами групп, в которых состоит пользователь.
* `products` — массив связей с продуктами компании.

Каждая связь с продуктом имеет вид:

* `id` — идентификатор продукта.
* `access` — [уровень доступа](vk-testers/employees#Уровни%20доступа%20сотрудников) в продукт.
* `status` — способ, которым сотрудник получил доступ в продукт. Возможные значения:
    * **6** — доступ получен на основе [группы доступа](vk-testers/employees#Группы%20доступа).
    * **7** — доступ выдан персонально.
