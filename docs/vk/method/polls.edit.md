# polls.edit

> Источник: [https://dev.vk.ru/ru/method/polls.edit](https://dev.vk.ru/ru/method/polls.edit)
Позволяет редактировать созданные опросы.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | нет | Идентификатор владельца опроса. |
| `poll_id` | `positive` | да | Идентификатор редактируемого опроса. |
| `question` | `string` | нет | Новый текст редактируемого опроса. |
| `add_answers` | `text` | нет | Список вариантов ответов, например:<br>```json<br>["yes", "no", "maybe"]<br>``` |
| `edit_answers` | `text` | нет | Объект, содержащий варианты ответов, которые необходимо отредактировать.<br>Ключ – идентификатор ответа, значение – новый текст ответа.<br>Пример:<br>```json<br>{"382967099":"option1", "382967103":"option2"}<br>``` |
| `delete_answers` | `text` | нет | Список идентификаторов ответов, которые необходимо удалить, например:<br>```json<br>[382967099, 382967103]<br>``` |
| `end_date` | `positive` | нет | Дата завершения опроса в `unixtime`. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`wall_ex`

## Типы ключа

`vk_apps`, `is_standalone`
