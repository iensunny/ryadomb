# utils.getLinkStats

> Источник: [https://dev.vk.ru/ru/method/utils.getLinkStats](https://dev.vk.ru/ru/method/utils.getLinkStats)
Возвращает статистику переходов по [сокращённой](utils.getShortLink) ссылке.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `key` | `string` | да | Сокращённая ссылка (часть URL после «vk.cc/»). |
| `source` | `string` | нет |  |
| `access_key` | `string` | нет | Ключ доступа к приватной статистике ссылки. |
| `interval` | `string` | нет | Единица времени для подсчета статистики. Возможные значения:<br>* `hour` — час;<br>* `day` — день;<br>* `week` — неделя;<br>* `month` — месяц;<br>* `forever` — все время с момента создания ссылки. |
| `intervals_count` | `positive` | нет | Длительность периода для получения статистики в выбранных единицах (из параметра `interval`). |
| `extended` | `checkbox` | нет | `1` — возвращать расширенную статистику (пол, возраст, страна, город).<br>`0` — возвращать только количество переходов. |

## Результат

Возвращает объект, содержащий поле `key` с входным параметром `key` и массив `stats` с данными о статистике. Каждый объект в массиве `stats` содержит поле `timestamp` с указанием времени начала отсчета, общее число переходов `views` и массивы, описывающие половозрастную или геостатистику: `sex_age`, `countries`, `cities`.

* Каждый объект в массиве `sex_age` содержит следующие поля:

### `age_range` 
`string`
Обозначение возраста.

### `female` 
`integer`
Число переходов пользователей женского пола.

### `male` 
`integer`
Число переходов пользователей мужского пола.

* Каждый объект в массиве `countries` (`cities`) содержит следующие поля:

### `country_id` (`city_id`) 
`integer`
Идентификатор страны (города).

###  `views`
 `integer`
 Число переходов из этой страны (города).

## Типы ключа

`group_access`, `allow_from_server`
