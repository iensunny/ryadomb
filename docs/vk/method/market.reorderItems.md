# market.reorderItems

> Источник: [https://dev.vk.ru/ru/method/market.reorderItems](https://dev.vk.ru/ru/method/market.reorderItems)
Изменяет положение товара в подборке.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `owner_id` | `integer` | да | Идентификатор владельца товара.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком «`-`» — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `album_id` | `integer` | нет | Идентификатор подборки, в которой находится товар. `0` — для сортировки общего списка товаров. |
| `item_id` | `positive` | да | Идентификатор товара. |
| `before` | `positive` | нет | Идентификатор товара, перед которым следует поместить текущий. |
| `after` | `positive` | нет | Идентификатор товара, после которого следует поместить текущий. |

## Результат

После успешного выполнения возвращает `1`.
