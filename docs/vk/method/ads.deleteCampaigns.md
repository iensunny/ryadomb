# ads.deleteCampaigns

> Источник: [https://dev.vk.ru/ru/method/ads.deleteCampaigns](https://dev.vk.ru/ru/method/ads.deleteCampaigns)
Архивирует рекламные кампании.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | Идентификатор рекламного кабинета. |
| `ids` | `text` | да | Сериализованный JSON-массив, содержащий id удаляемых кампаний. |

## Результат

Возвращает массив ответов на каждый запрос. Каждый ответ является либо `0`, что означает успешное удаление, либо код ошибки.

## Права доступа

`ads`

## Ошибки

- 629
- 602
- 601
