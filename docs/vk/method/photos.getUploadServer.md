# photos.getUploadServer

> Источник: [https://dev.vk.ru/ru/method/photos.getUploadServer](https://dev.vk.ru/ru/method/photos.getUploadServer)
Метод получает адрес сервера для [загрузки фотографий в альбом](api/upload/album-photos) пользователя или сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `album_id` | `integer` | нет | **Необязательный параметр.** Идентификатор альбома.<br>Идентификатор находится в адресной строке открытого альбома после знака `_`. |
| `group_id` | `integer` | нет | **Необязательный параметр.** Идентификатор сообщества, которому принадлежит альбом.<br>Укажите идентификатор сообщества, если хотите загрузить фотографию в альбом сообщества.<br>:::note<br>**Примечание.** Если параметр не указан, возвращается адрес для загрузки фотографии на стену текущего пользователя.<br>::: |

## Результат

Метод возвращает объект. Поля объекта:

| Поле | Тип | Описание |
|---|---|---|
| `album_id` | `integer` | Идентификатор альбома, в который нужно загрузить фотографии. |
| `upload_url` | `string` | Адрес, по которому нужно загрузить фотографии. |
| `user_id` | `integer` | Идентификатор пользователя или сообщества, в альбом которого будут загружены фотографии. |

Пример ответа:
 
 ```JSON
{
  "response":{
    "album_id":289219319
    "upload_url":"https://pu.vk.com/c856312/ss2152/upload.php?act=do_add&mid=743784474&aid=289219319&gid=0&hash=e76c268d9d55152f8d5799432956ef98&rhash=9f61ee6a7666b4735d9317525e37ffc4&swfupload=1&api=1"
    "user_id":743784474
  }
}
 ```
