# groups.removeUser

> Источник: [https://dev.vk.ru/ru/method/groups.removeUser](https://dev.vk.ru/ru/method/groups.removeUser)
Позволяет исключить пользователя из группы или отклонить заявку на вступление.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | Идентификатор группы, из которой необходимо исключить пользователя. |
| `user_id` | `positive` | да | Идентификатор пользователя, которого нужно исключить. |

## Результат

В случае успешного выполнения возвращает `1`.

## Права доступа

`groups_ex`

## Типы ключа

`is_standalone`
