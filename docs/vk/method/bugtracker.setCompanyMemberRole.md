# bugtracker.setCompanyMemberRole

> Источник: [https://dev.vk.ru/ru/method/bugtracker.setCompanyMemberRole](https://dev.vk.ru/ru/method/bugtracker.setCompanyMemberRole)
Изменяет [уровень доступа сотрудника](vk-testers/employees#Уровни%20доступа%20сотрудников) в [компании](vk-testers/company).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `integer` | да | Идентификатор пользователя. |
| `company_id` | `positive` | да | Идентификатор компании. Его можно найти в ссылке на страницу компании, например:<br>`https://vk.com/bugs_mng?company_id=3`<br> |
| `role` | `positive` | да | Устанавливает роль для сотрудника. Возможные значения:<br>* `0` — **Участник** – может присоединяться к открытым продуктам компании самостоятельно и быть присоединён к закрытым продуктам руководителем компании.<br>* `1` — **Руководитель** – имеет полный доступ к управлению компанией. |

## Результат

При успешном выполнении возвращает `1`.

Пример ответа:

```JSON
{
  "response": 1
}
```

## Типы ключа

`user_access_hidden`

## Ошибки

- 104
- 103

> Работает с [ключом доступа](vk-testers/access-tokens) компании.
