# wall.get

> Источник: [https://dev.vk.ru/ru/method/wall.get](https://dev.vk.ru/ru/method/wall.get)
Возвращает список записей со стены пользователя или сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `domain` | `string` | нет | Короткий адрес пользователя или сообщества. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определённого подмножества записей. |
| `count` | `positive` | нет | Количество записей, которое необходимо получить. Максимальное значение: `100`. |
| `filter` | `string` | нет | Определяет, какие типы записей на стене необходимо получить. Возможные значения:<br>* `suggests` — предложенные записи на стене сообщества (доступно только при вызове с передачей `access_token`);<br>* `postponed` — отложенные записи (доступно только при вызове с передачей `access_token`);<br>* `owner` — записи владельца стены;<br>* `others` — записи не от владельца стены;<br>* `all` — все записи на стене (`owner` + `others`).<br>* `donut` — записи для платных подписчиков на стене сообщества. [Подробнее о VK Donut API](https://dev.vk.com/api/donut/getting-started)<br>По умолчанию: `all`. |
| `extended` | `checkbox` | нет | `1` — в ответе будут возвращены дополнительные поля `profiles` и `groups`, содержащие информацию о пользователях и сообществах. По умолчанию: `0`. |
| `fields` | `string` | нет | Список дополнительных полей для [профилей](reference/objects/user) и [сообществ](reference/objects/group), которые необходимо вернуть.<br>Обратите внимание, этот параметр учитывается только при `extended`= `1`. |



## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [записей на стене](reference/objects/post) в поле `items`.

Если был задан параметр `extended` = `1`, возвращает число результатов в поле `count`, отдельно массив объектов [записей на стене](reference/objects/post) в поле `items`, [пользователей](reference/objects/user) в поле `profiles` и [сообществ](reference/objects/group) в поле `groups`.
