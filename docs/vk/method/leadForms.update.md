# leadForms.update

> Источник: [https://dev.vk.ru/ru/method/leadForms.update](https://dev.vk.ru/ru/method/leadForms.update)
Обновляет форму сбора заявок.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор группы, в которой надо обновить форму. |
| `form_id` | `integer` | да | Идентификатор формы, которую надо обновить. |
| `name` | `string` | да | Новое название формы (видно только администратору). |
| `title` | `string` | да | Новый заголовок формы (видят пользователи). |
| `description` | `string` | да | Новое описание формы. |
| `questions` | `text` | да | Новые вопросы формы. Подробнее см. метод [`leadForms.create`](method/leadForms.create). |
| `policy_link_url` | `string` | да | Новая ссылка на политику конфиденциальности. |
| `photo` | `string` | нет | Новая обложка формы. |
| `confirmation` | `string` | нет | Новый текст подтверждения, который увидит пользователь после отправки формы. |
| `site_link_url` | `string` | нет | Новая ссылка на сайт или сообщество автора формы. |
| `active` | `checkbox` | нет | Передайте `1`, чтобы активировать форму. Пользователи могут оставлять заявки только в активных формах. |
| `once_per_user` | `checkbox` | нет | Передайте `1`, чтобы разрешить каждому пользователю заполнять форму только один раз. |
| `pixel_code` | `string` | нет | Новый код пикселя ретаргетинга ВКонтакте. |
| `notify_admins` | `integer` | нет | Новый список идентификаторов пользователей, которым будут отправлены оповещения о заполнении пользователями формы. Оповещения могут быть отправлены только администраторам сообщества. |
| `notify_emails` | `string` | нет | Новый список email-адресов, разделённых запятой, на которые будут отправлены оповещения о заполнении пользователями формы. Можно указать до **10** адресов. |

## Результат

Возвращается структура с информацией об обновлённой форме:
*  `form_id` — идентификатор формы;
*  `url` — ссылка на форму.
