# ads.updateTargetPixel

> Источник: [https://dev.vk.ru/ru/method/ads.updateTargetPixel](https://dev.vk.ru/ru/method/ads.updateTargetPixel)
Редактирует пиксель ретаргетинга.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | Идентификатор рекламного кабинета. |
| `client_id` | `integer` | нет | **Только для рекламных агентств**. <br>ID клиента, в рекламном кабинете которого находится пиксель. |
| `target_pixel_id` | `integer` | да | Идентификатор пикселя. |
| `name` | `string` | да | Новое название пикселя — строка до 64 символов. |
| `domain` | `string` | нет | Новый домен сайта, на котором будет размещён код пикселя. |
| `category_id` | `integer` | да | Новый идентификатор категории сайта, на котором будет размещён пиксель. Для получения списка возможных идентификаторов можно использовать метод [`ads.getSuggestions`](method/ads.getSuggestions) (раздел `interest_categories`). |

## Результат

После успешного выполнения возвращает `1`.
