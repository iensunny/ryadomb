# groups.getCatalogInfo

> Источник: [https://dev.vk.ru/ru/method/groups.getCatalogInfo](https://dev.vk.ru/ru/method/groups.getCatalogInfo)
Возвращает список категорий для каталога сообществ.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `extended` | `checkbox` | нет | `1` — вернуть информацию о количестве сообществ в категории и три сообщества для предпросмотра. <br>По умолчанию `0`. |
| `subcategories` | `checkbox` | нет | `1` — вернуть информацию об подкатегориях. <br>По умолчанию `0`. |

## Результат

После успешного выполнения возвращает поле `enabled` (`0` — каталог недоступен для пользователя, `1` — каталог доступен), и, если `enabled`=`1`, массив `categories` объектов — категорий товаров.

### Объект массива `categories` — категория каталога товаров.

`id`
`положительное число`
Идентификатор категории.

`name`
`string`
Название категории.

`subcategories`
Поле возвращается при использовании `subcategories`=`1`. Массив объектов-подкатегорий. Каждый из объектов содержит поля `id` и `name`, содержащие идентификатор и название подкатегории.

### Дополнительные поля (`extended`=`1`)

`page_count`
`положительное число`
Количество сообществ в категории.

`page_previews`
Массив объектов [сообществ](reference/objects/group) для предпросмотра.
