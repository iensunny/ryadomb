# leadForms.list

> Источник: [https://dev.vk.ru/ru/method/leadForms.list](https://dev.vk.ru/ru/method/leadForms.list)
Возвращает список форм сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `integer` | да | Идентификатор сообщества. |

## Результат

Возвращает массив структур с описанием форм. Подробнее о структуре описания формы см. метод [`leadForms.get`](method/leadForms.get).

## Права доступа

`groups`
