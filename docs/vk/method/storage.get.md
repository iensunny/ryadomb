# storage.get

> Источник: [https://dev.vk.ru/ru/method/storage.get](https://dev.vk.ru/ru/method/storage.get)
Возвращает значение переменной, название которой передано в параметре `key`.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `key` | `string` | нет | Название переменной. Может содержать символы: `[a-zA-Z_\-0-9]`.  |
| `keys` | `string` | нет | Список названий переменных, разделённых запятыми. Если указан этот параметр, то параметр `key` не учитывается. |
| `user_id` | `positive` | нет | ID пользователя, переменная которого устанавливается, в случае если данные запрашиваются серверным методом. |

## Результат

Возвращает массив, содержащий объект(ы) с названием и значением переменной. Если переменная на сервере отсутствует, то в `value` вернется пустая строка.

## Типы ключа

`allow_from_server`, `group_access`
