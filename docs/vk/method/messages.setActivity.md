# messages.setActivity

> Источник: [https://dev.vk.ru/ru/method/messages.setActivity](https://dev.vk.ru/ru/method/messages.setActivity)
Изменяет статус набора текста пользователем в диалоге.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `string` | нет | Идентификатор пользователя. |
| `type` | `string` | нет | `typing` — пользователь печатает текст,<br>`audiomessage` — пользователь записывает голосовое сообщение,<br>`photo` — пользователь загружает фото,<br>`video` — пользователь загружает видео,<br>`file` — пользователь загружает файл,<br>`videomessage` — пользователь записывает видео сообщение. |
| `peer_id` | `integer` | нет | Идентификатор назначения.<br>Для групповой беседы:<br>* `2000000000` + `id` беседы.<br>Для сообщества:<br>* `-id` сообщества. |
| `group_id` | `positive` | нет | Идентификатор сообщества (для сообщений сообщества с ключом доступа пользователя). |

## Результат

После успешного выполнения возвращает `1`. 
Текст «N набирает сообщение...» отображается в течение 5-10 секунд (в зависимости от платформы) после вызова метода, либо до момента отправки сообщения.
