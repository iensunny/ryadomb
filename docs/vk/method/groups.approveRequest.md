# groups.approveRequest

> Источник: [https://dev.vk.ru/ru/method/groups.approveRequest](https://dev.vk.ru/ru/method/groups.approveRequest)
Позволяет одобрить заявку в группу от пользователя.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | Идентификатор группы, заявку в которую необходимо одобрить. |
| `user_id` | `positive` | да | Идентификатор пользователя, заявку которого необходимо одобрить. |

## Результат

В случае успешного выполнения возвращает `1`.

## Права доступа

`groups_ex`

## Типы ключа

`is_standalone`
