# video.getAlbumsByVideo

> Источник: [https://dev.vk.ru/ru/method/video.getAlbumsByVideo](https://dev.vk.ru/ru/method/video.getAlbumsByVideo)
Метод возвращает список альбомов, в которых находится видеозапись.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `target_id` | `integer` | нет | **Необязательный параметр.** Идентификатор пользователя или сообщества, для которого нужно получить список альбомов. Идентификатор сообщества должен начинаться со знака&nbsp;`-`.<br>:::note<br>**Примечание.** Если не передать значение параметра, оно определится автоматически по использованному в запросе ключу доступа.<br>::: |
| `owner_id` | `integer` | да | **Обязательный параметр.** Идентификатор владельца видеозаписи. Идентификатор сообщества должен начинаться со знака&nbsp;`-`. |
| `video_id` | `positive` | да | **Обязательный параметр.** Идентификатор видеозаписи, которую нужно найти в альбомах. |
| `extended` | `checkbox` | нет | **Необязательный параметр.** Информация о том, нужно ли получить расширенную информацию об альбомах. Возможные значения:<br>* `1` — получить расширенную информацию.<br>* `0` — не получать расширенную информацию. Значение используется по умолчанию. |

## Результат

Метод возвращает массив идентификаторов альбомов. Если передан параметр `extended` со значением `1`, возвращается объект альбома. Поля объекта:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `integer` | Идентификатор альбома. |
| `owner_id` | `integer` | Идентификатор создателя альбома. |
| `title` | `string` | Название альбома. |
| `count` | `integer` | Количество видеозаписей в альбоме. |
| `photo160` | `string` | **Deprecated** с версии API 5.101. Ссылка на квадратную обложку альбома с шириной 160 пикселей. Не возвращается в методах видеозаписей из каталога. |
| `photo320` | `string` | **Deprecated** с версии API 5.101. Ссылка на квадратную обложку альбома с шириной 320 пикселей. Не возвращается в методах видеозаписей из каталога. |
| `image` | `array[object]` | Массив объектов, каждый из которых хранит разрешение обложки и ссылку на неё. Поля объекта:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `url` (`string`) — URL-адрес изображения.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `width` (`integer`) — ширина изображения.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `height` (`integer`) — высота изображения.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `with_padding` (`integer`) — `1`, если изображение имеет чёрные поля. |
| `updated_time` | `integer` | Время последнего обновления в секундах ([Unix Timestamp](https://www.unixtimestamp.com/)). |
| `is_system` | `integer` | `1`, если это системный альбом, например **Добавленные**, или поле отсутствует. |
| `privacy` | `object` | Объект приватности пользователя. Поля объекта:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `category` (`string`) — тип приватности.&#x0d;&#x0a; &nbsp;&nbsp;&nbsp;&nbsp; &bullet; `all` — альбом доступен всем.&#x0d;&#x0a; &nbsp;&nbsp;&nbsp;&nbsp; &bullet; `friends` — альбом доступен друзьям текущего пользователя.&#x0d;&#x0a; &nbsp;&nbsp;&nbsp;&nbsp; &bullet; `friends_of_friends` — альбом доступен друзьям и друзьям друзей текущего пользователя.&#x0d;&#x0a; &nbsp;&nbsp;&nbsp;&nbsp; &bullet; `only_me` — альбом доступен только текущему пользователю.&#x0d;&#x0a; &nbsp;&nbsp;&nbsp;&nbsp; &bullet; `some` — альбом доступен некоторым пользователям.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `owners` (`object`) — информация о доступе к альбому конкретным пользователям.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `lists` (`object`) — информация о доступе к альбому конкретным спискам друзей.&#x0d;&#x0a;&#x0d;&#x0a;Поля объекта `owners`:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `allowed` (`array[integer]`) — массив идентификаторов пользователей, которым разрешён доступ.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `excluded` (`array[integer]`) — массив идентификаторов пользователей, которым запрещён доступ.&#x0d;&#x0a;&#x0d;&#x0a;Поля объекта `lists`:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `allowed` (`array[integer]`) — массив идентификаторов списков друзей, которым разрешён доступ.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `excluded` (`array[integer]`) — массив идентификаторов списков друзей, которым запрещён доступ.&#x0d;&#x0a;&#x0d;&#x0a;Возвращается, если создателем альбома является запрашивающий этот объект пользователь. |
