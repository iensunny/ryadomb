# photos.getAlbumsCount

> Источник: [https://dev.vk.ru/ru/method/photos.getAlbumsCount](https://dev.vk.ru/ru/method/photos.getAlbumsCount)
Возвращает количество доступных альбомов пользователя или сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_id` | `integer` | нет | Идентификатор пользователя, количество альбомов которого необходимо получить. |
| `group_id` | `integer` | нет | Идентификатор сообщества, количество альбомов которого необходимо получить. |

## Результат

После успешного выполнения возвращает количество альбомов  с учетом настроек приватности.
