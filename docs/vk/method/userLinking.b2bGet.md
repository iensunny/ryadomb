# userLinking.b2bGet

> Источник: [https://dev.vk.ru/ru/method/userLinking.b2bGet](https://dev.vk.ru/ru/method/userLinking.b2bGet)
Метод для получения дополнительных сведений по Access Token

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `user_access_token` | `string` | да | Токен пользователя, по которомы был осуществлён вход. |

Метод можно вызвать только b2b с использованием сервисного токена.

## Результат

В ответ получаем информацию о связке пользователя ВК ИД с пользователем во внешней OAuth системе.

## Типы ключа

`secure`

Если токен был получен через вход по внешнему OAuth то этот метод позволяет узнать через какого OAuth провайдера был осуществлён вход а так же данные по связки пользователя с аккаунтом во внешнем сервисе.
