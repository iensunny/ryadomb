# ads.deleteAds

> Источник: [https://dev.vk.ru/ru/method/ads.deleteAds](https://dev.vk.ru/ru/method/ads.deleteAds)
Архивирует рекламные объявления.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `account_id` | `integer` | да | Идентификатор рекламного кабинета. |
| `ids` | `text` | да | Сериализованный JSON-массив, содержащий идентификаторы объявлений. |

## Результат

Возвращает массив ответов на каждый запрос. Каждый ответ является либо `0`, что означает успешное удаление, либо код ошибки.

## Права доступа

`ads`

- 602
