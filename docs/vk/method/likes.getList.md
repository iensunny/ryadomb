# likes.getList

> Источник: [https://dev.vk.ru/ru/method/likes.getList](https://dev.vk.ru/ru/method/likes.getList)
Метод получает список идентификаторов пользователей, которые поставили у заданного объекта отметку «Нравится».

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `type` | `string` | да | Тип объекта. Возможные типы:<br>* `post` — запись на стене пользователя или сообщества.<br>* `post_ads` — рекламная запись.<br>* `comment` — комментарий к записи на стене.<br>* `photo` — фотография.<br>* `video` — видеозапись.<br>* `note` — заметка.<br>* `market` — товар.<br>* `photo_comment` — комментарий к фотографии.<br>* `video_comment` — комментарий к видеозаписи.<br>* `topic_comment` — комментарий в обсуждении.<br>* `market_comment` — комментарий к товару.<br>* `sitepage` — страница сайта, на котором установлен [виджет «Нравится»](widgets/like). |
| `owner_id` | `integer` | нет | Идентификатор владельца объекта:<br>* Идентификатор пользователя, если объект принадлежит пользователю.<br>* Идентификатор сообщества (со знаком «минус»), если объект принадлежит сообществу.<br>* Идентификатор приложения, если параметр `type` имеет значение `sitepage`.<br>Значение по умолчанию: если параметр не задан, он имеет значение идентификатора текущего пользователя или идентификатора текущего приложения, если параметр `type` имеет значение `sitepage`. |
| `item_id` | `integer` | нет | Идентификатор объекта. Имеет значение параметра `page_id`, если параметр `type` имеет значение `sitepage`. Значение параметра `page_id` используется при инициализации [виджета «Нравится»](widgets/like). |
| `page_url` | `string` | нет | URL страницы, на которой установлен [виджет «Нравится»](widgets/like). Используется вместо параметра `item_id`, если при размещении виджета не был указан параметр `page_id`. |
| `filter` | `string` | нет | Указывает, следует ли вернуть всех пользователей, поставивших у объекта отметку «Нравится», или только тех, которые рассказали о нём друзьям. Возможные значения:<br>* `likes` — возвращать информацию обо всех пользователях. <br>* `copies` — возвращать информацию только о пользователях, рассказавших об объекте друзьям.<br>По умолчанию возвращается информация обо всех пользователях. |
| `friends_only` | `integer` | нет | Указывает, необходимо ли возвращать только пользователей, которые являются друзьями текущего пользователя. Возможные значения:<br>* `0` — возвращать всех пользователей в порядке убывания времени добавления объекта.<br>* `1` — возвращать только друзей текущего пользователя в порядке убывания времени добавления объекта.<br>Если метод был вызван без авторизации или параметр не был задан, он имеет значение `0`.<br> |
| `extended` | `checkbox` | нет | Информация о том, возвращать ли расширенную информацию. Возможные значения:<br>* `1` — возвращать расширенную информацию о пользователях и сообществах из списка поставивших отметку «Нравится» или поделившихся записью.<br>* `0` — возвращать только идентификаторы пользователей и сообществ.<br>Значение по умолчанию: `0`. |
| `offset` | `positive` | нет | Смещение для возвращения идентификаторов относительно начала списка. Если параметр не задан, он имеет значение `0`. |
| `count` | `positive` | нет | Количество возвращаемых идентификаторов пользователей.<br>Значение по умолчанию: если параметр не задан или не задан параметр `friends_only`, он имеет значение `100`, в противном случае — `10`.<br>Максимальное значение параметра: если не задан параметр `friends_only` — `1 000`, в противном случае — `100`. |
| `skip_own` | `checkbox` | нет | Информация о том, возвращать ли информацию о самом пользователе.<br>Возможные значения:<br>* `true` — возвращать информацию о пользователе.<br>* `false` — не возвращать информацию о пользователе. |

## Результат

Метод возвращает объект. Параметры объекта:

| Параметр | Тип | Описание |
| --- | --- | --- |
| `count` | `integer` | Количество возвращаемых идентификаторов пользователей, которые поставили у заданного объекта отметку «Нравится». |
| `items` | `array[integer]` | Массив идентификаторов пользователей или сообществ. Если:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; Параметр `type` имеет значение `sitepage`, возвращается список пользователей, воспользовавшихся виджетом «Нравится» на внешнем сайте. Адрес страницы задаётся при помощи параметров `page_url` или `item_id`.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; Параметр `extended` имеет значение `1`, возвращается расширенная информация о [пользователях](reference/objects/user) или [сообществах](reference/objects/group).&#x0d;&#x0a; &nbsp;&nbsp; &bullet; Параметр `filter` имеет значение `copies`, возвращается список пользователей, поделившихся записью. Параметр возвращается, только если запрос отправляет администратор группы (права редактора и выше) или владелец стены для стены пользователя. |

Пример ответа, если параметр `type` имеет значение `sitepage`:

```JSON
{
  "response": {
    "count": 1295,
    "items": [
      743784474,
      743784479
    ]
  }
}
```

Пример ответа, если `extended` имеет значение `1`:

```JSON
{
  "response": {
    "count": 1390,
    "items": [
      {
        "id": 743784474,
        "type": "profile",
        "first_name": "Персик",
        "last_name": "Рыжий",
        "can_access_closed": true,
        "is_closed": false
      },
      {
        "id": 743784479,
        "type": "profile",
        "first_name": "Сеня",
        "last_name": "Хомяк",
        "can_access_closed": true,
        "is_closed": false
      }
    ]
  }
}
```
