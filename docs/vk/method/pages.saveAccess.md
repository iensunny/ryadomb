# pages.saveAccess

> Источник: [https://dev.vk.ru/ru/method/pages.saveAccess](https://dev.vk.ru/ru/method/pages.saveAccess)
Сохраняет новые настройки доступа на чтение и редактирование вики-страницы.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `page_id` | `string` | да | Идентификатор вики-страницы. |
| `group_id` | `string` | нет | Идентификатор сообщества, которому принадлежит вики-страница. |
| `user_id` | `string` | нет | Идентификатор пользователя, создавшего вики-страницу. |
| `view` | `integer` | нет | Значение настройки доступа на чтение. Возможные значения:<br>* `2` — просматривать страницу могут все;<br>* `1` — только участники сообщества;<br>* `0` — только руководители сообщества. |
| `edit` | `integer` | нет | Значение настройки доступа на редактирование. Возможные значения:<br>* `2` — редактировать страницу могут все;<br>* `1` — только участники сообщества;<br>* `0` — только руководители сообщества. |

## Результат

В случае успеха возвращает `id` страницы, доступ к которой был отредактирован.
