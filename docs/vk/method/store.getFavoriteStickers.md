# store.getFavoriteStickers

> Источник: [https://dev.vk.ru/ru/method/store.getFavoriteStickers](https://dev.vk.ru/ru/method/store.getFavoriteStickers)
Возвращает список избранных стикеров.

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [стикеров](reference/objects/sticker) в поле `items`.

## Права доступа

`ex`

## Типы ключа

`is_standalone`
