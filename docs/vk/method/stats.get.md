# stats.get

> Источник: [https://dev.vk.ru/ru/method/stats.get](https://dev.vk.ru/ru/method/stats.get)
Возвращает статистику сообщества или приложения.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | нет | Идентификатор сообщества. |
| `app_id` | `positive` | нет | Идентификатор приложения. |
| `date_from` | `string` | нет | Начальная дата выводимой статистики в формате `YYYY-MM-DD`. |
| `date_to` | `string` | нет | Конечная дата выводимой статистики в формате `YYYY-MM-DD`. |
| `timestamp_from` | `positive` | нет | Начало периода статистики в `Unixtime`. |
| `timestamp_to` | `positive` | нет | Окончание периода статистики в `Unixtime`. |
| `interval` | `string` | нет | Временные интервалы. Возможные значения: `day`, `week`, `month`, `year`, `all`. По умолчанию: `day`. |
| `intervals_count` | `positive` | нет | Количество интервалов времени. |
| `filters` | `string` | нет |  |
| `stats_groups` | `string` | нет | Фильтр для получения данных по конкретному блоку статистики сообщества. Возможные значения: `visitors`, `reach`, `activity`. |
| `extended` | `checkbox` | нет | `1` — возвращать дополнительно агрегированные данные в результатах. |

## Результат

После успешного выполнения возвращает [объект](reference/objects/stats-format) с данными статистики.
