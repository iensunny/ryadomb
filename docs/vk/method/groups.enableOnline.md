# groups.enableOnline

> Источник: [https://dev.vk.ru/ru/method/groups.enableOnline](https://dev.vk.ru/ru/method/groups.enableOnline)
Включает статус «онлайн» в сообществе.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `group_id` | `positive` | да | Идентификатор сообщества. |

## Результат

После успешного выполнения возвращает `1`.

## Права доступа

`groups_ex`

## Типы ключа

`group_access`, `is_standalone`
