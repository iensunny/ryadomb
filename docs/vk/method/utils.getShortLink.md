# utils.getShortLink

> Источник: [https://dev.vk.ru/ru/method/utils.getShortLink](https://dev.vk.ru/ru/method/utils.getShortLink)
Позволяет получить URL, сокращённый с помощью vk.cc.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `url` | `string` | да | URL, для которого необходимо получить сокращённый вариант. |
| `private` | `checkbox` | нет | `1` — статистика ссылки приватная. <br>`0` — статистика ссылки общедоступная. |

## Результат

Возвращает объект, содержащий следующие поля:

### `short_url`
`string` 
Сокращённая ссылка.

### `access_key`
`string`
Ключ для доступа к приватной статистике ссылки.
 
###  `key`
 `string`
 Содержательная часть ссылки (после «vk.cc»).
 
###  `url`
 `string`
 Оригинальный URL.

## Типы ключа

`group_access`, `allow_from_server`
