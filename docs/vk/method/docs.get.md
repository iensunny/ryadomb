# docs.get

> Источник: [https://dev.vk.ru/ru/method/docs.get](https://dev.vk.ru/ru/method/docs.get)
Возвращает расширенную информацию о документах пользователя или сообщества.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `count` | `positive` | нет | Количество документов, информацию о которых нужно вернуть. <br>По умолчанию: все документы. Максимальное количество документов, которое можно получить: 2000. |
| `offset` | `positive` | нет | Смещение, необходимое для выборки определенного подмножества документов. Максимальное значение: `1999`. |
| `type` | `positive` | нет | Тип файла.  Возможные значения:<br>*  `1` — текстовые документы.<br>*  `2` — архивы.<br>*  `3` — gif.<br>*  `4` — изображения.<br>*  `5` — аудио.<br>*  `6` — видео.<br>*  `7` — электронные книги.<br>*  `8` — неизвестный тип. |
| `owner_id` | `integer` | нет | Идентификатор пользователя или сообщества, которому принадлежат документы.<br>> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id=-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `return_tags` | `checkbox` | нет | `1` — добавить в ответ массив меток документа. |

## Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [файлов](reference/objects/doc) в поле `items`.
