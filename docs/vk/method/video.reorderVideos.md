# video.reorderVideos

> Источник: [https://dev.vk.ru/ru/method/video.reorderVideos](https://dev.vk.ru/ru/method/video.reorderVideos)
Позволяет переместить видеозапись в альбоме.

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `target_id` | `integer` | нет | Идентификатор пользователя или сообщества, в чьем альбоме нужно переместить видео.<br>> Обратите внимание, идентификатор сообщества в параметре `target_id` необходимо указывать со знаком `«-»` — например, `target_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.com/apiclub) (club1). |
| `album_id` | `integer` | нет | Идентификатор альбома с видеозаписью, которую нужно переместить. |
| `owner_id` | `integer` | да | Идентификатор владельца видеозаписи, которую нужно переместить (пользователь или сообщество). |
| `video_id` | `positive` | да | Идентификатор видеозаписи, которую нужно переместить. |
| `before_owner_id` | `integer` | нет | Идентификатор владельца видеозаписи, перед которой следует поместить текущую (пользователь или сообщество). |
| `before_video_id` | `positive` | нет | Идентификатор видеозаписи, перед которой следует поместить текущую. |
| `after_owner_id` | `integer` | нет | Идентификатор владельца видеозаписи, после которой следует поместить текущую (пользователь или сообщество). |
| `after_video_id` | `positive` | нет | Идентификатор видеозаписи, после которой следует поместить текущую. |

## Результат

После успешного выполнения возвращает `1`.
