# Общее описание

> Источник: [https://dev.vk.ru/ru/pay/payment-form/general-description](https://dev.vk.ru/ru/pay/payment-form/general-description)
Платёжное окно VK Pay — это всплывающее окно, в котором указана сумма платежа, способ оплаты, комментарий к платежу и данные продавца.

Платёжное окно отображается внутри интерфейса ВКонтакте.

В этом разделе описано подключение платёжного окна для [разработчиков мини-приложений](#Платёжное%20окно%20для%20разработчиков) и порядок оплаты через платёжное окно для [пользователей ВКонтакте](#Платёжное%20окно%20для%20плательщиков).

## Платёжное окно для плательщиков

В платёжном окне для пользователя будут отображаться способы оплаты, которые вы указали при [подключении](pay/connection).

Доступные способы оплаты: банковская карта и VK Кошелёк.

Подробнее о процессе оплаты для пользователя читайте в разделе [Платёжное окно для плательщиков](pay/payment-form/payment-form-for-users).

## Платёжное окно для разработчиков

Если вы разрабатываете мини-приложение, вы можете вызвать платёжное окно в своём приложении с помощью событий [библиотеки VK Bridge](bridge/getting-started#Как%20использовать%20библиотеку%20VK%20Bridge).

VK Bridge позволяет мини-приложениям взаимодействовать с API ВКонтакте и API операционной системы, установленной на устройстве пользователя.

Для вызова платёжного окна потребуется инициализировать своё приложение, отправить запрос для вызова платёжного окна с параметрами продавца и [мини-приложения](mini-apps/getting-started#О%20мини-приложениях), проверить результат вызова и получить платёжное уведомление о результате оплаты.

Подробности — в [сценарии взаимодействия](pay/payment-form/payment-form-for-developers#Сценарий%20взаимодействия%20с%20платёжным%20окном) и [пошаговом руководстве по вызову платёжного окна](pay/payment-form/payment-form-for-developers/payment-create).

Вы можете [протестировать](pay/payment-form-for-developers/payment-form/testing) работу платёжного окна  перед проведением настоящих платежей.

Чтобы делать отмену и возврат платежей, запрашивать статус транзакции и информацию о ней, используйте [API-запросы к платёжной системе](pay/seller/general-description).

## Отправка сообщений плательщику

ВКонтакте удобно общаться с вашими клиентами через сообщения сообществ. Например, присылать подробные данные и статус заказа, уточнять информацию о доставке или реагировать на обратную связь. Узнать подробнее о том, как их использовать, вы можете в [документации](api/community-messages/getting-started). 

Если вы принимаете оплату через VK Pay внутри ВКонтакте (в сервисе VK Mini Apps или в приложении сообщества), после платежа от имени пользователя в ваше сообщество отправляется сообщение с данными платежа. Это даёт вашему сообществу автоматическое разрешение на отправку ответных сообщений пользователю — вам не нужно отдельно запрашивать у него права. 

:::note
**Важно!** Отправка данных платежа работает только после добавления вашего приложения в каталог VK Mini Apps или VK Pay. Нужно учитывать это при тестировании — если вы общаетесь с пользователем в сообщениях сообщества, до размещения в каталоге вам необходимо запрашивать права для отправки ему первого сообщения или написать в сообщения группы от имени этого пользователя.
:::
