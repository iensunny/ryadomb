# Обработка ошибок

> Источник: [https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers/errors](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers/errors)
Если при вызове платёжного окна некорректно передан один из параметров, в консоли браузера отобразится ошибка.

| Ошибка | Описание | Рекомендации |
|---|---|---|
|`Bad sign` | В параметре `params.sign` передано некорректное значение [подписи приложения](pay/payment-form/payment-form-for-developers/app-sign-calculation). | &nbsp;&nbsp; 1. Проверьте защищённый ключ приложения `app secure key`.  &#x0d;&#x0a; &nbsp;&nbsp; 2. Проверьте, что строка для подписи, которая формируется на стороне VK Pay, и строка на серверной стороне вашего приложения совпадают. &#x0d;&#x0a; Если вы проводите платёж с тестовыми учётными данными, в консоли браузера в описании ошибки вы можете увидеть, как должна выглядеть строка для подписи приложения перед конкатенацией с защищённым ключом приложения `app secure key`.  &#x0d;&#x0a; &nbsp;&nbsp; 3. Проверьте, чтобы браузер не экранировал двойные кавычки при формировании подписи. &#x0d;&#x0a; &nbsp;&nbsp; 4. Попробуйте [сформировать подпись](pay/payment-form/payment-form-for-developers/app-sign-calculation) ещё раз.  |
| `Параметры запроса и параметры партнёра отличаются` | В объекте `params.data` передано некорректное значение подписи продавца `merchant_sign`. | Проверьте приватный ключ продавца `merchant_private_key` и попробуйте [сформировать подпись](pay/payment-form/payment-form-for-developers/merchant-sign-calculation) ещё раз. |
|` Invalid parameter: ts` | В объекте `params.data` передано некорректное значение временной метки формирования запроса `ts` . | Проверьте значение `ts`: оно должно быть меньше времени отправки запроса на отображение платёжного окна, но не более чем на час. Отправьте запрос с корректным значением `ts`. |
| `Invalid parameter: cashback` | В объекте `params.data.cashback` передано некорректное значение параметров кешбэка. | Проверьте параметры и отправьте запрос ещё раз.  |
| `Invalid_parameter: amount` | В параметре `params.amount` отсутствует или передано некорректное значение суммы платежа. | Проверьте значение `amount` и отправьте запрос ещё раз. |
| `Не удалось найти получателя по заданным параметрам` | В параметре `params.merchant_id` некорректно указан ваш идентификатор продавца, который был выдан при подключении к системе VK Pay. | Проверьте значение идентификатора `merchant_id` и отправьте запрос ещё раз. |
