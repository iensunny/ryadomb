# Как совершить платёж

> Источник: [https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers/payment-create](https://dev.vk.ru/ru/pay/payment-form/payment-form-for-developers/payment-create)
В разделе описано подключение платёжного окна VK Pay и проведение платежей в мини-приложениях.

Чтобы отобразить платёжное окно, используйте события [библиотеки VK Bridge](bridge/getting-started#Как%20использовать%20библиотеку%20VK%20Bridge). VK Bridge позволяет мини-приложениям взаимодействовать с API ВКонтакте и API операционной системы, установленной на устройстве пользователя.

Перед вызовом платёжного окна подключите VK Bridge и прочитайте об использовании библиотеки и вызове событий в документации [VK Bridge – Первые шаги](bridge/getting-started#Как%20использовать%20библиотеку%20VK%20Bridge).

## Шаг 1. Инициализируйте своё приложение

Чтобы работать с ВКонтакте через  VK Bridge, инициализируйте своё приложение: [отправьте событие `VKWebAppInit`](bridge/VKWebAppInit) с помощью [метода `bridge.send`](bridge/getting-started#bridge.send) приложению ВКонтакте.

## Шаг 2. Проверьте результат инициализации

Для обработки результата используйте объект `Promise`, который возвращается вызовом `bridge.send(...)`, или события `VKWebAppInitResult` и `VKWebAppInitFailed`. Подробнее&nbsp;— в [документации `VKWebAppInit`](bridge/VKWebAppInit#Результат).

В случае успешной инициализации приложение ВКонтакте вернёт [объект `Promise`](bridge/VKWebAppInit#Объект%20Promise) или [событие `VKWebAppInitResult`](bridge/VKWebAppInit#VKWebAppInitResult) с полем `result: true`.

При ошибке инициализации, приложение ВКонтакте вернёт [объект `Promise`](bridge/VKWebAppInit#Объект%20Promise) или [событие `VKWebAppInitResult`](bridge/VKWebAppInit#VKWebAppInitResult) с информацией [об ошибке](bridge/getting-started#Обработка%20ошибок).

## Шаг 3. Отправьте запрос на отображение платёжного окна VK Pay

Чтобы отобразить платёжное окно VK Pay, [отправьте событие `VKWebAppOpenPayForm`](bridge/VKWebAppOpenPayForm) с помощью [метода `bridge.send`](bridge/getting-started#bridge.send) приложению ВКонтакте. В событии передайте обязательные [параметры](bridge/VKWebAppOpenPayForm#Параметры):

* `app_id` — идентификатор мини-приложения.
* `action` — тип перевода. Всегда `pay-to-service` — перевод в пользу юридического лица.
* `params` — поля платёжной формы VK Pay — зависят от типа перевода `action`. Подробнее — в разделе [Параметры платежа](#Параметры%20платежа).

:::note
**Важно!** Если пользователи получают кешбэк за покупки в вашем магазине, размер и срок зачисления кешбэка нужно передать в момент вызова платёжной формы в [объекте `params.data.cashback`](#Объект%20cashback). Вам необходимо рассчитать сумму кешбэка до того, как пользователь совершит платёж.
:::


**Пример запроса для открытия платёжного окна с `action: 'pay-to-service'`**

```JavaScript
bridge.send('VKWebAppOpenPayForm', {
    app_id: 6909581,
    action: 'pay-to-service',
    params: {
      user_id: 743784474,
      description: `Test Payment`      
    }})
  .then((data) => {
    if (data.status) {
      // Экран VK Pay показан
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });

```

В случае успешного вызова платёжного окна ВКонтакте добавляет к запросу информацию о типе платежа и подпись приложения и отправляет запрос VK Pay.
VK Pay проверяет данные кошелька, авторизацию пользователя, подпись приложения и продавца, формирует ссылку на платёжное окно, подписывает ссылку и отображает платёжное окно пользователю по ссылке в iframe.

Если при вызове платёжного окна что-то пойдёт не так, в консоли браузера отобразится [ошибка](pay/payment-form/payment-form-for-developers/errors).

## Шаг 4. Проверьте результат вызова платёжного окна

Для обработки результата используйте объект `Promise`, который возвращается вызовом `bridge.send(...)`, или события `VKWebAppInitResult` и `VKWebAppInitFailed`. Подробнее — в [документации `VKWebAppOpenPayForm`](bridge/VKWebAppOpenPayForm#Результат).

Приложение ВКонтакте вернёт [объект `Promise`](bridge/VKWebAppOpenPayForm#Объект%20Promise) или [событие `VKWebAppInitResult`](bridge/VKWebAppOpenPayForm#События) со следующими данными:

* `status: true` — информация о результате платежа (`true` — платёж успешный, `false` — платёж неуспешный). Если пользователь закрыл платёжную форму, не оплачивая покупку, то `status` будет равен `false`.
* `transaction_id` — идентификатор транзакции.
* `amount` — сумма платежа.
* `extra` — дополнительные данные продавца. Содержит данные [объекта `params.data`](#Объект%20data).

При ошибке оплаты приложение ВКонтакте вернёт [объект `Promise`](bridge/VKWebAppOpenPayForm#Объект%20Promise) или [событие `VKWebAppInitResult`](bridge/VKWebAppOpenPayForm#События) с информацией [об ошибке](bridge/getting-started#Обработка%20ошибок).

## Шаг 5. Получите платёжное уведомление о результате оплаты

Если оплата прошла успешна и у вас [подключены уведомления](pay/seller/notifications), VK Pay пришлёт информацию о результате транзакции на ваш URL.

[Проверьте подпись уведомления](pay/seller/notifications#Шаг%202.%20Проверьте%20подпись%20уведомления) с помощью публичного ключа платёжной системы, который вы получили при подключении. Расшифруйте данные уведомления, обработайте и [отправьте API системы ответ](pay/seller/notifications#Шаг%204.%20Отправьте%20ответ%20на%20уведомление) с результатом обработки.

Со стороны клиента мини-приложение пришлёт в ваше сообщество ВКонтакте сообщение от лица пользователя, оплатившего покупку.
Подробнее — в разделе [Отслеживание статуса платежа](pay/payment-form/payment-form-for-developers/payment-status).

:::note
**Важно!** События, которые приходят от мини-приложения и VK Bridge, не гарантируют успешную оплату. Решение о предоставлении товара или услуги нужно принимать только на основании [платёжного уведомления](pay/seller/notifications), которое VK Pay пришлёт на ваш URL.
:::

## Параметры платежа

Параметры платежа VK Pay зависят от [типа платежа `action`](bridge/VKWebAppOpenPayForm#Параметры).
Пример генерации параметров на JavaScript можно найти [здесь](https://gist.github.com/mrsndmn/cd6be6ef477ba16d47c339f3f8a375c6).

### Объект `params`

| Поле | Тип | Описание |
|---|---|---|
|`amount`&#x0d;&#x0a;*необязательное*  | `integer`/`number`/`string` | Сумма платежа в формате `00.00`. &#x0d;&#x0a;Минимальная сумма — 1 ₽. &#x0d;&#x0a;Поле может быть передано как целое число, число с плавающей точкой (не более двух знаков после запятой, среди них незначащие нули недопустимы) или строка (не более двух знаков после запятой, незначащие нули допустимы).  &#x0d;&#x0a;Поле обязательное при фиксированных платежах в пользу юридического лица: значение поля `action` — `pay-to-service`. &#x0d;&#x0a;Поле `amount` участвует в формировании `merchant_data` для [подписи продавца](pay/payment-form/payment-form-for-developers/merchant-sign-calculation). |
|`description`&#x0d;&#x0a;*обязательное*  | `string` | Описание платежа для пользователя — текст, который будет показан в платёжном окне. &#x0d;&#x0a;Формат: строка в кодировке UTF-8, до 50 символов. |
|`action`&#x0d;&#x0a;*обязательное*  | `string` | Тип перевода. Всегда `pay-to-service` — перевод в пользу юридического лица. |
|`merchant_id`&#x0d;&#x0a;*обязательное*  | `integer` | Ваш идентификатор продавца в платёжной системе VK Pay, который был выдан при подключении к VK Pay вместе с приватным ключом продавца. |
|`version`&#x0d;&#x0a;*обязательное*  | `integer` | Версия платёжной системы. &#x0d;&#x0a;Актуальная версия: `2`. |
|`sign`&#x0d;&#x0a;*обязательное*  | `string` | Подпись мини-приложения ВКонтакте, которое вызывает платёжное окно. &#x0d;&#x0a;Подробности — в разделе [Как сформировать подпись приложения](pay/payment-form/payment-form-for-developers/app-sign-calculation). |
|`data`&#x0d;&#x0a;*обязательное*  | `object` | Служебные данные платежа. &#x0d;&#x0a;В этом JSON-объекте вы передаёте обязательные поля для валидации оплаты платёжной системой, и можете передать любое количество произвольных полей, которые хотите видеть в платёжном уведомлении. &#x0d;&#x0a;Описание полей — в разделе [Объект `data`](#Объект%20data). |
|`user_id`&#x0d;&#x0a;*необязательное*  | `integer` | Идентификатор пользователя. &#x0d;&#x0a;Обязателен при платежах пользователю: значение поля `action` всегда `pay-to-service`. |

**Пример объекта `params`**

```JSON
{ 
    "amount": 1.5, 
    "data": { 
        "currency": "RUB", 
        "merchant_data": "eyJvcmRlcl9pZCI6IjI1NTMxIiwidHMiOiIxNTM5MzI5NzcwIiwiYW1vdW50IjoxLjUsImN1cnJlbmN5IjoiUlVCIn0=", 
        "merchant_sign": "63d5dce9d2c9d29198ba12ba3f8e270e6606a221", 
        "order_id": "25531", 
        "ts": "1539329770" 
     }, 
    "description": "Test Payment", 
    "action": "pay-to-service", 
    "merchant_id": 617001, 
    "version": 2, 
    "sign": "818964335a550e39d9a1dd0d752e60ab" 
}
```

### Объект `data`

`data` — это JSON-объект с набором полей для валидации платежа (например, номер заказа и подпись продавца), а также любыми произвольными полями, которые могут быть нужны продавцу для обработки заказа (например, данными о способе доставки).
Остальные поля — в разделе [Объект `params`](#Объект%20params).
Содержимое `data` возвращается в [платёжном уведомлении](pay/seller/notifications) в поле `merchant_params`.

:::note
**Важно!** Названия полей внутри `data` должны быть отсортированы по алфавиту.
:::

| Поле | Тип | Описание |
|---|---|---|
| `order_id`&#x0d;&#x0a;*обязательное*  | `integer`/`string` | Идентификатор заказа в вашей системе. &#x0d;&#x0a;Для каждого платёжного окна должен быть уникальным. Повторный запрос с уже обработанным `order_id` будет проигнорирован. &#x0d;&#x0a;Поле `order_id` участвует в формировании `merchant_data` для [подписи продавца](pay/payment-form/payment-form-for-developers/merchant-sign-calculation). |
| `ts`&#x0d;&#x0a;*обязательное* | `number` | Временная отметка формирования запроса. &#x0d;&#x0a;Формат: число, [Unix Timestamp](https://www.unixtimestamp.com/). Время `ts` должно быть меньше времени отправки запроса на отображения платёжного окна, но не более чем на час. &#x0d;&#x0a;Поле `ts` участвует в формировании `merchant_data` для [подписи продавца](pay/payment-form/payment-form-for-developers/merchant-sign-calculation).|
| `currency`&#x0d;&#x0a;*обязательное* | `string` | Валюта платежа по [ISO 4217](https://normativ.kontur.ru/document?moduleId=1&documentId=456276). &#x0d;&#x0a;Сейчас поддерживается только `RUB`. &#x0d;&#x0a;Поле `currency` участвует в формировании `merchant_data` для [подписи продавца](pay/payment-form/payment-form-for-developers/merchant-sign-calculation). |
| `merchant_data`&#x0d;&#x0a;*обязательное* | `string` | BASE64-строка для формирования [подписи продавца](pay/payment-form/payment-form-for-developers/merchant-sign-calculation). Формируется из JSON-объекта, который включает в себя поля платёжного окна: `amount`, `cashback`, `currency`, `order_id` и `ts`. Других полей в JSON-объекте быть не должно. |
| `merchant_sign`&#x0d;&#x0a;*обязательное* | `string` | SHA1-подпись продавца. |
| `cashback`&#x0d;&#x0a;*необязательное* | `object` | Данные о кешбэке. &#x0d;&#x0a;Если кешбэка нет, передавать данные не нужно. &#x0d;&#x0a;Описание полей — в разделе [Объект `cashback`](#Объект%20cashback). &#x0d;&#x0a;Поле `cashback` участвует в формировании `merchant_data` для [подписи продавца](pay/payment-form/payment-form-for-developers/merchant-sign-calculation). |

### Объект `cashback`

Объект `cashback` содержит данные о кешбэке. Если кешбэка нет, передавать объект не нужно.

Если пользователи получают кешбэк за покупки в вашем магазине, данные о сумме и времени начисления передаются из мини-приложения вместе с другими параметрами платёжного окна и участвуют в [формировании подписи продавца `merchant_sign`](pay/payment-form/payment-form-for-developers/merchant-sign-calculation). Распоряжение на списание указанной суммы кешбэка в указанное время формируется в момент транзакции и не может быть изменено за исключением случаев отмены покупки (возврата средств пользователю).

Объект `cashback` входит в [объект `params.data`](#Объект%20data). Остальные поля — в разделе [Объект `params`](#Объект%20params).

| Поле | Тип | Описание |
|---|---|---|
|`pay_time`&#x0d;&#x0a;*необязательное*  | `integer` | Время зачисления кешбэка в [Unix Timestamp](https://www.unixtimestamp.com/). &#x0d;&#x0a;Время должно быть больше или равно времени платежа.|
|`amount_percent`&#x0d;&#x0a;*необязательное* | `integer` | Размер кешбэка в процентах от суммы платежа, если не передано значение `cashback.amount`. &#x0d;&#x0a;Максимальное значение: `5`.|
|`amount`&#x0d;&#x0a;*необязательное* | `number` | Размер кешбэка в валюте платежа, если не передано значение `cashback.amount_percent`. &#x0d;&#x0a;Максимальный размер — 5% от суммы платежа.|
