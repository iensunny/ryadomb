# Общее описание

> Источник: [https://dev.vk.ru/ru/pay/seller/general-description](https://dev.vk.ru/ru/pay/seller/general-description)
С помощью API платёжной системы (далее — API системы) вы можете:

* [Получать уведомления](pay/seller/notifications).
* [Узнавать о статусе транзакции](pay/seller/transaction-status).
* [Запрашивать информацию о транзакции](pay/seller/transaction-get).
* [Делать отмену и возврат платежей](pay/seller/refunds).
  
Формат данных и синтаксис запросов отличаются от [API ВКонтакте](api/overview).
Протокол взаимодействия — HTTPS с использованием шифрования не ниже TLS 1.2.

API системы поддерживает [`POST`-запросы](pay/seller/request-create).
Ответ от платёжной системы возвращается в [формате JSON](pay/seller/response).

Авторизация не используется. Вместо этого каждый запрос и ответ сопровождается подписью данных, что позволяет обнаружить возможную подмену.

## URL для запросов

```
https://api.money.mail.ru/money/2-03/{ваш-api-запрос}
```

## Как подключить

1. Чтобы зарегистрировать новый аккаунт продавца, напишите в техническую поддержку по адресу `vkpay_solutions@vk.team`.
2. После регистрации получите от технической поддержки идентификатор продавца, приватный ключ доступа для формирования подписи запроса и публичный ключ для проверки подписи ответа. Эти данные понадобятся для всех взаимодействий с API системы.
3. Чтобы подключить [платёжные уведомления](pay/seller/notifications), сообщите технической поддержке URL-адрес, по которому вы хотите их получать. Можно указать сразу несколько адресов.
4. Протестируйте работу API системы: [отправьте запрос](pay/seller/request-create), получите ответ и обработайте его в зависимости от результата запроса ([успех](pay/seller/response#Структура%20заголовка%20header%20при%20успешной%20обработке%20запроса) или [неуспех](pay/seller/response#Структура%20заголовка%20header%20при%20ошибке%20обработки%20запроса)), получите платёжное уведомление и [ответьте на него](pay/seller/notifications#Шаг%204.%20Отправьте%20ответ%20на%20уведомление).

## Техническая поддержка

Если у вас возникли вопросы или нужна помощь при подключении или использовании API системы, обратитесь в техническую поддержку по адресу `vkpay_solutions@vk.team`.
