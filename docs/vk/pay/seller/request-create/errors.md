# Ошибки запроса

> Источник: [https://dev.vk.ru/ru/pay/seller/request-create/errors](https://dev.vk.ru/ru/pay/seller/request-create/errors)
В случае [ошибки запроса](pay/seller/response#Структура%20заголовка%20header%20при%20ошибке%20обработки%20запроса) к API платёжной системы в ответе вернётся код и описание ошибки.


| Код | Описание |
|---|---|
| `ERR_SIGNATURE`| Некорректная подпись запроса. [Сформируйте подпись заново](pay/seller/request-create/request-sign-creating) и повторите запрос. |
| `ERR_ARGUMENTS` | Некорректные параметры запроса. При получении этой ошибки поле `error.message` будет содержать JSON-список в виде пары `ключ:значение`, где `ключ` – название некорректно переданного параметра в XPath-формате, `значение` – описание ошибки для этого параметра. |
| `ERR_NOAUTH` | Переданный в запросе `client_id` не найден. Проверьте данные и повторите запрос. |
| `ERR_ACCESS_DENIED` | Доступ запрещён — обратитесь в техническую поддержку по адресу `vkpay_solutions@vk.team`. |
| `ERR_IP_ACCESS_DENIED` | Запрещены запросы с этого IP-адреса. |
| `ERR_BUSY` | Система занята. Пожалуйста, повторите запрос позже. |
| `ERR_SYSTEM` | Системная ошибка, повторите запрос позже. Если ошибка повторяется, обратитесь в техническую поддержку по адресу `vkpay_solutions@vk.team`. |
