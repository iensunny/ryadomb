# Тестирование платёжного окна

> Источник: [https://dev.vk.ru/ru/pay/payment-form-for-developers/payment-form/testing](https://dev.vk.ru/ru/pay/payment-form-for-developers/payment-form/testing)
Вы можете протестировать работу [платёжного окна](pay/payment-form/general-description). Для этого убедитесь, что [всё готово](#Подготовка%20к%20тестированию), [проверьте работу платежей с тестовыми данными](#Тестирование), а затем — [с боевыми](#После%20тестирования).

При тестировании всё происходит как при настоящих платежах, но деньги никуда не переводятся.

Если вы хотите протестировать работу [API платёжной системы](pay/seller/general-description), напишите в техническую поддержку по адресу `vkpay_solutions@vk.team`.

## Ограничения

1. Протестировать можно только платежи банковской картой.
2. При тестировании нужно использовать тестовую банковскую карту с тестовой валютой платежа — реквизиты можно получить у технической поддержки.

## Подготовка к тестированию

Перед тестированием проверьте, что выполнили все пункты.

1. Создали приложение ВКонтакте.
2. [Подключили VK Pay](pay/connection).
3. [Подключили платёжные уведомления](pay/seller/notifications).
4. Получили от технической поддержки идентификатор продавца, реквизиты тестовой банковской карты и ключи доступа для тестирования: приватный ключ для формирования подписи запроса и публичный ключ для проверки подписи ответа.
5. [Интегрировали платёжное окно](pay/payment-form/payment-form-for-developers).

## Тестирование
   
1. [Проведите платёж с помощью тестовой банковской карты](pay/payment-form/payment-form-for-developers).
2. [Получите в ответ платёжное уведомление](pay/seller/notifications#Шаг%201.%20Получите%20уведомление).
3. [Обработайте ответ](pay/seller/notifications#Шаг%203.%20Обработайте%20данные%20уведомления) в зависимости от результата запроса: [успех](pay/seller/notifications#Формирование%20поля%20data%20при%20успешной%20обработке%20уведомления) или [неуспех](pay/seller/notifications#Формирование%20поля%20data%20при%20ошибке%20обработки%20уведомления).
   
## После тестирования

1. Запросите у технической поддержки ключи доступа для работы в боевой среде: приватный ключ для формирования подписи запроса и публичный ключ для проверки подписи ответа.
2. [Проверьте работу платёжного окна](pay/payment-form/payment-form-for-developers) в боевой среде.
