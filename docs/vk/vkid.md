# Авторизация VK

Для авторизации пользователя в вашем приложении можно использовать:

* [OAuth VK ID](#OAuth%20VK%20ID) — позволяет пользователям авторизоваться на вашем сайте, используя учётные записи не только ВКонтакте, но и сторонних сервисов Oдноклассники и Mail.ru без необходимости интегрировать их дополнительно.

* [OAuth-авторизация через Одноклассники](#OAuth%20Одноклассники) — позволяет добавить вход с использованием аккаунта в Одноклассниках и работать с API Одноклассников.

* [OAuth-авторизация через Mail.ru](#OAuth%20Mail.ru) — позволяет добавить вход с использованием аккаунта Mail.ru и работать с API Mail.ru.

## Преимущества авторизации VK

#### Удобно для пользователей

* Не надо создавать аккаунт в вашем приложении и запоминать его название и пароль.

* Можно одним нажатием авторизовываться в разных сервисах с помощью одного аккаунта.

* Для управления аккаунтом используется личный кабинет ВКонтакте, Mail.ru или Одноклассников.

* Данные хранятся и передаются безопасно.

#### Удобно для разработчиков

* В приложении не нужно реализовывать личные кабинеты и интерфейсы для создания и редактирования аккаунтов.

* Серверы, которые отвечают за вход, рассчитаны на высокую нагрузку и выдерживают миллионы одновременных обращений.

* Поддерживается двухфакторная аутентификация. При этом вам она ничего не стоит — сервисы берут оплату SMS на себя.

* Все способы позволяют не только авторизовать пользователя, но и получить access token для выполнения API-запросов к ВКонтакте, Mail.ru или Одноклассникам.


## OAuth VK ID

OAuth VK ID позволяет пользователю войти с любым из трёх аккаунтов: ВКонтакте, Одноклассники или Mail.ru. Для его подключения вы можете использовать VK ID SDK.

### VK ID SDK

Многофункциональный инструмент, который позволяет сторонним сервисам подключить авторизацию пользователей через OAuth VK ID и поддерживает работу на современном протоколе авторизации OAuth 2.1.

Библиотеки SDK доступны для платформ Android, iOS и Web.

Кроме того:

* SDK обновляется и поддерживается — от версии к версии добавляются новые функциональные возможности и исправляются недочёты.

* Пользователь может войти в ваше приложение [несколькими способами](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/intro/main):

    — По кнопке One Tap или через всплывающее окно Floating One Tap.

    — По QR-коду.

    — По OnePass.

    — По номеру телефона с подтверждением.
  
    — Через сторонние OAuth-сервисы: Одноклассники или Mail.ru.

    — С помощью мобильного приложения ВКонтакте.

  * Данные пользователя актуализируются — номер телефона пользователя регулярно верифицируется.

#### Как реализовать

Читайте в разделе [План интеграции OAuth VK ID](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/intro/plan).

### OAuth ВКонтакте

Это устаревший способ авторизации. Получить ключ доступа пользователя теперь можно только через [OAuth VK ID](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/tokens/access-token#Kak-poluchit-token). При этом ранее созданные приложения с OAuth ВКонтакте поддерживаются.

Если вам нужно организовать работу с API ВКонтакте от имени сообщества или публичной страницы, получите ключ доступа сообщества. Подробнее — в разделе [Ключ доступа сообщества](api/access-token/community-token).

## OAuth Одноклассники

Это способ авторизации, при котором пользователь для входа в сервис использует аккаунт Одноклассников. В его основе лежит реализация спецификации OAuth 2.1.

![alt=Пример формы с кнопкой входа с использованием аккаунта в Одноклассниках;title=Пример формы с кнопкой входа с использованием аккаунта в Одноклассниках](0399b152c12a96d2c6800b5168f428751f4a444f3903682fd04e3228 "8667807727621655734")

Можно использовать библиотеки для [большого количества платформ](https://apiok.ru/dev/sdk/).

#### Как реализовать

[OAuth-авторизация через Одноклассники](https://id.vk.com/about/business/go/docs/ru/vkid/latest/oauth/oauth-ok/index)

## OAuth Mail.ru

Этот способ позволяет сервисам авторизовать пользователя по его аккаунту в Mail.ru. Способ основан на спецификации OAuth 2.1.

![alt=Пример формы входа с использованием аккаунта Mail.ru;title=Пример формы входа с использованием аккаунта Mail.ru](2e5c5db4b9cd6d81b0035fa9626680632868c37a91af92efd883a2f8 "6826922793579627926")

Доступны библиотеки для платформ Android, iOS и Web.

Вы можете выбрать [вид кнопки авторизации](https://oauth.mail.ru/), чтобы она соответствовала стилю вашего приложения.

#### Как реализовать

[OAuth-авторизация через Mail.ru](https://id.vk.com/about/business/go/docs/ru/vkid/latest/oauth/oauth-mail/index)
