# Сценарий взаимодействия

> Источник: [https://dev.vk.ru/ru/vkcaptcha/web/scenario](https://dev.vk.ru/ru/vkcaptcha/web/scenario)
В статье описаны схема и порядок взаимодействия вашего веб-приложения с VK ID Captcha SDK Web и API ВКонтакте.

Как установить и подключить VK ID Captcha SDK для веб-платформы, смотрите в [инструкции](vkcaptcha/web/autointegration).

## Порядок взаимодействия

1. Веб-приложение [устанавливает и подключает](vkcaptcha/web/autointegration#Шаг%201.%20Установка) VK ID Captcha SDK Web.
1. Веб-приложение [интегрирует обработчик ошибки капчи](vkcaptcha/web/autointegration#Шаг%202.%20Интеграция%20обработчика%20для%20пакетного%20менеджера) в обработчик ответа Web API.
1. Запрос к API ВКонтакте.
1. API ВКонтакте возвращает веб-приложению [ошибку капчи](api/captcha-error) с кодом `error_code: 14`, сообщением `error_msg: "Captcha needed"` и ссылкой для инициализации сессии капчи в поле `redirect_uri`.
1. Веб-приложение отправляет в VK ID Captcha SDK Web запрос на отображение капчи с помощью метода [`captchaWidget.show()`](vkcaptcha/web/autointegration#captchaWidget.show()).
1. VK ID Captcha SDK Web отправляет в Captcha iframe запрос на отображение капчи.
1. Пользователь проходит капчу.
1. API ВКонтакте анализирует действия пользователя. В зависимости от результата возможны варианты:   
    * **Успешный сценарий: пользователь — человек, прошёл капчу.**
      1. API ВКонтакте формирует токен успешного прохождения капчи `success_token` и передаёт его в Captcha iframe.
      1. Captcha iframe передаёт `success_token` в VK ID Captcha SDK Web.
      1. В зависимости от типа отображения капчи `view`, Captcha iframe выполняет одно из действий:
          * Закрывает капчу, если она отображена в виде всплывающего окна (`view = popup`).
          * Оставляет капчу на странице, если она отображена в виде блока (`view = block`).
          Вы можете настроить закрытие капчи вручную с помощью метода [`captchaWidget.close()`](vkcaptcha/web/autointegration#captchaWidget.close()).
      1. VK ID Captcha SDK Web возвращает вашему веб-приложению промис с `success_token`.
      1. Веб-приложение отправляет API ВКонтакте повторный запрос (шаг 1), в ответ на который вернулась ошибка капчи. В запросе нужно передать `success_token` со полученным значением токена.
    * **Неуспешный сценарий: пользователь — бот.**
      1. API ВКонтакте передаёт в Captcha iframe ошибку.
      1. Пользователь блокируется. Повторный показ капчи возможен только в рамках новой сессии.   
    * **Неуспешный сценарий: пользователь закрыл окно с капчей.**
      1. API ВКонтакте возвращает в Captcha iframe ошибку.
      1. Captcha iframe возвращает в VK ID Captcha SDK Web ошибку.
      1. VK ID Captcha SDK Web возвращает промис с ошибкой `error = close`.   
1. Веб-приложение отображает пользователю результат прохождения капчи.
