# Общее описание

> Источник: [https://dev.vk.ru/ru/vkcaptcha/iOS/overview](https://dev.vk.ru/ru/vkcaptcha/iOS/overview)

Перед началом работы [интегрируйте](vkcaptcha/iOS/integration) VK ID Captcha SDK iOS.
