# Сценарий взаимодействия

> Источник: [https://dev.vk.ru/ru/vkcaptcha/iOS/scenario](https://dev.vk.ru/ru/vkcaptcha/iOS/scenario)
В статье описан порядок взаимодействия вашего iOS-приложения с VK ID Captcha SDK iOS и API ВКонтакте для случая автоматической обработки ошибки капчи от API ВКонтакте и отображения экрана капчи с помощью [метода `handleCaptcha()`](vkcaptcha/iOS/integration#handleCaptcha()%20(рекомендуется)).

Как установить и подключить VK ID Captcha SDK iOS, смотрите в [инструкции](vkcaptcha/iOS/integration).

## Порядок взаимодействия

1. Ваше приложение отправляет запрос к API ВКонтакте.
1. API ВКонтакте возвращает мобильному приложению ошибку капчи.
1. Мобильное приложение инициализирует класс `VKCaptchaHandler`.
1. Мобильное приложение отправляет в VK ID Captcha SDK iOS запрос на обработку ответа от сервера методом [`VKCaptchaHandler.handleCaptcha()`](vkcaptcha/iOS/integration#Классы,%20методы,%20протоколы%20(справочник)).
1. VK ID Captcha SDK iOS отправляет в Captcha WebView запрос на отображение капчи.
1. Пользователь проходит капчу.
1. API ВКонтакте анализирует действия пользователя. В зависимости от результата возможны варианты:
    * **Успешный сценарий: пользователь — человек, прошёл капчу.**
      1. API ВКонтакте формирует токен успешного прохождения капчи `VKCaptchaToken` и передаёт его в Captcha WebView.
      1. Captcha WebView передаёт `VKCaptchaToken` в VK ID Captcha SDK iOS и закрывает окно капчи.
      1. VK ID Captcha SDK iOS передаёт `VKCaptchaToken` в мобильное приложение.
      1. Мобильное приложение отправляет API ВКонтакте повторный запрос, в ответ на который вернулась ошибка капчи (шаг 2). В запросе нужно передать полученный токен успешного прохождения капчи `VKCaptchaToken`. В зависимости от типа капчи нужно указать токен в заголовке или в параметрах запроса.
      1. API ВКонтакте выполняет запрос.
    * **Неуспешный сценарий: пользователь — бот.**
      1. API ВКонтакте возвращает в Captcha WebView ошибку.
      1. Повторный показ капчи возможен после отправки повторного запроса (шаг 1). Пользователь может пройти капчу ещё раз или обратиться в техподдержку.
    * **Неуспешный сценарий: пользователь или бот закрыл окно с капчей или возникла неизвестная ошибка.**
      1. API ВКонтакте возвращает в Captcha WebView ошибку.
      1. Captcha WebView возвращает в VK ID Captcha SDK iOS ошибку `CaptchaHandlingError`.
      1. VK ID Captcha SDK iOS возвращает в мобильное приложение ошибку `CaptchaHandlingError`.
1. Мобильное приложение отображает пользователю результат прохождения капчи.
