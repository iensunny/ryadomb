# Анимация 3D-моделей

> Источник: [https://dev.vk.ru/ru/masks/animation/models](https://dev.vk.ru/ru/masks/animation/models)
С помощью эффекта [`model3d`](masks/effects/model3d) вы можете добавить в свою маску 3D-модель. Эту модель можно анимировать.

## 1. Создайте анимацию 3D-модели

<!-- Прежде чем использовать анимацию в маске, нужно подготовить анимированную 3D-модель и экпортировать её в ANI- файл. Подробности — в разделе [Экспорт 3D-моделей](masks/export). -->

Прежде чем использовать анимацию в маске, подготовьте скелетную анимацию вашей 3D-модели в [Blender](masks/tools).

:::note
**Обратите внимание**. Движок масок поддерживает только скелетные анимации.
:::

<!-- Эти файлы содержит информацию о кадрах, скорости и времени воспроизведения и других параметрах, которые необходимы для анимации модели. -->

## 2. Добавьте файл модели и анимации в маску

Экспортируйте созданную модель и настройки анимации. Вы получите MDL-файл, хранящий данные 3D-модели, а таккже ANI-файл c настройками анимации.

Включите оба файла в проект маски.

Подробности — в разделе [Экспорт анимации](masks/export#Экспорт%20анимации).

## 3. Укажите параметры анимации в маске

Чтобы указать параметры анимации, используйте параметры `animation` в JSON-разметке маски. Пример ниже демонстрирует использование этих параметров:

```JSON
{
    "icon": "mask-icon.png",
    "effects": [
        {
            "name": "model3d",
            "anchor": "forehead",
            "model": "Models/Cat.mdl",
            "material": {
                "technique": "Techniques/DiffUnlit.xml",
                "textures": {
                    "diffuse": "Textures/Cat_diffuse.png"
                }
            },
            "animation": {
                "file": "Models/Cat.ani",
                "speed": 0.8
            },
            "position": [0, 80, 10],
            "scale": [12, 12, 12]
        }
    ]
}
```

## Параметры анимации

| Параметр        | Описание                                                     |
| --------------- | ------------------------------------------------------------ |
| `file`          | Путь к файлу анимации 3D-модели относительно конфигурационного файла маски `mask.json`.&#x0d;&#x0a;Тип данных: `string`. |
| `speed`         | Скорость воспроизведения анимации. По умолчанию равна `1.0`.&#x0d;&#x0a;Тип данных: `float`. |
| `type`          | Тип воспроизведения:&#x0d;&#x0a; &bullet; `once` &mdash; одно проигрывание и остановка на первом кадре или&#x0d;&#x0a; &bullet; `loop` &mdash; зацикленное проигрывание.&#x0d;&#x0a;&#x0d;&#x0a;По умолчанию анимация проигрывается зацикленно.&#x0d;&#x0a;Тип данных: `string`. |
| `trigger_start` | Задаёт условие для старта анимации модели:&#x0d;&#x0a; &bullet; `mouth_open` &mdash; открытие рта.&#x0d;&#x0a; &bullet; `mouth_close` &mdash; закрытие рта.&#x0d;&#x0a; &bullet; `face_found` &mdash; начало трекинга лица.&#x0d;&#x0a; &bullet; `face_lost` &mdash; потеря трекинга лица.&#x0d;&#x0a; &bullet; `tap` &mdash; касание экрана. Касание отслеживается, если в [конфигурационном файле маски](masks/configuration) задан параметр `"mouse_input": true`.&#x0d;&#x0a;&#x0d;&#x0a;По умолчанию анимация начнёт воспроизводиться сразу после открытия маски.&#x0d;&#x0a;Тип данных: `string`. |
| `trigger_stop`  | Задаёт условие для остановки анимации модели:&#x0d;&#x0a; &bullet; `mouth_open` &mdash; открытие рта.&#x0d;&#x0a; &bullet; `mouth_close` &mdash; закрытие рта.&#x0d;&#x0a; &bullet; `face_found` &mdash; начало трекинга лица.&#x0d;&#x0a; &bullet; `face_lost` &mdash; потеря трекинга лица.&#x0d;&#x0a; &bullet; `tap` &mdash; касание экрана. Касание отслеживается, если в [конфигурационном файле маски](masks/configuration) задан параметр `"mouse_input": true`.&#x0d;&#x0a;&#x0d;&#x0a;Тип данных: `string`. |

## Об анимации текстур модели

Следует отличать анимацию 3D-модели от анимации текстур, которые могут накладываться на её поверхность (движок масок поддерживает и такую возможность).

Анимация текстур работает одновременно с анимацией модели. Движок достаточно умён для того, чтобы правильно обрабатывать оба вида анимации.

Подробно анимация текстур рассмотрена в разделе [Анимация текстур](masks/animation/textures).
