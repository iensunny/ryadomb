# Анимация в масках

> Источник: [https://dev.vk.ru/ru/masks/animation/overview](https://dev.vk.ru/ru/masks/animation/overview)
Маски ВКонтакте поддерживают добавление анимированных текстур и 3D-моделей. Это делает результирующее изображение живее и интереснее.
<!-- Движок поддерживает несколько способов создания анимации. -->
Например, вы можете:

* Накладывать анимированные текстуры на 3D-модель или лицо.

* Использовать анимированные текстуры как самостоятельные элементы в маске.

* Использовать анимированные 3D-модели.

* Добавлять движущиеся частицы в маску — снежинки, конфетти и другие.

Рассмотрим подробнее, какие эффекты и плагины для этого пригодятся.

## Анимация в эффектах

Вы можете использовать анимацию в следующих [эффектах](masks/effects/overview):

| Эффект | Описание |
| --- | --- |
| [patch](masks/effects/patch) | Эффект `patch` используется для добавления в маску текстуры на плоскости. С помощью анимации вы можете заменить статичную текстуру сменяющими друг друга изображениями. Подробное описание — в разделе [Анимация текстур](masks/animation/textures). |
| [facemodel](masks/effects/facemodel) | С помощью эффекта `facemodel` вы можете наложить на лицо изображение, подготовленное специальным образом. Вы можете заменить накладываемую текстуру сменяющими друг друга изображениями.&#x0d;&#x0a;Подробное описание параметров — в разделе [Анимация текстур](masks/animation/textures). |
| [plane](masks/effects/plane) | Эффект `plane` позволяет добавить в маску плоскость с наложенным на неё  материалом. Эффект поддерживает анимацию, что даёт возможность использовать не просто текстуру, эмулирующую материал, а последовательность сменяющих друг друга изображений.&#x0d;&#x0a;Подробнее — в разделе [Анимация текстур](masks/animation/textures). |
| [model3d](masks/effects/model3d) | С помощью эффекта `model3d` вы можете добавить в маску 3D-модель. Параметры эффекта позволяют анимировать как саму модель, так и наложенные на неё текстуры.&#x0d;&#x0a;Подробнее об анимации 3D-модели — в разделе [Анимация 3D-моделей](masks/animation/models).&#x0d;&#x0a;Подробнее об анимации текстур — в разделе [Анимация текстур](masks/animation/textures). |

## Анимация с помощью плагинов

С помощью [плагинов](masks/plugins/overview) можно добавить в маску движущиеся объекты: например сверкающие искры, падающие снежинки или конфетти, плавающие источники света, вращающиеся цветы.

Подробное описание — на странице каждого из плагинов.  

| Плагин | Описание |
| --- | --- |
| [particles](masks/plugins/particles) | Позволяет добавить различные движущиеся частицы в маску. Хорошо подходит для имитации конфетти, снежинок, огоньков.&#x0d;&#x0a;Добавьте в маску какую-либо текстуру с помощью эффекта [`patch`](masks/effects/patch), а в параметрах плагина укажите ссылку на неё. Движок масок будет использовать эту текстуру для создания движущихся частиц. |
| [wiggle](masks/plugins/wiggle) | Добавляет эффект дрожания, покачивания или вращения.&#x0d;&#x0a;Добавьте в маску текстуру с помощью эффекта [`patch`](masks/effects/patch) и обязательно установите какое-либо значение в её свойстве `tag`. В параметрах плагина сошлитесь на этот `tag` и укажите характеристики движения. |  
| [spinner3d](masks/plugins/spinner3d) | С помощью этого эффекта можно вращать 3D-модели вокруг головы пользователя в маске. Плагин может работать не только с эффектом `model3d`, но и c `plane` и `occluder`.|
