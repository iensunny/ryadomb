# Обзор возможностей

> Источник: [https://dev.vk.ru/ru/masks/development/overview](https://dev.vk.ru/ru/masks/development/overview)
В качестве 3D-движка для масок используйте [Urho3D](https://urho3d.io/).

Взаимодействие с Urho3D осуществляется с помощью [AngelScript API](https://github.com/urho3d/Urho3D/blob/master/Docs/AngelScriptAPI.h). Если вы умеете программировать, то можете расширить возможности создания масок с помощью [скриптов](masks/development/script-creation) на языке AngelScript и доступных [событий](masks/development/events/overview).
