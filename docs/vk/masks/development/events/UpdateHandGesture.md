# UpdateHandGesture

> Источник: [https://dev.vk.ru/ru/masks/development/events/UpdateHandGesture](https://dev.vk.ru/ru/masks/development/events/UpdateHandGesture)
Движок масок вызывает событие `UpdateHandGesture` для каждого кадра видеопотока, чтобы дать маске возможность обработать появление или исчезновение жестов рук пользователя в кадре.

<!-- Событие `UpdateHandGesture` происходит, когда движок масок распознаёт появление или исчезновение жестов рук пользователя в кадре. -->

:::note
Движок генерирует событие <!-- отслеживается -->, только если в [конфигурационном файле маски](masks/configuration) задан параметр `"gestures_required": true`.
:::

Движок может распознать до двух жестов одновременно, поэтому для каждого кадра событие вызывается дважды — по разу для каждого жеста. Если в кадре один жест или жесты отсутствуют, событие всё равно будет вызвано дважды: в первый раз для распознанного жеста, а второй — вхолостую.

С помощью [параметра `Detected`](#Данные%20события) вы можете определить, связано ли событие с появлением жеста или же вызвано вхолостую. Такой подход позволяет вам распознать исчезновение жеста. Если в предыдущем вызове жест был распознан, а потом пропал, значит, пользователь перестал его показывать.

## Пример обработчика

```AngelScript


void Init()
{
    SubscribeToEvent("UpdateHandGesture", "HandleHandGestureUpdate");
}

void HandleHandGestureUpdate(StringHash eventType, VariantMap &eventData)
{
    // Номер жеста в кадре: 0 или 1
    uint num = eventData["NGesture"].GetUInt();

    // Присутствует ли жест в кадре или событие вызвано вхолостую
    bool detected = eventData["Detected"].GetBool();

    // Выполните проверку if (detected), прежде чем получать данные о жесте
    if (detected) {
      // Тип жеста
      String gesture = eventData["Gesture"].GetString();

      // Положение
      Vector2 position = eventData["Position"].GetVector2();
      // Размер
      float size = eventData["Size"].GetFloat();
      // Поворот
      float angle = eventData["AngleDegrees"].GetFloat();  

      // Позиция вершины указательного пальца
      Vector2 ffp = eventData["ForeFingerPosition"].GetVector2();
      // Позиция основания указательного пальца
      Vector2 ffbp = eventData["ForeFingerBasePosition"].GetVector2();
      // Позиция основания среднего пальца
      Vector2 mfbp = eventData["MiddleFingerBasePosition"].GetVector2();
      // Позиция основания безымянного пальца
      Vector2 rfbp = eventData["RingFingerBasePosition"].GetVector2();
      // Позиция центра ладони
      Vector2 pbp = eventData["PalmBasePosition"].GetVector2();
    }  
}
```

## Данные события

Обработчик события получает два параметра:

* `eventType` — тип события.

* `eventData` — данные события: массив с информацией о жесте.

    Каждый элемент массива — объект, описывающий жест.

### Объект, описывающий жест

| Ключ | Тип | Описание |
| --- | --- | --- |
| `Gesture` | `string` | Тип жеста. Значение — одна из строковых констант, описанных [ниже](#Типы%20жестов).&#x0d;&#x0a;&#x0d;&#x0a;Любое значение не из этого списка или пустая строка означают, что жест не распознан. |
| `Position` | `Vector2` |  Положение ладони с жестом в кадре. Указывается относительно размера кадра. Представляет собой массив из двух чисел, каждое из которых находится в диапазоне от `0.0` до `1.0`. |
| `Size` | `float` | Размер ладони в ĸадре. Указывается относительно ширины кадра. Возможны значения от `0.0` до `1.0` включительно. |
| `AngleDegrees` | `float` | Угол поворота ладони в плоскости экрана. Возможные значения: от `-270` до `90` включительно. |
| `ForeFingerPosition` | `Vector2` | Положение вершины уĸазательного пальца в кадре.  Указывается относительно размера кадра. Представляет собой массив из двух чисел, каждое из которых находится в диапазоне от `0.0` до `1.0`. |
| `ForeFingerBasePosition` | `Vector2` | Положение основания уĸазательного пальца в кадре.  Указывается относительно размера кадра. Представляет собой массив из двух чисел, каждое из которых находится в диапазоне от `0.0` до `1.0`. |
| `MiddleFingerBasePosition` | `Vector2` | Положение основания среднего пальца в кадре.  Указывается относительно размера кадра. Представляет собой массив из двух чисел, каждое из которых находится в диапазоне от `0.0` до `1.0`. |
| `RingFingerBasePosition` | `Vector2` | Положение основания безымянного пальца.  Указывается относительно размера кадра. Представляет собой массив из двух чисел, каждое из которых находится в диапазоне от `0.0` до `1.0`. |

### Типы жестов

Константы ниже описывают тип распознанного жеста. Используйте их для проверки значения ключа [`Gesture`](#Объект,%20описывающий%20жест).

> Пустая строка или любое значение вне этого списка означают, что жест не распознан.

| Константа | Жест |
| --- | --- |
| `"PALM"` | ✋ |
| `"OK"` | 👌 |
| `"KHABIB"` | 👆 |
| `"FIST"` | ✊ |
| `"VICTORY"` | ✌ |
| `"THUMB_UP"` | 👍 |
| `"THUMB_DOWN"` | 👎 |
| `"THUMB"` | Как `"THUMB_UP"`, но большой палец направлен в сторону. |
| `"ONE"` | ☝ |
| `"ROCK"` | 🤘 |
| `"HOMMIE"` | 🤙 |
| `"HEART"` |  🫶 (пальцы обеих рук, сложенные в форме сердца). |
| `"HEART_LEFT"` | Как `"HEART"`, но с одной левой рукой. |
| `"HEART_RIGHT"` |  Как `"HEART"`, но с одной правой рукой. |

## Особенности использования

Движок не предоставляет информации о том, какой рукой выполнен жест. Вы можете проанализировать это самостоятельно. Например, если координаты жесты соответствуют левой части экрана, значит, собеседник двигает правой рукой.
