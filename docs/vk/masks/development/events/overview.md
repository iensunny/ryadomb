# События

> Источник: [https://dev.vk.ru/ru/masks/development/events/overview](https://dev.vk.ru/ru/masks/development/events/overview)
События предоставляют механизм подписки на то или иное действие, произошедшее в системе. Чтобы начать использовать события, необходимо:

1. Подписаться на событие.

2. Определить метод обработчика события.

## Список событий

| Событие | Описание |
| --- | --- |
| [`MouseEvent`](masks/development/events/MouseEvent) | Пользователь коснулся экрана. |
| [`MouthTrigger`](masks/development/events/MouthTrigger) | Рот открылся или закрылся. |
| [`PostUpdate`](masks/development/events/PostUpdate) | Кадр обновился. |
| [`SrcFrameUpdate`](masks/development/events/SrcFrameUpdate) | Кадр обновился. |
| [`Update`](masks/development/events/Update) | Кадр обновился. |
| [`UpdateFaceDetected`](masks/development/events/UpdateFaceDetected) | Найдено или потеряно лицо в кадре. |
| [`UpdateFacePOI`](masks/development/events/UpdateFacePOI) | Ключевые точки лица обновились. |
| [`UpdateHandGesture`](masks/development/events/UpdateHandGesture) | Найден жест в кадре или жест из кадра исчез. |
