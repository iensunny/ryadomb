# Экспорт 3D-модели

> Источник: [https://dev.vk.ru/ru/masks/export](https://dev.vk.ru/ru/masks/export)
Маска поддерживает 3D-модели только в формате MDL.

Вы можете использовать любой удобный инструмент для работы с 3D-графикой, но для экспорта модели в файл `.mdl` понадобится программа [Blender](masks/tools#Blender) с плагином [Urho3D-Blender](masks/tools#Urho3D-Blender).

> **Важно!** 3D-модель и скелетную анимацию мы рекомендуем готовить только в программе Blender.
> Экспорт 3D-модели из других программ может плохо сказаться на конечном результате.

## Установка и настройка программы для экспорта

1. Установите последнюю версию программы [Blender](https://www.blender.org/download/).
2. В репозитории плагина [Urho3D-Blender](https://github.com/reattiva/Urho3D-Blender/tree/2_80) скачайте ZIP-файл.

    ![alt=Скачайте Urho3D-Blender;title=Скачайте Urho3D-Blender](f477733137bd23ad33fb4f3082557a7ee0ff85048e527cb63f19f4b6 "6900814571887687431")

3. Зайдите в менеджер дополнений Blender (**Edit** → **Preferences…** → **Add-ons**) и нажмите **Install**.

    ![alt=Установите Urho3D-Blender;title=Установите Urho3D-Blender](357eb7b116bfae48f597be7f94a9f9ba184f024072aaab5072492aed "4150148630775891380")

4. Перейдите к скачанному ZIP-файлу, выберите его и нажмите на **Install Add-on from File**.

    ![alt=Установите Urho3D-Blender;title=Установите Urho3D-Blender](2266c81aaf2f935a1bae6e8594c4035cf4cb32bc8a4e6e94c37df9f6 "8429298435422958448")

5. В списке дополнений с помощью поиска найдите **Urho3D export** и убедитесь, что рядом с ним стоит галочка.

    ![alt=Проверьте установку Urho3D-Blender;title=Проверьте установку Urho3D-Blender](f3f2a78e0ce64057e337749f3d9abf24112ad95e22f8ab437bdac1e8 "4777563096242388283")

    ![alt=Urho3D-Blender установлен и готов к работе;title=Urho3D-Blender установлен и готов к работе](61179bdc88fc2c4ef50ddf9305fec09f6f031ef53f4fe4826a42f562 "3832809577559555808")

## Экспорт 3D-модели

1. Укажите в настройке **Output folder** адрес каталога, в который будет экспортирована 3D-модель.

2. Чтобы избежать ошибок при повторном экспорте модели в тот же каталог, поставьте галочку перед **Files overwrite**. Это позволит перезаписывать одноимённые файлы.

3. Настройка **Use sub folders** размещает файлы по подкаталогам. Если вы экспортируете модель сразу в папку **Models** каталога с маской, то рекомендуем снять этот флажок (чтобы не создалась дублирующая папка **Models**).

4. В настройках **Geometries** укажите, что файл должен содержать `Position`, `Normal`, `UV`, `Tangent` (если вы планируете использовать `Normal map`).

    ![alt=Настройка;title=Настройка](576c28f1dbd657f1c90bfef32c8a5de8b6625ab615972883aa7a113f "309954595943112515")

5. Выделите модель, которую хотите экспортировать (на рисунке она называется Cube), и нажмите **Export**.

    ![alt=Экспорт файла;title=Экспорт файла](796223efaa1564495bb085925607d193271cac294f91a858d3701e6b "-5071684104796925863")

    В случае успешного экспорта по указанному в разделе **Output folder** адресу будет создан файл формата MDL, который вы сможете использовать в маске с помощью эффекта [model3d](masks/effects/model3d) или [occluder](masks/effects/occluder).

## Экспорт анимации

Чтобы экспортировать анимацию:

1. В настройках плагина Urho3D-Blender отметьте **Skeletons** и **Animations**, а затем выберите **Timeline**.

2. В разделе **Geometries** отметьте **Position**, **UV**, **Tangent**, **Normal**, **Weights**.

3. Выделите вашу модель (скелет выделять не нужно) и нажмите на кнопку **Export**.

    ![alt=Экспорт анимации;title=Экспорт анимации](384da65591a7b202dc00c5a97f238f001b1846cf52781aa8ac473af9 "-415155809045234912")

После этого по указанному в настройках пути (**Оutput folder**) будет создан файл модели `.mdl` и файл анимации `.ani`. Эти файлы нужно перенести в каталог **Models** каталога с маской, чтобы использовать для импорта в движок.
