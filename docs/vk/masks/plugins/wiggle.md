# wiggle

> Источник: [https://dev.vk.ru/ru/masks/plugins/wiggle](https://dev.vk.ru/ru/masks/plugins/wiggle)
Плагин `wiggle` используется для создания эффекта покачивания, дрожания или вращения текстуры или маски. Применяется к эффектам [`patch`](masks/effects/patch), [`model3d`](masks/effects/model3d) и [`plane`](masks/effects/plane).

Текстура или 3D-модель двигается хаотично относительно точки привязки. Параметры плагина определяют характер движения.

### Объявление плагина в JSON-коде маски

```JSON
{
    "icon": "mask-icon.png",
    "effects": [
        {
            "name": "patch",
            "tag": "snowflake",
            "anchor": "free",
            "texture": "Textures/Snowflake.png",
            "size": [20.0,20.0],
        }
    ],
    "plugins": [
        {
            "name": "wiggle",
            "tag":  "snowflake",
            "speed": 5.0,
            "amplitude": 20.0,
            "rotation": 20.0
        }

    ]
}    
```

## Параметры

| Параметр | Описание |  
| --- | --- |
| `name` | Имя плагина. Должно быть `"wiggle"`. |
| `tag` | Тег эффекта, к которому плагин будет привязан. Значение должно совпадать с параметром `tag` желаемого эффекта.  |
| `speed` | Скорость движения: количество единиц сцены в секунду. Указывается как число с плавающей точкой. `0.0` означает отсутствие перемещения. |
| `amplitude` | Максимально возможное смещение текстуры или модели от точки её привязки. Задаётся в виде числа с плавающей точкой в единицах измерения сцены. |
| `rotation` | Скорость вращения текстуры: количество градусов в секунду. Положительное число означает вращение по часовой стрелке, отрицательное — против часовой стрелки. |
