# particles

> Источник: [https://dev.vk.ru/ru/masks/plugins/particles](https://dev.vk.ru/ru/masks/plugins/particles)
Плагин позволяет создать простую систему частиц, например: боке, конфетти, падающие снежинки.

Для работы плагина нужно объявить один эффект [`patch`](masks/effects/patch) c тегом, определяющим, что эффект будет использоваться системой частиц.

## Пример

```JSON
{
  "icon": "Icon.png",
  "effects": [
    {
      "name": "patch",
      "tag": "snowflake",
      "anchor": "free",
      "texture": "Textures/Snowflake.png"
    }
  ],
  "plugins": [
    {
      "name": "particles",
      "tag": "snowflake",
      "min_speed": [-0.1, -0.01, 0, 0.001],
      "max_speed": [0.1, -0.2, 20, 0.035],
      "size": 0.2,
      "count": 30,
      "min_radius": 0.01,
      "max_radius": 0.05
    }
  ]
}
```

## Параметры

| Параметр | Тип | Описание |
| - | - | - |
| `tag` | `string` | Тег эффекта, к которому будет применён плагин. |
| `min_speed` и `max_speed` | `array<float>[4]` | Минимальные и максимальные параметры скорости частиц: постоянная компонента скорости по оси Х, постоянная компонента скорости по оси Y, частота изменения скорости по оси X с течением времени, амплитуда изменения скорости по оси X с течением времени. |
| `size` | `float` | Коэффициент размера частицы; он будет умножен на размер каждой частицы. |
| `count` | `int` | Количество частиц (рекомендуется не делать больше 50). |
| `min_radius` и `max_radius` | `float` | Минимальный и максимальный радиус частиц. |
