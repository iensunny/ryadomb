# pickerui

> Источник: [https://dev.vk.ru/ru/masks/plugins/pickerui](https://dev.vk.ru/ru/masks/plugins/pickerui)
С помощью плагина `pickerui` вы можете добавить в маску меню для выбора эффектов. Таким образом вы даёте пользователю возможность попробовать разные варианты отображения внутри одной маски.

Меню отображается поверх изображения, поступающего с камеры. Меню не попадает в саму историю или клип.

![alt=Пример меню в маске;title=Пример меню в маске](25d48950bf6ad5fcf4e074d59186cd39dc363b857d96b699517df63b "6381000870350183406")

Для работы плагина назначьте эффектам теги. Они будут определять, какой эффект или какие эффекты будут активны.

## Пример

### Объявление плагина в JSON-коде маски

```JSON
{
    "icon": "icon.png",

    "gallery_asset_required" : true,

    "effects": [
        {
            "name": "colorfilter",
            "tag": "warm",
            "lookup": "ColorFilter/warm_shade.png",
            "intensity": 0.75
        },
        {
            "name": "colorfilter",
            "tag": "cold",
            "lookup": "ColorFilter/cold_shade.png",
            "intensity": 0.75
        },
        {
            "name": "colorfilter",
            "tag": "bw",
            "lookup": "ColorFilter/bw_shade.png",
            "intensity": 0.75
        }
    ],
    
    "plugins": [
        {
            "name": "pickerui",
            "tags" : [ "warm" , "cold", "bw" ],
            "icons": ["icon-ward.png", "icon-cold.png", "icon-bw.png"]
        }
    ]
}
```

### Пример проекта

[Пример проекта маски](https://mask.vk.me/sample/pickerui.zip), использующей плагин `pickerui`.

## Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `name` | `string` | Название плагина. Должна использоваться строка `"pickerui"`. |
| `tags` | `array<string>` | Теги, которые плагин будет использовать для пунктов меню. Каждый элемент массива соответствует одному пункту меню, которое создаёт плагин. Порядок тегов в массиве соответствует порядку пунктов меню. |
| `icons` | `array<string>` | Имена файлов иконок, которые плагин будет показывать для тегов. Количество иконок должно быть равно количеству тегов. |

:::note
**Важно.** Для работы плагина добавьте в конфигурационный файл маски параметр `"gallery_asset_required": true`. Он должен располагаться на верхнем уровне иерархии объектов. Параметр указывает на необходимость создания меню для выбора компонентов маски.
:::

## Примечания

* Вы можете назначить один и тот же тег нескольким эффектам. То есть тег может соответствовать набору эффектов.

    Плагин будет показывать все эффекты, которым назначен выбранный тег, то есть переключать наборы эффектов.  

* Плагин влияет только на эффекты, теги которых указаны в параметре `tags`.

* При открытии маски по умолчанию активен первый тег, указанный в параметре `tags`.

* Движок масок работает только с одним плагином `pickerui` в маске. Если вы добавите в [конфигурационный файл](masks/configuration) несколько плагинов `pickerui`, будет использоваться первый.

* Плагин `pickerui` похож на плагин [`maskswitching`](masks/plugins/maskswitching). Отличие в том, что `pickerui` даёт пользователю возможность выбрать эффекты с помощью меню, а `maskswitching` активирует эффекты по действию, например, когда пользователь касается экрана или открывает рот.
