# randomtest

> Источник: [https://dev.vk.ru/ru/masks/plugins/randomtest](https://dev.vk.ru/ru/masks/plugins/randomtest)
Плагин позволяет создавать маски для тестов вида `«Кто ты из…?»` с использованием вложенного набора текстур.

> Для работы плагина нужно объявить два эффекта типа [`patch`](masks/effects/patch) c соответствующими тегами, которые определяют, какой эффект будет отвечать за отображение вопроса, а какой — за отображение ответа.
>
> Также необходимо, чтобы в [конфигурационном файле маски](masks/configuration) был задан параметр `"mouse_input": true`.

## Пример

```JSON
{
    "icon": "Icon.png",
    "mouse_input": true,
    "effects": [
        {
            "name": "patch",
            "tag": "question",
            "anchor": "forehead",
            "texture": {
                "texture": "Textures/Question.png"
            },
            "size": [60, 60],
            "offset": [0, 25, -22]
        },
        {
            "name": "patch",
            "tag": "answer",
            "anchor": "forehead",
            "texture": {
                "texture": "Textures/Answer/Answer.png"
            },
            "size": [60, 60],
            "offset": [0, 25, -22]
        }
    ],
    "plugins": [
        {
            "name": "randomtest",
            "question": {
                "tag": "question"
            },
            "answer": {
                "tag": "answer",
                "slow_down": true,
                "time": 5,
                "jump": true
            },
            "trigger": "mouth"
        }
    ]
}
```

## Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `question` | [`question`](#Параметры%20question) | Поле, в котором описываются параметры вопроса. |
| `answer` | [`answer`](#Параметры%20answer) | Поле, в котором описываются параметры ответа. |
| `trigger` | `string` | Задаёт триггер для запуска теста:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `"mouth"` — открытие рта;&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `"recording"` — начало записи;&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `"tap+recording"` — касание экрана и начало записи;&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `"tap"` — касание экрана.&#x0d;&#x0a;&#x0d;&#x0a;Во всех случаях тест сбрасывается с помощью касания экрана.|
| `delay`| `float` | Время задержки старта теста после срабатывания триггера. Указывается в секундах. Например:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `1.0` — 1 секунда;&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `0.2` — 200 миллисекунд;&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `2.5` — 2 с половиной секунды.&#x0d;&#x0a;&#x0d;&#x0a;По умолчанию установлено значение `0` — тест запускается сразу при срабатывании триггера. |

### Параметры `question`

| Параметр | Тип | Описание |
| - | - | - |
| `tag` | `string` | Тег эффекта, отображающего вопрос. В связанном эффекте должен быть указан путь к текстуре вопроса. |

### Параметры `answer`

| Параметр | Тип | Описание |
| - | - | - |
| `tag` | `string` | Тег эффекта, отображающего ответ. В связанном эффекте должен быть указан путь к первой текстуре ответа. Остальные текстуры должны быть пронумерованы от 1. |
| `slow_down` | `bool` | Определяет, будет ли плавное завершение переключений (перелистываний). |
| `time` | `float` | Длительность переключения ответов в секундах. |
| `jump` | `bool` | Определяет, подпрыгнет ли выпавший ответ. |
