# Обзор

> Источник: [https://dev.vk.ru/ru/masks/effects/overview](https://dev.vk.ru/ru/masks/effects/overview)
Изображение камеры можно дополнить с помощью эффектов.

Все эффекты перечисляются в конфигурационном [файле mask.json](masks/configuration) в поле:&nbsp;`"effects": [...]`.
Их можно сравнить со слоями в графическом редакторе.

Каждый эффект начинается с обязательного поля `name` — названия эффекта.
Далее указываются все необходимые параметры: точка привязки, путь до текстуры, анимация, размер, смещение относительно точки привязки. 

## Пример объявления эффекта

```JSON
{
    "icon": "Icon.png",
    "effects": [
        {
            "name": "beautify",
            "mix": 0.6
        },
        {
            "name": "patch",
            "anchor": "fullscreen",
            "texture": "Textures/Dust.png"
        },
        {
            "name": "colorfilter",
            "lookup": "ColorFilter/lookup.png",
            "intensity": 0.75
        }
    ]
}
```

## Список эффектов

| Эффект | Описание |
| --- | --- |
| [`facemodel`](masks/effects/facemodel) | Трёхмерная маска, накладываемая поверх лица. |
| [`patch`](masks/effects/patch)                 | Плоскость с текстурой. |
| [`plane`](masks/effects/plane)               | Плоскость с наложенным материалом. Используется в масках с перспективной проекцией. Относится к классу 3D-эффектов. |
| [`colorfilter`](masks/effects/colorfilter)     | Фильтр цветокоррекции. |
| [`beautify`](masks/effects/beautify)           | Сглаживание кожи лица. |
| [`liquifiedwarp`](masks/effects/liquifiedwarp) | Пластическая деформация. |
| [`posteffect`](masks/effects/posteffect)       | Постэффекты. |
| [`copyface`](masks/effects/copyface)           | Копирование элементов лица. |
| [`pasteface`](masks/effects/pasteface)         | Вставка элементов лица. |
| [`model3d`](masks/effects/model3d)             | 3D-модель. |
| [`occluder`](masks/effects/occluder)           | 3D-модель, которая используется для скрытия геометрии других 3D-эффектов. |
| [`light`](masks/effects/light)                 | Источник света для 3D-моделей. |
| [Сегментация](masks/effects/segmentation)                 | Выделение областей изображения и заливка их текстурой. |

> **Важно!** Применение эффектов к исходному изображению происходит в том порядке, в котором они описаны. Это значит, что эффекты, описанные строками выше, могут перекрываться теми, которые описаны строками ниже. Исключение из этого правила — 3D-эффекты (`model3d`, `light`, `plane`). Они отрисовываются в том месте, где был объявлен первый такой эффект.

## Отключение эффектов и их параметров

Отключить эффект можно двумя способами:

* Добавить символ минуса `-` в поле с названием эффекта. Пример: `-name`.
* Добавить дополнительное поле `“disabled" : true/false` (скрыть/показать) после поля с названием эффекта.

#### Пример отключения эффекта `patch`

```JSON
{
  "icon": "Icon.png",
  "effects": [
    {
      "-name": "patch",
      ...
    },
    {
      "name": "patch",
      "disabled": true,
      ...
    }
  ]
}
```

С помощью символа `-` можно отключать и любой другой параметр эффекта. Для этого нужно добавить его в поле с названием параметра, например так: `-texture`.

#### Пример отключения параметра `texture`

```JSON
{
    "icon": "Icon.png",
    "effects": [
        {
            "name": "patch",
            "anchor": "fullscreen",
            "-texture": "Textures/Red_overlay.png",
            "texture": "Textures/Blue_overlay.png"
        }
    ]
}
```

Отключать параметры удобно при тестировании нескольких вариантов. 
Например, когда одну из текстур необходимо скрыть, а другую показать.
