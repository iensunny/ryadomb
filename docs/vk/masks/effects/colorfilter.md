# colorfilter

> Источник: [https://dev.vk.ru/ru/masks/effects/colorfilter](https://dev.vk.ru/ru/masks/effects/colorfilter)
## Об эффекте

**сolorfilter** — это эффект фильтра цветокоррекции. Применяется ко всему изображению или области внутри него.

Пример работы эффекта:

![alt=Работа сolorfilter применительно ко всему изображению;title=Работа сolorfilter применительно ко всему изображению](8747d87333b292a239eb96aa67d9b3ac3a0292e8a23908e608db8a84 "2828629211988078565")

Для создания фильтра возьмите исходный файл цветовой таблицы [`lookup.png`](https://mask.vk.me/template/lookup.png) и примените к нему те же настройки цветокоррекции, что и к изображению. Получившийся файл разместите в папке, содержащей файлы вашей маски.

> **Совет**: для более удобной организации файлов создайте в папке маски подпапку `ColorFilter` и разместите в ней получившийся файл.

Подробности об организации файлов — в разделе [Подготовка ресурсов проекта](masks/publication/resources).

## Пример

```JSON
{
    "icon": ""my-mask-icon.png",
    "effects": [
        {
            "name": "colorfilter",
            "lookup": "ColorFilter/lookup.png",
            "intensity": 0.75
        }
    ]
}
```

## Параметры эффекта

| Параметр    | Описание                                                     |
| ----------- | ------------------------------------------------------------ |
| `name`      | Название эффекта. Должно быть `"colorfilter"`.&#x0d;&#x0a;Тип данных: `string`. |
| `lookup`    | Путь к файлу цветовой таблицы относительно конфигурационного файла `mask.json`. &#x0d;&#x0a;Тип данных: `string`. |
| `intensity` | Интенсивность фильтра цветокоррекции. Указывается как число в диапазоне от `0.0` до `1.0`. По умолчанию интенсивность фильтра максимальна (`1.0`).&#x0d;&#x0a;Тип данных: `float`. |
| `anchor`    | Точка привязки области, к которой будет применён эффект, в пространстве. Возможно одно из следующих строковых значений:&#x0d;&#x0a; &bullet; `fullscreen` &mdash; весь экран;&#x0d;&#x0a; &bullet; `right_eye` &mdash; правый глаз;&#x0d;&#x0a; &bullet; `left_eye` &mdash; левый глаз;&#x0d;&#x0a; &bullet; `middle_eyes` &mdash; переносица;&#x0d;&#x0a; &bullet; `forehead` &mdash; лоб;&#x0d;&#x0a; &bullet; `nose` &mdash; нос;&#x0d;&#x0a; &bullet; `mouth` &mdash; центр рта;&#x0d;&#x0a; &bullet; `right_cheek` &mdash; центр правой щеки;&#x0d;&#x0a; &bullet; `left_cheek` &mdash; центр левой щеки;&#x0d;&#x0a; &bullet; `lower_lip` &mdash; нижняя губа;&#x0d;&#x0a; &bullet; `upper_lip` &mdash; верхняя губа;&#x0d;&#x0a; &bullet; `lt_corner` &mdash; левый верхний край;&#x0d;&#x0a; &bullet; `lb_corner` &mdash; левый нижний край;&#x0d;&#x0a; &bullet; `rt_corner` &mdash; правый верхний край;&#x0d;&#x0a; &bullet; `rb_corner` &mdash; правый нижний край;&#x0d;&#x0a; &bullet; `free` &mdash; центр экрана;&#x0d;&#x0a; &bullet; `top_center` &mdash; центр верхней стороны;&#x0d;&#x0a; &bullet; `left_center` &mdash; центр левой стороны;&#x0d;&#x0a; &bullet; `right_center` &mdash; центр правой стороны;&#x0d;&#x0a; &bullet; `bottom_center` &mdash; центр нижней стороны.&#x0d;&#x0a;&#x0d;&#x0a;Значение по умолчанию: `fullscreen`, то есть эффект применяется ко всему экрану.&#x0d;&#x0a;Тип данных: `string`. |
| `size` | Ширина и высота области, к которой будет применён эффект. Как правило, размер задаётся в единицах измерения сцены как число с плавающей точкой, но возможно его [указание в процентах от ширины или высоты экрана](masks/effects/size-offset).&#x0d;&#x0a;Параметр игнорируется, если используется `"anchor": "fullscreen"`.&#x0d;&#x0a;Тип данных: `array<(float или obj)>[2]`. |
| `offset` | Смещение области, к которой будет применён эффект, относительно точки привязки в трёхмерном пространстве XYZ. Как правило, смещение указывают в единицах измерения сцены как число с плавающей точкой, но возможно его [указание в процентах от ширины или высоты экрана](masks/effects/size-offset).&#x0d;&#x0a;Параметр игнорируется, если используется `"anchor": "fullscreen"`.&#x0d;&#x0a;Тип данных: `array<(float или obj)>[3]`. |
| `rotation`       | 3 числа с плавающей точкой, определяющие углы вращения области, к которой будет применён эффект, в трёхмерном пространстве XYZ.&#x0d;&#x0a;Будьте внимательны: если используется точка привязки `"anchor": "free"`, то некоторые значения `rotation` могут привести к тому, что эта область выйдет за границы области отрисовки полностью или частично.&#x0d;&#x0a;Параметр игнорируется, если используется `"anchor": "fullscreen"`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `allow_rotation` | Параметр указывает, будет ли область, к которой применяется эффект, вращаться вместе с головой (`true`) или нет (`false`).  Работает только в случае, когда точка привязки (`anchor`) находится на голове (щёки, нос, глаза, уши, рот, губы). Значение по умолчанию: `true`.&#x0d;&#x0a;Тип данных: `bool`. |
| `visible`        | Условия видимости эффекта:&#x0d;&#x0a; &bullet; `"always"` &mdash; всегда;&#x0d;&#x0a; &bullet; `"face"` &mdash; применяется только при найденном лице;&#x0d;&#x0a; &bullet; `"mouth_open"` &mdash; применяется, когда рот открыт.&#x0d;&#x0a;&#x0d;&#x0a;Значение по умолчанию: `always`.&#x0d;&#x0a;Тип данных: `string`. |

:::note
**Особенности и ограничения**. Параметры `size` и `offset` игнорируются, если используется `"anchor": "fullscreen"`.
:::
