# Сегментация

> Источник: [https://dev.vk.ru/ru/masks/effects/segmentation](https://dev.vk.ru/ru/masks/effects/segmentation)
С помощью эффекта **сегментации** вы можете выделить область на изображении и заполнить её текстурой или выполнить обводку. Например, можно выделить фоновую область и заменить её изображением на морскую тематику или выбрать тело пользователя и заполнить его пиксельным изображением.  

![alt=Примеры работы эффекта: оригинал — пикселизация — замена фона;title=Примеры работы эффекта: оригинал — пикселизация — замена фона](9939b2df8bcc26735bc1e3c235f65f622607aad77afe7f016f6c777a "8767272132722390420")

Для выделения областей движок масок использует алгоритмы искусственного интеллекта.

## Как добавить эффект

1. В [конфигурационном файле](masks/configuration) маски добавьте параметр `"person_segmentation_required": true`.

1. Также добавьте эффект [`patch`](masks/effects/patch).

    В его настройках укажите:

    * Параметр `"anchor": "fullscreen"`.

    * Параметр `"visible": "always"`.

    * В параметре `"texture"`/`"texture"` укажите ссылку на файл текстуры, которая будет использоваться для заполнения области.

    * В параметре `"shader"` укажите одну из следующих констант. Они определяют область для выделения.

        | Константа | Описание |
        | --- | --- |
        | `BackgroundSegment` | Область фона, то есть всё, что не относится к голове, туловищу и рукам пользователя. |
        | `PersonSegment` | Область пользователя: голова, туловище, руки. |
  
## Пример

```JSON
{
  "icon": "icon.png",
  "person_segmentation_required": true,

  "effects": [
    {
      "name" : "patch",
      "anchor"  : "fullscreen",
      "visible" : "always",
      "texture" : {
        "texture" : "Textures/background.png",
        "shader" : "BackgroundSegment"}
    }
  ]
}
```

## Особенности использования

* В настоящее время эффект работает только в мобильном приложении ВКонтакте.

* Эффект находится в стадии разработки. В дальнейшем мы добавим выделение других областей изображения и разнообразим возможные эффекты наложения.
