# occluder

> Источник: [https://dev.vk.ru/ru/masks/effects/occluder](https://dev.vk.ru/ru/masks/effects/occluder)
## Об эффекте

Используйте эффект **occluder**, чтобы добавить в маску объект, который будет скрывать геометрию позади себя, но при этом оставаться прозрачным. Изображение объясняет работу эффекта. В качестве накладываемого объекта используется модель головы. Она скрывает внутреннюю часть шапки:

![alt=Пример работы эффекта occluder;title=Пример работы эффекта occluder](3fdae7684b6a4e8c65d864d27b5eb997a9c1298556ad972feac8c30e "4703824557908489476")

Эффект `occluder` воздействует на отображение всех [3D-эффектов](masks/effects/overview#Список%20эффектов) в маске, независимо от порядка их подключения  в [конфигурационном файле `mask.json`](masks/configuration).

В качестве скрывающего объекта эффект `occluder` использует 3D-модель в формате `.mdl`. Этот файл надо предварительно сгенерировать или экспортировать из соответствующего инструмента разработки. Подробное описание — в разделе [Экспорт 3D-модели](masks/export).

## Пример

```JSON
{
    "icon": "my-mask-icon.png",
    "effects": [
        {
            "name": "occluder",
            "anchor": "forehead",
            "model": "Models/head.mdl",
            "position": [0, -12, 115],
            "rotation": [0, 90, -90 ],
            "scale": [2.29, 2.29, 2.29]
        }
    ]
}
```

## Параметры эффекта

| Параметр     | Описание                                                     |
| ------------ | ------------------------------------------------------------ |
| `name`       | Название эффекта. Должно быть `"occluder"`.&#x0d;&#x0a;Тип данных: `string`. |
| `anchor`     | Точка привязки эффекта:&#x0d;&#x0a; &bullet; `face` &mdash; центр лица.&#x0d;&#x0a; &bullet; `right_eye` &mdash; правый глаз.&#x0d;&#x0a; &bullet; `left_eye` &mdash; левый глаз.&#x0d;&#x0a; &bullet; `middle_eyes` &mdash; переносица.&#x0d;&#x0a; &bullet; `forehead` &mdash; лоб.&#x0d;&#x0a; &bullet; `nose` &mdash; нос.&#x0d;&#x0a; &bullet; `mouth` &mdash; центр рта.&#x0d;&#x0a; &bullet; `right_cheek` &mdash; центр правой щеки.&#x0d;&#x0a; &bullet; `left_cheek` &mdash; центр левой щеки.&#x0d;&#x0a; &bullet; `lower_lip` &mdash; нижняя губа.&#x0d;&#x0a; &bullet; `upper_lip` &mdash; верхняя губа.&#x0d;&#x0a;&#x0d;&#x0a;Тип данных: `string`. |
| `model`      | Путь к файлу накладываемой 3D-модели относительно конфигурационного файла маски `mask.json`.&#x0d;&#x0a;Тип данных: `string`. |
| `position`   | Три числа с плавающей точкой, которые определяют позицию накладываемой модели в трёхмерном пространстве XYZ относительно точки привязки `anchor`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `rotation`   | Три числа с плавающей точкой, которые указывают углы вращения модели в трёхмерном пространстве XYZ в градусах относительно центра модели.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `scale`      | Три числа с плавающей точкой, указывающих масштаб модели в трёхмерном пространстве XYZ.&#x0d;&#x0a;Если модель не видно, проверьте, что вы не выставили слишком большой или слишком маленький масштаб.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `visible`    | Режим видимости накладываемой 3D-модели. Одно из следующих значений:&#x0d;&#x0a; &bullet; `always` &mdash; показывать всегда.&#x0d;&#x0a; &bullet; `face` &mdash; показывать только при обнаруженном лице.&#x0d;&#x0a; &bullet; `mouth_open` &mdash; показывать, когда открыт рот.&#x0d;&#x0a;&#x0d;&#x0a;По умолчанию модель отображается при обнаруженном лице.&#x0d;&#x0a;Тип данных: `string`. |
