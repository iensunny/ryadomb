# copyface

> Источник: [https://dev.vk.ru/ru/masks/effects/copyface](https://dev.vk.ru/ru/masks/effects/copyface)
## Об эффекте

Эффект **copyface** копирует в память части лица, полученные с камеры или содержащие уже применённые эффекты. В дальнейшем скопированные данные можно добавить в результирующее изображение с помощью эффекта [`pasteface`](masks/effects/pasteface).      

![alt=Примеры работы эффектов copyface и pasteface;title=Пример работы эффектов copyface и pasteface](265d54f9fead6b4915e824bca15cde39d7afa19a6650a1961c7587ee "-6557510792551533803")

> **Важно!** Эффект `copyface` можно использовать в маске только один раз.

## Пример

```JSON
{
    "icon": "Icon.png",
    "effects": [
        {
            "name": "copyface"
        },
        {
            "name": "pasteface",
            "element": "nose",
            "size": [1.5, 1.5]
        },
        {
            "name": "pasteface",
            "element": "mouth",
            "size": [1.5, 1.5]
        }
    ]
}
```

## Параметры эффекта

| Параметр        | Описание                                                     |
| --------------- | ------------------------------------------------------------ |
| `name`          | Название эффекта. Должно быть `"copyface"`.&#x0d;&#x0a;Тип данных: `string`. |
| `facemask`      | Путь к .png файлу текстуры вида [`facemodel`](masks/effects/facemodel), где белым цветом на прозрачном фоне размечены вырезаемые области лица: глаза и рот. См. [пример](#Пример%20текстуры%20с%20размеченной%20вырезаемой%20областью) ниже. Путь к файлу должен быть указан относительно конфигурационного файла `mask.json`.&#x0d;&#x0a;Если не указать этот параметр, то будет использоваться вырезаемая область по умолчанию.&#x0d;&#x0a;Тип данных параметра: `string`. |
| `facemask_nose` | Путь к .png файлу текстуры вида [`facemodel`](masks/effects/facemodel), где белым цветом на прозрачном фоне размечена вырезаемая область носа. См. [пример](#Пример%20текстуры%20с%20размеченной%20вырезаемой%20областью) ниже. Путь к файлу должен быть указан относительно конфигурационного файла `mask.json`.&#x0d;&#x0a;Если не указать этот параметр, то будет использоваться вырезаемая область по умолчанию.&#x0d;&#x0a;Тип данных параметра: `string`. |

## Пример текстуры с размеченной вырезаемой областью

![alt=Текстура с разметкой вырезаемых областей;title=Текстура с разметкой вырезаемых областей](63e83231f9ba1f14414badd6821afb7f543f727092d1585bba2ee112 "-5648983863472100602")

Для предпросмотра вырезаемой области временно добавьте эффект типа [`facemodel`](masks/effects/facemodel) к вашей маске, указав в ее параметрах путь к той же текстуре, которую планируете использовать в параметрах `facemask` или `facemask_nose` эффекта `copyface`. Например:

```JSON
  {
    "icon": "Icon.png",

    "effects": [
      {
        "name": "facemodel",
        "texture": "Textures/mask.png",
        "eyes": true,
        "mouth": true
      }
    ]
  }
```

![alt=Предпросмотр вырезаемой области;title=Предпросмотр вырезаемой области](09e4add5f497995249984531d925fae87b9aefc5217d9200c3ba1dc0 "5951886345740811464")

Не забудьте удалить эффект `facemodel` из маски после проверки.
