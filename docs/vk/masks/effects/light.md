# light

> Источник: [https://dev.vk.ru/ru/masks/effects/light](https://dev.vk.ru/ru/masks/effects/light)
## Об эффекте

Используйте эффект **light** для включения в маску источников света. Эффект влияет на все 3D-модели и плоскости, добавленные к маске с помощью эффектов [`model3d`](masks/effects/model3d) и [`plane`](masks/effects/plane), независимо от порядка их подключения.

Если в маске отсутствуют эффекты `light`, то будет действовать [источник света по умолчанию](#Характеристики%20источника%20света%20по%20умолчанию). 

## Пример

```JSON
{
    "icon": "Icon.png",

    "effects": [
        {
            "name": "light",
            "type" : "ambient",
            "color" : [1.0, 0.85, 0.95]
        }
    ]
}
```

## Параметры эффекта

| Параметр             | Описание                                                     |
| -------------------- | ------------------------------------------------------------ |
| `name`               | Название эффекта. Должно быть `"light"`.&#x0d;&#x0a;Тип данных: `string`. |
| `type`               | Тип источника света. Допустимые значения: &#x0d;&#x0a; &bullet; `"ambient"` — заполняющий свет, не имеющий явного источника;&#x0d;&#x0a;  &bullet; `"direct"` — направленный источник света, свет идёт в одном направлении;&#x0d;&#x0a; &bullet; `"point"` — точечный источник света, излучает свет во все возможные от себя направления.&#x0d;&#x0a;Тип данных: `string`. |
| `color`              | RGB-компоненты цвета источника света, например, `"color": [1.5, 0.5, 0.5]`. Каждое значение &mdash; число с плавающей точкой, означающее силу цветового канала. Для увеличения силы канала, используйте значения больше `1.0`; для уменьшения силы канала &mdash; значения меньше `1.0` или отрицательные. &#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `brightness`         | Яркость источника света. Значения больше `1.0` приводят к увеличению яркости. Значения меньше `1.0` можно использовать для симуляции слабых источников; отрицательные значения &mdash; для затенения.&#x0d;&#x0a;Тип данных: `float`. |
| `specular_intensity` | Яркость отражаемого блика. Значения больше `1.0` приводят к увеличению яркости; значения меньше `1.0` &mdash; к её уменьшению.&#x0d;&#x0a;Тип данных: `float`. |
| `anchor`             | Для источников вида `"type": "point"`. Точка привязки положения источника света. Принимает одно из следующих значений:&#x0d;&#x0a;&bull; `"face"` &mdash; центр лица;&#x0d;&#x0a; &bull; `"right_eye"`  &mdash; правый глаз;&#x0d;&#x0a;&bull; `"left_eye"`  &mdash; левый глаз;&#x0d;&#x0a;&bull; `"middle_eyes"`  &mdash; переносица;&#x0d;&#x0a;&bull; `"forehead"`  &mdash; лоб;&#x0d;&#x0a;&bull; `"nose"`  &mdash; нос;&#x0d;&#x0a;&bull; `"mouth"`  &mdash; центр рта;&#x0d;&#x0a;&bull; `"right_cheek"`  &mdash; центр правой щеки;&#x0d;&#x0a;&bull; `"left_cheek"`  &mdash; центр левой щеки;&#x0d;&#x0a;&bull; `"lower_lip"`  &mdash; нижняя губа;&#x0d;&#x0a;&bull; `"upper_lip"`  &mdash; верхняя губа.&#x0d;&#x0a;&#x0d;&#x0a;Тип данных: `string`.|
| `position`           | Для источников вида `"type": "point"`. Положение источника света в трёхмерном пространстве XYZ относительно точки привязки `anchor`, например, `"position": [100.0, -22.5, 150]`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `range`              | Для источников вида `"type": "point"`.  Максимальная дальность, на которую распространяется свет от источника. Если не указывать данный параметр, то значение по умолчанию `"range": 500`.&#x0d;&#x0a;Тип данных: `float`. |
| `direction`          | Для источников вида `"type": "direct"`. Направление светового потока, заданное как вектор в трёхмерном пространстве XYZ. Если не указывать данный параметр, то значение по умолчанию `"direction": [0.0, 0.0, 1.0]`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `rotation`           | Для источников вида `"type": "direct"`. Направление светового потока, заданное углами поворота в трёхмерном пространстве XYZ в градусах. Если не указывать данный параметр, то значение по умолчанию `"rotation": [0.0, 0.0, 0.0]`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |

#### Особые случаи

* Для источников вида `"type": "ambient"` используется только параметр `color`.
* Параметры `direction` и `rotation` работают только для источников вида `"type": "direct"`.
* Параметры `anchor`, `position` и `range` используются только источниками вида `"type": "point"`.

#### Характеристики источника света по умолчанию

Если в маске отсутствуют эффекты `light`, то по умолчанию используется источник света со следующими свойствами:

* Направленный свет (`"type": "direct"`). 

* Световой поток следует вдоль оси Z из камеры на лицо пользователя.

* Значения свойств:
  - `"color": [1.0, 1.0, 1.0]` (белый свет)
  - `"brightness": 1.0`
  - `"specular_intensity": 1.0`
  - `"range": 500`
