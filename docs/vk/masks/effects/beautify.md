# beautify

> Источник: [https://dev.vk.ru/ru/masks/effects/beautify](https://dev.vk.ru/ru/masks/effects/beautify)
## Об эффекте

**beautify** используется для сглаживания кожи лица.

## Пример
```JSON
{
    "icon": "Icon.png",
    "effects": [
        {
            "name": "beautify",
            "mix": 0.65
        }
    ]
}
```

## Параметры эффекта

| Параметр | Описание                                                     |
| -------- | ------------------------------------------------------------ |
| `name`   | Название эффекта. Должно быть `"beautify"`.&#x0d;&#x0a;Тип данных: `string`. |
| `mix`    | Степень интенсивности эффекта (степень смешения с исходным изображением). Указывается, как число в диапазоне от `0.0` до `1.0`.  Значение по умолчанию: `0.65`.&#x0d;&#x0a;Тип данных: `float`. |
