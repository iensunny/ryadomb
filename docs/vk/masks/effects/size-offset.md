# Способы указания размера и смещения

> Источник: [https://dev.vk.ru/ru/masks/effects/size-offset](https://dev.vk.ru/ru/masks/effects/size-offset)
Параметры `size` и `offset` используются для изменения размера и позиционирования плоскости в результирующем изображении в эффектах [`colorfilter`](masks/effects/colorfilter) и [`patch`](masks/effects/patch).
При задании значений этих параметров используются специальные соглашения.
Размер можно указать как число или процент от ширины или высоты экрана.
В примере ниже — возможные способы указания значений:

```JSON
{
  "icon": "my-mask-icon.png",

  "effects": [
    {
      "name": "patch",
      "anchor": "free",
      "texture": "Textures/texture-file.png",
      "size": [{ "w": 1.0 }, { "h": 0.3 }],
      "offset": [{ "pix": 10.0 }, { "h": -0.2 }, 0.0]
    }
  ]
}
```

Для указания значений используются следующие константы:

| Константа | Описание                                             |
| --------- | ---------------------------------------------------- |
| `w`       | Значение в процентах от ширины экрана.               |
| `h`       | Значение в процентах от высоты экрана.               |
| `pix`     | Значение в пикселях.                                 |
| `max`     | Значение в процентах от максимальной стороны экрана. |
| `min`     | Значение в процентах от минимальной стороны экрана.  |

Проценты указываются как число в диапазоне от `0.0` до `1.0`.

Процентные значения от ширины или высоты можно использовать для указания горизонтальных и вертикальных размеров и смещений.
