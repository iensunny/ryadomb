# model3d

> Источник: [https://dev.vk.ru/ru/masks/effects/model3d](https://dev.vk.ru/ru/masks/effects/model3d)
## Об эффекте

**model3d** добавляет в маску трёхмерную модель.

Поддерживаются модели в формате `.mdl` либо анимации в формате `.ani.` Перед добавлением этих файлов в маску их надо предварительно сгенерировать или экспортировать из соответствующего инструмента разработки. Подробное описание экспорта есть в разделе [Экспорт 3D-модели](masks/export).

> **Совет:** чтобы скрыть некоторую часть 3D-модели, используйте инструмент [Invisible Occluder](#Invisible%20Occluder).

## Пример

```JSON
{
    "icon": "Icon.png",
    "effects": [
        {
            "name": "model3d",
            "anchor": "forehead",
            "model": "Models/Cap.mdl",
            "material": {
                "technique": "Techniques/DiffUnlit.xml",
                "textures": {
                    "diffuse": "Textures/Cap_diffuse.png"
                }
            },
            "position": [0, 45, 10],
            "rotation": [10, 0, 0],
            "scale": [28, 28, 28]
        }
    ]
}
```

## Параметры эффекта

| Параметр     | Описание                                                     |
| ------------ | ------------------------------------------------------------ |
| `name`       | Название эффекта. Должно быть `"model3d"`.&#x0d;&#x0a;Тип данных: `string`. |
| `anchor`     | Точка привязки 3D-модели:&#x0d;&#x0a; &bullet; `"face"` &mdash; центр лица;&#x0d;&#x0a; &bullet; `"right_eye"` &mdash; правый глаз;&#x0d;&#x0a; &bullet; `"left_eye"` &mdash; левый глаз;&#x0d;&#x0a; &bullet; `"middle_eyes"` &mdash; переносица;&#x0d;&#x0a; &bullet; `"forehead"` &mdash; лоб;&#x0d;&#x0a; &bullet; `"nose"` &mdash; нос;&#x0d;&#x0a; &bullet; `"mouth"` &mdash; центр рта;&#x0d;&#x0a; &bullet; `"right_cheek"` &mdash; центр правой щеки;&#x0d;&#x0a; &bullet; `"left_cheek"` &mdash; центр левой щеки;&#x0d;&#x0a; &bullet; `"lower_lip"` &mdash; нижняя губа;&#x0d;&#x0a; &bullet; `"upper_lip"` &mdash; верхняя губа.&#x0d;&#x0a;&#x0d;&#x0a;Тип данных: `string`. |
| `model`      | Путь к файлу 3D-модели относительно конфигурационного файла маски `mask.json`.&#x0d;&#x0a;Тип данных: `string`. |
| `material`   | Описание материала модели. Материалы отвечают за то, как будет отображаться поверхность 3D-модели во время отрисовки.&#x0d;&#x0a;В модели может быть один или несколько материалов.&#x0d;&#x0a;Если в модели один материал, то этот параметр представлен одним набором параметров, описывающих этот материал.&#x0d;&#x0a;Если при разработке модели было заложено несколько материалов, то параметр представлен последовательностью (массивом) наборов, по одному на каждый материал.&#x0d;&#x0a;**Важно:** материалы в массиве нужно указать в том же порядке, в котором они были определены до экспорта файла модели.&#x0d;&#x0a;Полная информация об описании материалов &mdash; в разделе [Параметры материалов](#Параметры%20материалов).&#x0d;&#x0a;Тип данных: `obj` или `array<obj>`. |
| `animation`  | Набор параметров, описывающих анимацию 3D-модели. Подробности см. в разделе [Анимация 3D-моделей](masks/animation/models).&#x0d;&#x0a;Тип данных: `obj`. |
| `position`   | 3 числа с плавающей точкой, которые определяют позицию накладываемой модели в трёхмерном пространстве XYZ относительно точки привязки `anchor`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `rotation`   | 3 числа с плавающей точкой, которые указывают углы вращения в трёхмерном пространстве XYZ в градусах относительно центра модели.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `scale`      | 3 числа с плавающей точкой, указывающих масштаб модели в трёхмерном пространстве XYZ.&#x0d;&#x0a;Если модель не видно, то проверьте, что вы не выставили слишком большой или слишком маленький масштаб.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `visible`    | Режим видимости 3D-модели. Одно из следующих значений:&#x0d;&#x0a; &bullet; `"always"` &mdash; показывать всегда;&#x0d;&#x0a; &bullet; `"face"` &mdash; показывать только при обнаруженном лице;&#x0d;&#x0a; &bullet; `"mouth_open"` &mdash; показывать, когда открыт рот.&#x0d;&#x0a;&#x0d;&#x0a;По умолчанию модель отображается при обнаруженном лице.&#x0d;&#x0a;Тип данных: `string`. |
| `show_delay` | Задержка появления модели в секундах после того, как движок масок определит открытый рот пользователя. Параметр работает только при `"visible": "mouth_open"`. По умолчанию модель появляется без задержек.&#x0d;&#x0a;Обратите внимание, что задержка указывается в секундах. Если нужны доли секунды, указывайте дробную часть после запятой.&#x0d;&#x0a;Тип данных: `float`. |
| `hide_delay` | Задержка исчезновения модели в секундах, после того как движок масок определит, что пользователь закрыл рот. Параметр работает только при `"visible": "mouth_open"`. По умолчанию модель скрывается мгновенно.&#x0d;&#x0a;Обратите внимание, что задержка указывается в секундах. Если нужны доли секунды, указывайте дробную часть после запятой.&#x0d;&#x0a;Тип данных: `float`. |

## Параметры материалов

### material

Материалы отвечают за отображение поверхности 3D-модели при отрисовке. Модель может использовать один или несколько материалов. Их описание находится в поле `material`.   

Каждый материал содержит одну или несколько текстурных карт:

* `diffuse` — Информация о цвете и alpha-канале.
* `normal` — Информация о рельефе.
* `specular` — Информация об интенсивности и цвете блика.
* `environment` — Информацию о цвете окружения.
* `emissive` — Информация о самосвечении.

#### Пример объявления одного материала в модели 

```JSON
{
    "icon": "Icon.png",
    "effects": [
        {
            "name": "model3d",
            "anchor": "forehead",
            "model": "Models/Cap.mdl",
            "material": {
                "technique": "Techniques/DiffUnlit.xml",
                "textures": {
                    "diffuse": "Textures/Cap_diffuse.png"
                }
            },
            "position": [0, 45, 10],
            "rotation": [10, 0, 0],
            "scale": [28, 28, 28]
        }
    ]
}
```

#### Пример объявления нескольких материалов

```JSON
  {
    "icon": "Icon.png",
    "effects": [
        {
            "name": "model3d",
            "anchor": "forehead",
            "model": "Models/Cap.mdl",
            "material": [
                {
                    "technique": "Techniques/DiffUnlit.xml",
                    "textures": {
                        "diffuse": "Textures/Cap/Body_diffuse.png"
                    }
                },
                {
                    "technique": "Techniques/DiffEnvCube.xml",
                    "textures": {
                        "diffuse": "Textures/Cap/Logo_diffuse.png",
                        "environment": "Textures/Cap/Environment.xml"
                    },
                    "parameters": {
                        "MatEnvMapColor": [0.6, 0.6, 0.6]
                    }
                }
            ],
            "position": [0, 45, 10],
            "rotation": [10, 0, 0],
            "scale": [28, 28, 28]
        }
    ]
}
```

| Параметр      | Описание                                                     |
| ------------- | ------------------------------------------------------------ |
| `technique`   | Путь к файлу с данными о технике материала относительно конфигурационного файла `mask.json`, например, `"technique": "Techniques/DiffEnvCube.xml"`. Техника материала определяет, какие проходы отрисовки будет выполнять  движок масок для отображения материала.&#x0d;&#x0a;Файлы с базовыми техниками материалов не обязательно помещать в папку, содержащую файлы маски. Они могут подгружаться из [встроенных ресурсов](masks/development/assets). Подробнее о доступных файлах техник, см. раздел [technique](#technique).&#x0d;&#x0a;Тип данных: `string`. |
| `textures`    | Набор параметров для сопоставления текстурных карт (`diffuse`, `normal`, `specular`, `environment`, `emissive`). Подробнее см. [textures](#textures).&#x0d;&#x0a;Тип данных: `obj`. |
| `parameters`  | Набор параметров для задания цветовых настроек для отображения текстур. См. [parameters](#parameters).&#x0d;&#x0a;Тип данных: `obj`. |
| `renderorder` | Порядковый номер материала во время отрисовки. Значение по умолчанию: `128`.&#x0d;&#x0a;Тип данных: `int`. |
| `cull`        | Сторона материала для отрисовки:&#x0d;&#x0a; &bullet; `"ccw"` &mdash; только внешняя;&#x0d;&#x0a; &bullet; `"cw"` &mdash; только внутренняя;&#x0d;&#x0a; &bullet; `"none"` &mdash; и внешняя, и внутренняя.&#x0d;&#x0a;&#x0d;&#x0a;По умолчанию отрисовывается внешняя сторона материала.&#x0d;&#x0a;Тип данных: `string`. |

### technique

Термин &laquo;техника&raquo; применительно к отрисовке материалов означает порядок и правила отрисовки. Параметр `technique` указывает на файл, который описывает технику отрисовки.

Во [встроенных ресурсах](masks/development/assets) доступны следующие файлы техник:

* NoTexture.xml
* NoTextureAlpha.xml
* NoTextureEnvCube.xml
* NoTextureEnvCubeAlpha.xml
* NoTextureNormal.xml
* NoTextureNormalAlpha.xml
* NoTextureUnlit.xml
* NoTextureUnlitAlpha.xml
* Diff.xml
* DiffMultiply.xml
* DiffEmissive.xml
* DiffEmissiveAlpha.xml
* DiffEnvCube.xml
* DiffEnvCubeAlpha.xml
* DiffNormal.xml
* DiffNormalAlpha.xml
* DiffNormalAlphaMask.xml
* DiffNormalEmissive.xml
* DiffNormalEmissiveAlpha.xml
* DiffNormalEnvCube.xml
* DiffNormalEnvCubeAlpha.xml
* DiffNormalSpec.xml
* DiffNormalSpecAlpha.xml
* DiffNormalSpecAlphaMask.xml
* DiffSpec.xml
* DiffSpecAlpha.xml
* DiffSpecAlphaMask.xml
* DiffUnlit.xml
* DiffUnlitAlpha.xml
* DiffUnlitAlphaMask.xml

Каждое имя включает нескольких подстрок (`Diff`, `Alpha`, `Unlit` и других). Они отражают наличие или отсутствие определенных свойств материала:

| Подстрока     | Значение                                                     |
| ------------- | ------------------------------------------------------------ |
| **NoTexture** | У материала отсутствует текстура `diffuse`. С помощью параметра [`MatDiffColor`](#parameters) можно задать цвет материала, выставив необходимые коэффициенты RGB. ![alt=Пример использования NoTexture и MatDiffColor;title=Пример использования NoTexture и MatDiffColor](deac878e5f734bd9258954c7a12e84bc3356e370bac67cc2e4d4c50a "8378697193319088794") |
| **Diff**      | У материала имеется текстура `diffuse`. С помощью параметра [`MatDiffColor`](#parameters) можно задать коэффициенты RGB пропускающего текстурой цвета. ![alt=Пример использования Diff и MatDiffColor;title=Пример использования Diff и MatDiffColor](4bce055107a9a727a9248552f22d96f1ec090518ec03638c0335d88f "3953860234734718197") |
| **Normal**    | У материала имеется текстура `normal`. ![alt=Пример использования Normal и DiffNormal;title=Пример использования Normal и DiffNormal](898e598c1b493a98eb1f8cff04c872f2756e86347be8c67bb28ea804 "-2695761252376548678") |
| **Spec**      | У материала имеется текстура `specular`. С помощью параметра [`MatSpecColor`](#parameters) тремя первыми значениями можно задать коэффициенты RGB отражающего цвета, а четвёртым — значение силы затухания блика. При этом, если не задать строку `"Spec"` в названии техники материала, то по-прежнему можно управлять бликом через параметр `MatSpecColor`. ![alt=Пример использования Spec и MatSpecColor;title=Пример использования Spec и MatSpecColor](23ec354a8dca0d261aaf1011439ac131b305d7d83f179b140a476ab0 "4663437868827510381") |
| **EnvCube**   | У материала имеется текстура `environment`. С помощью параметра [`MatEnvMapColor`](#parameters) можно  задать коэффициенты RGB отражённого от окружения цвета. ![alt=Пример использования EnvCube и MatEnvMapColor;title=Пример использования EnvCube и MatEnvMapColor](6c5951ab01cbde6f699eefdd545d01c8c67a8a67f00c20dd218e8283 "5537163705064858376") |
| **Emissive**  | У материала имеется текстура `emissive`. С помощью параметра [`MatEmissiveColor`](#parameters) можете задать коэффициенты RGB яркости самосвечения. При этом, если не задать строку `"Emissive"` в названии технике материала, то можно управлять самосвечением материала в целом через параметр `MatEmissiveColor`. ![alt=Пример использования Emissive и MatEmissiveColor;title=Пример использования Emissive и MatEmissiveColor](e23be3ab73b46d6ded6ee9dc1d68d1c149d6f5553f352aa761fe9bae "-917700794188665663") |
| **Unlit**     | Цвет материала не зависит от источников света.![alt=Влияние Unlit;title=Влияние Unlit](82979ad2aae251072d25342e80c660c36850e8014223af7092e13006 "-8083226995836614431") |
| **Alpha**     | Материал полупрозрачный. Прозрачность отдельных пикселей определяется alphа-каналом `diffuse` текстуры. С помощью параметра [`MatDiffColor`](#parameters) в поле `value` тремя первыми значениями вы можете задать коэффициенты RGB пропускающего текстурой цвета, а четвёртым — коэффициент прозрачности материала в целом. Обратите внимание: движок масок отрисовывает объекты с подстрокой `"Alpha"` в названии техники материала после всех остальных объектов. |
| **AlphaMask** | Материал в каких-то местах полностью прозрачный, а в каких-то – нет. При этом, в отличие техники `"Alpha"`, прозрачность у `"AlphaMask"` определяется следующим образом: если значение alpha-канала у пикселя `diffuse` текстуры меньше или равно `0.5`, то материал полностью прозрачный, если более `0.5`, то материал в этом месте не прозрачный. |
| **Multiply**  | Материал будет накладываться на фон в режиме `Multiply` &mdash; режим &laquo;умножение&raquo; (термин соответствует терминам, используемым графическими редакторами). |

### textures

Параметр `textures` служит для указания файлов текстурных карт материала. Пример декларации:

```JSON
{
    "icon": "Icon.png",
    "effects": [
        {
            "name": "model3d",
            "anchor": "forehead",
            "model": "Models/Cap.mdl",
            "material": {
                "technique": "Techniques/DiffUnlit.xml",
                "textures": {
                    "diffuse": "Textures/Cap/Logo_diffuse.png",
                    "environment": "Textures/Cap/Environment.png"
                }
            }
        }
    ]
}
```

| Параметр      | Описание                                                     |
| ------------- | ------------------------------------------------------------ |
| `diffuse`     | Путь до файла текстуры `diffuse`.&#x0d;&#x0a;Тип данных: `string`. |
| `normal`      | Путь до файла текстуры `normal`.&#x0d;&#x0a;Тип данных: `string`. |
| `specular`    | Путь до файла текстуры `specular`.&#x0d;&#x0a;Тип данных: `string`. |
| `environment` | Путь до файла текстуры `environment`. См. [Создание файла environment-текстуры](#Создание#файла%20environment%20текстуры). &#x0d;&#x0a;Тип данных: `string`. |
| `emissive`    | Путь до файла текстуры `emissive`.&#x0d;&#x0a;Тип данных: `string`. |

Примечания:

* Все параметры должны указывать файловые пути относительно конфигурационного файла маски (`mask.json`). 

* Поддерживаемые форматы изображений для всех текстур: PNG и JPG.

##### Создание файла environment текстуры

1. Текстура вида environment создаётся на основе 360-панорамных HDRI-изображений. Сделайте такую панорамную фотографию или скачайте готовое HDRI-изображение с одного из сайтов, например [https://polyhaven.com/hdris](https://polyhaven.com/hdris).

2. Сконвертируйте ваше изображение в cubemap-развёртку с помощью сервиса [https://berrymoor.github.io/cubemap/](https://berrymoor.github.io/cubemap/).&#x0d;&#x0a;Сохраните сконвертированное изображение как файл PNG или JPG. 

3. Разместите файл в папке с файлами маски (мы рекомендуем сохранять текстуры в подпапке `Textures`). Укажите путь до файла в параметре `environment`:

```JSON
{
  ...
      "material": {
        "technique": "Techniques/DiffUnlit.xml",
        "textures": {
           "environment": "Textures/Cap/Environment.png"          
        }
      }
  ...
}
``` 

Теперь модель будет использовать вашу environment-текстуру.

### parameters

Это поле служит для задания цветовых настроек текстур материала. 

| Параметр           | Описание                                                     |
| ------------------ | ------------------------------------------------------------ |
| `MatDiffColor`     | Коэффициенты RGBA для `diffuse` текстуры.&#x0d;&#x0a;Тип данных: `array<float>[4]`. |
| `MatSpecColor`     | Последовательность из 4 чисел в плавающей точкой. Три первые значения задают коэффициенты RGB для текстуры `specular`, а четвёртый – значение силы затухания блика.&#x0d;&#x0a;Тип данных: `array<float>[4]`. |
| `MatEnvMapColor`   | Коэффициенты RGB для отражённого от окружения света или текстуры `environment`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `MatEmissiveColor` | Коэффициенты RGB яркости самосвечения или текстуры `emissive`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |

### Особые случаи

* Для техник `Diff`, `Normal`, `Spec`, `EnvCube`, `Emissive` обязательно наличие соответствующей текстуры.

* Допустимо управление параметрами `MatDiffColor`, `MatEmissiveColor`, `MatSpecColor` без объявления соответствующей техники.

## Анимация модели и текстур

Эффект `model3d` поддерживает анимацию 3D-модели в маске и анимацию текстур, которые накладываются на модель.

### Анимация модели

Что настроить анимацию 3D-модели в маске, используйте параметры `animation`. Подробное описание этих параметров, а также описание того, как подготовить и анимировать модель, — в разделе [Анимация 3D-моделей](masks/animation/models).

### Анимация накладываемых текстур

Анимация текстур позволяет оживить поверхность 3D-модели. Можно анимировать текстуры различных типов: `diffuse`,`normal`, `specular`, `environment`, `emissive`.

Для анимации текстуры движок масок зачитывает кадры из отдельных PNG-файлов и воспроизводит их последовательно. Для указания первого кадра, задания скорости воспроизведения и других настроек включите в параметры текстуры группу  `animation`. Подробное описание — в разделе [Анимация текстур](masks/animation/textures).
