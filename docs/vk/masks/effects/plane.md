# plane

> Источник: [https://dev.vk.ru/ru/masks/effects/plane](https://dev.vk.ru/ru/masks/effects/plane)
## Об эффекте

**plane** добавляет к маске плоскость с наложенным на неё материалом. Используя текстурные карты этого материала, вы можете контролировать цвет, рельеф, интенсивность блика, самосвечение и другие параметры для достижения желаемого результата.

Эффект `plane` подобен эффекту [`patch`](masks/effects/patch), но по сравнению с последним лучше смотрится при работе с масками, в которых используется перспективная проекция.

`plane` относится к группе 3D-эффектов.

## Пример

```JSON
{
    "icon": "my-mask-icon.png",
    "effects": [
        {
            "name": "plane",
            "anchor": "forehead",
            "material": {
                "technique": "Techniques/DiffUnlit.xml",
                "textures": {
                    "diffuse": "Textures/Cap_diffuse.png"
                }
            },
            "position": [0, 45, 10],
            "rotation": [10, 0, 0],
            "scale": [28, 28, 28]
        }
    ]
}
```

## Параметры эффекта

| Параметр     | Описание                                                     |
| ------------ | ------------------------------------------------------------ |
| `name`       | Название эффекта. Должно быть `"plane"`.&#x0d;&#x0a;Тип данных: `string`. |
| `anchor`     | Точка привязки плоскости:&#x0d;&#x0a; &bullet; `face` &mdash; центр лица.&#x0d;&#x0a; &bullet; `right_eye` &mdash; правый глаз.&#x0d;&#x0a; &bullet; `left_eye` &mdash; левый глаз.&#x0d;&#x0a; &bullet; `middle_eyes` &mdash; переносица.&#x0d;&#x0a; &bullet; `forehead` &mdash; лоб.&#x0d;&#x0a; &bullet; `nose` &mdash; нос.&#x0d;&#x0a; &bullet; `mouth` &mdash; центр рта.&#x0d;&#x0a; &bullet; `right_cheek` &mdash; центр правой щеки.&#x0d;&#x0a; &bullet; `left_cheek` &mdash; центр левой щеки.&#x0d;&#x0a; &bullet; `lower_lip` &mdash; нижняя губа.&#x0d;&#x0a; &bullet; `upper_lip` &mdash; верхняя губа.&#x0d;&#x0a;&#x0d;&#x0a;Тип данных: `string`. |
| `material`   | Описание материала плоскости. Материалы отвечают за то, как будет отображаться поверхность плоскости во время отрисовки. Полная информация об описании материала &mdash; в разделе [Параметры материала](#Параметры%20материала).&#x0d;&#x0a;Тип данных: `obj`. |
| `position`   | Три числа с плавающей точкой, которые определяют позицию накладываемой плоскости в трёхмерном пространстве XYZ относительно точки привязки `anchor`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `rotation`   | Три числа с плавающей точкой, которые определяют углы вращения в трёхмерном пространстве XYZ в градусах относительно точки привязки.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `scale`      | Два числа с плавающей точкой, определяющих масштаб плоскости по горизонтали и вертикали.&#x0d;&#x0a;Если плоскость не видна, проверьте, что вы не выставили слишком большой или слишком маленький масштаб.&#x0d;&#x0a;Тип данных: `array<float>[2]`. |
| `visible`    | Режим видимости эффекта. Возможно одно из следующих значений:&#x0d;&#x0a; &bullet; `always` &mdash; показывать всегда.&#x0d;&#x0a; &bullet; `face` &mdash; показывать только при обнаруженном лице.&#x0d;&#x0a; &bullet; `mouth_open` &mdash; показывать, когда открыт рот.&#x0d;&#x0a;&#x0d;&#x0a;Значение по умолчанию: `face`.&#x0d;&#x0a;Тип данных: `string`. |
| `show_delay` | Задержка появления плоскости в секундах, после того как движок масок определит открытый рот пользователя. Параметр работает только при `"visible": "mouth_open"`. По умолчанию плоскость появляется без задержек.&#x0d;&#x0a;Обратите внимание, что задержка указывается в секундах. Если нужны доли секунды, указывайте дробную часть после запятой.&#x0d;&#x0a;Тип данных: `float`. |
| `hide_delay` | Задержка исчезновения плоскости в секундах, после того как движок масок определит, что пользователь закрыл рот. Параметр работает только при `"visible": "mouth_open"`. По умолчанию плоскость скрывается мгновенно.&#x0d;&#x0a;Обратите внимание, что задержка указывается в секундах. Если нужны доли секунды, указывайте дробную часть после запятой.&#x0d;&#x0a;Тип данных: `float`. |

## Параметры материала

### material

Материалы отвечают за отображение плоскости при отрисовке. Описание материала, который накладывается на плоскость `plane`, располагается в параметре `material`.

Каждый материал содержит одну или несколько текстурных карт:

* `diffuse` — Информация о цвете и alpha-канале.
* `normal` — Информация о рельефе.
* `specular` — Информация об интенсивности и цвете блика.
* `environment` — Информация о цвете окружения.
* `emissive` — Информация о самосвечении.

#### Пример объявления материала

```JSON
{
    "icon": "my-mask-icon.png",
    "effects": [
        {
            "name": "plane",
            "anchor": "forehead",
            "material": {
                "technique": "Techniques/DiffUnlit.xml",
                "textures": {
                    "diffuse": "Textures/Cap_diffuse.png"
                }
            },
            "position": [0, 45, 10],
            "rotation": [10, 0, 0],
            "scale": [28, 28, 28]
        }
    ]
}
```


| Параметр      | Описание                                                     |
| ------------- | ------------------------------------------------------------ |
| `technique`   | Путь к файлу с данными о технике материала относительно конфигурационного файла `mask.json`. Например, `"technique": "Techniques/DiffEnvCube.xml"`. Техника материала определяет, какие проходы отрисовки будет выполнять  движок масок для отображения материала.&#x0d;&#x0a;Файлы с базовыми техниками материалов необязательно помещать в папку, содержащую файлы маски. Они могут подгружаться из [встроенных ресурсов](masks/development/assets). Подробнее о доступных файлах техник — в разделе [technique](#technique).&#x0d;&#x0a;Тип данных: `string`. |
| `textures`    | Набор параметров для сопоставления текстурных карт (`diffuse`, `normal`, `specular`, `environment`, `emissive`). Подробнее — в разделе [textures](#textures).&#x0d;&#x0a;Тип данных: `obj`. |
| `parameters`  | Набор параметров для задания цветовых настроек для отображения текстур. Смотрите раздел [parameters](#parameters).&#x0d;&#x0a;Тип данных: `obj`. |
| `renderorder` | Порядковый номер материала во время отрисовки. Значение по умолчанию: `128`.&#x0d;&#x0a;Тип данных: `int`. |
| `cull`        | Сторона материала для отрисовки:&#x0d;&#x0a; &bullet; `ccw` &mdash; только внешняя.&#x0d;&#x0a; &bullet; `cw` &mdash; только внутренняя.&#x0d;&#x0a; &bullet; `none` &mdash; и внешняя, и внутренняя.&#x0d;&#x0a;&#x0d;&#x0a;По умолчанию отрисовывается внешняя сторона материала.&#x0d;&#x0a;Тип данных: `string`. |

### technique

Термин &laquo;техника&raquo; применительно к отрисовке материалов означает порядок и правила отрисовки. Параметр `technique` указывает на файл, который описывает технику отрисовки.

Во [встроенных ресурсах](masks/development/assets) доступны следующие файлы техник:

* NoTexture.xml
* NoTextureAlpha.xml
* NoTextureEnvCube.xml
* NoTextureEnvCubeAlpha.xml
* NoTextureNormal.xml
* NoTextureNormalAlpha.xml
* NoTextureUnlit.xml
* NoTextureUnlitAlpha.xml
* Diff.xml
* DiffMultiply.xml
* DiffEmissive.xml
* DiffEmissiveAlpha.xml
* DiffEnvCube.xml
* DiffEnvCubeAlpha.xml
* DiffNormal.xml
* DiffNormalAlpha.xml
* DiffNormalAlphaMask.xml
* DiffNormalEmissive.xml
* DiffNormalEmissiveAlpha.xml
* DiffNormalEnvCube.xml
* DiffNormalEnvCubeAlpha.xml
* DiffNormalSpec.xml
* DiffNormalSpecAlpha.xml
* DiffNormalSpecAlphaMask.xml
* DiffSpec.xml
* DiffSpecAlpha.xml
* DiffSpecAlphaMask.xml
* DiffUnlit.xml
* DiffUnlitAlpha.xml
* DiffUnlitAlphaMask.xml

Каждое имя включает несколько подстрок (`Diff`, `Alpha`, `Unlit` и другие). Они отражают наличие или отсутствие определённых свойств материала.

| Подстрока     | Значение                                                     |
| ------------- | ------------------------------------------------------------ |
| **NoTexture** | У материала отсутствует `diffuse` текстура. С помощью параметра [`MatDiffColor`](#parameters) можно задать цвет материала, выставив необходимые коэффициенты RGB. ![alt=Пример использования NoTexture и MatDiffColor;title=Пример использования NoTexture и MatDiffColor](deac878e5f734bd9258954c7a12e84bc3356e370bac67cc2e4d4c50a "8378697193319088794") |
| **Diff**      | У материала имеется текстура `diffuse`. С помощью параметра [`MatDiffColor`](#parameters) можно задать коэффициенты RGB пропускающего текстурой цвета. ![alt=Пример использования Diff и MatDiffColor;title=Пример использования Diff и MatDiffColor](4bce055107a9a727a9248552f22d96f1ec090518ec03638c0335d88f "3953860234734718197") |
| **Normal**    | У материала имеется текстура `normal`. ![alt=Пример использования Normal и DiffNormal;title=Пример использования Normal и DiffNormal](898e598c1b493a98eb1f8cff04c872f2756e86347be8c67bb28ea804 "-2695761252376548678") |
| **Spec**      | У материала имеется текстура `specular`. С помощью параметра [`MatSpecColor`](#parameters) тремя первыми значениями можно задать коэффициенты RGB отражающего цвета, а четвёртым — значение силы затухания блика. При этом если не задать строку `"Spec"` в названии техники материала, то по-прежнему можно управлять бликом через параметр `MatSpecColor`. ![alt=Пример использования Spec и MatSpecColor;title=Пример использования Spec и MatSpecColor](23ec354a8dca0d261aaf1011439ac131b305d7d83f179b140a476ab0 "4663437868827510381") |
| **EnvCube**   | У материала имеется текстура `environment`. С помощью параметра [`MatEnvMapColor`](#parameters) можно  задать коэффициенты RGB отражённого от окружения цвета. ![alt=Пример использования EnvCube и MatEnvMapColor;title=Пример использования EnvCube и MatEnvMapColor](6c5951ab01cbde6f699eefdd545d01c8c67a8a67f00c20dd218e8283 "5537163705064858376") |
| **Emissive**  | У материала имеется текстура `emissive`. С помощью параметра [`MatEmissiveColor`](#parameters) можете задать коэффициенты RGB яркости самосвечения. При этом если не задать строку `"Emissive"` в названии техники материала, то можно управлять самосвечением материала в целом через параметр `MatEmissiveColor`. ![alt=Пример использования Emissive и MatEmissiveColor;title=Пример использования Emissive и MatEmissiveColor](e23be3ab73b46d6ded6ee9dc1d68d1c149d6f5553f352aa761fe9bae "-917700794188665663") |
| **Unlit**     | Цвет материала не зависит от источников света.![alt=Влияние Unlit;title=Влияние Unlit](82979ad2aae251072d25342e80c660c36850e8014223af7092e13006 "-8083226995836614431") |
| **Alpha**     | Материал полупрозрачный. Прозрачность отдельных пикселей определяется alphа-каналом `diffuse` текстуры. С помощью параметра [`MatDiffColor`](#parameters) в поле `value` тремя первыми значениями можно задать коэффициенты RGB пропускающего текстурой цвета, а четвёртым — коэффициент прозрачности материала в целом. Обратите внимание: движок масок отрисовывает объекты с подстрокой `"Alpha"` в названии техники материала после всех остальных объектов. |
| **AlphaMask** | Материал в каких-то местах полностью прозрачный, а в каких-то – нет. При этом, в отличие от техники `"Alpha"`, прозрачность у `"AlphaMask"` определяется следующим образом: если значение alpha-канала у пикселя `diffuse` текстуры меньше или равно `0.5`, то материал полностью прозрачный, если более `0.5`, то материал в этом месте непрозрачный. |
| **Multiply**  | Материал будет накладываться на фон в режиме `Multiply` &mdash; режим &laquo;умножение&raquo; (аналогичный термин используется в графических редакторах). |

### textures

Параметр `textures` служит для указания файлов текстурных карт материала. Пример:

```JSON
{
    "icon": "my-mask-icon.png",
    "effects": [
        {
            "name": "plane",
            "anchor": "forehead",
            "material": {
                "technique": "Techniques/DiffUnlit.xml",
                "textures": {
                    "diffuse": "Textures/Cap/Logo_diffuse.png",
                    "environment": "Textures/Cap/Environment.png"
                }
            }
        }
    ]
}
```

| Параметр      | Описание                                                     |
| ------------- | ------------------------------------------------------------ |
| `diffuse`     | Путь до файла текстуры `diffuse`.&#x0d;&#x0a;Тип данных: `string`. |
| `normal`      | Путь до файла текстуры `normal`.&#x0d;&#x0a;Тип данных: `string`. |
| `specular`    | Путь до файла текстуры `specular`.&#x0d;&#x0a;Тип данных: `string`. |
| `environment` | Путь до файла текстуры `environment`. Смотрите [Создание файла текстуры environment](#Создание%20файла%20текстуры%20environment). &#x0d;&#x0a;Тип данных: `string`. |
| `emissive`    | Путь до файла текстуры `emissive`.&#x0d;&#x0a;Тип данных: `string`. |

Примечания:

* Все параметры должны указывать файловые пути относительно конфигурационного файла маски (`mask.json`). 

* Поддерживаемые форматы изображений для всех текстур: PNG и JPEG.

#### Создание файла текстуры environment

1. Текстура вида environment создаётся на основе 360-панорамных HDRI-изображений. Сделайте такую панорамную фотографию или скачайте готовое HDRI-изображение с одного из сайтов, например с [https://polyhaven.com/hdris](https://polyhaven.com/hdris).

2. Сконвертируйте ваше изображение в cubemap-развёртку с помощью сервиса [https://berrymoor.github.io/cubemap/](https://berrymoor.github.io/cubemap/).&#x0d;&#x0a;Сохраните сконвертированное изображение как файл PNG или JPEG.

3. Разместите файл в папке с файлами маски (мы рекомендуем сохранять текстуры в подпапке `Textures`). Укажите путь до файла в параметре `environment`:

```JSON
{
  ...
      "material": {
        "technique": "Techniques/DiffUnlit.xml",
        "textures": {
           "environment": "Textures/Cap/Environment.png"          
        }
      }
  ...
}
```

Теперь плоскость, которую добавляет эффект `plane`, будет использовать вашу текстуру `environment`.

### parameters

Это поле служит для задания цветовых настроек текстур материала.

| Параметр           | Описание                                                     |
| ------------------ | ------------------------------------------------------------ |
| `MatDiffColor`     | Коэффициенты RGBA для текстуры `diffuse`.&#x0d;&#x0a;Тип данных: `array<float>[4]`. |
| `MatSpecColor`     | Последовательность из 4 чисел с плавающей точкой. Три первые значения задают коэффициенты RGB для текстуры `specular`, а четвёртый — значение силы затухания блика.&#x0d;&#x0a;Тип данных: `array<float>[4]`. |
| `MatEnvMapColor`   | Коэффициенты RGB для отражённого от окружения света или текстуры `environment`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |
| `MatEmissiveColor` | Коэффициенты RGB яркости самосвечения или текстуры `emissive`.&#x0d;&#x0a;Тип данных: `array<float>[3]`. |

### Особые случаи

* Для техник `Diff`, `Normal`, `Spec`, `EnvCube`, `Emissive` обязательно наличие соответствующей текстуры.

* Допустимо управление параметрами `MatDiffColor`, `MatEmissiveColor`, `MatSpecColor` без объявления соответствующей техники.

### textures/animation

Эффект `plane` поддерживает анимацию накладываемых текстур. Такая анимация позволяет оживить поверхность.

Анимировать можно текстуры различных типов: `diffuse`,`normal`, `specular`, `environment`, `emissive`. 

Для анимации текстуры движок масок зачитывает кадры из отдельных PNG-файлов и воспроизводит их последовательно. Для указания настроек анимации добавьте в параметры текстуры группу `animation`. Подробное описание — в разделе [Анимация текстур](masks/animation/textures).
