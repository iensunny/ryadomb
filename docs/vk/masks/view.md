# Просмотр маски

> Источник: [https://dev.vk.ru/ru/masks/view](https://dev.vk.ru/ru/masks/view)
Для просмотра маски необходимо мобильное устройство или компьютер с камерой. На мобильном устройстве должно быть установлено официальное приложение ВКонтакте.

## Просмотр маски на компьютере

### Шаг 1. Установите приложение для просмотра

#### Windows

1. Скачайте приложение  [test.mask для Windows](https://mask.vk.me/app/test.mask3_windows.zip). Извлеките содержимое архива.
1. Найдите `test.mask3_windows` — это и есть основной файл приложения. Щёлкните дважды по файлу, чтобы запустить приложение.

Рекомендуем сразу создать ярлык приложения на рабочем столе.

##### Запуск test.mask с консолью

Если маска работает неправильно или вовсе не запускается, то разобраться в проблеме помогут сообщения об ошибках и другая информация, которую приложение выводит в консоль. По умолчанию консоль скрыта.

Чтобы приложение test.mask открывалось с консолью, необходимо изменить его настройки:

1. Создайте ярлык приложения test.mask.
1. Откройте правой кнопкой мыши свойства ярлыка.
1. В конце строки `Объект` через пробел допишите: `-console`.
1. Сохраните настройки.

#### macOS

1. Скачайте приложение [test.mask для macOS](https://mask.vk.me/app/test.mask3_macos.zip). Извлеките содержимое архива.
1. Найдите `test.mask3_macos` — это и есть основной файл приложения. Щёлкните дважды по файлу, чтобы запустить приложение.

> В macOS консоль с сообщениями об ошибках запускается по умолчанию.

###  Шаг 2. Откройте маску в приложении

#### Windows

1. В приложении test.mask нажмите на кнопку **Open mask**.
1. Зайдите через проводник в каталог с вашей маской, выберите файл `mask.json` и нажмите **Открыть**. Если вы всё сделали правильно, то увидите маску на своём лице.

#### macOS

1. В меню приложения test.mask выберите **File** → **Open Mask...** .
1. Выберите каталог с проектом маски и нажмите **Open**. Если вы всё сделали правильно, то увидите маску на своем лице.

## Просмотр маски в мобильном приложении

1. Откройте на компьютере папку с проектом вашей маски и упакуйте все файлы и папки внутри неё в ZIP-архив. Обратите внимание, необходимо архивировать не папку проекта, а файлы и папки внутри проекта.
1. Откройте сообщество [Маски ВКонтакте](https://vk.com/msx) и нажмите **Написать сообщение**.
1. Прикрепите ZIP-архив к сообщению и отправьте его. В ответ бот пришлёт вам ссылку на маску. Например такую:
    ```
    https://vk.com/mask66629999_17689
    ```
1. Откройте ссылку на мобильном устройстве. Если вы всё сделали правильно, то увидите маску на своём лице. Маска будет видна только вам, её автору (см. раздел [Уровни доступа](masks/publication/overview)).

## FAQ

### Как получить ссылку на маску?

Нужно [отправить архив с готовой маской](#Просмотр%20маски%20в%20мобильном%20приложении) боту.

### Моя маска не открывается у друзей.

Сначала маску может тестировать только её автор. Если вы хотите показать свою маску друзьям, сперва её нужно [отправить на модерацию](masks/publication/moderation).

### Моя маска не отображается в каталоге.

Чтобы ваша маска появилась в каталоге, её нужно [отправить на модерацию](masks/publication/moderation).

### После загрузки архива не появляется ни ссылка на маску, ни ошибка.

![alt=Маска загружается и скоро будет доступна;title=Маска загружается и скоро будет доступна](db856c8dd9ad19bbc3c6211a82d0f75ac2d61a036a8d08c7e1547cc8 "-4356079128229541997")

Чаще всего ссылку на маску не получается создать из-за проблем с архивом. Попробуйте найти и исправить проблему так:

1. **Удалите файлы скриптов**. Если в вашей маске не используются скрипты, удалите все файлы с расширением `.as` — обычно это файл `main.as`, а также содержимое папок `Scripts` и `ScriptEngine`.

1. **Проверьте формат изображений.** Чаще всего такая ошибка случается в macOS, если при сохранении изображения в графическом редакторе не указать формат файла явно. Проверьте, что все изображения сохранены в формате PNG. Не полагайтесь только на название файла — расширение `.png` не гарантирует, что используется именно PNG. Один из признаков неверного формата — большой вес файла.

    ![alt=Выбирайте формат PNG при сохранении;title=Выбирайте формат PNG при сохранении](5781ec295f045499653c81bafa2edbc6a1ad3a8ef7c3675dbc3883b3 "-5218902659859092982")

### Маска загрузилась, но не отображается в камере, хотя в приложении для тестирования всё было в порядке.

Обычно такая проблема связана с чувствительностью мобильных устройств к регистру символов. Например, текстура расположена по адресу `Textures/Stars.png`, а в файле конфигурации путь к ней описан в нижнем регистре (маленькими буквами), как в примере ниже. Такая маска не будет работать на мобильном устройстве. Чтобы решить проблему, поправьте описание пути к текстуре с учётом регистра.

```JSON
    {
        ...
        "effects" : [
            {
                "name" : "patch",
                "textures" : "textures/stars.png",
                ...
            }
        ]
    }
```

### [Ошибка] ZIP-архив содержит повторяющиеся имена файлов

![alt=Архив содержит повторяющиеся имена файлов;title=Архив содержит повторяющиеся имена файлов](cfc09de8f8276a8a3a91e2387e79eb21f2e879f1b4d838adc9273db5 "-6155024118646842628")

Ошибка возникает в следующих случаях:

* В архиве присутствует папка верхнего уровня, в которой находятся файлы маски. Перепакуйте архив, не включая в него папку верхнего уровня. Добавьте файлы так, как описано в вопросе [В корне архива не найден файл `mask.json`](#[Ошибка]%20в%20корне%20архива%20не%20найден%20файл%20mask.json).

* Проблема связана с встроенным архиватором macOS. Он создаёт скрытые файлы с повторяющимися именами. Попробуйте использовать другой архиватор, например бесплатный [архиватор Keka](https://www.keka.io/ru/). Скачайте его, запустите и в настройках установите галочку **Исключить вилки ресурсов Mac**. После этого перетащите нужные файлы в окно архиватора Keka, чтобы создать архив маски.

### [Ошибка] в корне архива не найден файл `mask.json`

Эта ошибка может возникнуть в двух случаях: либо в вашем архиве действительно отсутствует файл `mask.json`, либо вы упаковали в ZIP-архив лишние папки.

Если все файлы маски находятся, например, в папке `Stars`, то в архив надо поместить именно содержимое `Stars`, а не саму папку. В примерах ниже показано, как архивировать правильно, а как — неправильно.
