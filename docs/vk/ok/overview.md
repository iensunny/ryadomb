# Приложения в Одноклассниках

Приложения и игры, созданные на платформе VK Mini Apps, можно опубликовать в [Одноклассниках](https://ok.ru). Вся настройка выполняется в панели управления игры или мини-приложения на [единой платформе](https://dev.vk.com/ru/admin/apps-list).

При создании приложений для Одноклассников важно учитывать их отличия от приложений, размещённых ВКонтакте.

## Требования

* Не используйте внешние ссылки — они не должны уводить пользователя из Одноклассников. Проверьте, что при шаринге приложения ссылки не ведут ВКонтакте или на другие сайты.
* Храните прогресс для каждой соцсети отдельно. Прогресс пользователей Одноклассников сохраняйте на бэкенде приложения и синхронизируйте между устройствами.

## Разработка

### Библиотека VK Bridge

Учитывайте особенности событий VK Bridge при работе на платформе Одноклассники. В [таблице](ok/development/bridge) мы указали все события, которые поддерживаются в Одноклассниках.

Рекомендуем обратить особое внимание на [методы социальных механик](ok/development/bridge#Социальные%20механики%20и%20взаимодействие), а также:
* [`VKWebAppGetClientVersion`](bridge/VKWebAppGetClientVersion)
* [`VKWebAppCallAPIMethod`](bridge/VKWebAppCallAPIMethod)
* [`VKWebAppGetAuthToken`](bridge/VKWebAppGetAuthToken)

### API Одноклассников

Чтобы обратиться к API Одноклассников:

1. Вызовите сначала событие [`VKWebAppGetAuthToken`](bridge/VKWebAppGetAuthToken) для получения ключа доступа. В параметре `append_local` укажите значение `true`. Ключ доступа для Одноклассников вернётся в ответе в поле `local_access_token`.
1. Вызовите нужный метод API c помощью события [`VKWebAppCallAPIMethod`](bridge/VKWebAppCallAPIMethod), указав нужный метод. В параметре `use_local` укажите значение `true`.

### Параметры запуска

Если приложение работает в Одноклассниках, оно получает другие значения параметров запуска. Подробнее — в разделе [Параметры запуска в Одноклассниках](ok/development/launch-parameters).

## Публикация

Опубликовать мини-приложения и игры можно сразу и ВКонтакте, и в Одноклассниках. Для этого в панели управления подайте заявки на модерацию на платформы Web и Mobile и выберите площадки для публикации: ВКонтакте или Одноклассники. Игры в Одноклассниках будут размещены в каталоге, мини-приложения станут доступны по ссылке всем пользователям.

Подробнее — в разделе [Публикация в Одноклассниках](ok/publishing).

## Монетизация

### Реклама

Если в вашем приложении ВКонтакте уже подключена рекламная монетизация, объявления автоматически будут показываться и в Одноклассниках.

Подробнее — в разделах:

* [VK Games | Монетизация | Реклама в играх](games/monetization/ad/overview)
* [Мини-приложения | Монетизация | Реклама в мини-приложениях](mini-apps/monetization/ad/overview)

### Голоса и ОКи

ВКонтакте и Одноклассники используют [голоса](mini-apps/glossary#Голос) и [ОКи](mini-apps/glossary#ОКи) — условные единицы, которые пользователи могут обменять на виртуальные ценности.

Код и настройки приложения нужно адаптировать под каждую социальную сеть, чтобы голоса использовались только ВКонтакте, а ОКи — в Одноклассниках.

Подробнее об использовании ОКов в Одноклассниках — в разделах:

* [Продажа виртуальных ценностей](api/payments/virtual-goods/ok)
* [Продажа подписок](api/payments/subscriptions/ok)
* [Обработка платёжных уведомлений](api/payments/notifications/ok)

## Продвижение

* Используйте социальные механики — обратите внимание на соответствующие [события библиотеки VK Bridge](ok/development/bridge#Социальные%20механики%20и%20взаимодействие).
* После размещения игры в каталоге Одноклассников вы сможете продвигать её через фичеринг, добавление в подборки и другие доступные способы продвижения.

Подробнее — в разделе [Продвижение](ok/promotion/overview).
