# Оповещения всем пользователям приложения

Чтобы отправить оповещение пользователям приложения в Одноклассниках, чьи профили соответствуют заданным критериям, используйте метод API Одноклассников `notifications.sendMass`.

Подробнее о работе с API Одноклассников — в разделе [Вызовы API на стороне сервера](ok/development/api#Вызовы%20API%20на%20стороне%20сервера).

## Ограничения

* Оповещения получат только пользователи, которые запускали приложение не более 7 дней назад.
* У пользователя может отображаться только одно оповещение от приложения, поэтому новое оповещение заменит предыдущее, если оно ещё не закрыто.

## Параметры запроса

При обращении к API Одноклассников также необходимо передать [общие параметры запроса](ok/development/api#Общие%20параметры).

| Поле | Тип | Описание |
| --- | --- | --- |
| `text` | `string` | **Обязательное поле**. Текст оповещения. Максимум 100 символов. Допускается не более 5 спецсимволов или эмодзи. |
| `expires` | `string` | **Обязательное поле**. Дата и время, до которых оповещение активно. Формат: `гггг.ММ.дд ЧЧ:мм`. Значение должно быть не более чем на 14 дней позже текущей даты. Часовой пояс MSK (UTC+03:00). |
| `status` | `string` | Видимость оповещения. Возможные значения: &#x0d;&#x0a; &nbsp;&nbsp; &bullet; `PUBLIC` или `P` — пользователи приложения (используется по умолчанию). &#x0d;&#x0a; &nbsp;&nbsp; &bullet; `ADMINS_ONLY` или `A` — разработчики приложения. |
| `gender` | `string` | Пол получателей по данным профиля. Возможные значения: &#x0d;&#x0a; &nbsp;&nbsp; &bullet; `MALE` или `M`. &#x0d;&#x0a; &nbsp;&nbsp; &bullet; `FEMALE` или `F`. |
| `age_range` | `string` | Возрастной диапазон получателей. Формат: `<мин>-<макс>`, например `20-25`. |
| `birthday_range` | `string` | Диапазон дат рождения получателей. Формат `ММ.дд-ММ.дд`. |
| `country` | `string` | Код страны в профиле пользователя. |
| `city` | `string` | Код города в профиле пользователя. |
| `custom_button_key` | `string` | [Ключ кнопки действия](#Кнопка%20действия%20в%20оповещении) в оповещении. По умолчанию `button_launch` (Начать играть). |

## Параметры ответа

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `string` | Идентификатор рассылки в формате: `t12345678912345000_123_m`. |

## Пример

Отправить массовое оповещение «Вашему другу нужна помощь» всем пользователям, которые соответствуют критериям: пол мужской, возраст 20–25 лет. Оповещение будет активно до 12:00 5 августа 2026 года. В оповещении отобразится кнопка «Подробнее».

Если запрос выполнен успешно, в результате вернётся идентификатор рассылки в формате `t12345678912345000_123_m`.

### CURL

```bash
curl 'https://api.ok.ru/fb.do' \
  -X POST \
  -F 'application_key=<публичный_ключ>' \
  -F 'method=notifications.sendMass' \
  -F 'text=Вашему другу нужна помощь' \
  -F 'expires=2026.07.30 12:00' \
  -F 'status=PUBLIC' \
  -F 'custom_button_key=button_more' \
  -F 'sig=<подпись_запроса>'
```

### JavaScript (Node.js)

```JavaScript
const params = {
    text: 'Вашему другу нужна помощь',
    expires: '2026.08.05 12:00',
    status: 'PUBLIC',
    gender: 'M',
    age_range: '20-25',
    custom_button_key: 'button_more'
};

callAPI('notifications.sendMass', params)
    .then(data => console.log(data));
```

> Пример функции `callAPI` с формированием подписи запроса описан в разделе [Работа с API Одноклассников](ok/development/api#Примеры).

## Прекратить рассылку

Чтобы отменить рассылку оповещений, используйте метод `notifications.stopSendMass`. В поле `id` передайте идентификатор рассылки, полученный в [ответе на запрос `notifications.sendMass`](#Параметры%20ответа):

```bash
curl 'https://api.ok.ru/fb.do' \
  -X POST \
  -F 'application_key=<публичный_ключ>' \
  -F 'method=notifications.stopSendMass' \
  -F 'id=<идентификатор_рассылки>' \
  -F 'sig=<подпись_запроса>'
```

## Кнопка действия в оповещении

Вы можете выбрать, какой текст будет отображаться на кнопке действия в оповещении:

* `button_join` — Вступить.
* `button_accept` — Принять.
* `button_attach_badge` — Прикрепить.
* `button_attend` — Я пойду.
* `button_close` — Закрыть.
* `button_confirmFriend` — Подтвердить.
* `button_decline` — Отклонить.
* `button_enable` — Включить.
* `button_hide` — Скрыть.
* `button_install` — Установить.
* `button_launch` — Начать играть.
* `button_launch_app` — Запустить.
* `button_more` — Подробнее.
* `button_open` — Посмотреть.
* `button_open_all` — Посмотреть все.
* `button_pay` — Оплатить.
* `button_realProlong` — Продлить.
* `button_rejectRequest` — Отказать.
* `button_sendPresent` — Подарить.
* `button_show` — Показать.
* `button_subscribe` — Подписаться.
* `button_unsubscribe_cancel` — Отменить.
* `button_use_coupon` — Использовать купон.
* `button_view` — Посмотреть, что внутри.
