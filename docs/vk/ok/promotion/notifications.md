# Оповещения в Одноклассниках

Вы можете отправлять пользователям в Одноклассниках оповещения — сообщения, которые напоминают о приложении, помогают удерживать активных пользователей и возвращать тех, кто давно не открывал приложение. 

Для отправки оповещений используйте методы API Одноклассников:

* [`notifications.sendSimple`](ok/promotion/notifications/user#Отправить%20оповещение%20одному%20пользователю) — чтобы отправить оповещение одному пользователю по его идентификатору.
* [`notifications.sendList`](ok/promotion/notifications/user#Отправить%20массив%20оповещений%20разным%20пользователям) — чтобы отправить массив оповещений разным пользователям по их идентификаторам одним запросом.
* [`notifications.sendMass`](ok/promotion/notifications/group) — чтобы отправить оповещение пользователям приложения, чьи профили соответствуют заданным критериям.

Подробнее о работе с API Одноклассников — в разделе [Вызовы API на стороне сервера](ok/development/api#Вызовы%20API%20на%20стороне%20сервера).
