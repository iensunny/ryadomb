# Параметры запуска игр и мини-приложений

> Источник: [https://dev.vk.ru/ru/api/app-run-parameters](https://dev.vk.ru/ru/api/app-run-parameters)
При запуске игры или мини-приложения ВКонтакте в него передаются данные об источнике запуска, пользователе, его правах доступа и другая информация.

## Игры

Подробнее о параметрах запуска игр — в разделе [Список параметров](games/development/parameters).

Также в разделе [Архив](games/development/parameters/old) приведены устаревшие параметры запуска. Архивные параметры не используются в играх, которые были созданы после 8 августа 2024 года.

## Мини-приложения

Подробнее о параметрах запуска мини-приложений — в разделе [Список параметров](mini-apps/development/launch-params).
