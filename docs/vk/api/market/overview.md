# Товары ВКонтакте

> Источник: [https://dev.vk.ru/ru/api/market/overview](https://dev.vk.ru/ru/api/market/overview)
Товары ВКонтакте – это витрина с товарами и услугами в вашем сообществе ВКонтакте. 

![title=Блок с товарами на главной странице сообщества](f6056150db7319b292c37ba758d87bb660218de2edd493353e590dea "-7475762717591151946")

Действующие интернет-магазины смогут привлечь новых клиентов с помощью товаров ВКонтакте. А для начинающих предпринимателей сервис поможет сократить расходы на создание отдельного сайта для продаж.

## Как это работает?

Вы добавляете в сообщество товары с фотографиями, ценами и подробным описанием. Чтобы клиенты могли быстро разобраться в ассортименте, используйте подборки – коллекции товаров по категориям. 

В настройках сообщества вы можете выбрать валюту магазина, регионы доставки, контактное лицо. Подробнее — в документации [Помощь: Маркет](https://vk.com/support?act=faqs&c=131).

## API для товаров

API позволяет автоматизировать работу с товарами и заказами. Используйте готовое решение для импорта товаров из внешней базы или создайте собственный инструмент. 

Подробнее о методах API ВКонтакте для работы с товарами в сообществах мы рассказали в разделе [API для товаров](api/market/getting-started).
