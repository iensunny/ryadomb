# API для товаров

Добавлять [товары в сообщества](api/market/overview) ВКонтакте можно вручную или программно, с помощью API ВКонтакте. Мы объединили такие запросы в группу [`market`](method/market). Этот раздел рассказывает, как их использовать.

## Подготовка к работе

### 1. Подготовьте сообщество

Сообщества ВКонтакте могут содержать материалы разных видов. Один из них — товары. По умолчанию товары в сообществах отключены. Для работы API-запросов их необходимо подключить.

Подключить товары может администратор сообщества.

1. Откройте страницу сообщества и в меню справа нажмите на **Управление**.

1. Перейдите в **Настройки &rarr; Разделы**.

1. Включите раздел **Товары**.

1. В браузере откройте страницу [id.vk.com/business/go](https://id.vk.com/business/go?utm_source=dev_vk&utm_medium=referral&utm_campaign=docs_api_market_getting_Started_link_VKID).
1. Войдите в сервис авторизации под своим аккаунтом VK ID и разрешите запрашивать доступ к данным вашего аккаунта.

### 3. Включите доступ к товарам

После создания приложения вы можете настраивать его в [личном кабинете](https://id.vk.com/about/business/go). 

Вам необходимо включить расширенный доступ **Товары**. Чтобы его включить, пройдите [верификацию](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/verification) и напишите на почту [devsupport@corp.vk.com](mailto:devsupport@corp.vk.com).

### 4. Запустите авторизацию

В результате авторизации пользователя вы получите значение `code`, которое нужно обменять на ключ доступа пользователя. 

Подготовьте параметры для авторизации и откройте в браузере URL следующего вида:

```URL
https://id.vk.com/authorize?response_type=code&client_id=12345&scope=email%20phone&redirect_uri=https%3A%2F%2Fyour.site&state=XXXRandomZZZ&code_challenge=K8KAyQ82WSEncryptedVerifierGYUDj8K&code_challenge_method=S256
```

### 5. Получите ключ доступа

После успешного входа в VK ID произойдёт редирект на адрес, указанный в `redirect_uri`. Данные авторизации пользователя вы найдёте в `url` в параметре `payload`.

Чтобы получить ключ доступа, обменяйте значение `code` в параметре `payload` на ключ доступа с помощью запроса:

```bash
curl -X POST 'https://api.vk.ru/method/market.edit' \
  -H 'Authorization: Bearer <КЛЮЧ_ДОСТУПА>' \
  -F 'owner_id=-123456' \
  -F 'item_id=10243117' \
  -F 'main_photo_id=457239024' \
  -F 'v=:version'
```

После получения ключа доступа вы готовы к работе с API ВКонтакте. Время жизни токена — 1 час. Когда оно истечёт, нужно получить новый. 

Подробнее — в разделе [Обработка результата авторизации](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/start-integration/auth-without-sdk/auth-without-sdk-web#Obrabotka-rezultata-avtorizacii) документации VK ID.

## Работа с товарами

### Добавление товара

#### Подготовка

* Каждый товар должен принадлежать какой-то категории. Идентификатор категории надо будет указать при добавлении товара.

    <!--Чтобы получить список возможных категорий, выполните запрос [`market.getCategories`](method/market.getCategories).-->

* Чтобы указать картинку товара, изображение надо предварительно загрузить в сообщество. Этот процесс включает несколько шагов. Подробности — в разделе [Загрузка фотографии для товара в сообществе](api/upload/photo-in-market).

    Фотографию можно указать при добавлении товара в сообщество или позже, при редактировании свойств товара.

#### Добавление товара в сообщество

Чтобы добавить товар в сообщество, отправьте API-запрос [`market.add`](method/market.add). Передайте следующие обязательные параметры:

| Обязательный параметр | Описание |
| --- | --- |
| `owner_id` | Идентификатор вашего сообщества.&#x0d;&#x0a;&#x0d;&#x0a;Идентификатор сообщества — отрицательное число, поэтому в параметре указывайте его со знаком «минус». |
| `name` и&#x0d;&#x0a;`description` | Название и описание товара. |
| `category_id` | Идентификатор категории товара. Если вы не знаете идентификатор нужной категории, укажите значение `1`. |

Также в запросе вы можете указать необязательные параметры.

| Необязательный параметр | Описание |
| --- | --- |
| `price` | Цена товара. Формат данных: строка. |
| `main_photo_id` и&#x0d;&#x0a;`photo_ids` | Идентификаторы основной и дополнительной фотографии товара.&#x0d;&#x0a;&#x0d;&#x0a;Идентификаторы — строки в формате `market{owner_id}_{market_item_id}`, например `market-12345_54321`. Вы получаете их при загрузке фотографий для товаров и подписок. |
| `deleted` | Доступен ли товар пользователям. Если товар пока недоступен, передайте `deleted = 1`. В этом случае пользователи не будут его видеть. |

### Добавление изображения к товару

Процедура добавления фотографий к товарам и подпискам включает несколько шагов. Подробности — в следующих разделах: 

* [Загрузка фотографии для товара в сообществе](api/upload/photo-in-market)

| --- | --- |
| [`market.get`](market.get) | Получение списка товаров в сообществе. |

| [`market.edit`](market.edit) | Редактирование информации о товаре. |
| [`market.delete`](market.delete) | Удаление товара. |

### Действия с заказами

Чтобы получать информацию о заказах, используйте следующие API-запросы:

| API-запрос | Описание |
| --- | --- |
| [`market.getGroupOrders`](method/market.getGroupOrders) | Возвращает информацию о заказах в сообществе. |
| [`market.getOrderById`](method/market.getOrderById) | Возвращает информацию о заказе по его идентификатору. |
| [`market.getOrderItems`](method/market.getOrderItems) | Возвращает информацию о товарах в заказе. |

Для редактирования свойств заказа, например изменения его статуса, используйте API-запрос [`market.editOrder`](method/market.editOrder).

При создании или изменении заказа ВКонтакте отправляет [события](api/community-events/json-schema) `market_order_new` и `market_order_edit` вашему сообществу. Для обработки этих событий используйте инструменты [Callback API](api/callback/getting-started) или [Bots Longpoll API](api/bots-long-poll/getting-started). Вы можете сконфигурировать их в настройках сообщества.

### Работа с подборками товаров

Товары в сообществе можно объединять в подборки. Для работы с подборками используйте следующие API-запросы:

| API-запрос | Описание |
| --- | --- |
| [`market.addToAlbum`](market.addToAlbum) | Добавление товара в одну или несколько подборок. |
| [`market.addAlbum`](market.addAlbum) | Создание новой подборки товаров. |
| [`market.getAlbums`](market.getAlbums) | Получение списка подборок товаров в сообществе. |
| [`market.getAlbumById`](market.getAlbumById) | Получение подборки по её идентификатору. |
| [`market.editAlbum`](market.editAlbum) | Редактирование параметров подборки. |
| [`market.reorderItems`](market.reorderItems) | Сортировка товаров в подборке. |

### Работа с комментариями к товарам

| API-запрос | Описание |

### Поиск товаров

| API-запрос | Описание |

### Группы товаров

Товары с одинаковыми значениями свойств можно объединять в группы. Для работы с группами используйте следующие API-запросы:

| API-запрос | Описание |
| --- | --- |
| [`market.groupItems`](method/market.groupItems) | Объединение товаров в группу. |
| [`market.ungroupItems`](method/market.ungroupItems) | Удаление группы. |

### Свойства товаров

С помощью API-запросов вы можете добавлять свойства, например «Цвет», «Размер» или «Возрастная группа», к товарам, находящимся в одной группе. Для таких свойств вы также можете указывать возможные значения. Используйте для этого следующие API-запросы:

| API-запрос | Описание |
| --- | --- |
| [`market.addProperty`](method/market.addProperty) | Добавляет свойство к товарам в группе, например «Размер» или «Цвет». |
| [`market.editProperty`](method/market.editProperty) | Изменяет название или тип свойства товаров в сообществе. |
| [`market.deleteProperty`](method/market.deleteProperty) | Удаляет свойство товаров в сообществе. |
| [`market.addPropertyVariant`](method/market.addPropertyVariant) | Добавляет возможное значение свойства товаров в сообществе. Например, если вы добавили свойство «Цвет», вы можете добавить его возможные значения — «Красный» или «Фиолетовый в крапинку». |
| [`market.editPropertyVariant`](method/market.editPropertyVariant) | Редактирует параметры значения свойства товаров. |
| [`market.deletePropertyVariant`](method/market.deletePropertyVariant) | Удаляет возможное значение свойства товаров в сообществе. |
