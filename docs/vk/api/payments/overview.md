# Платежи виртуальной валютой

Продажа виртуальных ценностей — один из способов монетизации игр и мини-приложений. Продавать такие товары можно только за [голоса ВКонтакте](mini-apps/glossary#Голос) или [ОКи в Одноклассниках](mini-apps/glossary#ОКи).

[Продажа](mini-apps/monetization/payments#Продажа%20товаров%20за%20деньги) реальных товаров и услуг за денежные средства возможна только в мини-приложениях. Для выполнения таких платежей используйте другой механизм — [VK Pay](pay/getting-started).

Подробнее об особенностях продажи товаров в приложениях:

* [Продажа игровых товаров](games/monetization/digital-goods)
* [Продажа товаров в мини-приложениях](mini-apps/monetization/payments)

## Виды платежей

Поддерживаются следующие виды платежей:

* **Разовые списания** используются для покупки товаров.
* **Подписки** — для покупки и обновления подписок.

Вам не надо создавать диалоговые окна для подтверждения покупки или отсылать API-запросы своему серверу приложений. Воспользуйтесь встроенными функциями.

## Особенности использования на разных площадках

Обмен данными между приложением и площадкой имеют некоторые отличия в Одноклассниках и ВКонтакте. Используйте пошаговые инструкции для каждой площадки:

* [Покупка виртуальных ценностей ВКонтакте](api/payments/virtual-goods/vk)
* [Покупка виртуальных ценностей в Одноклассниках](api/payments/virtual-goods/ok)
* [Покупка подписок ВКонтакте](api/payments/subscriptions/vk)
* [Покупка подписок в Одноклассниках](api/payments/subscriptions/ok)
