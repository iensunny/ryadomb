# Получение информации о подписке (get_subscription)

ВКонтакте отправляет уведомление `get_subscription` серверу приложения (игры или мини-приложения) перед показом диалогового окна покупки [подписки](api/payments/subscriptions/vk). Сервер в своём ответе должен предоставить информацию о подписке, которая будет отображена в окне покупки.

## Уведомление

Данные приходят в теле запроса в виде строки, содержащей пары `параметр=значение`. Пары разделены символами `&`.

### Пример

```
app_id=1524456&item=subscription_item_1&lang=ru_RU&notification_type=get_item_test&order_id=104659&receiver_id=1&user_id=1&version=5.132&sig=b5aec4bdc12340af74a83796ee357cd3
```

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `app_id` | `integer` | Идентификатор приложения, в котором происходит действие с подпиской.&#x0d;&#x0a;&#x0d;&#x0a;Значение должно совпадать с идентификатором, который отображается в [настройках приложения](mini-apps/management/settings#Настройки). |
| `item` | `string`  | Идентификатор подписки, который используется в вашем приложении и который оно передало событию [`VKWebAppShowSubscriptionBox`](bridge/VKWebAppShowSubscriptionBox) библиотеки VK Bridge. [Пример вызова события](api/payments/subscriptions#Шаг%203.%20Вызовите%20событие%20VK%20Bridge%20для%20показа%20окна%20покупки). |
| `lang` | `string` | Язык пользователя, создавшего заказ. Возможно одно из следующих значений:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `ru_RU` — русский&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `uk_UA` — украинский&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `be_BY` — белорусский&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `en_US` — английский.&#x0d;&#x0a;&#x0d;&#x0a;Ваш сервер может проверять значение этого параметра, чтобы [возвращать описание товара на языке пользователя](api/payments/notifications/vk#Поддержка%20многоязычных%20интерфейсов). |
| `notification_type` | `string` | Тип уведомления. В рабочем режиме прохождения платежей параметр равен `get_subscription`, в [тестовом](api/payments/testing) — `get_subscription_test`. |
| `order_id` | `integer` | Идентификатор заказа в системе платежей ВКонтакте. |
| `receiver_id` | `integer` | Идентификатор пользователя, который получит заказ. В данный момент совпадает с `user_id`, но в будущем может отличаться. |
| `user_id` | `integer` | Идентификатор пользователя, создавшего заказ. |
| `version` | `string` | Версия формата данных уведомления. Совпадает с версией, указанной в настройках приложения в разделе **Платежи** в поле [Версия API](api/payments/subscriptions#Шаг%202.%20Укажите%20адрес%20обратного%20вызова%20в%20настройках%20приложения).&#x0d;&#x0a;&#x0d;&#x0a;Параметр используется только для версии `5.132` и более поздних. |
| `sig` | `string` | Подпись параметров уведомления. Позволяет защититься от подмены параметров третьими лицами. [Подробнее о подписи и её проверке](api/payments/notifications/vk#Подпись%20параметров).|

Строковые значения закодированы в URL-encoded формате, применяемом в PHP. Вам необходимо [раскодировать их](api/payments/notifications/vk#Работа%20со%20строковыми%20данными) перед обработкой.

## Ответ сервера

По идентификатору подписки, указанному в параметре запроса `item`, сервер должен вернуть информацию о подписке. Если запрашиваемая подписка отсутствует, надо вернуть ошибку с [кодом `20`](api/payments/notifications/vk#Коды%20ошибок)(«Товара не существует»).

### Пример ответа

```JSON
{
  "response": {
    "item_id": "subscription_id_1",
    "title":"+2 радиус обзора (на месяц)",
    "photo_url":"http://my-app.example.com/sale-item-images/subscription-1.png",
    "price": 24,
    "period": 7,
    "trial_duration": 3,
    "expiration": 3600
  }
}
```

### Поля

| Поле | Тип | Описание |
| --- | --- | --- |
| `item_id` | `string` | Идентификатор подписки, используемый в вашем приложении. Передайте то же значение, которое было получено в параметре `item` уведомления. |
|`title`&#x0d;&#x0a;*обязательное* | `string` | Название подписки.&#x0d;&#x0a;В названии можно указать период подписки.&#x0d;&#x0a;&#x0d;&#x0a;Максимально допустимая длина `title` — 48 символов. |
| `description` | `string` | Описание подписки.  |
| `photo_url` | `string` |  Полный URL изображения подписки (включая адрес сервера и протокол). Рекомендуемый размер изображения&nbsp;—&nbsp;75&times;75&nbsp;px. |
| `period`&#x0d;&#x0a;*обязательное* | `integer` | Период действия подписки в днях. Используйте одно из следующих значений:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `7`&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `30`&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `90`|
| `price`&#x0d;&#x0a;*обязательное* | `integer` | Стоимость подписки за указанный период в [голосах ВКонтакте](mini-apps/glossary#Голос). |
|`trial_duration` | `integer` | Длительность бесплатного пробного периода в днях. Используйте одно из следующих значений:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `3`&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `7`&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `30` |
| `expiration` | `integer` | Временной период, в течение которого платформа будет хранить информацию о подписке в кеше. Период указывается в секундах. Допустимый диапазон — от `600` до `604800`. Если значение меньше нижней или больше верхней границы, то будет установлено минимальное или максимальное значение. `0` означает отказ от кеширования. |

> **Совет**. Мы рекомендуем всегда использовать [кеширование](api/payments/notifications/vk#Кеширование%20информации%20о%20товарах%20и%20подписках). Это ускоряет процесс покупки для пользователей, а также уменьшает количество обращений к серверу приложения. Пока информация о подписке хранится в кеше, ВКонтакте использует данные из кеша и не отсылает уведомления `get_subscription` серверу.

Поля `title`, `price`, `period` должны обязательно присутствовать в ответе вашего сервера. Иначе подписка не будет оформлена.

Значения в полях ответа можно изменять в зависимости от языка пользователя, указанного в параметре `lang` запроса. То есть для одного и того же идентификатора подписки можно возвращать разные названия и изображения в зависимости от языка.

Данные для разных языков пользователя кешируются отдельно друг от друга.

### В случае ошибки

В случае ошибки нужно вернуть объект следующей структуры:

```JSON
{
  "error": {
    "error_code": 1, 
    "error_msg": "Ошибка обновления информации на сервере. Попробуйте ещё раз позже.",
    "critical": true
  }
}
```

Подробнее о полях объекта и кодах ошибок — в разделе [Формат ответа при ошибке](api/payments/notifications/vk#Формат%20ответа%20при%20ошибке).
