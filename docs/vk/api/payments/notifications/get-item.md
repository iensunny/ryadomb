# Получение информации о товаре (get_item)

> Источник: [https://dev.vk.ru/ru/api/payments/notifications/get-item](https://dev.vk.ru/ru/api/payments/notifications/get-item)
ВКонтакте отправляет уведомление `get_item` серверу приложения (игры или мини-приложения) перед показом окна [покупки](api/payments/virtual-goods/vk#Обмен%20данными%20между%20ВКонтакте%20и%20приложением). Сервер в своём ответе должен предоставить информацию, которая будет отображена в окне покупки.

## Уведомление

Данные приходят в теле запроса в виде строки, содержащей пары `параметр=значение`. Пары разделены символами `&`.

### Пример

```
app_id=1524456&item=sale_item_1&lang=ru_RU&notification_type=get_item_test&order_id=2044594&receiver_id=1&user_id=1&version=5.132&sig=a71ec5b6c78940fa47a83796ee983ab6
```

### Параметры

| **Параметр** | **Тип** | **Примечание** |
| --- | --- | --- |
| `app_id` | `integer` | Идентификатор приложения, в котором происходит покупка.&#x0d;&#x0a;&#x0d;&#x0a;Значение должно совпадать с идентификатором, который отображается в [настройках приложения](mini-apps/management/settings#Настройки). |
| `item` | `string`  | Идентификатор товара, который использует ваше приложение и который оно передало событию [`VKWebAppShowOrderBox`](bridge/VKWebAppShowOrderBox) библиотеки VK Bridge. [Пример вызова события](api/payments/virtual-goods/vk#Шаг%203.%20Вызовите%20событие%20VK%20Bridge%20для%20показа%20окна%20покупки).&#x0d;&#x0a;&#x0d;&#x0a;Сервер в своём ответе должен предоставить информацию о покупаемом товаре, которая будет отображена в окне покупки. |
| `lang` | `string` | Язык пользователя, создавшего заказ. Возможно одно из следующих значений:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `ru_RU` — русский&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `uk_UA` — украинский&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `be_BY` — белорусский&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `en_US` — английский.&#x0d;&#x0a;&#x0d;&#x0a;Ваш сервер может проверять значение этого параметра, чтобы [возвращать описание товара на языке пользователя](api/payments/notifications/vk#Поддержка%20многоязычных%20интерфейсов). |
| `notification_type` | `string` | Тип уведомления. В рабочем режиме прохождения платежей параметр равен `get_item`, в [тестовом](api/payments/testing) — `get_item_test`. |
| `order_id` | `integer` | Идентификатор заказа в системе платежей ВКонтакте. |
| `receiver_id` | `integer` | Идентификатор пользователя, который получит заказ. В данный момент совпадает с `user_id`, но в будущем может отличаться. |
| `user_id` | `integer` | Идентификатор пользователя, создавшего заказ. |
| `version` | `string` | Версия формата данных уведомления. Совпадает с версией, указанной в настройках приложения в разделе **Платежи** в поле [Версия API](api/payments/subscriptions#Шаг%202.%20Укажите%20адрес%20обратного%20вызова%20в%20настройках%20приложения).&#x0d;&#x0a;&#x0d;&#x0a;Параметр используется только для версии `5.132` и более поздних. |
| `site` | `string` | Площадка, на которой пользователь совершает покупку. &#x0d;&#x0a;`VK` — ВКонтакте. Значение по умолчанию &#x0d;&#x0a;`OK` — в Одноклассниках. |
| `sig` | `string` | Подпись параметров уведомления. Позволяет защититься от подмены параметров третьими лицами. [Подробнее о подписи и её проверке](api/payments/notifications/vk#Подпись%20параметров).|

Строковые значения закодированы в URL-encoded формате, применяемом в PHP. Вам необходимо [раскодировать их](api/payments/notifications/vk#Работа%20со%20строковыми%20данными) перед обработкой.

## Ответ сервера

По идентификатору товара, указанному в параметре запроса `item`, сервер должен вернуть информацию о товаре. Если запрашиваемый товар отсутствует, надо вернуть ошибку с [кодом `20`](api/payments/notifications/vk#Коды%20ошибок) («Товара не существует»).

### Пример ответа

```JSON
{
  "response": {
    "title": "300 изумрудов",
    "price": 27,
    "photo_url": "https://my-app.example.com/sale-item-1.png",
    "discount": 3,
    "item_id": "sale_item_1",
    "expiration": 3600
  }
}
```

### Поля

 | Поле | Тип |  Описание |
|---|---|---|
 | `title`&#x0d;&#x0a;*обязательное* | `string` | Название товара для отображения в диалоговом окне покупки. Максимальная длина — 48 символов. |
 | `photo_url` | `string` |  Полный URL изображения товара (включая адрес сервера и протокол). Рекомендуемый размер изображения&nbsp;—&nbsp;75&times;75&nbsp;px. |
 | `price`&#x0d;&#x0a;*обязательное*| `integer` | Стоимость товара в [голосах ВКонтакте](mini-apps/glossary#Голос). |
 | `discount` | `integer` | Размер скидки на товар в голосах. Значение скидки должно быть в пределах от `1` до `1 000` и должно быть меньше, чем стоимость товара, указанная в поле `price`.&#x0d;&#x0a;Если скидка не предусмотрена, верните `0` или не указывайте параметр в ответе. |
 | `item_id` | `string` | Идентификатор товара, используемый в вашем приложении. Передайте то же значение, которое было получено в параметре `item` уведомления. |
 | `expiration` | `integer` | Временной период, в течение которого платформа будет хранить информацию о товаре в кеше. Период указывается в секундах. Допустимый диапазон — от `600` до `604 800`. Если значение меньше нижней или больше верхней границы, то будет установлено минимальное или максимальное значение. `0` означает отказ от кеширования. |

> **Совет**. Мы рекомендуем всегда использовать [кеширование](api/payments/notifications/vk#Кеширование%20информации%20о%20товарах%20и%20подписках). Это ускоряет процесс покупки для пользователей, а также уменьшает количество обращений к серверу приложения. Пока информация о товаре хранится в кеше, ВКонтакте использует данные из кеша и не отсылает уведомления `get_item` серверу.

Значения в полях ответа можно изменять в зависимости от языка пользователя, указанного в параметре `lang` запроса. То есть для одного и того же идентификатора товара можно возвращать разные названия и изображения в зависимости от языка.

Данные для разных языков пользователя кешируются отдельно друг от друга.

### В случае ошибки

В случае ошибки нужно вернуть объект следующей структуры:  

```JSON
{
  "error": {
        "error_code": 20, 
        "error_msg": "Товара не существует",
        "critical": true
    }
}
```

Подробнее о полях объекта и кодах ошибок — в разделе [Формат ответа при ошибке](api/payments/notifications/vk#Формат%20ответа%20при%20ошибке).
