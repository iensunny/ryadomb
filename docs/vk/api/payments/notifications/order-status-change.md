# Изменение статуса заказа (order_status_change)

ВКонтакте отправляет уведомление `order_status_change` серверу приложения (игры или мини-приложения) в следующих случаях:

* После того как пользователь подтвердил оплату в [окне покупки](api/payments/virtual-goods/vk#Обмен%20данными%20между%20ВКонтакте%20и%20приложением) в этом приложении.

* При возврате заказа. Уведомление о возврате доступно при использовании версии `5.132` платёжного API или более поздних версий.

## Уведомление

Данные приходят в теле запроса в виде строки, содержащей пары `параметр=значение`. Пары разделены символами `&`.

### Пример

```
app_id=12345678&date=1656358147&item=sale_item_1&item_discount=3&item_id=sale_item_1_internal_id&item_photo_url=http%3A%2F%2Fmy-app.example.com%2Fsale-item-images%2Fsale-item-1.png&item_price=24&item_title=%D0%A7%D1%83%D0%B4%D0%BE-%D0%B7%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5&notification_type=order_status_change_test&order_id=2044861&receiver_id=1&status=chargeable&user_id=1&version=5.132&sig=ab87f7355c523ed8c52482b69723eef4
```

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `app_id` | `integer` | Идентификатор приложения, в котором происходит покупка.&#x0d;&#x0a;&#x0d;&#x0a;Значение должно совпадать с идентификатором, который отображается в [настройках приложения](mini-apps/management/settings#Настройки). |
 | `date` | `integer` | Дата создания заказа в Unix-формате, то есть как целое число — количество секунд, прошедших с 00:00:00 1 января 1970 года. |
| `item` | `string`  | Идентификатор товара, который используется в вашем приложении и который оно передало событию [`VKWebAppShowOrderBox`](bridge/VKWebAppShowOrderBox) библиотеки VK Bridge. [Пример вызова события](api/payments/virtual-goods/vk#Шаг%203.%20Вызовите%20событие%20VK%20Bridge%20для%20показа%20окна%20покупки). |
| `item_discount` | `integer` | Размер скидки на товар в [голосах ВКонтакте](mini-apps/glossary#Голос), если скидка применяется. Это то же значение, которое ваш сервер передал в поле `discount` ответа на уведомление [`get_item`](api/payments/notifications/get-item). |
| `item_id` | `string` | Идентификатор проданного товара, который сгенерировал ВКонтакте.&#x0d;&#x0a;&#x0d;&#x0a;Это значение используется для последующих операций с заказом. Сохраните этот идентификатор на стороне своего сервера, чтобы правильно обрабатывать запросы ВКонтакте. |
| `item_photo_url` | `string` |  Полный URL изображения товара (включая адрес сервера и протокол). Это то же значение, которое ваш сервер передал в поле `photo_url` ответа на уведомление [`get_item`](api/payments/notifications/get-item). |
| `item_price` | `integer` | Стоимость товара в [голосах ВКонтакте](mini-apps/glossary#Голос). Это то же значение, которое ваш сервер передал в поле `price` ответа на уведомление [`get_item`](api/payments/notifications/get-item). |
| `item_title` | `string` | Название товара. Это то же значение, которое ваш сервер передал в поле `title` ответа на уведомление [`get_item`](api/payments/notifications/get-item). |
| `notification_type` | `string` | Тип уведомления. В рабочем режиме прохождения платежей параметр равен `order_status_change`, в [тестовом](api/payments/testing) — `order_status_change_test`. |
| `order_id` | `integer` | Идентификатор заказа в системе платежей ВКонтакте. |
| `receiver_id` | `integer` | Идентификатор пользователя, который получит заказ. В данный момент совпадает с `user_id`, но в будущем может отличаться. |
| `status` | `string` | Статус заказа. Возможны следующие значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `chargeable` — Пользователь подтвердил оплату в окне продажи. Необходимо оформить заказ внутри приложения. В случае ответа об успехе платёжная система перечислит голоса на счёт приложения. Если в ответе будет сообщение об ошибке, заказ отменится автоматически.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `refunded` — Заказ отменён. Необходимо забрать игровые ценности, выданные пользователю за платежи. Это значение доступно в уведомлениях, [использующих формат](api/payments/virtual-goods/vk#Шаг%202.%20Укажите%20адрес%20обратного%20вызова%20в%20настройках%20приложения) версии `5.132` или более поздний. |
| `user_id` | `integer` | Идентификатор пользователя, создавшего заказ. |
| `version` | `string` | Версия формата данных уведомления. Совпадает с версией, указанной в настройках приложения в разделе **Платежи** в поле [Версия API](api/payments/virtual-goods/vk#Шаг%202.%20Укажите%20адрес%20обратного%20вызова%20в%20настройках%20приложения).&#x0d;&#x0a;&#x0d;&#x0a;Параметр используется только для версии `5.132` и более поздних. |
| `sig` | `string` | Подпись параметров уведомления. Позволяет защититься от подмены параметров третьими лицами. [Подробнее о подписи и её проверке](api/payments/notifications/vk#Подпись%20параметров).|

Строковые значения закодированы в URL-encoded формате, применяемом в PHP. Вам необходимо [раскодировать их](api/payments/notifications/vk#Работа%20со%20строковыми%20данными) перед обработкой.

## Ответ сервера

Обработчик уведомления должен выполнить следующие задачи:

* В случае, когда параметр `status` равен `chargeable`, сервер должен предоставить пользователю купленный товар и отправить ответ о проведении платежа. ВКонтакте переведёт голоса со счёта пользователя на счёт вашего приложения после того, как получит положительный ответ на это уведомление.  

* В случае, когда параметр `status` равен `refunded`, сервер должен отменить покупку и отправить ответ об успешном прохождении этой операции. После этого ВКонтакте переведёт голоса со счёта вашего приложения на счёт пользователя. На счёте приложения должна быть достаточное количество голосов для перевода.

:::note
Чтобы избежать повторных начислений товаров, реализуйте на сервере проверку по уникальному `order_id` и статусу заказа:

* Начисляйте товар по каждому `order_id` только один раз.
* Если получаете повторные уведомления, в которых статус заказа прежний, а по `order_id` уже начислен товар, возвращайте тот же успешный ответ, что и при первом начислении.
:::

### Пример ответа

При успешном выполнении операции в ответе надо вернуть объект следующей структуры:  

```JSON
{
  "response": {
    "order_id": 207184,
    "app_order_id": 6492
  }
}
```

### Поля

| Поле | Тип | Описание |
| --- | --- | --- |
| `order_id`&#x0d;&#x0a;*обязательное* | `integer` | Идентификатор заказа в системе платежей ВКонтакте. |
| `app_order_id` | `integer` | Идентификатор заказа в приложении. Это значение должно быть уникальным для каждого заказа. Оно используется для отмены заказа. |

### В случае ошибки

В случае ошибки нужно вернуть объект следующей структуры:  

```JSON
{
  "error": {
        "error_code": 21, 
        "error_msg": "Нет в наличии",
        "critical": true
    }
}
```

Подробнее о полях объекта и кодах ошибок — в разделе [Формат ответа при ошибке](api/payments/notifications/vk#Формат%20ответа%20при%20ошибке).
