# Изменение статуса подписки (subscription_status_change)

ВКонтакте отправляет это уведомление серверу приложения (игры или мини-приложения), когда пользователь подтвердил операцию покупки, отмены или возобновления подписки в этом приложении.

Подробная информация о покупке подписок и об обмене данными между ВКонтакте и серверами игр и мини-приложений — в разделе [Продажа подписок](api/payments/subscriptions/vk).

## Уведомление

### Пример

```
app_id=12345678&item_id=sale_item_subscription_1&item_price=24&next_bill_time=1656971381&notification_type=subscription_status_change_test&status=chargeable&subscription_id=subscr_internal_id_123&user_id=1&version=5.132&sig=59829d05b420870e94207024ef0b5e61
```

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `app_id` | `integer` | Идентификатор приложения, в котором происходит покупка.&#x0d;&#x0a;&#x0d;&#x0a;Значение должно совпадать с идентификатором, который отображается в [настройках приложения](mini-apps/management/settings#Настройки). |
| `cancel_reason` | `string` | Используется в случаях, когда параметр `status` равен `active` или `cancelled`.  Указывает причину отмены подписки. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `user_decision` — подписка отменена по инициативе пользователя.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `app_decision` — подписка отменена по инициативе приложения (вызов API-запроса [`orders.cancelSubscription`](orders.cancelSubscription)).&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `payment_fail` — подписка отменена из-за ошибки платежа.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `unknown` — отмена по другой причине, либо подписка была возобновлена. |
| `item_id` | `string` | Идентификатор подписки, используемый в вашем мини-приложении или игре. Это то же значение, которое использовалось для окна покупки и которое ваш сервер передал в поле `item_id` ответа на уведомление [`get_subscription`](api/payments/notifications/get-subscription). |
| `item_price` | `integer` | Стоимость подписки за период. Это то же значение, которое ваш сервер передал в поле `price` ответа на уведомление [`get_subscription`](api/payments/notifications/get-subscription). |
| `notification_type` | `string` | Тип уведомления. В рабочем режиме прохождения платежей параметр равен `subscription_status_change`, в [тестовом](api/payments/testing) — `subscription_status_change_test`. |
| `status` | `string` | Статус подписки. Возможные значения:&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `chargeable` — подписка готова к оплате. Необходимо оформить заказ пользователю внутри приложения. После получения ответа об успехе платёжная система зачислит голоса на счёт приложения. Если в ответе будет передано сообщение об ошибке, заказ будет отменён.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `active` — подписка оформлена и активна. Это уведомление приходит спустя некоторое время после `chargeable` как подтверждение того, что подписка была оформлена успешно на стороне ВКонтакте. В этом случае параметр `cancel_reason` равен `unknown`.&#x0d;&#x0a;Также `active` приходит при отмене подписки. В этом случае `cancel_reason` сообщает причину отмены. Отменённую подписку можно восстановить до окончания оплаченного периода.&#x0d;&#x0a; &nbsp;&nbsp; &bullet; `cancelled` — подписка отменена. Восстановить такую подписку нельзя. |
| `next_bill_time` | `integer` | Дата следующего платежа. Указана в Unix-формате. То есть это число — количество секунд, прошедших с 00:00:00 1 января 1970 года. |
| `pending_cancel` | `integer` | Используется в случае, когда параметр `status=active`). Если `1`, то подписка действует до конца периода. |
| `subscription_id` | `integer` | Идентификатор экземпляра подписки.&#x0d;&#x0a;&#x0d;&#x0a;**Важно!** Это значение сгенерировано ВКонтакте автоматически. Оно используется для дальнейшей работы с подпиской, например для отмены и восстановления.&#x0d;&#x0a;Мы рекомендуем сохранить это значение на стороне сервера вашего приложения, чтобы в дальнейшем давать правильные ответы на запросы платформы. |
| `user_id` | `integer` | Идентификатор пользователя, создавшего заказ. |
| `version` | `string` | Версия формата данных уведомления. Совпадает с версией, указанной в настройках приложения в разделе **Платежи** в поле [Версия API](api/payments/virtual-goods/vk#Шаг%202.%20Укажите%20адрес%20обратного%20вызова%20в%20настройках%20приложения).&#x0d;&#x0a;&#x0d;&#x0a;Параметр используется только для версии `5.132` и более поздних. |
| `sig` | `string` | Подпись параметров уведомления. Позволяет защититься от подмены параметров третьими лицами. [Подробнее о подписи и её проверке](api/payments/notifications/vk#Подпись%20параметров).|

Строковые значения закодированы в URL-encoded формате, применяемом в PHP. Вам необходимо [раскодировать их](api/payments/notifications/vk#Работа%20со%20строковыми%20данными) перед обработкой.

## Ответ сервера

Обработчик уведомления должен выполнить следующие задачи:

* В случае, когда параметр `status` равен `chargeable`, сервер должен предоставить пользователю подписку и отправить ответ о подтверждении покупки. Перевод голосов со счёта пользователя на счёт игры или мини-приложения произойдёт только после того, как ВКонтакте получит положительный ответ на это уведомление.  

* В случае, когда параметр `status` равен `cancelled`, сервер должен отменить преимущества, предлагаемые подпиской, и отправить ответ об успешном прохождении операции.

* Случай, когда параметр `status` равен `active`, а `cancel_reason` равен `user_decision` означает, что подписка была отменена по инициативе пользователя. В этом случае ваше приложение может выполнить какие-либо действия, чтобы показать преимущества подписки пользователю и подтолкнуть его к возврату.  

:::note
Чтобы избежать повторных оформлений подписок, реализуйте на сервере проверку по уникальному `order_id` и статусу заказа:

* Оформляйте подписку по каждому `order_id` только один раз.
* Если получаете повторные уведомления, в которых статус заказа прежний, а по `order_id` уже оформлена подписка, возвращайте тот же успешный ответ, что и при первом начислении.
:::

### Пример ответа

При успешном выполнении операции в ответе надо вернуть объект следующей структуры:

```JSON
{
  "response": {
    "subscription_id": 12345, 
    "app_order_id": 6492
  }
}
```

### Поля

| Поле | Тип | Описание |
| --- | --- | --- |
| `subscription_id`&#x0d;&#x0a;*обязательное* | `integer` | Идентификатор экземпляра подписки, сгенерированный ВКонтакте. |
| `app_order_id` | `integer` | Идентификатор заказа в приложении. Должен быть уникальным для каждого заказа. Используется для отмены. |

### В случае ошибки

В случае ошибки нужно вернуть объект следующей структуры:

```JSON
{
  "error": {
    "error_code": 1, 
    "error_msg": "При обработке произошла ошибка на сервере. Попробуйте ещё раз позже.",
    "critical": true
    }
}
```

Подробнее о полях объекта и кодах ошибок — в разделе [Формат ответа при ошибке](api/payments/notifications/vk#Формат%20ответа%20при%20ошибке).
