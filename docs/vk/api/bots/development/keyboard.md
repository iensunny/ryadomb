# Клавиатура

**Клавиатура чат-бота** — блок с кнопками, которые показываются на экране ввода сообщения. Они упрощают и ускоряют общение: пользователи могут отправить сообщение или запрос, не печатая текст.

![alt=Пример клавиатуры;title=Пример клавиатуры](23da71d33405de08fec50d8805eb69fbf7024196a16dad3d328de21b "616200134238115590")

Количество кнопок в блоке, их название, цвет, выполняемые действия и другие параметры можно настроить.
Это даёт возможность формировать блок в соответствии со спецификой чата или предыдущих ответов пользователя.

## Как использовать

### Включите клавиатуру в настройках сообщества

Чтобы клавиатура отображалась в окне чата, включите её:

1. Откройте ваше сообщество ВКонтакте.

1. Перейдите на страницу **Управление&nbsp;&rarr; Сообщения** и включите **Сообщения сообществ**.

    ![alt=Включение сообщений сообществ;title=Включение сообщений сообществ](6bc865352846259bfd68a6cb4e4ef1af880f49744db1c9f7fa1b44c5 "4769949190848485831")

    Сохраните изменения.

1. Переключитесь в раздел **Управление&nbsp;&rarr; Сообщения&nbsp;&rarr; Настройки для бота** и включите **Возможности ботов**.

    ![alt=Настройка «Возможности ботов»;title=Настройка «Возможности ботов»](27925e8aa51fd0983715b4c71a2171d79275171e7164d9febb7214cd "8771630178755964749")

    Вы можете поставить галочку в пункте **Добавить кнопку «Начать»**. В этом случае клавиатура по умолчанию будет содержать кнопку «Начать».

    ![alt=Кнопка «Начать» в окне чата;title=Кнопка «Начать» в окне чата](19a46df68a48f3ce7125045f1dd2395ba25f3b885b2a7a2a6a64fd5c "-4460650811340367935")

    Сохраните изменения.

Теперь вы можете добавлять клавиатуру к сообщениям.

### Добавьте клавиатуру к сообщениям

Чтобы добавить клавиатуру к сообщению, используйте [API ВКонтакте](reference): отправьте ответ пользователю с помощью API-запроса [`messages.send`](method/messages.send) и укажите желаемую конфигурацию кнопок в параметре `keyboard` этого запроса. Параметр принимает данные в виде JSON-строки. Формат используемых объектов и их свойств описан [ниже](#Описание%20клавиатуры).

Если в формате будут ошибки, запрос [`messages.send`](method/messages.send) вернёт ошибку `911. Keyboard format is invalid`.

## Описание клавиатуры

### Пример

Описание клавиатуры задаётся в виде JSON-строки. Передайте её в параметр `keyboard` API-запроса [`messages.send`](method/messages.send).

```JSON
{
  "one_time": false,
  "buttons":[
    [
      {
        "action":{
          "type":"location",
          "payload":"{\"button\": \"1\"}"
        }
      }
    ],
    [
      {
        "action":{
          "type":"vkpay",
          "hash":"action=transfer-to-group&group_id=12345&aid=10"
        }
      }
    ],
    [
      {
        "action":{
          "type":"text",
          "payload":"{\"button\": \"1\"}",
          "label":"Red"
        },
        "color":"negative"
      },
      {
        "action":{
          "type":"text",
          "payload":"{\"button\": \"2\"}",
          "label":"Green"
        },
        "color":"positive"
      },
      {
        "action":{
          "type":"text",
          "payload":"{\"button\": \"2\"}",
          "label":"Blue"
        },
        "color":"primary"
      },
      {
        "action":{
          "type":"text",
          "payload":"{\"button\": \"2\"}",
          "label":"White"
        },
        "color":"secondary"
      }
    ]
  ]
}
```

### Объект, описывающий клавиатуру

| Поле | Тип | Описание |
| --- | --- | --- |
| `buttons`&#x0d;&#x0a;*обязательное*  | `array` | Массив, элементы которого соответствуют рядам клавиатуры. Каждый элемент, в свою очередь, тоже является массивом. Этот массив содержит объекты, [описывающие кнопки](#Объект,%20описывающий%20кнопку). |
| `one_time`&#x0d;&#x0a;*необязательное* | `bool` | Указывает, надо ли скрывать клавиатуру после нажатия на какую-либо кнопку на ней (`true`) или нет (`false`).&#x0d;&#x0a;&#x0d;&#x0a;Работает, только если `"inline": false`. |
| `inline`&#x0d;&#x0a;*необязательное*   | `bool` | Определяет тип клавиатуры. Подробности — [ниже](#Типы%20клавиатур). |

### Объект, описывающий кнопку

| Поле | Тип | Описание |
| --- | --- | --- |
| `action`&#x0d;&#x0a;*обязательное* | [`object`](#Типы%20кнопок) | [Объект](#Типы%20кнопок), описывающий тип кнопки и её параметры. |
| `color`&#x0d;&#x0a;*необязательное*  | `string` | Цвет кнопки. Параметр используется только для кнопок типа [`text`](#text) и [`callback`](#callback).  |

### Возможные значения цвета кнопок

| Константа |  Описание | Цвет в светлой теме | Цвет в тёмной теме | 
| --- | --- | --- | --- |
| `primary`   | Используется для кнопок, выполняющих основное действие. | `#5181B8` | `#E1E3E6` | 
| `secondary` | Используется для обычных кнопок. | `#E5EBF1` | `#424242` |
| `negative`  | Используется для кнопок, выполняющих опасное действие или отмену, например «Удалить» или «Отклонить». | `#E64646` | `#FF5C5C` |
| `positive` | Используется для кнопок, с помощью которых пользователь выражает согласие или подтверждает свои действия, например «Согласиться» или «Подтвердить». | `#4BB34B` | `#4BB34B` |

## Типы клавиатур

Поле `inline` в объекте, описывающем клавиатуру, указывает тип клавиатуры.

### Клавиатура чата

Если `"inline": false`, то клавиатура располагается под полем ввода текста в окне чата.

![alt=`inline: false`. Клавиатура отображается под полем для ввода сообщения.;title=`inline: false`. Клавиатура отображается под полем для ввода сообщения.](23da71d33405de08fec50d8805eb69fbf7024196a16dad3d328de21b "616200134238115590")

Такая клавиатура может иметь до 40 кнопок, которые могут быть сгруппированы в 10 рядов до 5 кнопок в каждом.

### Inline-клавиатура

Если `"inline": true`, клавиатура показывается в поле сообщения.

![alt=`inline: true`. Клавиатура отображается в сообщении.;title=`inline: true`. Клавиатура отображается в сообщении.](ea51b7f45bf0a0d0c1d393d5990e6e51728c00ddb5ab984134578f1a "6537326869192998723")

Такая клавиатура может иметь до 10 кнопок, сгруппированных в 6 рядов до 5 кнопок в каждом.

### Общие параметры клавиатур

* Высота всех кнопок одинаковая.

* Кнопки, расположенные в одной строке, имеют одинаковую ширину.

* Ширина каждой строки равна ширине клавиатуры.

* Текст отображается по центру кнопки и обрезается, если не помещается в границы кнопки полностью.

## Типы кнопок

Вы можете добавлять различные кнопки на клавиатуру. Мы называем кнопки по их типу, который указывается в поле `type`.  

### text

Отправляет сообщение с текстом, который указан в поле `label`.  

| Поле | Тип | Описание |
| --- | --- | --- |
| `type`&#x0d;&#x0a;*обязательное*    | `string` | Тип кнопки. Должен быть `"text"`. |
| `label`&#x0d;&#x0a;*обязательное*   | `string` | Текст для вставки в сообщение. Максимальная длина — 40 символов.&#x0d;&#x0a;&#x0d;&#x0a;Этот текст также отображается как текст кнопки. |
| `payload`&#x0d;&#x0a;*необязательное* | `string` | Дополнительные данные в формате JSON-строки. Они будут отправлены серверу бота в сообщении [`message_new`](api/community-events/json-schema#message_new), в поле `payload`. Максимальная длина — 255 символов.&#x0d;&#x0a;&#x0d;&#x0a;Строка должна представлять собой описание JSON-объекта, то есть начинаться и заканчиваться фигурными скобками. |

Для `text`-кнопок вы также можете указать [цвет кнопки](#Объект,%20описывающий%20кнопку).

### location

Открывает диалоговое окно с информацией о местоположении. Пользователь может выбрать своё местоположение в этом окне и отправить его в чат. Администраторы сообщества получат изображение карты в чате. Координаты точки придут на сервер бота в поле `message.geo.coordinates` в сообщении [`message_new`](api/community-events/json-schema#message_new).

:::note
Ряд, в котором находится кнопка `location`, может содержать не больше 2 кнопок. В противном случае при вызове `messages.send` произойдёт ошибка.
:::

| Поле | Тип | Описание |
| --- | --- | --- |
| `type`&#x0d;&#x0a;*обязательное*    | `string` | Тип кнопки. Должен быть `"location"`. |
| `payload`&#x0d;&#x0a;*необязательное* | `string` | Дополнительные данные в формате JSON-строки. Они будут отправлены серверу бота в сообщении [`message_new`](api/community-events/json-schema#message_new), в поле `payload`. Максимальная длина — 255 символов.&#x0d;&#x0a;&#x0d;&#x0a;Строка должна представлять собой описание JSON-объекта, то есть начинаться и заканчиваться фигурными скобками. |

### `vkpay`

Открывает окно оплаты VK Pay с предопределёнными параметрами. Кнопка называется «Оплатить через VK Pay», VK Pay отображается как логотип.

:::note
Кнопка должна быть единственной в строке. В противном случае при вызове `messages.send` произойдёт ошибка.
:::

| Поле | Тип | Описание |
| --- | --- | --- |
| `type`&#x0d;&#x0a;*обязательное*    | `string` | Тип кнопки. Должен быть `"vkpay"`. |
| `hash`&#x0d;&#x0a;*обязательное*    | `string` | Строка, содержащая [параметры платежа VK Pay](pay/getting-started) и идентификатор приложения в параметре `aid`, отделённый `&`. Пример: `action=transfer-to-group&group_id=1&aid=10`. |
| `payload`&#x0d;&#x0a;*необязательное* | `string` | Дополнительные данные в формате JSON-строки. Они будут отправлены серверу бота в сообщении [`message_new`](api/community-events/json-schema#message_new), в поле `payload`. Максимальная длина — 255 символов.&#x0d;&#x0a;&#x0d;&#x0a;Строка должна представлять собой описание JSON-объекта, то есть начинаться и заканчиваться фигурными скобками. |

### open_link

Открывает ссылку, указанную в поле `link`.

| Поле | Тип | Описание |
| --- | --- | --- |
| `type`&#x0d;&#x0a;*обязательное*    | `string` | Тип кнопки. Должен быть `"open_link"`. |
| `link`&#x0d;&#x0a;*обязательное*    | `string`    | Ссылка, которая будет открыта при нажатии на кнопку. |

Максимальная длина — 255 символов.&#x0d;&#x0a;&#x0d;&#x0a;Строка должна представлять собой описание JSON-объекта, то есть начинаться и заканчиваться фигурными скобками. |

| `app_id`&#x0d;&#x0a;*обязательное*   | `integer`| Идентификатор мини-приложения или игры, которую надо открыть.  [Где найти идентификатор приложения?](mini-apps/settings/overview#Где%20найти%20ID%20мини-приложения?) |

| `hash`&#x0d;&#x0a;*необязательное* | `string` | Хеш для навигации в приложении, он будет передан в строке параметров запуска после символа `#`. |
| `payload`&#x0d;&#x0a;*необязательное*  | `string` | Дополнительные данные в формате JSON-строки. ### `callback`

Нажатие на кнопку не отправляет какое-либо сообщение от пользователя в чат, но направляет серверу бота сообщение [`message_event`](api/community-events/json-schema#message_event), которое информирует о том, что пользователь нажал кнопку. В серверном коде вы можете проверить параметры сообщения и выполнить какие-то действия в ответ на нажатие. Подробности работы с кнопками — в разделе [Работа с callback-кнопками](#Работа%20с%20callback-кнопками).

| Поле | Тип | Описание |
| --- | --- | --- |
| `type`&#x0d;&#x0a;*обязательное*     | `string` | Для этой клавиши имеет значение `callback`. |
| `label`&#x0d;&#x0a;*обязательное*    | `string` | Текст кнопки. Максимальная длина — 40 символов.&#x0d;&#x0a;&#x0d;&#x0a;После нажатия на кнопку текст на ней сменяется курсором, означающим ожидание. |
| `payload`&#x0d;&#x0a;*необязательное*  | `string` | Дополнительные данные в JSON-формате. Они будут отправлены серверу бота в сообщении [`message_event`](api/community-events/json-schema#message_event), в поле `payload`. Максимальная длина — 255 символов.&#x0d;&#x0a;&#x0d;&#x0a;Если на клавиатуре несколько `callback`-кнопок, используйте это значение, чтобы идентифицировать кнопку, которую пользователь нажал.&#x0d;&#x0a;&#x0d;&#x0a;Строка должна представлять собой описание JSON-объекта, то есть начинаться и заканчиваться фигурными скобками.|

Для `callback`-кнопок вы также можете указать [цвет кнопки](#Объект,%20описывающий%20кнопку).

## Особенности работы

* В зависимости от параметра клавиатуры [`inline`](#Объект,%20описывающий%20клавиатуру) в запросе `messages.send`, ВКонтакте  может либо скрыть клавиатуру, после того как пользователь нажмёт какую-либо кнопку, либо продолжить использовать клавиатуру в последующих сообщениях. При дальнейшем использовании, чтобы изменить кнопки, передайте новую конфигурацию в параметре `keyboard` при отправке сообщения.

    Чтобы скрыть клавиатуру в чате, передайте в параметре `keyboard` пустой набор клавиш:

    ```Cодержимое&nbsp;параметра&nbsp;keyboard,&nbsp;JSON
    {
      "buttons": []
    }
    ```

* Значения, указанные в параметре `payload` из описания кнопки, передаются на сервер чат-бота. Некоторые технически грамотные пользователи могут подменять это значение при отправке. Поэтому мы рекомендуем проверять поступающие в `payload` данные на стороне сервера и принимать к обработке только допустимые значения.  

## Работа с callback-кнопками

Callback-кнопки позволяют боту получать уведомление о нажатиях на кнопки без отправки сообщения от пользователя и после этого выполнять необходимое действие, например редактировать сообщение, показывать текстовую информацию, отправлять новую клавиатуру или открывать ссылку.

### Внешний вид

Callback-кнопки выглядят так же, как и обычные кнопки, и поддерживают все стили. После нажатия на кнопку на время выполнения действия возникает индикатор загрузки.

![alt=Пример callback-кнопки;title=Пример callback-кнопки](2ded1e4a35c7dae08f9d64009478dee14f2498cd1876683b67a36bcf "-532726193596602097")

### Примеры использования

* Реализация основного меню бота: после нажатия на callback-кнопку на клавиатуре бот обновляет её, выполняя переход на уровень глубже по вложенности меню. При этом пользователю не нужно отправлять боту дополнительное сообщение.

* Редактирование сообщения: пользователь нажимает на callback-кнопку в inline-клавиатуре из сообщения, выбирая категорию блюда в меню. Бот редактирует сообщение, предлагая блюда из этой категории. Пользователь при этом не отправляет боту сообщение.

* Отправка результата действия: пользователь нажимает на callback-кнопку, например «Пополнить баланс», которая совершает определённое действие. После его успешного выполнения бот показывает пользователю информацию «Баланс пополнен» при помощи снекбара. Отправка сообщения при этом не требуется.

### Принцип работы

* Бот отправляет клавиатуру с [callback-кнопкой](#callback).

* Пользователь нажимает на кнопку.

* Бот получает новое событие `message_event` в Callback или LongPoll API.

* Бот определяет действие с помощью параметра `event_data` в методе [`messages.sendMessageEventAnswer`](method/messages.sendMessageEventAnswer).

* Код на стороне пользователя получает ответ от бота и выполняет нужное действие.

### Типы действий

#### Действие `show_snackbar`

Показать исчезающее сообщение. Снекбар показывается в течение 10 секунд и автоматически скрывается, при этом у пользователя есть возможность смахнуть его с экрана.

![](de951d983e604c2aabe128a8e5e1ccb37de792b2b582d9ca221db1dc "-3563741600283602501")

| Поле | Тип | Описание |
| --- | --- | --- |
| `type` | `string` | Строка `'show_snackbar'`. |
| `text` | `string` | Текст, который нужно вывести (максимум — 90 символов). |

#### Действие `open_link`

Осуществляется переход по указанному адресу.

| Поле | Тип | Описание |
| --- | --- | --- |
| `type` | `string` | Строка `open_link`. |
| `link` | `string` | URL, который нужно открыть. |

#### Действие `open_app`

Открыть VK Mini App. Происходит переход в мини-приложение.

| Поле | Тип | Описание |
| --- | --- | --- |
| `type`     | `string` | Строка  `'open_app'`. |
| `app_id`   | `int`    | Идентификатор вызываемого приложения с типом VK Mini Apps. |
| `owner_id` | `int`    | Идентификатор сообщества, в котором установлено приложение, если требуется открыть в контексте сообщества. |
| `hash`     | `string` | Хеш для навигации в приложении. Будет передан в строке параметров запуска после символа `#`. |

## Общение бота с приложением

Приложения, установленные в сообществах, могут генерировать событие `app_payload` в Callback или LongPoll API с помощью события [`VKWebAppSendPayload`](bridge/VKWebAppSendPayload) библиотеки [VK Bridge](bridge/overview).

Бот может передавать приложению параметры при запуске, используя поле `hash`.

Если необходимо наладить получение события от бота в приложении, то такого механизма не существует, но вы можете разработать собственное API бота.

С помощью этих механизмов можно расширять возможности своего бота, используя платформу VK Mini Apps. Например, можно реализовать настройки бота через приложение или сделать заполнение форм не через сообщения.

### Приложение «Выберите друга»

Приложение позволяет пользователю выбирать человека из списка друзей.

* [Добавьте приложение в сообщество](https://vk.com/add_community_app?aid=51625447).

* В сообществе включите событие «Событие от VK Mini Apps» в Callback или LongPoll API.

* Отправьте клавиатуру, используя клавишу `open_app` и указав идентификатор вашей группы в поле `owner_id`. В примере ниже используется поле `hash` для передачи параметров запуска приложения.

    ```JSON
    {
        "inline": true,
        "buttons": [
            [{
                "action": {
                    "type": "open_app",
                    "label": "Выберите друга", 
                    "app_id": 6979558,
                    "owner_id": -1234,
                    "hash": "#entity=подарок&payload=randomuuid1234"
                }
            }]
        ]
    }
    ```

* После выбора друга приложение отправит боту событие `app_payload`. Пример события:

    ```JSON
    {
      "group_id": 1234,
      "type": "app_payload",
      "event_id": "166a12a0b4334b97f94c3fc33dfdd6d2c773e7b4",
      "v": ":version",
      "object": {
        "user_id": 61351294,
        "app_id": 51625447,
        "payload": "{\"from_id\":61351294,\"to_id\":355449586,\"payload\":\"randomuuid1234\"}"
      }
    }
    ```

* В поле `to_id` будет указан ID выбранного друга.

### Приложение «Форма сбора заявок»

Приложение позволяет собирать заявки и делать опросы.

* [Добавьте приложение в сообщество](https://vk.com/add_community_app?aid=6013442).

* Создайте новую форму в настройках приложения.

* В сообществе включите событие «Lead forms: Новая заявка» в Callback или LongPoll API.

* Отправьте клавиатуру, используя клавишу `open_app` и указав id вашей группы в поле `owner_id`.

    ```JSON
    {
        "inline": true,
        "buttons": [
            [{
                "action": {
                    "type": "open_app",
                    "label": "Заполнить форму", 
                    "app_id": 6013442,
                    "owner_id": -1234,
                    "hash": "#form_id=1"
                }
            }]
        ]
    }
    ```

* После отправки формы приложение отправит боту событие `lead_forms_new`. Пример события:

    ```JSON
    {
      "group_id": 1234,
      "type": "lead_forms_new",
      "event_id": "b348eda8432391d89d9032eeca1cabdce14cedc4",
      "v": ":version",
      "object": {
        "lead_id": 54321,
        "group_id": 1234,
        "user_id": 61351294,
        "form_id": 1,
        "form_name": "Тестовая форма",
        "answers": [
          {
            "key": "first_name",
            "question": "Имя",
            "answer": "Евгений"
          },
          {
            "key": "last_name",
            "question": "Фамилия",
            "answer": "Котляров"
          },
          {
            "key": "custom_1",
            "question": "Ваша любимая еда",
            "answer": "Оптоволокно"
          }
        ]
      }
    }
    ```

## Кнопка «Начать»

Если кнопка включена и у пользователя ещё нет переписки с сообществом, мы показываем кнопку «Начать», которая отправляет команду `start`. Параметр [`payload`](#Отправка%20клавиатуры) этого сообщения будет выглядеть так:

```
{"command":"start"}
```
