# Сервисный ключ доступа

Сервисный ключ доступа используется для выполнения запросов к VK API, когда не требуется авторизация пользователя. Такие запросы считаются выполненными от имени игры, мини-приложения, Standalone-приложения. Сервисный ключ доступа также называют ключом доступа приложения.

Способ получения ключа доступа зависит от типа приложения, из которого выполняется запрос к VK API:

| Способ получения | Для каких приложений | Где использовать |
| --- | --- | --- |
| [Панель управления](#Панель%20управления%20dev.vk.com) | Игра или мини-приложение | Серверная часть приложения |
| [Cервис авторизации VK ID](#Сервис%20авторизации%20VK%20ID) | Любое приложение или сайт (Standalone-приложение) | Серверная часть приложения |

## Особенности работы

* Срок действия сервисного ключа доступа не ограничен. Если сервисный ключ скомпрометирован, его можно обновить в настройках приложения.

* В целях безопасности используйте сервисный ключ только для выполнения запросов с серверной стороны вашего приложения. Не передавайте и не храните этот ключ в клиентской части.

## Права доступа

Для сервисного ключа не требуется запрашивать права доступа. Такой ключ используют при вызове методов, предназначенных для работы с играми и мини‑приложениями, например методов из [группы `apps`](method/apps).

## Получить сервисный ключ доступа 

### Панель управления dev.vk.com

VK генерирует сервисный ключ доступа при регистрации игры или мини-приложения на [портале для разработчиков](https://dev.vk.com/ru/admin/apps-list). Администратор игры или мини-приложения может получить такой ключ в панели управления в разделе **Разработка** → **Ключи доступа**.

VK ID генерирует сервисный ключ доступа при создании приложения в [кабинете сервиса авторизации](https://id.vk.com/about/business/go).
