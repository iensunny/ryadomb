# Ключ доступа сообщества

Ключ доступа (токен) сообщества позволяет вызывать методы VK API от имени сообщества или публичной страницы. Такой ключ доступа нужен в сценариях, где действие должно выполняться от имени сообщества — например, для переписки с подписчиками. При создании ключа доступа сообщества ему предоставляются определённые [права](#Права%20доступа). 

Способ получения ключа доступа зависит от типа приложения и от того, где выполняется код: в серверной или клиентской части приложения. 

| Способ получения | Для каких приложений | Где использовать |
| --- | --- | --- |
| [Настройки сообщества](#Настройки%20сообщества) | Любое приложение или сайт (Standalone-приложение) | Серверная часть приложения |
| [OAuth ВКонтакте](#OAuth%20ВКонтакте) — Authorization Code Flow | Любое приложение или сайт (Standalone-приложение)| Серверная часть приложения |
| [OAuth ВКонтакте](#OAuth%20ВКонтакте) — Implicit Flow | Любое приложение или сайт (Standalone-приложение) | Клиентская часть приложения |
| [Событие `VKWebAppGetCommunityToken`](#Событие%20VK%20Bridge) | Мини‑приложение или плагин ВКонтакте | Клиентская часть приложения |

## Особенности работы

* Получить ключ доступа может только администратор этого сообщества.
* Срок действия ключа доступа сообщества не ограничен. Если ключ скомпрометирован, вы можете его [отозвать](#Отозвать%20ключ%20доступа%20сообщества).
* Все созданные ключи доступа отображаются в настройках сообщества.

## Права доступа

Права доступа определяют, с какими разделами данных может работать ключ доступа. Например, для получения фотографий сообщества нужен ключ доступа с правами `photos`. Подробнее — в разделе [Права доступа и приватность](api/privacy#Права%20доступа%20для%20ключа%20доступа%20сообщества).

## Получить ключ

### Настройки сообщества

Самый простой способ получить ключ доступа — создать его в настройках вашего сообщества. В настройках можно создать несколько ключей с разным набором прав, а также в любой момент отозвать ключ. Чтобы создать ключ:

1. Откройте сообщество, в котором вы являетесь администратором.

1. В меню справа выберите **Управление** → **Дополнительно** → **Работа с API**.

1. На вкладке **Ключи доступа** нажмите **Создать ключ**.

1. Выберите права доступа для ключа и нажмите **Создать**.

После подтверждения ключ появится на вкладке **Ключи доступа**.

### OAuth ВКонтакте

Этот способ подходит, если вы хотите получать ключ доступа сообщества программно.

1. Получите список сообществ, в которых пользователь является администратором. Для этого необходимо выполнить запрос [`groups.get`](method/groups.get) с параметром `filter=admin`.

1. Запросите ключ доступа сообщества при помощи одного из сценариев:

   * Если вызовы VK API выполняются на сервере приложения, используйте Authorization Code Flow. Ключ доступа, полученный этим способом, не привязан к IP‑адресу. 
   
      Подробнее — в документации VK ID: [Authorization Code Flow для получения Access token сообщества](https://id.vk.com/about/business/go/docs/ru/vkid/latest/oauth/oauth-vkontakte/authcode-flow-community). 

   * Если вызовы VK API выполняются в клиентском коде на устройстве администратора сообщества, используйте Implicit Flow. 
   
      Подробнее — в документации VK ID: [Implicit Flow для получения Access token сообщества](https://id.vk.com/about/business/go/docs/ru/vkid/latest/oauth/oauth-vkontakte/implicit-flow-community).

### Событие VK Bridge

Если вы разрабатываете мини‑приложение и вызываете VK API из клиентского кода, ключ доступа сообщества можно запросить через событие `VKWebAppGetCommunityToken` библиотеки VK Bridge. Этот вариант обычно используют в [приложениях сообществ](plugins/overview).

Подробнее — в описании события [`VKWebAppGetCommunityToken`](bridge/VKWebAppGetCommunityToken).

## Отозвать ключ доступа сообщества

Все созданные ключи доступа отображаются в настройках сообщества в разделе **Управление** → **Дополнительно** → **Работа с API** на вкладке **Ключи доступа**.

Чтобы отозвать ключ, выберите его из списка и нажмите **Удалить ключ** или **Удалить все ключи приложения**.
