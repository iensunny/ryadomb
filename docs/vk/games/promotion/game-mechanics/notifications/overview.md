# Уведомления

Игра может отправлять пользователям уведомления — сообщения, которые напоминают пользователю об игре, помогают удерживать постоянных игроков и возвращать неактивных.

Уведомления можно увидеть в ленте в разделе **Игры** &rarr; **Профиль** десктопной версии сайта ВКонтакте. Также уведомления могут приходить в колокольчик и в виде push-уведомлений в Одноклассниках и ВКонтакте.

По умолчанию уведомления в игре включены. При первом запуске игры ВКонтакте пользователь увидит всплывающее сообщение о получении уведомлений.

* ВКонтакте пользователь может нажать **Настройки** во всплывающем сообщении и отключить уведомления. Либо сделать это позже из меню **Действия &rarr; Настройки**.
* В Одноклассниках пользователь может отключить уведомления, выбрав **Ещё &rarr; Оповещения**.

## Типы уведомлений

Игры ВКонтакте поддерживают уведомления следующих типов:

| Тип | Описание |
| --- | --- |
| [Разовые](games/promotion/game-mechanics/notifications/single) | Сообщают пользователям об отдельных событиях, связанных с игрой, таких как: конкурсы, кампании или предложения к праздникам.|
| [Неактивным пользователям](games/promotion/game-mechanics/notifications/automatic) | Напоминают пользователям об игре, если они не запускали её в течение нескольких дней.&#x0d;&#x0a;&#x0d;&#x0a;C помощью этих уведомлений игра также может сообщать пользователю, что его друг выполнил какую-либо миссию. |
| [Всем пользователям](games/promotion/game-mechanics/notifications/mass) | Используются для массовой рассылки оповещений активным пользователям в честь какого-либо события. |

Далее в документации рассказывается о настройке уведомлений для игр ВКонтакте. В Одноклассниках также можно настроить оповещения пользователей. Подробнее — в разделе [Оповещения в Одноклассниках](ok/promotion/notifications).

## Ограничения

* Уведомления можно использовать в игре только после того, как она прошла модерацию и была [опубликована в каталоге](games/catalog/moderation).  Неопубликованные игры могут отправлять уведомления только своим администраторам.
* Для создания уведомлений [состояние игры](games/settings/general/placement#Состояние%20для%20пользователей) должно быть **Включено**.
* В настройках профиля пользователя ВКонтакте и Одноклассников должны быть включены уведомления от игр и приложений.
