# Права доступа

> Источник: [https://dev.vk.ru/ru/games/development/permissions](https://dev.vk.ru/ru/games/development/permissions)
:::note
Информация на странице устарела. Теперь игра будет запрашивать права доступа во время своей работы — перед первым использованием функциональности, для которого нужно разрешение. 
:::

Игре могут потребоваться разрешения пользователя на выполнение различных действий, например на получение информации о друзьях пользователя или на отправку уведомлений.

## Режимы запроса прав

Игра может запрашивать разрешения при первом запуске, во время игрового процесса либо использовать комбинированный подход.

Администраторы игры устанавливают режим запроса в настройках игры. Доступны следующие варианты:

* [При запуске игры](#При%20запуске%20игры)
* [По мере необходимости](#По%20мере%20необходимости)
* [По мере необходимости (тестовый режим)](#По%20мере%20необходимости%20(тестовый%20режим))

### При запуске игры

На старте игра покажет экран с информацией о требуемых правах. Нажатие на кнопку «Запустить игру» означает согласие пользователя на предоставление требуемых разрешений.

![alt=Пример экрана с информацией о требуемых правах;title=Пример экрана с информацией о требуемых правах](78c2d5c74e129fa68bebe645b0331b73bf58cbc441ed45ec1b90f360 "3864056844312991549")

Конкретные права и разрешения, которые игра запрашивает и которые будут отображены в списке, вы можете указать в настройке **Права доступа при запуске**.

О значениях в этом списке мы расскажем ниже, в разделе [Подробнее о правах доступа при запуске](#Подробнее%20о%20правах%20доступа%20при%20запуске).

При необходимости игра может запросить дополнительные права в процессе работы.

### По мере необходимости

Игра не показывает информацию о необходимых правах на старте, пользователь сразу переходит к игровому экрану. Игра будет запрашивать права доступа во время своей работы — перед первым использованием функциональности, для которой нужно разрешение. Например, если код игры вызывает событие библиотеки [VK Bridge](bridge/overview) для [отправки запроса друзьям пользователя](games/promotion/game-mechanics/overview), игровая платформа запросит разрешение пользователя на выполнение таких действий.

![alt=Пример диалогового окна запроса прав;title=Пример диалогового окна запроса прав](83700c75adab82ad6a69a7946e8c0fad922eadd4c100f412a8dc9386 "-8310406117063104150")

Режим **По мере необходимости** используется в играх по умолчанию.

### По мере необходимости (тестовый режим)

Когда выбрано это значение, режим **По мере необходимости** будет работать только для пользователей, добавленных в список тестировщиков. Для остальных пользователей права будут запрашиваться в режиме **При запуске игры**.

## Выбор режима запроса прав

1. Перейдите на страницу [Мои приложения](https://vk.com/apps?act=manage), найдите игру в списке и нажмите на ссылку **Редактировать** напротив неё.

1. В левом меню переключитесь в раздел **Настройки**. Прокрутите страницу вниз до блока **Запрос прав**.

1. Выберите режим запроса прав для игр Direct Games и Web.

1. Если вы выбрали режим **При запуске игры** для какого-то типа игр, нажмите на ссылку в настройке **Права доступа при запуске** и в выпадающем списке выберите необходимые разрешения.

## Подробнее о правах доступа при запуске

Права доступа, которые игра запрашивает во время запуска, определяют, может ли игра выполнить API-запросы, которые оперируют данными пользователя. Ключ доступа, который игра получает при запуске в параметре [`access_token`](games/development/parameters), разрешает работу тех или иных API-методов.

Таблица ниже поясняет, какие разрешения даёт то или иное значение, выбранное в списке **Права доступа при запуске**.

:::note
Обратите внимание, что настройка **Права доступа при запуске** работает и для игр Web, и для игр Direct Games, если для них выбран режим **При запуске игры**.
:::

## Запрос прав во время выполнения

### Общая схема

Чтобы проверить, что у вашей игры есть права на выполнение какого-либо API-метода, вызовите событие [`VKWebAppCheckAllowedScopes`](bridge/VKWebAppCheckAllowedScopes) библиотеки [VK Bridge](bridge/overview).

Для запроса новых прав используйте событие [`VKWebAppGetAuthToken`](bridge/VKWebAppGetAuthToken). При успешном выполнении вызов вернёт новый ключ доступа для использования в API-запросах.

Обратите внимание, что возвращаемый ключ доступа ограничен в действии по времени: он устареет в течение суток. Поэтому не откладывайте API-вызов с использованием ключа.

Ниже в этом разделе приведён пример объекта, который позволяет получать права и вызывать тот или иной API-метод.  
Общая схема его использования выглядит следующим образом:

```JavaScript

// Использование
const requestAPIHelper = new RequestAPIHelper(appId, accessToken, allowedScopes);

requestAPIHelper.trySendRequest(apiMethodName, scope, paramsMethod)
  .then( (data) => { 
    // Обработка данных пользователя, 
    // полученных в ответе на запрос к API.
  })
  .catch( (err) => {
    // Обработка ошибки, 
    // полученной в ответе на API-запрос. 
  })
```

### Параметры конструктора

| Параметр | Тип | Описание |
| --- | --- | --- |
| `appId` | `integer` | Идентификатор вашей игры. Вы можете найти его в [настройках игры](games/getting-started#Скопируйте%20идентификатор%20игры). |
| `accessToken` | `string`| Ключ доступа для отправки API-запросов. Он передаётся игре при старте в параметре [`access_token`](games/development/parameters). |
| `allowedScopes` | `Map` | Список прав, выданных игре. Должен быть представлен в виде объекта `Map`. Формат элементов: `Map.set(scope-name, true | false)`. |

### Параметры `trySendRequest()`

Функция `trySendRequest(...)`  используется для выполнения API-запроса. Она принимает следующие параметры:

| Параметр | Тип | Описание |
| --- | --- | --- |
| `apiMethodName` | `string` | Имя метода API ВКонтакте для вызова, например `friends.getAppUsers`. |
| `scope` | `string` | Право доступа, которое необходимо вызываемому методу API ВКонтакте, например `friends`. |
| `paramsMethod`  | `object` | Параметры API-запроса. |

### Код класса и его методов

```JavaScript
import bridge from '@vkontakte/vk-bridge';

export default class RequestAPIHelper {

  constructor(appId, accessToken, allowedScopes) {
    this.appId = appId; // ID игры
    this.accessToken = accessToken; // Ключ доступа, полученный при старте
    this.scopes = allowedScopes; // Map-объект с текущими правами доступа 
  }

  // Вызов API-метода
  async trySendRequest(method, scope, params) {

    // Служебная функция для выполнения API-запроса  
    const sendApiRequest = (method, params) => {
      return bridge.send('VKWebAppCallAPIMethod', {
        method: method, // Имя вызываемого метода
        request_id: '123', // Порядковый номер запроса
        params: params, // Параметры вызова
      })
    };

    // Проверяем, поддерживает ли библиотека 
    // событие VKWebAppCheckAllowedScopes 
    const checkSupport = await bridge.supportsAsync('VKWebAppCheckAllowedScopes')

    if (checkSupport && !this.scopes.has(scope)) {
      try {

        const allowedScopes = await bridge.send('VKWebAppCheckAllowedScopes', {
          app_id: this.appId,
          scopes: scope,
        });

        this.scopes.set(
          scope,
          allowedScopes.some( (item) => {
            return item.scope === scope && item.allowed
          })
        );
      } catch (e) {
        console.error(e); // Событие не поддерживается
      }
    }

    // Если нужных прав нет...
    if (!this.scopes.get(scope)) {
      try {
        // ...то запрашиваем их

        const authTokenData = await bridge.send('VKWebAppGetAuthToken', {
          app_id: this.appId,
          scope: scope,
        });

        this.accessToken = authTokenData.access_token; // Получаем access_token
        this.scopes.set(scope, true); // Сохраняем права в список прав

      } catch (e) {
        console.error(e); // Ошибка при запросе прав
      }

      // Вызываем API-метод
      params['access_token'] = this.accessToken;
      return sendApiRequest(method, params);

    } else {
      // Если нужные права есть,
      // вызываем API-метод
      return sendApiRequest(method, params);
    }
  }
}
```

Обратите внимание, что если вы включаете библиотеку VK Bridge в HTML-код своих страниц, то в коде надо использовать имя объекта `vkBridge`, а не `bridge`.

## FAQ

#### Когда лучше запрашивать доступ к данным?

Мы рекомендуем запрашивать доступ к данным непосредственно перед тем, как их использовать.

Накопленная статистика говорит, что если запрашивать все разрешения на экране при первом запуске, игра теряет больший процент аудитории, чем при отдельных запросах в процессе работы.

Можно использовать комбинированный подход: при запуске запрашивать только права, необходимые для старта игры и выполнения первого запроса, а другие права запрашивать позже по мере необходимости.

#### Как узнать, какие права есть у игры в момент запуска?

Информация о доступных правах передаётся в игру при запуске в параметре [`access_token_settings`](games/development/parameters#Параметры).

#### Как узнать, какие права нужны событию VK Bridge или API-запросу?

Эта информация есть в документации. Например, замечание о необходимых правах на странице API-метода выглядит следующим образом:

![alt=Пример замечания о необходимых правах доступа в документации по API-методам;title=Пример замечания о необходимых правах доступа в документации по API-методам](5cfcefebb47b1f86a547c35e64927dc3f5b48da8aab2ebe0b1ee7a58 "6603728912519918386")

#### Что такое первый запрос к API?

:::note
Информация устарела. Теперь первый запрос к API не нужен.
:::

Первый запрос к API выполняется при запуске игры. Обычно он используется, чтобы получить некоторые данные о пользователе и отобразить их в интерфейсе игры. Например, можно получить имя и фото профиля пользователя, список его друзей, участвующих в игре, их очки.

Для выполнения первого запроса у игры должны быть права, которые этому запросу требуются для работы. Например, метод [`users.get`](method/users.get) будет успешно выполнен в первом запросе к API, так как он не требует дополнительных прав. Но метод [`friends.getAppUsers`](method/friends.getAppUsers) будет успешно выполнен только после получения игрой права доступа `friends`.

#### Как увидеть окно запроса прав в разных режимах?

Чтобы увидеть окно запроса прав в разных режимах, используйте следующие тестовые приложения:

* Режим «По мере необходимости»: https://vk.com/app7851579.

    В приложении переключитесь на вкладку **Запросы API** и выполните какой-либо запрос из списка.

* Режим «При запуске игры»: https://vk.com/app7170524.

    При запуске этого приложения вы увидите список требуемых прав внизу экрана.

    Переключитесь на вкладку **Запросы API** и выполните какой-нибудь запрос из предложенных. Обратите внимание на различия в режимах, а также на то, как отличаются запросы к API.

#### Что делать, если событие `VKWebAppCheckAllowedScopes` не возвращает данные?

Обновите мобильное приложение ВКонтакте до последней версии.

Также возможно, что версия библиотеки VK Bridge, которую вы используете, не поддерживает событие. Чтобы это проверить, используйте метод `bridge.supportsAsync()`, например:

```JavaScript
bridge.supportsAsync('VKWebAppCheckAllowedScopes').then( res => {
    if (res) {
        bridge.send('VKWebAppCheckAllowedScopes');
    }
})
```

[Обновите библиотеку](https://github.com/VKCOM/vk-bridge) при необходимости.
