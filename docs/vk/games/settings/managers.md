# Администраторы (настройки игр)

Администраторы — пользователи, авторизованные на [единой платформе](https://dev.vk.com/ru/admin/apps-list) по VK ID, которые занимаются разработкой, тестированием и поддержкой работы игры. Они могут, например, менять настройки игры, запускать её, когда она отключена для остальных пользователей, проверять работу платежей.

В разделе **Администраторы** вы можете просматривать список администраторов и работать с ним: добавлять новых пользователей, изменять настройки у существующих, передавать доступ.

**Чтобы открыть настройки администраторов:**
1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).
1. Откройте настройки нужной игры.
1. В меню слева выберите **Администраторы**.

## Доступ

Редактировать список администраторов может:

* [Создатель](#Создатель) игры.
* [Администратор с полным доступом](#Администратор%20с%20полным%20доступом).

Для [администраторов с частичным доступом](#Администратор%20с%20частичным%20доступом) раздел недоступен. Вместо него они видят другой раздел — [Доступ к приложению](games/settings/access-to-app).

## Виды администраторов

Всеми правами на игру обладает пользователь с правами создателя. Остальные администраторы могут иметь полный или частичный доступ к настройкам игры.

### Создатель

**Создатель** — это главный администратор игры. Он обладает доступом ко всем настройкам. Только он может:

* Выводить средства, полученные за показы рекламы или продажу товаров.
* Публиковать игру на [других площадках](games/settings/general/other-sites).
* Удалить игру с платформы.

Управлять списком администраторов может не только создатель, но и [администратор с полным доступом](#Администратор%20с%20полным%20доступом).

В списке администраторов может быть только один пользователь с правами создателя. Изначально это пользователь, который зарегистрировал игру на платформе VK Mini Apps.

### Администратор с полным доступом

У администраторов этого типа есть доступ к настройкам игры, но они не обладают исключительными правами [создателя](#Создатель).

У администраторов с полным доступом есть права на все разделы настроек, которые присутствуют в [частичном](#Администратор%20с%20частичным%20доступом) доступе. Кроме того, администратор с полным доступом может:

* Редактировать список администраторов (но не может переназначить создателя).
* Редактировать [список тестировщиков](games/settings/test-groups).
* Подавать [заявку на размещение в каталоге](games/settings/moderation).
* Тестировать игру до прохождения модерации на всех подключённых площадках.
* Обращаться в Поддержку.

## Редактирование списка администраторов

Добавлять новых администраторов, изменять их права или удалять может [создатель](#Создатель) либо [администратор с полным доступом](#Администратор%20с%20полным%20доступом).

Создателю доступны все операции над списком. Администраторам с полным доступом — все действия над другими администраторами, кроме создателя.

### Добавить администратора

* Для добавления нового администратора нажмите **Добавить** и укажите ссылку на его страницу ВКонтакте. Подойдёт как обычная ссылка вида `https://vk.com/id743784474`, так и ссылка с [никнеймом](https://vk.com/faq18038).

    ![alt=Добавление администратора;title=Добавление администратора](2d6faef8fda4cf8282b8a09051518c186eae2b10febc69940b0dce70 "-7584319541056723248")

* После того как вы подтвердите добавление администратора, платформа отправит ему приглашение. Пользователь станет администратором только после того, как примет приглашение.

Пользователи, которые пока не приняли приглашение, отображаются в списке администраторов, но администраторами не являются.

### Удалить администратора

Удалить администраторов из списка могут создатель или администратор с полным доступом. Для этого нажмите иконку с мусорной корзиной напротив нужного администратора.

Удалить создателя из списка администраторов нельзя. Если создатель хочет выйти из администрирования, он должен [передать свои права](#Передача%20управления) кому-либо из администраторов с полным доступом и затем отказаться от администрирования самостоятельно либо попросить нового создателя об удалении.

## Передать права создателя

[Создатель](#Создатель) может передать права администратору с полным доступом. Для этого в разделе **Администраторы** нужно нажать **Передать доступ** и выбрать из списка одного из администраторов с полным доступом.

Выбранный администратор должен принять приглашение и подтвердить переход прав к нему. До этого момента исключительные права остаются за текущим создателем.

После подтверждения перехода прав создатель становится администратором с полным доступом. 

:::note
**Важно!**
* Если для игры настроена [интеграция с Одноклассниками](ok/publishing#Шаг%202.%20Подключите%20приложение%20к%20Одноклассникам), создателем можно назначить только пользователя, который имеет права разработчика на платформе Одноклассники. Подробнее — в разделе [Администрирование приложений](ok/administrators#Связать%20аккаунты%20разработчика%20VK%20ID%20и%20OK%20ID).

* Если в приложении подключена монетизация, при передаче прав создателя укажите актуального исполнителя в кабинете выплат, чтобы продолжить зарабатывать на подключённых инструментах и выводить средства. Подробнее — в разделе [Вывод средств](games/monetization/withdrawal/overview).
:::

## Выход из администрирования

Администраторы с полным и частичным доступом могут отказаться от администрирования самостоятельно. Чтобы сделать это, просто нажмите **Отказаться от доступа** напротив своего имени в списке администраторов.

Администраторы с полным доступом видят эту кнопку в разделе **Администрирование**.
Администраторам с частичным доступом кнопка доступна в разделе [Доступ к приложению](games/settings/access-to-app).

Создатель игры выйти из администрирования не может. Сначала он должен [передать свои права](#Передача%20управления) кому-либо из администраторов с полным доступом.
