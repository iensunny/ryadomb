# Размещение (настройки игр)

> Источник: [https://dev.vk.ru/ru/games/settings/general/placement](https://dev.vk.ru/ru/games/settings/general/placement)
Раздел содержит настройки, необходимые для запуска игры из интерфейса площадок ВКонтакте и Одноклассники.

:::note
**Важно!** Если настройки размещения не указаны, игра не будет работать.
:::

**Чтобы открыть раздел:**

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).
1. Откройте настройки нужной игры.
1. В меню слева выберите **Размещение**.

## Доступ

Редактировать настройки размещения может:

* Создатель игры.
* Администратор с полным доступом.
* Администратор с частичным доступом, с правом «Редактирование».

Подробнее о правах — в разделе [Администраторы](games/settings/managers).

## Состояние для пользователей

Настройка указывает, кому доступна игра.

|  Состояние | Описание |
| --- | --- |
| **Отключено** | Состояние игры сразу после создания. ВКонтакте игра с таким состоянием доступна только администраторам. Запустить игру в Одноклассниках может только создатель.&#x0d;&#x0a;&#x0d;&#x0a;Чтобы опубликовать игру в Одноклассниках, нужно привязать OK ID в разделе [Другие площадки](games/settings/general/other-sites). Игра станет доступна в Одноклассниках в течение 15 минут.|
| **Включено** | Игра ВКонтакте станет доступна по ссылке всем пользователям. В Одноклассниках доступ будет только у создателя игры. Чтобы игра стала доступна всем пользователям, нужно пройти [модерацию](games/settings/moderation).|

Подробнее о доступности игры — в разделе [Запуск игры](games/launch-game).

## Настройки платформ

Раздел содержит настройки запуска игры для различных платформ. Вы можете настроить запуск игры на всех доступных платформах или выбрать только необходимые.

| Раздел | Описание |
| --- | --- |
| **Мобильное приложение**&#x0d;&#x0a;(ранее **Direct Games**) | Настройки для запуска игры из мобильного приложения ВКонтакте и Одноклассники для Android и iOS.&#x0d;&#x0a;&#x0d;&#x0a;Игра будет открываться в элементе управления WebView и будет выглядеть похожей на обычные приложения для Android и iOS. |
| **Web** | Настройки для запуска игры из десктопной версии сайта ВКонтакте ([vk.com](https://vk.com)) и Одноклассники ([ok.ru](https://ok.ru)).&#x0d;&#x0a;&#x0d;&#x0a;В браузере у пользователя будет открыта страница сайта vk.com, а игра будет загружена в HTML-элемент `<iframe>` на этой странице. |
| **Мобильная версия сайта** | Настройки для запуска игры из мобильной версии сайта ВКонтакте ([m.vk.com](https://m.vk.com)) и Одноклассники ([m.ok.ru](https://m.ok.ru)).&#x0d;&#x0a;&#x0d;&#x0a;Игра будет открываться в элементе управления WebView и будет выглядеть похожей на обычные приложения для Android и iOS. |

### URL

Адрес для запуска игры. Площадка отправит этот адрес в WebView или <iframe> для загрузки.

Чтобы передать параметры, укажите их в URL после символа `?`, например `https://my-game.com/start?param1=value1`.

### Режим разработки

Используйте эту настройку, чтобы включить или отключить режим разработки. В поле укажите адрес, по которому будет доступна версия игры только для администраторов.

Режим разработки полезен, когда игра уже опубликована в каталоге, но вам надо проверить изменения в ней. Этот режим работает для всех [администраторов](games/settings/managers) игры. Когда они запустят игру, она будет загружена из адреса, указанного в настройке **Режим разработки**, а не из настройки **URL**. Для остальных пользователей игра продолжит открываться по **URL**, для них подмены не произойдёт.

### Приоритеты URL для загрузки игры

Когда администратор запускает игру, URL для загрузки приложения определяется в следующем порядке:

1. URL, указанный в настройках [тестовой группы](games/settings/test-groups), если администратор включён в какую-либо тестовую группу. Этот URL имеет наивысший приоритет относительно остальных.

1. URL, указанный для режима разработки, если режим разработки включён для выбранной платформы.

1. URL, указанный в настройке [URL](#URL). Приоритет этого URL ниже адресов, указанных в тестовой группе или в режиме разработки.

## Удалить игру

Чтобы удалить игру с платформы, в правом нижнем углу страницы нажмите **Удалить приложение**. Кнопка доступна только [создателю](games/settings/managers#Создатель) игры.

> Удалённую игру нельзя восстановить. Можно создать новую с другим идентификатором.
