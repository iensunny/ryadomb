# Ключи доступа (настройки игр)

В этом разделе вы можете просмотреть и обновить ключи доступа, необходимые для работы с игрой. Значения ключей генерируются автоматически при создании игры.

**Чтобы открыть раздел**

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).
1. Откройте настройки нужной игры.
1. В меню слева выберите **Разработка&nbsp;&rarr; Ключи доступа**.

## Доступ

Редактировать ключи доступа может:

* Создатель игры.

* Администратор с полным доступом.

* Администратор с частичным доступом, с правом «Редактирование».

Подробнее о правах — в разделе [Администраторы](games/settings/managers).

## Защищённый ключ

Библиотеки ВКонтакте могут использовать защищённый ключ на стороне пользователя для различных целей. Например, для [проверки подписи параметров запуска](games/development/parameters-sign) или для [проверки подлинности данных](mini-apps/development/protect-with-signature).

## Сервисный ключ

[Сервисный ключ](api/access-token/getting-started) используется для отправки запросов API ВКонтакте из серверной части игры, например запросов группы [secure](method/secure).

:::note
**Важно!** Не передавайте и не используйте сервисный ключ в коде на стороне пользователя. Это небезопасно. Работайте с сервисным ключом доступа только в серверной части игры.
:::

## Публичный ключ

Публичный ключ используется совместно с [защищённым ключом](#Защищённый%20ключ) для взаимодействия с методами [API Одноклассников](https://apiok.ru/dev/methods/rest/) от имени приложения. Ключ отобразится после того, как игра будет подключена к Одноклассникам в разделе [Другие площадки](games/settings/general/other-sites).

Подробнее об использовании ключа – в разделе [Вызовы API на стороне сервера](ok/development/api#Вызовы%20API%20на%20стороне%20сервера).

## Работа с ключами

### Скопировать ключ

Чтобы скопировать ключ, нажмите **Показать** → **Просмотреть** и затем подтвердите действие предложенным способом.

### Изменить ключ

Чтобы обновить значение ключа, нажмите **Создать новый** → **Сменить** и затем подтвердите действие предложенным способом.

После создания нового старый ключ восстановить невозможно. Обновите значение ключа в коде вашей игры.
