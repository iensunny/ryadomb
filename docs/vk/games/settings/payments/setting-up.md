# Подключение (настройки игр)

Игры могут предоставлять [виртуальные ценности](mini-apps/glossary#Виртуальная%20ценность) за [голоса ВКонтакте](mini-apps/glossary#Голос) и [ОКи в Одноклассниках](mini-apps/glossary#ОКи).

В разделе **Подключение** вы можете указать параметры для выполнения платежей и просмотреть журнал платёжных уведомлений.  

Если вы планируете предоставлять виртуальные ценности за голоса и ОКи, зарегистрируйтесь в [кабинете выплат](https://cashout.vk.com/).

Подробнее:

* О регистрации в кабинете выплат и получении вознаграждения — в разделе [Вывод средств](games/monetization/withdrawal/overview).
* О продаже виртуальных товаров — в разделе [Платежи виртуальной валютой](api/payments/overview).

**Чтобы открыть раздел:**

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).
2. Откройте настройки нужной игры.
3. В меню слева выберите **Платежи**&nbsp;&rarr; **Подключение**.

## Доступ

Получить доступ к разделу может:

* Создатель игры.
* Администратор с полным доступом.
* Администратор с частичным доступом, с правом «Платежи».

Подробнее о правах — в разделе [Администраторы](games/settings/managers).

## Настройки

Вкладка содержит настройки, необходимые для работы платежей.

### URL для платёжных уведомлений ВКонтакте

При продаже виртуальных ценностей площадка запрашивает у игры информацию о товарах, а также отправляет уведомления о покупке или возврате. 

Эта настройка указывает URL на сервере игры, на который будут отправляться запросы о товарах и уведомления о платежах. Сервер игры должен обрабатывать запросы, поступающие на этот адрес, и предоставлять ответы.

<!-- exclusions/_images/mini-apps/settings/payments/url-vk.png -->
![alt=URL для платёжных уведомлений ВКонтакте;title=URL для платёжных уведомлений ВКонтакте](7ca6f9ed62fca8db603d4617a22c7e4efa6a8a62a8472ac2fb4a39c9 "-1179481700110383535")

* Для игр ВКонтакте на этот URL оправляются все уведомления для получения информации о товаре и подписке, а также уведомления о покупке. Подробнее — в разделе [Обработка платёжных уведомлений ВКонтакте](api/payments/notifications/vk).
* Для игр в Одноклассниках на этот URL оправляется только уведомление [`get_item`](api/payments/notifications/get-item) для получения информации о виртуальном товаре. Подробнее — в разделе [Обработка платёжных уведомлений в Одноклассниках](api/payments/notifications/ok).
* URL-адреса для платёжных уведомлений ВКонтакте и Одноклассников должны быть разными.

### URL для платёжных уведомлений Одноклассников

Эта настройка указывает URL на сервере игры, на который будут отправляться запросы о покупке виртуальных ценностей и подписок в Одноклассниках. Подробнее — в разделе [Обработка платёжных уведомлений в Одноклассниках](api/payments/notifications/ok).

### Тестировщики платежей

Список [администраторов игры](games/settings/managers), для которых платежи будут работать в тестовом режиме. Средства со счетов этих пользователей при выполнении платежей не списываются.

Если игра не прошла модерацию и не попала в каталог, то платежи доступны только пользователям, указанным в списке **Тестировщики платежей**. После модерации и публикации в каталоге платежи становятся доступны всем пользователям, но для тестировщиков платежей они продолжают работать в тестовом режиме.

Подробнее о тестировании платежей ВКонтакте и в Одноклассниках — в разделе [Тестирование платежей](api/payments/testing).

### Версия API

Формат платёжных уведомлений может меняться при изменении API ВКонтакте. Используйте эту настройку, чтобы указать версию API ВКонтакте, ожидаемую сервером игры. Платформа ВКонтакте будет отправлять серверу игры уведомления в формате, который поддерживается в указанной версии.

> Настройка особенно актуальна для игр, которые были зарегистрированы на платформе до января 2024 года. Игры, зарегистрированные позже, используют формат платёжных уведомлений, принятый в версии 5.132 API ВКонтакте. Описание формата — в разделе [Платежи виртуальной валютой](api/payments/overview).

## Логи

При продаже товаров и подписок платформа ВКонтакте отправляет серверу игры запросы для получения информации о товарах и уведомления об оплате или возврате.

Вкладка **Логи** содержит журнал таких сообщений. Используйте эту информацию для отладки платежей в вашей игре и проверки обмена данными.

## Оплата голосами

Игра может принимать платежи виртуальной валютой после того, как она будет размещена в [каталоге игр](games/catalog/overview). 

Чтобы опубликовать игру в каталоге, отправьте её на проверку модераторам ВКонтакте. Подробности добавления в каталог — в разделе [Как попасть в каталог](games/catalog/moderation).

:::note
**Важно!** До отправки заявки убедитесь, что зарегистрировались в [кабинете выплат](https://cashout.vk.com/) и что платежи в вашей игре работают правильно. Они заработают для всех пользователей сразу после прохождения модерации.

Подробнее о регистрации в кабинете выплат и получении вознаграждения — в разделе [Вывод средств](games/monetization/withdrawal/overview).
:::
