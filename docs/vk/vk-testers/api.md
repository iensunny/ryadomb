# Открытый API

> Источник: [https://dev.vk.ru/ru/vk-testers/api](https://dev.vk.ru/ru/vk-testers/api)
У платформы тестирования VK Testers есть [открытый API](method/bugtracker), который позволяет интегрировать её в процессы любой компании. 

Примеры сценариев, реализуемых с помощью API:

* Связывание CI/CD с платформой тестирования — автоматическая [публикация обновлений](vk-testers/product-versions) и [тестовых сборок](vk-testers/product-builds) на платформе.
* Остановка и возобновление приёма отчётов во время технических работ над проектом.
* Синхронное изменение статуса отчётов на платформе и во внутренних баг-трекерах компании.
* Автоматическое добавление комментариев, связанных с отчётами на платформе, в инфраструктуру заказчика при выполнении определённых действий.
* Интеграция систем контроля доступа компании с управлением участниками компании — автоматическое добавление и исключение сотрудников компании, добавление и удаление сотрудников в группах.

Ограничение на количество запросов к API в сутки определяется подключённым [тарифом](https://mcs.mail.ru/vk-testers/#price) и дополнительными опциями компании. Запросы к API осуществляются с [ключами доступа](vk-testers/access-tokens) компании и продуктов: первые позволяют делать запросы ко всем продуктам компании, вторые — к одному конкретному продукту.

Сейчас в документации мы подробно рассказываем про первый пункт — [публикацию версий](vk-testers/product-versions) и [загрузку сборок](vk-testers/product-builds).
