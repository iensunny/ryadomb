# Статичная карта

> Источник: [https://dev.vk.ru/ru/vkmaps/map-display-services/static-map](https://dev.vk.ru/ru/vkmaps/map-display-services/static-map)
Сервис позволяет получить изображение карты в заданной точке и необходимого масштаба и размера.

:::note
`/staticmap/png` — точка вызова сервиса.
:::

## Запрос (GET)

### Обязательные параметры запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `api_key` | `hex-string` | [Доступ к сервисам](vkmaps/general-information/api-key). | `api_key=fa749bace6d8a3b1....` |
| `bbox` | `float`,`float`,`float`,`float` | Область местонахождения объекта, которая описывается парой координат в порядке: `lat1,lon1,lat2,lon2`. Широта и долгота координат указывается через запятую. Координаты разделяются запятой.&#x0d;&#x0a;&#x0d;&#x0a;Если в запросе используется параметр `bbox`, параметры `zoom` и `latlon` игнорируются. | `bbox=55.7,37.65,55.8,37.66` |
| `latlon` | `float`,`float` | Широта и долгота (в градусах) геометрического центра требуемого изображения карты. Широта и долгота указывается через запятую.&#x0d;&#x0a;&#x0d;&#x0a;Если в запросе указан параметр `bbox`, параметр `latlon` игнорируется. Если `bbox` отсутствует, `latlon` должен быть указан. | `latlon=55.727,37.59` |

### Дополнительные параметры запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `zoom` | `integer` | Уровень масштабирования в диапазоне от `0` до `17`, где &#x0d;&#x0a;  &bull; `0` (по умолчанию) — соответствует уровню обзора мира;&#x0d;&#x0a;  &bull; `17` — соответствует уровню обзора здания.&#x0d;&#x0a;&#x0d;&#x0a;Если в запросе указан параметр `bbox`, параметр `zoom` игнорируется. | `zoom=13` |
| `width` | `integer` | Ширина изображения карты. Значение может находиться в диапазоне от `32` до `1024` пикселей. По умолчанию — `512`. | `width=640` |
| `height` | `integer` | Высота изображения карты. Значение может находиться в диапазоне от `32` до `1024` пикселей. По умолчанию — `512`. | `height=480` |
| `pins` | `string` | Параметры, которые определяют расположение и тип булавок, добавляемых на карту. Параметры должны передаваться в формате: `lat1,lon1,icon1`\|`lat2,lon2,icon2`\|..., где&#x0d;&#x0a;  &bull; `lat1...latN` — широта расположения булавки в градусах;&#x0d;&#x0a;  &bull; `lon1...lonN` — долгота расположения булавки в градусах;&#x0d;&#x0a;  &bull; `icon1...iconN` — формат булавки. Форматы доступных булавок представлены в [коллекции булавок](#Коллекция%20булавок). | `pins=55.75,37.61,blue_star`\|`60.65,38.12,red_camera` |
| `style` | `string` | Параметр выбора стиля отображения карты. Ознакомиться с доступными для использования стилями можно на странице [Стили карт](vkmaps/map-display-services/map-styles). По умолчанию используется стиль: `main`. | `style=light` |
| `padding` | `integer` | Параметр смещения атрибутов карты. Смещение определяется в пикселях и равно расстоянию от правого края надписи до правого края атрибутов. Ограничения: значение может находиться в диапазоне от `5` до `width/2` пикселей. По умолчанию — `5`. | `padding=40` |
| `scale` | `integer` | Параметр масштабирования изображения. Возможные значения `1` или `2`. По умолчанию `1`. Если `scale=2`, то размеры итогового изображения будут в 2 раза больше за счёт большей плотности пикселей. Например, при запросе `width=200&height=200&scale=2` результирующее изображение будет размером 400x400 пикселей, но выглядеть будет, как при запросе `width=200&height=200`, а не `width=400&height=400`. | `scale=2` |

## Запрос (POST)

### Обязательные url-параметры запроса

| Имя параметра | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `api_key` | `hex-string` | [Доступ к сервисам](vkmaps/general-information/api-key). | `api_key=fa749bace6d8a3b1....` |

### Обязательные JSON-поля в теле HTTP-запроса

В запросе должен быть указан либо параметр `bbox`, либо параметр `coord`.

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `bbox` | JSON-массив из 2-х элементов | Область местонахождения объекта, которая описывается парой координат.&#x0d;&#x0a;&#x0d;&#x0a;Если в запросе указан параметр `bbox`, параметры `coord` и `zoom` игнорируются. | `"bbox": [{"lat":55.71, "lon":37.65}, {"lat":55.8, "lon":37.6535}]` |
| `coord` | JSON-объект с `float` полями `lat` и `lon` | Широта и долгота (в градусах) геометрического центра требуемого изображения карты.&#x0d;&#x0a;&#x0d;&#x0a;Если в запросе указан параметр `bbox`, параметр `coord` игнорируется. Если `bbox` отсутствует, `coord` должен быть указан. | `{"lat":55.727, "lon":37.59}` |

### Дополнительные JSON-поля в теле HTTP-запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `zoom` | `integer` | Уровень масштабирования в диапазоне от `0` до `17`, где &#x0d;&#x0a;  &bull; `0` (по умолчанию) — соответствует уровню обзора мира;&#x0d;&#x0a;  &bull; `17` — соответствует уровню обзора здания.&#x0d;&#x0a;&#x0d;&#x0a;Если в запросе указан параметр `bbox`, параметр `zoom` игнорируется. | `"zoom": 13` |
| `width` | `integer` | Ширина изображения карты. Значение может находиться в диапазоне от `32` до `1024` пикселей. По умолчанию — `512`. | `"width": 640` |
| `height` | `integer` | Высота изображения карты. Значение может находиться в диапазоне от `32` до `1024` пикселей. По умолчанию — `512`. | `"height": 480` |
| `pins` | JSON-массив объектов | Описание булавок, добавляемых на карту. | `"pins": [ {  "coord": {  "lat": 55.73,  "lon": 37.59  },  "icon": {  "symbol": "mail-corp_photo"  } } ]` |
| `coord` | JSON-массив | Определяет расположение булавок, добавляемых на карту. | `"coord": {  "lat": 55.76,  "lon": 37.59  }` |
| `icon` | JSON-массив | Описание визуального представления булавок, добавляемых на карту. | `"icon": {  "symbol": "mail-corp_photo"  }` |
| `symbol` | `string` | Поле содержит формат визуального представления булавки. Форматы доступных булавок представлены в [коллекции булавок](#Коллекция%20булавок). | `"symbol": "mail-corp_photo"` |
| `base64` | `string` | Изображение булавки в формате PNG в base64-закодированном виде (не больше 250 тысяч символов). | `"base64": "iVBORw0KGgoA"...` |
| `url` | `string` | URL изображения в формате .png. Длина URL не должна превышать 1000 символов, размер изображения не должен превышать 512 КБ. Поддерживается только транспорт HTTPS, передача без сжатия и редиректов. | `"url": "https://maps.vk.com/logo-50x50.png"` |
| `features` | GeoJSON-объект | [GeoJSON](https://tools.ietf.org/html/rfc7946), описывающий геометрию для отображения на верхнем слое карты. Свойство `properties` является опциональным. | `"features": {  "type": "FeatureCollection",  "features": [...] }` |
| `features-style` | JSON-объект | Настройка визуального отображения GeoJSON, переданного в `features`. Отображение точек, линий и многоугольников настраивается отдельно:&#x0d;&#x0a;  &bull; `point` — настройки точек. Точки отображаются в виде кругов;&#x0a;&#x0d;    &#x0d;&#x0a;  &bull; `circle-color` — цвет круга;    &#x0d;&#x0a;  &bull; `circle-opacity` — прозрачность круга;    &#x0d;&#x0a;  &bull; `circle-radius` — радиус круга в пикселях;&#x0d;&#x0a;  &bull; `line` — настройки линий;&#x0a;&#x0d;    &#x0d;&#x0a;  &bull; `line-width` — толщина линии в пикселях;    &#x0d;&#x0a;  &bull; `line-color` — цвет линии;    &#x0d;&#x0a;  &bull; `line-opacity` — прозрачность линии;&#x0d;&#x0a;  &bull; `polygon` — настройки многоугольников;&#x0a;&#x0d;    &#x0d;&#x0a;  &bull; `fill-color` — цвет заливки;    &#x0d;&#x0a;  &bull; `fill-opacity` — прозрачность заливки | `"features-style": {  "point": {  "circle-color": "#ffffff",  "circle-opacity": 0.8,  "circle-radius": 4.0  },  "line": {  "line-color": "#2688eb",  "line-width": 2.0  },  "polygon": {  "fill-color": "#2688eb",  "fill-opacity": 0.5  }  }` |
| `style` | `string` | Параметр выбора стиля отображения карты. Ознакомиться с доступными для использования стилями можно на странице [Стили карт](vkmaps/map-display-services/map-styles). По умолчанию используется стиль: `main` | `"style": "light"` |
| `padding` | `integer` | Параметр смещения атрибутов карты. Смещение определяется в пикселях и равно расстоянию от правого края надписи до правого края атрибутов. Ограничения: значение может находиться в диапазоне от `5` до `width/2` пикселей. По умолчанию — `5`. | `padding=40` |
| `scale` | `integer` | Параметр масштабирования изображения. Возможны значения `1` или `2`. По умолчанию — `1`. | `"scale": 2` |

## Ответ

В ответ вы получите изображение части карты соответствующей параметрам, указанным в запросе.

### Пример GET-запроса

[https://demo.maps.vk.com/api/staticmap/png?latlon=55.727,37.59&style=main&zoom=10&width=1024&height=512&pins=55.73,37.59,mail-corp_photo|55.76,37.59,green_star|55.745,37.67,mail-electric_a&scale=2](https://demo.maps.vk.com/api/staticmap/png?latlon=55.727,37.59&style=main&zoom=10&width=1024&height=512&pins=55.73,37.59,mail-corp_photo%7C55.76,37.59,green_star%7C55.745,37.67,mail-electric_a&scale=2)

### Пример POST-запроса

```
curl -X POST \
 -H "Content-type: application/json" \
 -H "Accept: application/json" \
 -d '{"width":660,"height":600,"bbox":[{"lat":55.71,"lon":37.65},{"lat":55.8,"lon":37.6535}],"padding":200,"scale":2,"coord":{"lat":55.7505,"lon":37.6165},"pins":[{"coord":{"lat":55.73,"lon":37.59},"icon":{"symbol":"mail-corp_photo"}},{"coord":{"lat":55.76,"lon":37.59},"icon":{"symbol":"green_star"}},{"coord":{"lat":55.745,"lon":37.67},"icon":{"symbol":"mail-electric_a"}}],"zoom":11,"style":"main"}' \
 "https://demo.maps.vk.com/api/staticmap/png" --output example.png
```

## Коллекция булавок

### Общая информация

Название иконки (параметр запроса `icon`) формируется как `цвет`+`_`+`тип`. `icon=color_image`.

Например, если вам необходима булавка красного цвета с изображением камеры, то `icon=red_camera`.

:::note
При использовании сервиса создания изображения со статичной картой доступны только заранее предопределённые булавки.
Если вам необходимо добавить дополнительные булавки для вашего проекта, обратитесь в поддержку VK Карт по электронной почте: `support.maps@lists.vk.team`.
:::
