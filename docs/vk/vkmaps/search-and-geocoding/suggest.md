# Подсказчик

**Подсказчик** — это сервис предлагающий подсказки для автозаполнения адреса и/или названий мест интереса при посимвольном вводе в строку поиска.

:::note
`/suggest` — точка вызова подсказчика адреса и названий мест интереса при посимвольном вводе.
:::

## Запрос

### Обязательные параметры запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `api_key` | `hex-string` | [Доступ к сервисам](vkmaps/general-information/api-key) | `api_key=fa749bace6d8a3b1....` |
| `q` | `string` | Тело поискового запроса | `q=Россия Москва`; `q=Москва Ленинградс`; `q=Москва Ленинградский проспект`; `q=Москва Ленинский д. 1`; `q=метро Аэро` |


### Дополнительные параметры запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `fields` | `fieldname1,`&#x0d;&#x0a;`fieldname2,...`&#x0d;&#x0a;`fieldnameN` | Выбор полей, отображаемых в ответе. Возможные значения:&#x0d;&#x0a;  &bull; `name` (по умолчанию) — найденный объект;&#x0d;&#x0a;  &bull; `address_details` — детальная информация о найденном адресе с почтовым индексом без координат;&#x0d;&#x0a;  &bull; `address` (по умолчанию) — полный найденный адрес одной строкой;&#x0d;&#x0a;  &bull; `ref` — ID найденного объекта;&#x0d;&#x0a;  &bull; `type` (по умолчанию) — тип объекта. | `fields=name` |
| `types` | `string` | Тип объектов, по которым осуществляется поиск:&#x0d;&#x0a;  &bull; `address` (по умолчанию) — адрес;&#x0d;&#x0a;  &bull; `place` — название места интереса. | `types=address,place` |
| `lang` | 2-х&#x0d;&#x0a;символьный&#x0d;&#x0a;код языка | Язык ответа на одном из [доступных языков](vkmaps/general-information/general#Поддерживаемые%20языки). По умолчанию на языке региона, в котором найден объект. | `lang=en` |
| `location` | `string` | Координата, относительно которой будет осуществляться поиск и ранжирование результатов ответа. Координаты в формате `lat,lon`, где:&#x0d;&#x0a;  &bull; `lat` — широта искомой точки в градусах (используется 6 знаков после запятой);&#x0d;&#x0a;  &bull; `lon` — долгота искомой точки в градусах (используется 6 знаков после запятой). Результаты поиска будут отсортированы по расстоянию от указанной координаты. | `location=55.796743,37.537354` |
| `radius` | `integer` | Радиус поиска в метрах относительно параметра `location`. Параметр `location` при использовании параметра `radius` является обязательным. В случае использования малого радиуса объект может быть не найден. | `radius=500` |
| `admin_level` | `rank number` | Ограничение ответа по административному уровню. Возможные значения:&#x0d;&#x0a;  &bull; `1` — страна;&#x0d;&#x0a;  &bull; `2` — регион;&#x0d;&#x0a;  &bull; `3` — населённый пункт;&#x0d;&#x0a;  &bull; `4` — улица;&#x0d;&#x0a;  &bull; `5` — дом. По умолчанию ограничение не задано — поиск осуществляется по всем административным уровням. | `admin_level=3` |
| `limit` | `integer` | Ограничение числа объектов в ответе. Поддерживаются значения в интервале от `1` до `100`. По умолчанию — `5`. В случае использования больших значений, длительность получения ответа может увеличиться. | `limit=10` |


## Ответ

Ответ предоставляется только в JSON формате. Используемый JSON формат является разработанным для сервиса  и содержит информацию, найденную по запросу.

### JSON формат

| Имя поля | Формат | Описание |
| --- | --- | --- |
| `request` | `string` | Запрос. |
| `results` | `list` | Найденный результат. |
| `address` | `string` | Полный найденный адрес. |
| `ref` | `hex` | Идентификатор найденного объекта. Идентификатор объекта не является стабильным и может изменяться. |
| `type` | `string` | Тип найденного объекта. |
| `name` | `string` | Название найденного объекта. |

### Описание полей address_details

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `country` | `string` | Страна. | `"country": "Россия"` |
| `region` | `string` | Область. | `"region": "Москва"` |
| `subregion` | `string` | Район. | `"subregion": "Северный административный округ"` |
| `locality` | `string` | Населённый пункт. | `"locality": "Москва"` |
| `sublocality` | `string` | Микрорайон или название жилого комплекса. | `"sublocality": "Аэропорт"` |
| `street` | `string` | Улица. | `"street": "Проспект Ленинградский"` |
| `building` | `string` | Номер дома, части дома или строения. | `"building": "39 с80"` |
| `suburb` | `string` | Район или микрорайон населённого пункта. | `"suburb": "Хорошёвский"` |
| `postal_code` | `string` | Почтовый код. | `"postal_code": "125167"` |
