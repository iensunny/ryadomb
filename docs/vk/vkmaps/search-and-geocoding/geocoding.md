# Геокодирование

> Источник: [https://dev.vk.ru/ru/vkmaps/search-and-geocoding/geocoding](https://dev.vk.ru/ru/vkmaps/search-and-geocoding/geocoding)
**Сервис геокодирования (далее — Геокодер)** — это сервис, который обеспечивает прямое и обратное геокодирование.

**Прямое геокодирование** — это процесс преобразования адресов в географические координаты (широта и долгота), которые можно использовать для размещения маркеров на карте или для размещения карты на экране.

**Обратное геокодирование** — это процесс преобразования географических координат (широта и долгота) в адрес или часть адреса (страна, город, регион и т. д.).

Все сервисы геокодирования работают по территории всего мира на [всех доступных языках](vkmaps/general-information/general#Поддерживаемые%20языки).

:::note
`/search` — единая точка вызова сервисов прямого и обратного геокодирования адресных объектов.
:::

## Запрос

### Обязательные параметры запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `api_key` | `hex-string` | [Доступ к сервисам](vkmaps/general-information/api-key). | `api_key=fa749bace6d8a3b1....` |
| `q` | `string` | Тело поискового запроса. Для обратного геокодирования — координаты в формате `lat,lon`, где:&#x0d;&#x0a;  &bull; `lat` — широта искомой точки в градусах (используется 6 знаков после запятой);&#x0d;&#x0a;  &bull; `lon` — долгота искомой точки в градусах (используется 6 знаков после запятой).Для прямого геокодирования — текстовая строка. Для геокодирования объектов найденных в сервисе  возможно использование ID найденного объекта в качестве аргумента поискового запроса. | `q=Москва Ленинградский 39с80`; `q=Мюнхен`; `q=Austria`; `q=55.7967432,37.5373542`; `q=030000000026FCFD` |

### Общие дополнительные параметры запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `lang` | 2-х&#x0d;&#x0a;символьный&#x0d;&#x0a;код языка | Язык ответа на одном из [доступных языков](vkmaps/general-information/general#Поддерживаемые%20языки). По умолчанию на языке региона, в котором найден объект. | `lang=en` |
| `limit` | `unsigned integer` | Ограничение числа объектов в ответе. поддерживаются значения в интервале от 1 до 100. По умолчанию — `5`. | `limit=10` |
| `fields` | `field1,`&#x0d;&#x0a;`field2,...`&#x0d;&#x0a;`fieldN` | Выбор полей, отображаемых в ответе. Возможные значения:&#x0d;&#x0a;  &bull; `address_details` (по умолчанию) — детальная информация о найденном адресе с почтовым индексом без координат. Подробное описание параметров см. в [таблице](#Описание%20полей%20address_details);&#x0d;&#x0a;  &bull; `address` — полный найденный адрес одной строкой;&#x0d;&#x0a;  &bull; `pin` (по умолчанию) — координаты найденного объекта (долгота и широта);&#x0d;&#x0a;  &bull; `bbox` — область местонахождения объекта;&#x0d;&#x0a;  &bull; `geometry` — границы объекта;&#x0d;&#x0a;  &bull; `entrances` — информация о входах в здание;&#x0d;&#x0a;  &bull; `type` —  тип объекта. | `fields=geometry,``address_details` |
| `admin_level` | `admin level` | Ограничение ответа по административному уровню. Возможные значения:&#x0d;&#x0a;  &bull; `1` — страна;&#x0d;&#x0a;  &bull; `2` — регион;&#x0d;&#x0a;  &bull; `3` — населённый пункт;&#x0d;&#x0a;  &bull; `4` — улица;&#x0d;&#x0a;  &bull; `5` — дом. По умолчанию ограничение не задано — поиск осуществляется по всем административным уровням. | `admim_level=2` |

### Дополнительные параметры запроса для прямого геокодирования

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `location` | `string` | Координата, относительно которой будет осуществляться поиск и ранжирование результатов ответа. Координаты в формате `lat,lon`, где:&#x0d;&#x0a;  &bull; `lat` — широта искомой точки в градусах (используется 6 знаков после запятой);&#x0d;&#x0a;  &bull; `lon` — долгота искомой точки в градусах (используется 6 знаков после запятой). Результаты поиска будут отсортированы по расстоянию от указанной координаты. | `location=55.7967432,37.5373542` |
| `isocode` | `2char` | Ограничение геометрии поиска страной, по умолчанию поиск осуществляется по всему миру. Двухбуквенный код страны указывается согласно ISO 3166-1 alpha-2, указать можно только один код. | `isocode=RU` |

### Дополнительные параметры запроса для обратного геокодирования

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `radius` | `integer` | Радиус поиска в метрах относительно координат, указанных в запросе в параметре `q`. В случае использования малого радиуса объект может быть не найден. | `radius=300` |

## Ответ

Ответ предоставляется только в JSON формате. Используется JSON формат, разработанный специально для сервиса  и содержит информацию найденную по запросу.

### JSON формат

| Имя поля | Формат | Описание |
| --- | --- | --- |
| `request` | `string` | Запрос. |
| `results` | `list` | Найденный результат. |
| `address` | `string` | Полный найденный адрес. |
| `pin` | `list` | Координаты найденного объекта (долгота и широта). |
| `bbox` | `list` | Границы местонахождения найденного объекта для позиционирования на карте. |
| `geometry` | `list` | Геометрия найденного объекта. |
| `entrances` | `list` | Информация о входах в здание. |
| `type` | `string` | Тип объекта. |

### Описание полей address_details

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `country` | `string` | Страна. | `"country": "Россия"` |
| `isocode` | `2char` | Двухбуквенный код страны согласно ISO 3166-1 alpha-2. | `"isocode": "RU"` |
| `region` | `string` | Область. | `"region": "Москва"` |
| `subregion` | `string` | Район. | `"subregion": "Северный административный округй"` |
| `locality` | `string` | Населённый пункт. | `"locality": "Москва"` |
| `sublocality` | `string` | Микрорайон или название жилого комплекса. | `"sublocality": "Аэропорт"` |
| `street` | `string` | Улица. | `"street": "Проспект Ленинградский"` |
| `building` | `string` | Номер дома, части дома или строения. | `"building": "39 с80"` |
| `suburb` | `string` | Район/микрорайон населённого пункта. | `"suburb": "Хорошёвский"` |
| `postal_code` | `string` | Почтовый код. | `"postal_code": "125167"` |

### Описание полей geometry

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `type` | `string` | Тип геометрии:&#x0d;&#x0a;  &bull; `Point` — точка;&#x0d;&#x0a;  &bull; `MultiPoint` — несколько точек;&#x0d;&#x0a;  &bull; `LineString` — линия;&#x0d;&#x0a;  &bull; `MultiLineString` — несколько линий;&#x0d;&#x0a;  &bull; `Polygon` — полигон;&#x0d;&#x0a;  &bull; `MultiPolygon` — несколько полигонов. | `"type": "Polygon"` |
| `coordinates` | `list` | Массив точек (долгота и широта) описывающий геометрию объекта. | `"coordinates": [[100.0, 0.0], [101.0, 0.0], [101.0, 1.0], [100.0, 1.0], [100.0, 0.0]]` |

### Описание полей entrances

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `pin` | `list` | Координаты входа/выхода в здание. | `"pin" : [55.8621913, 37.4475714]` |
| `name` | `string` | Номер подъезда. | `"name":"2"` |
| `flats` | `string` | Номера квартир подъезде. | `"flats":"45-88"` |
| `type` | `string` | Тип входа/выхода: &#x0d;&#x0a;  &bull; `main` — главный вход в здание;&#x0d;&#x0a;  &bull; `exit` — проход, предназначенный только для выхода;&#x0d;&#x0a;  &bull; `service` — сервисный вход в здание;&#x0d;&#x0a;  &bull; `emergency` — проход, предназначенный для использования в случае пожара или другой аварийной ситуации;&#x0d;&#x0a;  &bull; `staircase` — дверь в подъезд, парадную или на лестницу в многоквартирном доме. | `"type":"main"` |
| `wheelchare` | `string` | Оборудован ли вход для маломобильных групп граждан, возможны значения: &#x0d;&#x0a;  &bull; `yes`&#x0d;&#x0a;  &bull; `no`&#x0d;&#x0a;  &bull; `limited` | `"wheelchare":"yes"` |

В случае, если по запросу ничего не найдено, ответ будет выглядеть как представлено ниже:

```
{
    "results": [],
 "request": "/v3/search?limit=1&q=Ленингрвавамский вца"
}
```
