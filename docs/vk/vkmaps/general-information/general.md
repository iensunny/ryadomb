VK Карты – картографический продукт компании VK, использующий базу открытых данных OpenStreetMap. Возможности продукта применяются в Mail, ВКонтакте, Юле и других продуктах корпорации. VK Карты также доступны широкому кругу разработчиков для использования в приложениях на различных платформах.

[Получите ключ и начните использовать VK Карты сейчас &rarr;](https://maps.vk.com/ru/welcome/)

## Решаемые задачи

Ниже — примеры типичных задач, которые вы можете выполнить с помощью VK Карт:

* [Отобразить карту в приложении](vkmaps/map-display-services/javascript-sdk/about).

* Помочь пользователям с [поиском адресов и интересных мест](vkmaps/search-and-geocoding/places).

* [Построить пешеходные, велосипедные и автомобильные маршруты](vkmaps/routing/direction) между точками.

* [Выбрать оптимальный маршрут](vkmaps/routing/optimal-route) для посещения нескольких мест.

* Помочь курьерам [найти оптимальные пути](vkmaps/routing/distance-matrix) к складам, а затем к заказчикам.

* [Определить область](vkmaps/routing/iso), достижимую в течение заданного времени.

* [Определить местоположение по IP-адресу](vkmaps/additional-services/ip2geo).

* Определить [высоту над уровнем моря](vkmaps/additional-services/elevation), [часовой пояс](vkmaps/additional-services/timezone) или [почтовый индекс точки](vkmaps/additional-services/postcode).

## Поддерживаемые языки

Мы стремимся к созданию полнофункциональных карт всего мира с максимальной поддержкой языков, интересующих наших клиентов. На текущий момент доступность того или иного языка определяется непосредственно самим языком и географическим регионом. Основные поддерживаемые языки — русский, английский и локальный в регионе.

## API

С помощью API VK Карт вы можете получать и использовать данные сервиса в любых приложения. Подробности — в разделе [Использование API VK Карт](vkmaps/general-information/api-key).

## С чего начать?

С получения ключа доступа. Он необходим для работы с SDK или API VK Карт.

[Получите ключ сейчас &rarr;](https://maps.vk.com/ru/welcome/)

## Демосервер

Чтобы опробовать работу с VK Картами, вы можете воспользоваться демонстрационным сервером по адресу: `https://demo.maps.vk.com/api/{endpoint}?{params}`. Для отправки запросов к нему ключ доступа не требуется.

Этот сервер нельзя использовать для продуктовой эксплуатации ваших приложений. Его работоспособность не гарантируется, а суммарное число запросов в секунду к нему ограничено.

## Техническая поддержка

Если вам необходима помощь или возникли вопросы при использовании сервисов VK Карт, отправьте нам сообщения по адресу `support.maps@lists.vk.team`. Обращайтесь по этому же адресу для получения актуальной информации по имеющимся у вас ключам доступа и действиям с ними.

## Поддерживаемые языки

## Ограничение скорости запросов

По умолчанию все ключи доступа имеют одинаковое ограничение числа запросов в секунду. При необходимости вы можете как уменьшить скорость запросов по отдельному ключу (см. в разделе [Доступ к сервисам](vkmaps/general-information/api-key)), так и увеличить. Для увеличения скорости запросов вам необходимо обратиться к вашему менеджеру со стороны VK Карт.

Стандартное ограничение скорости обращений к сервисам — `50 RPS`.

Демонстрационный доступ к сервисам выполняется по URL `https://demo.maps.vk.com/api/{endpoint-name}`. Суммарное число запросов в секунду от всех клиентов ограничено. Работоспособность сервисов по данной ссылке не гарантируется.

## Статистика использования

Статистика использования продуктов VK Карты формируется в течение двух рабочих дней месяца, следующего за отчетным.

Сформированная статистика отправляется ответственному менеджеру со стороны клиента, который был указан в контракте, в электронном виде.

На основании статистики в дальнейшем будут сформированы счёт на оплату и закрывающие документы.
