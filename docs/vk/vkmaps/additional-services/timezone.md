# Определение часового пояса

> Источник: [https://dev.vk.ru/ru/vkmaps/additional-services/timezone](https://dev.vk.ru/ru/vkmaps/additional-services/timezone)
Сервис позволяет определить часовой пояс в любой точке мира.

:::note
`/timezone` — точка вызова сервиса для определения часового пояса в любой точке земли, а также смещения времени относительно `UTC`.
:::

### Обязательные параметры запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `api_key` | `hex-string` | [Доступ к сервисам](vkmaps/general-information/api-key). | `api_key=fa749bace6d8a3b1....` |
| `q` | `string` | Тело поискового запроса. Координаты в формате `lat,lon`, где:&#x0d;&#x0a;  &bull; `lat` — широта искомой точки в градусах (используется 6 знаков после запятой);&#x0d;&#x0a;  &bull; `lon` — долгота искомой точки в градусах (используется 6 знаков после запятой). | `q=55.479205,37.32733` |


### Дополнительные параметры запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `timestamp` | `unix timestamp` | Временная метка, для которой будут вычислены параметры таймзоны. Если не указано, используется текущее время. | `timestamp=1264753640` |

## Ответ

### Параметры ответа

| Имя поля | Формат | Описание |
| --- | --- | --- |
| `tzid` | `string` | Идентификатор часового пояса, определённый проектом [CLDR — Unicode Common Locale Data Repository](http://cldr.unicode.org/). |
| `utc_delta` | `int` | Смещение часового пояса запрошенного местоположения от `UTC` (в секундах). |

## Запрос

### Пример запроса

[https://demo.maps.vk.com/api/timezone?q=55.479205,37.32733](https://demo.maps.vk.com/api/timezone?q=55.479205,37.32733)

### Пример ответа

```
{
    "request": "/timezone?api_key=demo&q=55.479205,37.32733",
    "results":
    [
        {
            "tzid": "Europe/Moscow",
            "utc_delta": 10800
        }
    ]
}
```
