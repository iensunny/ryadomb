Первый вход

Загрузка → три шага онбординга → лента семьи. После этого доступна нижняя навигация.

Добавление истории

Лента → «Начните новую историю» → выбор типа → сохранить → новая карточка появляется в ленте.

Сборка книги

Книга → отметить истории → выбрать обложку → предпросмотр → заказ печати.

Библиотека

Вкладки переключают личные записи, потешки и сказки. «В книгу» пока тестовая кнопка.

Семейный доступ

Семья → «Пригласить родных» → модалка с join-ссылкой → закрытие кнопкой «Готово».

Ограничение прототипа

Оплата, реальная отправка ссылок, транскрибация и печать пока заменены тестовыми состояниями.

0. Экран загрузки

Первый визуальный контакт с брендом.

Семейные истории
Загрузка...
Автоматически ведёт на онбординг 1.

Нужен для ощущения приложения, а не обычной веб-страницы.

1. Онбординг: голоса

Объясняет эмоциональную ценность продукта.

Голоса вашей семьи не должны исчезать
Далее
«Далее» → онбординг 2.

Текст из презентации сохранён почти дословно.

2. Онбординг: способы

Показывает, что историю можно добавить разными способами.

Голосом, фото или текстом
Далее
«Далее» → онбординг 3.

Снимает страх записи: можно не говорить голосом, если неудобно.

3. Онбординг: книга

Обещает конечный результат — семейную книгу.

Соберите из историй книгу
Начать
«Начать» → лента.

Для входа по invite позже этот шаг можно пропускать.

4. Лента

Дом семьи: последние записи и главный CTA.

Семейные истории
Начните новую историю + Колыбельная бабушки Вали Как мы ездили на дачу
CTA «Начните новую историю» → экран записи.
Нижнее меню → библиотека / книга / семья.

После сохранения история добавляется в начало ленты.

5. Новая история

Создание записи голосом, текстом или фото.

Голос · Текст · Фото 00:00 / текст / фото Сохранить в библиотеку
«Назад» → лента без сохранения.
«Сохранить» → лента с новой карточкой.
Табы меняют режим создания.

В прототипе запись голоса тестовая, но кнопка запрашивает микрофон.

Экраны

Библиотека, книга, семья и заказ

Эти разделы доступны после онбординга через нижнюю навигацию или вложенные переходы.

6. Библиотека

Личные записи плюс общие потешки и сказки.

Наши записи · Потешки · Сказки Первый снег в Нягани Сорока-белобока
Табы переключают списки.
«В книгу» пока не меняет состояние, это задел.

Позже «В книгу» должен добавлять библиотечный текст в конструктор.

7. Конструктор книги

Выбор историй и обложки будущей книги.

✓ Колыбельная бабушки Вали ✓ Как мы ездили на дачу Лён · Тёмная · Орех Смотреть книгу
Чекбокс истории → включает/исключает из книги.
Обложка → меняет preview.
«Смотреть книгу» → предпросмотр.

Кнопка disabled, если не выбрана ни одна история.

8. Предпросмотр книги

Показывает книгу такой, какой она пойдёт в печать.

Колыбельная бабушки Вали
Страница 1 из 3 Заказать печатную книгу
«Назад» → конструктор.
«Далее/Назад» → листание страниц.
«Заказать» → экран заказа.

Если у истории нет фото, показывается заглушка «Фото для этой страницы».

9. Семья

Показывает участников и даёт пригласить родных.

Мама — Автор Бабушка Валя — Соавтор + Пригласить родных
«Пригласить родных» → модалка приглашения.
Нижнее меню → другие разделы.

Роли соответствуют выбранной модели: автор и соавторы.

10. Приглашение

Показывает тестовую ссылку на семью.

Семья Ивановых
vk.com/appXXXX#join_8f3k2p Готово
«Готово» → закрывает модалку.
Клик по фону → закрывает модалку.

Позже сюда добавим копирование ссылки и шаринг VK/OK.

11. Заказ

Выбор типа обложки, тиража и расчёт суммы.

Мягкая · Твёрдая 1 экз. · 3 экз. · 5 экз. Итого 5 700 ₽ Оформить заказ
«Назад» → предпросмотр.
Выбор тиража/обложки → пересчёт итога.
«Оформить заказ» пока без действия.

Для MVP лучше заменить оплату на заявку, пока нет типографии.
